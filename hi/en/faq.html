सामान्य प्रश्न

बर्क क्या है?

बर्क एक आधुनिक सिस्टम प्रोग्रामिंग भाषा है। यह जंग-स्तर की मेमोरी सुरक्षा और C/C++-स्तर का प्रदर्शन प्रदान करता है। यह एलएलवीएम बैकएंड का उपयोग करके मूल कोड उत्पन्न करता है और 19 लक्ष्य प्लेटफार्मों के लिए समर्थन प्रदान करता है। द्विभाषी वाक्यविन्यास सुविधा के साथ, आप तुर्की और अंग्रेजी दोनों कीवर्ड का उपयोग कर सकते हैं।

मुझे बर्क का उपयोग क्यों करना चाहिए?

  • उच्च प्रदर्शन: एलएलवीएम (98-100%) के साथ सी/सी++ स्तर पर नेटिव कोड जनरेशन
  • जंग-स्तर की सुरक्षा: आधुनिक प्रकार की प्रणाली, पैटर्न मिलान, व्यापक त्रुटि प्रबंधन
  • व्यापक स्टैडलिब: 75 मॉड्यूल (42 कोर + 33 एचएएल), 4100+ फ़ंक्शन, NumPy/SciPy स्तर की वैज्ञानिक कंप्यूटिंग, एम्बेडेड सिस्टम समर्थन
  • क्रॉस प्लेटफार्म: डेस्कटॉप (विंडोज़/लिनक्स/मैकओएस), एंबेडेड (एआरएम/आरआईएससी-वी/एवीआर/ईएसपी32), मोबाइल (एंड्रॉइड/आईओएस), वेबअसेंबली
  • यूजर फ्रेंडली: स्वच्छ वाक्यविन्यास, स्पष्ट त्रुटि संदेश, आरईपीएल समर्थन, वैकल्पिक द्विभाषी कीवर्ड

BERK किस प्लेटफॉर्म पर काम करता है?

डेस्कटॉप: विंडोज़ x64 (सक्रिय), लिनक्स x64, macOS ARM64

एंबेडेड (7 प्लेटफ़ॉर्म, 95% पूर्ण, 100% बाज़ार कवरेज):

  • टीयर 1: ईएसपी32 (वाईफाई/बीएलई, 35% बाजार), एसटीएम32एफ4 (औद्योगिक, 25%), आरपी2040 (निर्माता, 15%)
  • कतार 2: एनआरएफ52 (बीएलई, 8%), जीडी32 (चीन, 7%), नुवोटन (एशिया, 5%)
  • 3 टियर: Arduino (शैक्षिक, 30M उपयोगकर्ता)

गतिमान: एंड्रॉइड (एआरएम/x86), आईओएस (एआरएम64) - प्रायोगिक

वेबअसेंबली: WASM32, WASI - नियोजित

एचएएल समर्थन: 61 प्लेटफ़ॉर्म-विशिष्ट मॉड्यूल, ऑटो-जनरेटर (15,901 लाइनें सीएमएसआईएस परीक्षण)

क्या बर्क खुला स्रोत है?

हां, बीईआरके जीपीएल-3 लाइसेंस के तहत एक ओपन सोर्स प्रोजेक्ट है। GitHub पर सक्रिय विकास हो रहा है। 98% समग्र पूर्णता के साथ v1.0.0 के बहुत करीब।

वाक्य-विन्यास और भाषा विशेषताएँ

द्विभाषी वाक्यविन्यास कैसे काम करता है?

बर्क में आप एक ही प्रोग्राम को दो अलग-अलग तरीकों से लिख सकते हैं:

// Türkçe
function merhaba() {
    print("Merhaba Dünya!")
}

// İngilizce
function hello() {
    print("Hello World!")
}

दोनों शैलियाँ एक ही बाइटकोड पर संकलित होती हैं। आप उन्हें एक ही फ़ाइल में मिला भी सकते हैं!

यह किन प्रोग्रामिंग प्रतिमानों का समर्थन करता है?

  • अनिवार्य प्रोग्रामिंग: प्रक्रियात्मक कोड, प्रत्यक्ष स्मृति नियंत्रण
  • कार्यात्मक प्रोग्रामिंग: पुनरावर्तक, उच्च-क्रम कार्य, अपरिवर्तनीयता
  • संरचित प्रोग्रामिंग: संरचनाएं, मॉड्यूलर वास्तुकला, पैटर्न मिलान
  • सिस्टम प्रोग्रामिंग: निम्न स्तर का नियंत्रण, शून्य लागत सार, इनलाइन असेंबली (v1.0 नियोजित)
  • सुरक्षा टाइप करें: मजबूत स्थैतिक प्रकार की जाँच,सामान्य प्रकार (चरण 4.1-4.4 पूर्ण)

क्या कचरा संग्रहकर्ता है?

नहीं, BERK मैन्युअल मेमोरी प्रबंधन का उपयोग करता है।जंग-शैली स्वामित्व प्रणाली v0.9.0 में पूरी हुई- उधार चेकर, नॉन-लेक्सिकल लाइफटाइम्स (एनएलएल), मूव सिमेंटिक्स (geçir, paylaş, değiştir) जंग-स्तरीय मेमोरी सुरक्षा प्रदान करता है। इसमें रीजन मेमोरी (263x मॉलोक से तेज़) और मिमैलोक एकीकरण भी है।

प्रदर्शन की तुलना रस्ट/सी से कैसे की जाती है?

एलएलवीएम बैकएंड की बदौलत बीईआरके सी/सी++ (98-100%) के बराबर प्रदर्शन प्रदान करता है। एलएलवीएम आईआर ऑप्टिमाइज़ेशन पास, रीजन मेमोरी एलोकेटर (263x स्पीडअप), और मिमलोक इंटीग्रेशन का उपयोग करता है। -O0 से -O3 तक अनुकूलन स्तरों का समर्थन करता है। बेंचमार्क सुइट के साथ निरंतर प्रदर्शन की निगरानी की जाती है।

क्या मैं C/C++ लाइब्रेरी का उपयोग कर सकता हूँ?

हाँ!एफएफआई (फॉरेन फंक्शन इंटरफेस) प्रणाली v0.9.0 में पूरी हुई। 30+ परीक्षण, libm एकीकरण (40+ गणित फ़ंक्शन), और प्रत्यक्ष C लाइब्रेरी कॉल के साथ पूर्ण C ABI समर्थन। सिक्योर सी इंटरऑप को रस्ट अनसेफ एफएफआई-जैसे सिंटैक्स के साथ प्रदान किया गया है।

प्रदर्शन और अनुकूलन

बर्क कितना तेज़ है?

एलएलवीएम बैकएंड के लिए धन्यवाद, यह सी/सी++ के बराबर प्रदर्शन प्रदान करता है। यह नेटिव कोड जनरेशन, एलएलवीएम ऑप्टिमाइज़ेशन पास और शून्य-लागत एब्स्ट्रैक्शन के साथ सिस्टम प्रोग्रामिंग के लिए आवश्यक गति प्रदान करता है। रोडमैप में JIT कंपाइलर और BLAS/LAPACK एकीकरण शामिल है।

अनुकूलन स्तर क्या हैं?

berk build -O0  # Optimizasyon yok (hızlı derleme, debug)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (dengelenmiş performans)
berk build -O3  # Agresif optimizasyon (maksimum hız)

एलएलवीएम अनुकूलन पाइपलाइन का उपयोग करता है: डेड कोड उन्मूलन, निरंतर फोल्डिंग, लूप अनरोलिंग, इनलाइन विस्तार। लिंक-टाइम ऑप्टिमाइज़ेशन (एलटीओ) समर्थन भविष्य के संस्करणों में जोड़ा जाएगा।

क्या समानांतर प्रोग्रामिंग समर्थित है?

हाँ,threadआप मॉड्यूल के साथ मल्टी-थ्रेडिंग कर सकते हैं:

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    let t1 = thread.spawn(işçi, 1)
    let t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}

berk repl
>>> let x = 10
>>> print(x * 2)
