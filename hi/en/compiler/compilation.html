BERK Programlama Dili

संकलन प्रक्रिया

बर्क कंपाइलर, आपका स्रोत कोडदेशी मशीन कोड के लिएयह एक मल्टी-स्टेज पाइपलाइन का उपयोग करता है जो परिवर्तित होती है

संकलन चरण

1. शाब्दिक विश्लेषण (लेक्सर)

सोर्स कोडटोकनमें विभाजित है:

let x = 42
// Token'lar:
// [let] [x] [=] [42]

लेक्सर कार्य:

  • रिक्त स्थान और टिप्पणियाँ साफ़ करता है
  • कीवर्ड पहचानें (चर, फ़ंक्शन, यदि...)
  • तुर्की/अंग्रेज़ी कीवर्ड मैपिंग
  • संख्याओं, स्ट्रिंग्स, ऑपरेटरों को अलग करता है

2. सिंटैक्स विश्लेषण (पार्सर)

टोकनसार सिंटेक्स ट्री (एएसटी)इसे संरचना में परिवर्तित करता है:

let x = 42 + 10

AST:
VariableDeclaration
  ├─ name: "x"
  └─ value: BinaryExpression
      ├─ left: Literal(42)
      ├─ operator: "+"
      └─ right: Literal(10)

पार्सर मिशन:

  • वाक्यविन्यास नियमों की जाँच करता है
  • एक पदानुक्रमित संरचना बनाता है
  • वाक्यविन्यास त्रुटियों का पता लगाता है

3. शब्दार्थ विश्लेषण

आपका कोडअर्थ संबंधी सटीकताजाँच:

let x: sayı = "merhaba"  // ❌ Tip hatası!

सिमेंटिक विश्लेषक कार्य:

  • जाँच टाइप करें
  • परिवर्तनीय परिभाषा नियंत्रण
  • फ़ंक्शन हस्ताक्षर सत्यापन
  • स्वामित्व और जीवनकाल विश्लेषण
  • मृत कोड का पता लगाना

4. मध्यवर्ती प्रतिनिधित्व (आईआर)

अधीनस्थएलएलवीएम आईआरप्रारूप में कनवर्ट करता है:

define i32 @main() {
entry:
  %x = alloca i32
  store i32 42, i32* %x
  %0 = load i32, i32* %x
  ret i32 %0
}

एलएलवीएम आईआर लाभ:

  • मंच स्वतंत्र
  • अनुकूलन के लिए उपयुक्त
  • ढेर सारा बैकएंड समर्थन

5. अनुकूलन

एलएलवीएम ऑप्टिमाइज़र कोड को गति देता है:

  • मृत कोड उन्मूलन: अप्रयुक्त कोड हटा देता है
  • निरंतर तह: 5 + 10 → 15
  • इनलाइन: कॉल के बजाय छोटे फ़ंक्शन कॉपी करता है
  • लूप का खुलना: चक्र प्रदर्शन में सुधार करता है
  • वैश्वीकरण: SIMD निर्देशों का उपयोग करता है

6. कोड जनरेशन

अनुकूलित आईआर सेमूल सभापैदा करता है:

main:
    push rbp
    mov rbp, rsp
    mov DWORD PTR [rbp-4], 42
    mov eax, DWORD PTR [rbp-4]
    pop rbp
    ret

7. लिंक करना

सभी ऑब्जेक्ट फ़ाइलों को मर्ज करता है और निष्पादन योग्य फ़ाइल बनाता है:

  • स्टेटिक लिंकिंग: सभी लाइब्रेरी बाइनरी में शामिल हैं
  • डायनामिक लिंकिंग: सिस्टम लाइब्रेरी से लिंक करना

संकलन आदेश

सरल संकलन

# Kaynak dosyayı derle
berk-lang build program.berk

# Çıktı dosyası belirt
berk-lang build program.berk -o program.exe

# Birden fazla dosya
berk-lang build main.berk lib.berk utils.berk

संकलन मोड

# Debug modu (varsayılan)
berk-lang build --debug program.berk

# Release modu (optimizasyonlu)
berk-lang build --release program.berk

# Profiling for
berk-lang build --profile program.berk

मध्यवर्ती आउटपुट

# AST print
berk-lang build --print-ast program.berk

# Tip bilgilerini göster
berk-lang build --print-types program.berk

# LLVM IR oluştur
berk-lang build --emit-llvm program.berk -o program.ll

# Assembly oluştur
berk-lang build --emit-asm program.berk -o program.s

# Object file oluştur
berk-lang build --emit-obj program.berk -o program.o

संकलन समय अनुकूलन

वृद्धिशील संकलन

यह केवल परिवर्तित मॉड्यूल को पुन: संकलित करता है:

# İlk derleme: 10 saniye
berk-lang build main.berk

# Tek bir dosya değişti: 0.5 saniye
berk-lang build main.berk

कैश तंत्र:

  • .berk-cache/मध्यवर्ती फ़ाइलें निर्देशिका में संग्रहीत की जाती हैं
  • यदि फ़ाइल नहीं बदली है, तो इसका उपयोग कैश से किया जाता है
  • यदि निर्भरता बदलती है, तो संबंधित मॉड्यूल को पुन: संकलित किया जाता है

समानांतर संकलन

# Tüm CPU çekirdeklerini use
berk-lang build --parallel program.berk

# Belirli sayıda thread
berk-lang build --jobs=4 program.berk

त्रुटि संदेश

बर्क संकलकसमझने योग्य त्रुटि संदेशदेता है:

error[E0308]: type uyuşmazlığı
  --> src/main.berk:5:14
   |
 5 |     let x: sayı = "merhaba";
   |              ^^^^      ^^^^^^^^^ beklenen: sayı, bulunan: String
   |
   = yardım: "merhaba" string'ini sayıya çevirmek for `String::sayıya()` kullanın

त्रुटि संदेश विशेषताएँ:

  • त्रुटि कोड (E0308)
  • फ़ाइल और लाइन नंबर
  • कोड स्निपेट
  • विवरण और सिफ़ारिशें
  • Color output (if terminal supports it)

संकलन प्रदर्शन

परियोजना का आकारप्रथम संकलनINCREMENTALसमानांतर (8 कोर)
1,000 पंक्तियाँ~0.2s~0.05s~0.15s
10,000 लाइनें~1s~0.1s~0.4s
100,000 पंक्तियाँ~8s~0.5s~2s
1,000,000 लाइनें~80 के दशक~5s~20s

संकलन झंडे

सामान्य झंडे

# Verbose çıktı
berk-lang build -v program.berk

# Uyarıları göster
berk-lang build --warnings program.berk

# Uyarıları hata say
berk-lang build --warnings-as-errors program.berk

# Bağımlılık grafiği göster
berk-lang build --show-deps program.berk

# İstatistikler
berk-lang build --stats program.berk

झंडे डीबग करें

# Debug sembolleri ekle
berk-lang build -g program.berk

# Debug bilgisi seviyesi
berk-lang build --debug-info=2 program.berk

# Assertion'ları aktif et
berk-lang build --enable-assertions program.berk

सिस्टम इंटीग्रेशन बनाएं

बनाना

build:
    berk-lang build main.berk -o program.exe

release:
    berk-lang build --release main.berk -o program.exe

clean:
    rm -rf .berk-cache/ program.exe

सीएमके

add_custom_command(
    OUTPUT program.exe
    COMMAND berk-lang build ${CMAKE_SOURCE_DIR}/main.berk -o program.exe
    DEPENDS main.berk
)

  • ✅ एलएलवीएम बैकएंड: प्लेटफ़ॉर्म स्वतंत्र, अनुकूलित मूल कोड
  • ✅ वृद्धिशील संकलन: तेजी से पुन:संकलन
  • ✅ समानांतर संकलन: मल्टी-कोर प्रोसेसर सपोर्ट
  • ✅ समझने योग्य गलतियाँ: विस्तृत त्रुटि संदेश और सुझाव
  • ✅ त्वरित संकलन: 10K लाइनें ~1 सेकंड
