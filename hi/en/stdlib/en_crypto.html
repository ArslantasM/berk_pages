🔒 क्रिप्टो - क्रिप्टोग्राफी और एन्क्रिप्शन

एन्क्रिप्शन, हैशिंग और डिजिटल हस्ताक्षर संचालन के लिए व्यापक क्रिप्टोग्राफी उपकरण

📋अवलोकन

cryptoमॉड्यूल आधुनिक क्रिप्टोग्राफी एल्गोरिदम, हैशिंग फ़ंक्शन, डिजिटल हस्ताक्षर और सुरक्षित कुंजी प्रबंधन के साथ डेटा एन्क्रिप्शन के लिए व्यापक उपकरण प्रदान करता है। एईएस, आरएसए, एसएचए, एचएमएसी और अधिक का समर्थन करता है।

🔐 सममित एन्क्रिप्शन

  • क्रिप्टो.एईएस_एन्क्रिप्ट()- एईएस एन्क्रिप्शन (128/192/256 बिट)
  • क्रिप्टो.aes_solve()- एईएस डिक्रिप्शन
  • क्रिप्टो.चाचा20()- चाचा20 स्ट्रीम एन्क्रिप्शन
  • क्रिप्टो.एईएस_जीसीएम()- एईएस-जीसीएम (प्रमाणीकृत एन्क्रिप्शन)

🔑 असममित एन्क्रिप्शन

  • क्रिप्टो.rsa_create_key_pair()- आरएसए कुंजी जोड़ी पीढ़ी
  • क्रिप्टो.rsa_encrypt()- आरएसए के साथ एन्क्रिप्शन
  • क्रिप्टो.rsa_solve()- आरएसए के साथ डिक्रिप्शन
  • क्रिप्टो.ecc_key_generate()- अण्डाकार वक्र स्विच

#️⃣ मिश्रित कार्य

  • क्रिप्टो.sha256()- SHA-256 हैश
  • क्रिप्टो.sha512()- SHA-512 हैश
  • क्रिप्टो.sha3()- SHA-3 हैश
  • क्रिप्टो.ब्लेक3()- BLAKE3 तेज़ हैश
  • क्रिप्टो.hmac()- एचएमएसी संदेश प्रमाणीकरण

✍️ डिजिटल हस्ताक्षर

  • क्रिप्टो.rsa_sign()- आरएसए डिजिटल हस्ताक्षर
  • क्रिप्टो.rsa_verify()- आरएसए हस्ताक्षर सत्यापन
  • क्रिप्टो.ecdsa_sign()- ईसीडीएसए पर हस्ताक्षर
  • क्रिप्टो.ed25519_साइन()- Ed25519 पर हस्ताक्षर

🔐 पासवर्ड सुरक्षा

  • क्रिप्टो.पासवर्ड_हैश()- सुरक्षित पासवर्ड हैश (Argon2id)
  • क्रिप्टो.पासवर्ड_सत्यापन()- पासवर्ड सत्यापन
  • क्रिप्टो.pbkdf2()- PBKDF2 कुंजी व्युत्पत्ति
  • क्रिप्टो.बीक्रिप्ट()- बीक्रिप्ट पासवर्ड हैश

🎲सुरक्षित यादृच्छिकता

  • क्रिप्टो.random_byte()- क्रिप्टोग्राफ़िक यादृच्छिक बाइट्स
  • क्रिप्टो.random_full()- सुरक्षित यादृच्छिक पूर्णांक
  • क्रिप्टो.uuid()- यादृच्छिक यूयूआईडी पीढ़ी

एईएस एन्क्रिप्शन और डिक्रिप्शन

use crypto
use encoding

// AES-256-GCM şifreleme (kimlik doğrulamalı)
değer mesaj = "Bu çok gizli bir mesajdır!"
değer anahtar = crypto.rastgele_bayt(32)  // 256-bit anahtar
değer nonce = crypto.rastgele_bayt(12)    // 96-bit nonce

print("Orijinal mesaj: " + mesaj)

// Şifreleme
değer şifreli = crypto.aes_gcm_şifrele(
    veri: mesaj.bayt(),
    anahtar: anahtar,
    nonce: nonce
)

değer şifreli_base64 = encoding.base64_kodla(şifreli)
print(f"\nŞifreli (Base64): {şifreli_base64}")

// Şifre çözme
değer çözülmüş = crypto.aes_gcm_çöz(
    veri: şifreli,
    anahtar: anahtar,
    nonce: nonce
).aç()

değer çözülmüş_metin = Dize.bayttan(çözülmüş)
print(f"Çözülmüş mesaj: {çözülmüş_metin}")

// Anahtar and nonce'ı güvenli sakla
print(f"\nAnahtar (hex): {encoding.hex_kodla(anahtar)}")
print(f"Nonce (hex): {encoding.hex_kodla(nonce)}")

आरएसए असममित एन्क्रिप्शन

use crypto

// RSA anahtar çifti oluşturma (2048-bit)
değer (açık_anahtar, özel_anahtar) = crypto.rsa_anahtar_çifti_oluştur(2048)

print("RSA anahtar çifti oluşturuldu!")

// Açık anahtarla şifreleme
değer mesaj = "Gizli veriler: hesap bakiyesi = 10000 TL"
değer şifreli = crypto.rsa_şifrele(mesaj.bayt(), açık_anahtar)

print(f"\nMesaj şifrelendi ({şifreli.len} bayt)")

// Özel anahtarla şifre çözme
değer çözülmüş = crypto.rsa_çöz(şifreli, özel_anahtar).aç()
değer çözülmüş_metin = Dize.bayttan(çözülmüş)

print(f"Çözülmüş: {çözülmüş_metin}")

// Dijital imza oluşturma
değer imza = crypto.rsa_imzala(mesaj.bayt(), özel_anahtar)
print(f"\nDijital imza oluşturuldu ({imza.len} bayt)")

// İmza doğrulama
değer geçerli = crypto.rsa_doğrula(mesaj.bayt(), imza, açık_anahtar)
if geçerli {
    print("✓ İmza geçerli!")
} elseif {
    print("✗ İmza geçersiz!")
}

सुरक्षित पासवर्ड प्रबंधन

use crypto
use time

class ParolaYöneticisi {
    değer parola_karmaları: Sözlük<Dize, Dize>
    
    function new() -> ParolaYöneticisi {
        return ParolaYöneticisi {
            parola_karmaları: {}
        }
    }
    
    function kullanıcı_ekle(kullanıcı_adı: Dize, parola: Dize) -> Sonuç<null, Err> {
        // Parola gücünü kontrol et
        if parola.len < 8 {
            return Err("Parola en az 8 char_at olmalı")
        }
        
        // Argon2id ile güvenli karma oluştur
        değer Getting Started = time.now()
        değer karma = crypto.parola_karma(parola, maliyet: 15)
        değer süre = time.now() - Getting Started
        
        bu.parola_karmaları[kullanıcı_adı] = karma
        print(f"Parola karması oluşturuldu ({süre.milisaniye}ms)")
        
        return Ok(null)
    }
    
    function Introduction_yap(kullanıcı_adı: Dize, parola: Dize) -> boolean {
        if kullanıcı_adı !in bu.parola_karmaları {
            return false
        }
        
        değer karma = bu.parola_karmaları[kullanıcı_adı]
        değer Getting Started = time.now()
        değer geçerli = crypto.parola_doğrula(parola, karma)
        değer süre = time.now() - Getting Started
        
        print(f"Parola doğrulama: {süre.milisaniye}ms")
        return geçerli
    }
}

// Usage
değer yönetici = ParolaYöneticisi.new()

// Kullanıcı ekleme
yönetici.kullanıcı_ekle("ahmet", "Güçlü_P@rol@_123").aç()
yönetici.kullanıcı_ekle("ayşe", "Başka_Güçlü_P@ss").aç()

// Introduction denemeleri
print("\n--- Introduction Denemeleri ---")

if yönetici.Introduction_yap("ahmet", "Güçlü_P@rol@_123") {
    print("✓ Ahmet başarıyla Introduction yaptı")
} elseif {
    print("✗ Introduction başarısız")
}

if yönetici.Introduction_yap("ahmet", "yanlış_parola") {
    print("✓ Introduction başarılı")
} elseif {
    print("✗ false parola!")
}

फ़ाइल एन्क्रिप्शन प्रणाली

use crypto
use fs
use encoding

class DosyaŞifreleyici {
    function dosya_şifrele(
        kaynak: Dize,
        hedef: Dize,
        parola: Dize
    ) -> Sonuç<null, Err> {
        // Dosyayı read
        değer Content = fs.fs::read(kaynak)?
        
        // Parola'from anahtar türet
        değer tuz = crypto.rastgele_bayt(16)
        değer anahtar = crypto.pbkdf2(
            parola.bayt(),
            tuz,
            iterasyon: 100000,
            len: 32
        )
        
        // Şifreleme for nonce oluştur
        değer nonce = crypto.rastgele_bayt(12)
        
        // AES-GCM ile şifrele
        değer şifreli = crypto.aes_gcm_şifrele(
            veri: Content,
            anahtar: anahtar,
            nonce: nonce
        )
        
        // Dosya formatı: [TUZ:16][NONCE:12][ŞİFRELİ_VERİ]
        değer çıktı = tuz + nonce + şifreli
        fs.dosya_yaz(hedef, çıktı)?
        
        print(f"✓ Dosya şifrelendi: {kaynak} -> {hedef}")
        print(f"  Boyut: {Content.len} -> {çıktı.len} bayt")
        
        return Ok(null)
    }
    
    function dosya_çöz(
        kaynak: Dize,
        hedef: Dize,
        parola: Dize
    ) -> Sonuç<null, Err> {
        // Şifreli dosyayı read
        değer veri = fs.fs::read(kaynak)?
        
        // Tuz and nonce'ı ayıkla
        değer tuz = veri[0..16]
        değer nonce = veri[16..28]
        değer şifreli = veri[28..]
        
        // Parola'from anahtar türet
        değer anahtar = crypto.pbkdf2(
            parola.bayt(),
            tuz,
            iterasyon: 100000,
            len: 32
        )
        
        // Şifreyi çöz
        değer Content = crypto.aes_gcm_çöz(
            veri: şifreli,
            anahtar: anahtar,
            nonce: nonce
        )?
        
        // Dosyaya print
        fs.dosya_yaz(hedef, Content)?
        
        print(f"✓ Dosya çözüldü: {kaynak} -> {hedef}")
        print(f"  Boyut: {veri.len} -> {Content.len} bayt")
        
        return Ok(null)
    }
}

// Usage
değer şifreleyici = DosyaŞifreleyici {}

// Dosya şifreleme
şifreleyici.dosya_şifrele(
    "gizli_Documentation.pdf",
    "gizli_Documentation.pdf.enc",
    "çok_güçlü_parola_123"
).aç()

// Dosya çözme
şifreleyici.dosya_çöz(
    "gizli_Documentation.pdf.enc",
    "gizli_Documentation_çözülmüş.pdf",
    "çok_güçlü_parola_123"
).aç()

🎯अच्छे आचरण

  • निजी कुंजी या पासवर्ड को कभी भी हार्डकोड न करें
  • एईएस-जीसीएम के लिए प्रमाणित एन्क्रिप्शन का उपयोग करें
  • Argon2id या bcrypt के लिए पासवर्ड हैश को प्राथमिकता दें
  • के लिए यादृच्छिक संख्या पीढ़ीcrypto.rastgele_bayt()उपयोग
  • आरएसए के लिए कम से कम 2048-बिट कुंजी आकार का उपयोग करें
  • सुरक्षित कुंजी प्रबंधन प्रणालियों में कुंजियाँ संग्रहीत करें
  • चाबियाँ नियमित रूप से घुमाएँ
  • पुराने क्रिप्टोग्राफी एल्गोरिदम (MD5, SHA1, DES) से बचें

⚠️ सुरक्षा चेतावनियाँ

  • 🔴 कभी भी निजी कुंजी साझा न करें या उन्हें स्रोत कोड में शामिल न करें
  • 🔴 पासवर्ड या कुंजी निर्माण में मानकrandomउपयोग नहीं करो
  • 🔴 एन्क्रिप्टेड डेटा से छेड़छाड़ के हमलों के खिलाफ एचएमएसी या जीसीएम का उपयोग करें
  • 🔴 संवेदनशील डेटा को मेमोरी (मेमोरी डंप) में रखते समय सावधान रहें
