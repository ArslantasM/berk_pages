    मॉडल मॉड्यूल प्रशिक्षित मॉडलों को सहेजने, लोड करने और साझा करने के लिए अनुकूलित क्रमबद्धता प्रदान करता है। यह LZ4 कम्प्रेशन एल्गोरिदम के साथ 28.8x तेज बचत और 882x छोटा फ़ाइल आकार प्रदान करता है।

    पहले (JSON)

    880ms

    रिकॉर्डिंग समय

    131एमबी

    शुद्ध आकार

    के बाद (LZ4)

    30ms

    रिकॉर्डिंग समय

    0.15एमबी

    शुद्ध आकार

    एक मॉडल सहेजा जा रहा है

    सरल पंजीकरण

    use ai/model;
use ai/nn;

let model = Sequential::new([
    Linear::new(784, 256),
    ReLU::new(),
    Linear::new(256, 10)
]);

// Model eğitimi...

// LZ4 sıkıştırma ile kaydet
model.kaydet("model.berk")?;
print("Model kaydedildi!");

    संपीड़न स्तर

    use ai/model;

// Hızlı kaydetme (Level 1 - varsayılan)
model.kaydet_sıkıştırma("model.berk", seviye: 1)?;

// Maksimum sıkıştırma (Level 9)
model.kaydet_sıkıştırma("model_compressed.berk", seviye: 9)?;

// Sıkıştırmasız (debug for)
model.kaydet_ham("model_raw.berk")?;

    मॉडल लोड हो रहा है

    सरल स्थापना

    use ai/model;
use ai/nn;

// Model yapısını tanımla
let model = Sequential::new([
    Linear::new(784, 256),
    ReLU::new(),
    Linear::new(256, 10)
]);

// Ağırlıkları yükle
model.yükle("model.berk")?;

// Inference
let x = Tensor::random([1, 784]);
let pred = model.ileri(x);
print("Tahmin: {}", pred.argmax());

    आंशिक लोड हो रहा है

    use ai/model;

// Sadece belirli katmanları yükle
model.yükle_kısmi("model.berk", katmanlar: ["conv1", "conv2", "fc"])?;

// Transfer learning for
model.dondur_katmanlar(["conv1", "conv2"]); // Bu katmanları eğitme
model.çöz_katmanlar(["fc"]);                 // Sadece fc'yi eğit

    चेकप्वाइंट प्रबंधन

    प्रशिक्षण चौकियाँ

    use ai/model;
use ai/train;

// Her 10 epoch'ta kaydet
her epoch in range(100) for do
    trainer.eğit_epoch();
    
    if epoch % 10 == 0 then do
        model.kaydet(f"checkpoints/epoch_{epoch}.berk")?;
        print("Checkpoint kaydedildi: epoch {}", epoch);
    end
end

// En iyi modeli kaydet
if val_loss < best_loss then do
    model.kaydet("checkpoints/best_model.berk")?;
    best_loss = val_loss;
end

    एपीआई संदर्भ

    मॉडल क्लास

    • kaydet(path: dizgi) -> Sonuç- मॉडल सहेजें (LZ4 लेवल 1)
    • yükle(path: dizgi) -> Sonuç- मॉडल अपलोड करें
    • kaydet_sıkıştırma(path: dizgi, seviye: int) -> Sonuç- कस्टम संपीड़न स्तर
    • yükle_kısmi(path: dizgi, katmanlar: [dizgi]) -> Sonuç- आंशिक लोडिंग
    • oku_metadata(path: dizgi) -> Metadata- बस मेटाडेटा पढ़ें
    • onnx_export(path: dizgi, ...) -> Sonuç- ओएनएनएक्स निर्यात

    चेकप्वाइंट क्लास

    • kaydet_checkpoint(epoch, model, optimizer, metrics)
    • yükle_checkpoint(path) -> (epoch, model, optimizer)
    • en_iyi_checkpoint() -> dizgi- सर्वोत्तम चेकपॉइंट पथ
    • checkpoint_listesi() -> [dizgi]- सभी चौकियाँ
