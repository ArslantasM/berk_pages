मानक पुस्तकालय v0.9.4

बीईआरके स्टैंडर्ड लाइब्रेरी आधुनिक सॉफ्टवेयर विकास के लिए आवश्यक सभी बुनियादी कार्य प्रदान करती है।v0.9.4संस्करण के साथ75 मॉड्यूल(42 एसटीडीलिब + 33 एचएएल) और4100+ फ़ंक्शनयह एक व्यापक पारिस्थितिकी तंत्र प्रदान करता है।

📊सांख्यिकी

  • 75 मॉड्यूल- 42 stdlib + 33 HAL (एम्बेडेड सिस्टम)
  • 1140KB- Stdlib कोड का आकार
  • 4100+ फ़ंक्शन- व्यापक एपीआई
  • 7 एम्बेडेड प्लेटफार्म- ESP32, STM32F4, RP2040, nRF52, GD32, Nuvoton, Arduino
  • शून्य निर्भरता- केवल बर्क में लिखा गया

संख्यात्मक सिमुलेशन

// Monte Carlo π tahmini
kullan random

variable içerde = 0
variable toplam = 1000000

variable rng = random_xoshiro_seed(12345)

variable i = 0
while (i < toplam) do
    variable x = random_xoshiro_next_float(rng)
    variable y = random_xoshiro_next_float(rng)
    
    if (x*x + y*y < 1.0) ise do
        içerde = içerde + 1
    end
    
    i = i + 1
end

variable pi_tahmini = 4.0 * içerde / toplam
print("π ≈ " + pi_tahmini)  // ~3.14159

अनुकूलन समस्याएँ

// Gradyan inişi ile function minimizasyonu
use optim
use linalg

// f(x, y) = x² + y² - 2x - 4y + 5
function gradyan(pos: [float], n: tam_sayı): [float] do
    variable grad = [2.0 * pos[0] - 2.0, 2.0 * pos[1] - 4.0]
    return grad
end

variable Getting Started = [0.0, 0.0]
variable minimum = optim_gradient_descent(gradyan, Getting Started, 2, 0.1, 100, 0.001)

print("Minimum nokta: (" + minimum[0] + ", " + minimum[1] + ")")
// Beklenen: (1.0, 2.0)
