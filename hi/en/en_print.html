बर्क प्रोग्रामिंग भाषा

बर्कएक आधुनिक, सुरक्षित और उच्च-प्रदर्शन सिस्टम प्रोग्रामिंग भाषा है जिसे दुनिया में पहली बार सच्चे द्विभाषी वाक्यविन्यास (तुर्की/अंग्रेजी) के साथ डिजाइन किया गया है। 19 विभिन्न लक्ष्य प्लेटफार्मों (डेस्कटॉप, मोबाइल, एम्बेडेड, वेबअसेंबली) पर उत्पादकता सक्षम बनाता है।

📖 बर्क नाम क्यों चुना गया?

इज़टर्क उत्पत्ति: "मजबूत, मजबूत, ठोस"

बर्कशब्द Öztürk में"मजबूत, टिकाऊ, दृढ़ और ठोस"ये गुण सीधे प्रोग्रामिंग भाषा के तकनीकी लक्ष्यों से मेल खाते हैं: मेमोरी सुरक्षा, टाइप सिस्टम शुद्धता, मजबूत कंपाइलर आर्किटेक्चर और स्थिर प्रदर्शन।

अरबी से अर्थ: "बिजली"

तुर्की में एक और अर्थ पाया जाता है **"बिजली"**। यह अर्थ BERK भाषा की गति, प्रदर्शन और चपलता के दृष्टिकोण को दर्शाता है: LLVM, C++ स्तर के प्रदर्शन और अनुकूलित कर्नेल आर्किटेक्चर पर आधारित तेज़ संकलन।

अर्थों का संयोजन

बर्क, दोनों तुर्की मूल के हैंमजबूतीअवधारणा के साथ-साथ आधुनिक तकनीक की दुनिया में भीगति और चपलतायह अवधारणाओं को मिलाकर एक मजबूत ब्रांड पहचान बनाता है।

अंतरराष्ट्रीय स्तर की

बर्क,परे-कुशल रनटाइम कर्नेल(रनटाइम कोर परे दक्षता)।

इस पुस्तक के बारे में

यह पुस्तक बर्क प्रोग्रामिंग भाषा सीखने के लिए एक व्यापक संसाधन है।जंग लगी किताबशपथपायथन दस्तावेज़ीकरणजैसे संसाधनों के सर्वोत्तम पहलुओं को एक साथ लाकर इसे तैयार किया गया है।

लक्ष्य समूह

  • प्रोग्रामिंग में शुरुआती
  • अनुभवी डेवलपर्स
  • सिस्टम प्रोग्रामर
  • डेवलपर्स तुर्की सामग्री की तलाश में हैं

आपको पुस्तक का उपयोग कैसे करना चाहिए?

  1. अनुक्रमिक वाचन: हमारा सुझाव है कि आप इसे शुरू से अंत तक क्रम से पढ़ें।
  2. उदाहरण आज़माएँ: प्रत्येक उदाहरण को अपने कंप्यूटर पर चलाएँ
  3. अभ्यास: प्रत्येक अनुभाग के अंत में अभ्यास करें
  4. संदर्भ: जब भी आपको आवश्यकता हो, संदर्भ अनुभाग पर वापस लौटें

भाषा का दर्शन

बर्क के बुनियादी डिजाइन सिद्धांत:

1. अभिगम्यता

तुर्की कीवर्ड के लिए धन्यवाद, प्रोग्रामिंग का परिचय उन लोगों के लिए आसान हो गया है जो अंग्रेजी नहीं बोलते हैं।

2. सुरक्षा

संकलन समय पर स्मृति त्रुटियों को पकड़ता है। यह रनटाइम त्रुटियों को कम करता है।

3. प्रदर्शन

एलएलवीएम बैकएंड की बदौलत यह सी/सी++ स्तर का प्रदर्शन प्रदान करता है।

4. स्पष्टता

स्पष्ट और समझने योग्य वाक्यविन्यास। इसे कोड लिखने के बजाय कोड पढ़ने के लिए अनुकूलित किया गया है।

5. इंटरॉप

सी/सी++ पुस्तकालयों के साथ संगत। यह मौजूदा पारिस्थितिकी तंत्र में एकीकृत हो सकता है।

आइए कोड को समझें

आइए इसकी पंक्ति दर पंक्ति जांच करें:

1.फ़ंक्शन परिभाषा

function ana() -> integer
  • function(याfunction): फ़ंक्शन को परिभाषित करें
  • ana(याmain): फ़ंक्शन का नाम. कार्यक्रमana()फ़ंक्शन से प्रारंभ होता है
  • (): पैरामीटर सूची (शून्य)
  • -> integer: रिटर्न प्रकार (पूर्णांक)

2.फंक्शन बॉडी

do
    ...
end
  • do(याdo): समारोह की शुरुआत
  • end(याend): समारोह का अंत

3.मुद्रण

print("Merhaba Dünya!")
  • print()(याprint()): स्क्रीन पर प्रिंट होता है
  • "Merhaba Dünya!": शाब्दिक स्ट्रिंग

4. वापसी मूल्य

return 0
  • return(याreturn):फ़ंक्शन से बाहर निकलें
  • 0: सफल प्रोग्राम 0 लौटाते हैं (यूनिक्स परंपरा)

// y = ax + b modelini fit et
function linear_fit(X: [float], y: [float], n: tam_sayı): (float, float) do
    // X matrix: [ones, x_values]
    variable A = yeni_dizi(n * 2)
    variable i = 0
    while (i < n) do
        A[i * 2] = 1.0
        A[i * 2 + 1] = X[i]
        i = i + 1
    end
    
    // Normal equations: (A^T A) β = A^T y
    variable params = linalg_least_squares(A, y, n, 2)
    return (params[0], params[1])  // (b, a)
end

function center_data(data: [float], m: tam_sayı, n: tam_sayı): [float] do
    variable centered = linalg_mat_kopyala(data, m, n)
    
    // Her sütun for ortalamayı pop
    variable j = 0
    while (j < n) do
        variable avg = 0.0
        variable i = 0
        while (i < m) do
            avg = avg + linalg_mat_al(data, i, j, n)
            i = i + 1
        end
        avg = avg / m
        
        i = 0
        while (i < m) do
            variable değer = linalg_mat_al(centered, i, j, n) - avg
            linalg_mat_yaz(centered, i, j, n, değer)
            i = i + 1
        end
        
        j = j + 1
    end
    
    return centered
end

// Kovaryans matrisini hesapla
function covariance_matrix(data: [float], m: tam_sayı, n: tam_sayı): [float] do
    variable centered = center_data(data, m, n)
    variable CT = linalg_transpoz(centered, m, n)
    variable cov = linalg_mat_çarp(CT, centered, n, m, n)
    
    // (n-1) ile split
    variable i = 0
    while (i < n * n) do
        cov[i] = cov[i] / (m - 1)
        i = i + 1
    end
    
    return cov
end

function beam_cost(dimensions: [float], n: tam_sayı): float do
    variable width = dimensions[0]
    variable height = dimensions[1]
    
    // Maliyet = malzeme × domain
    variable cost = width * height

    variable I = (width * height * height * height) / 12.0
    variable penalty = 0.0
    if (I < 1000.0) then do
        penalty = 1000.0 * (1000.0 - I)
    end
    
    return cost + penalty
end

सामान्य प्रश्न

बर्क क्या है?

बर्क एक आधुनिक, सुरक्षित और उच्च प्रदर्शन वाली प्रोग्रामिंग भाषा है। द्विभाषी वाक्यविन्यास समर्थन के साथ, आप तुर्की और अंग्रेजी दोनों कीवर्ड का उपयोग कर सकते हैं। एलएलवीएम बैकएंड का उपयोग करके मूल कोड उत्पन्न करता है।

मुझे बर्क का उपयोग क्यों करना चाहिए?

  • द्विभाषी सिंटेक्स: तुर्की या अंग्रेजी कीवर्ड, जो चाहें उपयोग करें
  • स्मृति सुरक्षा: आधुनिक प्रकार की प्रणाली और त्रुटि प्रबंधन
  • उच्च प्रदर्शन: एलएलवीएम के साथ मूल कोड, शून्य लागत सार
  • रिच स्टैडलिब: 18 मॉड्यूल, 600+ फ़ंक्शन, वैज्ञानिक गणना समर्थन
  • आसान सीखना: स्वच्छ वाक्यविन्यास, त्रुटि संदेश साफ़ करें

BERK किस प्लेटफॉर्म पर काम करता है?

Windows x64 के लिए एक कंपाइलर वर्तमान में उपलब्ध है। Linux और macOS समर्थन रोडमैप पर है।

क्या बर्क खुला स्रोत है?

हां, बीईआरके एमआईटी लाइसेंस के तहत एक ओपन सोर्स प्रोजेक्ट है। GitHub पर विकास हो रहा है.

वाक्य-विन्यास और भाषा विशेषताएँ

द्विभाषी वाक्यविन्यास कैसे काम करता है?

बर्क में आप एक ही प्रोग्राम को दो अलग-अलग तरीकों से लिख सकते हैं:

// Türkçe
function merhaba() {
    print("Merhaba Dünya!")
}

// İngilizce
function hello() {
    print("Hello World!")
}

दोनों शैलियाँ एक ही बाइटकोड पर संकलित होती हैं। आप उन्हें एक ही फ़ाइल में मिला भी सकते हैं!

यह किन प्रोग्रामिंग प्रतिमानों का समर्थन करता है?

  • अनिवार्य प्रोग्रामिंग: क्लासिक प्रक्रियात्मक कोड
  • कार्यात्मक प्रोग्रामिंग: पुनरावर्तक, उच्च-क्रम कार्य, अपरिवर्तनीयता
  • संरचित प्रोग्रामिंग: संरचनाएं, मॉड्यूलर वास्तुकला
  • सुरक्षा टाइप करें: स्थैतिक प्रकार की जाँच, जेनरिक (रोडमैप में)

क्या कचरा संग्रहकर्ता है?

नहीं, बर्क मैन्युअल मेमोरी प्रबंधन का उपयोग करता है (अभी के लिए)। भविष्य में जंग जैसी स्वामित्व प्रणाली या वैकल्पिक जीसी की योजना बनाई गई है।

मानक पुस्तकालय

stdlib में क्या शामिल है?

BERK v1.4 stdlib में 18 मॉड्यूल हैं:

बुनियादी मॉड्यूल: io, स्ट्रिंग, संग्रह, परिणाम, समय
प्रणाली: एफएस, थ्रेड, सिस, टर्मिनल
कार्यात्मक: धक्का, एफएमटी
वैज्ञानिक: गणित, भौतिकी, जटिल, यादृच्छिक, लाइनलग, सांख्यिकी, ऑप्टिम

कुल 600+ फ़ंक्शन और 285 KB कोड।

क्या NumPy/SciPy जैसी सुविधाएं हैं?

हाँ! वैज्ञानिक गणना मॉड्यूल v1.4 के साथ जोड़े गए:

  • linalg: मैट्रिक्स ऑपरेशंस, एलयू/क्यूआर/चोलेस्की, आइजेनवैल्यू
  • stats: सांख्यिकी, प्रतिगमन, परिकल्पना परीक्षण, वितरण
  • optim: अनुकूलन एल्गोरिदम, ग्रेडिएंट डिसेंट, बीएफजीएस

क्या मैं C/C++ लाइब्रेरीज़ का उपयोग कर सकता हूँ?

वर्तमान में कोई प्रत्यक्ष एफएफआई (फॉरेन फंक्शन इंटरफ़ेस) समर्थन नहीं है। C लाइब्रेरी एकीकरण की योजना v0.9 में बनाई गई है।

प्रदर्शन और अनुकूलन

बर्क कितना तेज़ है?

एलएलवीएम बैकएंड के लिए धन्यवाद, यह सी/सी++ के बराबर प्रदर्शन प्रदान करता है। बेंचमार्क विकासाधीन हैं।

अनुकूलन स्तर क्या हैं?

berk build -O0  # Optimizasyon yok (hızlı derleme)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (균衡)
berk build -O3  # Agresif optimizasyon

क्या समानांतर प्रोग्रामिंग समर्थित है?

हाँ,threadआप मॉड्यूल के साथ मल्टी-थ्रेडिंग कर सकते हैं:

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    variable t1 = thread.spawn(işçi, 1)
    variable t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}
