BERK Programlama Dili

वीएस कोड ऐड-इन

बर्क बनाम कोड एक्सटेंशन,व्यावसायिक विकास का अनुभवयह पूर्ण विशेषताओं वाला IDE समर्थन प्रदान करता है। भाषा सर्वर प्रोटोकॉल (एलएसपी) द्वारा संचालित।

स्थापित करना

बाज़ार के माध्यम से

  1. वीएस कोड खोलें
  2. एक्सटेंशन (Ctrl+Shift+X) मेनू पर जाएं
  3. "बर्क भाषा समर्थन" खोजें
  4. "इंस्टॉल करें" बटन पर क्लिक करें

कमांड लाइन से

code --install-extension ArslantasM-tools.berk-lang

प्रमुख विशेषताऐं

1. सिंटैक्स हाइलाइटिंग

  • ✅ तुर्की और अंग्रेजी कीवर्ड
  • ✅ स्ट्रिंग प्रक्षेप
  • ✅ टिप्पणी पंक्तियाँ
  • ✅ हाइलाइट्स टाइप करें
  • ✅ फ़ंक्शन नाम

2. IntelliSense (कोड पूर्णता)

// 'let' yazın and Ctrl+Space
let x = 42

// 'x.' yazın - otomatik metodlar gösterilir
x.to_string()
x.karakter_uzunluğu()

3. परिभाषा पर जाएँ (F12)

किसी भी फ़ंक्शन/वेरिएबल पर F12 दबाएँ:

let sonuç = hesapla(10)  // F12 ile hesapla() tanımına git

4. सभी संदर्भ खोजें (Shift+F12)

किसी प्रतीक के सभी उपयोग खोजें

5. प्रतीक का नाम बदलें (F2)

सुरक्षित नाम परिवर्तन - सभी संदर्भ स्वचालित रूप से अपडेट हो जाते हैं

6. होवर सूचना

किसी भी प्रतीक पर होवर करें:

  • जानकारी टाइप करें
  • प्रलेखन
  • हस्ताक्षर संबंधी जानकारी

7. निदान (त्रुटि जाँच)

वास्तविक समय त्रुटि जाँच:

  • 🔴 सिंटेक्स त्रुटियाँ
  • 🟠चेतावनी
  • 🔵 जानकारी

8. कोड क्रियाएँ (Ctrl+.)

त्वरित सुधार और रीफैक्टरिंग:

  • स्वचालित जोड़ आयात करें
  • प्रकार विवरण जोड़ें
  • परिवर्तनीय निष्कर्षण

9. हस्ताक्षर सहायता (Ctrl+Shift+Space)

function hesapla(x: sayı, y: sayı, z: sayı) do
end

hesapla(  // Ctrl+Shift+Space - parametre yardımı

10. दस्तावेज़ चिह्न (Ctrl+Shift+O)

फ़ाइल में सभी प्रतीकों (फ़ंक्शन, वेरिएबल) की सूची

11. सिमेंटिक टोकन

उन्नत सिंटैक्स हाइलाइटिंग - प्रकार की जानकारी के आधार पर रंग भरना

12. जड़ संकेत

इनलाइन प्रकार और पैरामीटर विवरण

13. कोड लेंस

संदर्भ संख्याएँ और त्वरित कार्रवाई

डिबगिंग समर्थन

launch.jsonविन्यास:

{
  \"version\": \"0.2.0\",
  \"configurations\": [
    {
      \"type\": \"berk\",
      \"request\": \"launch\",
      \"name\": \"Debug BERK Program\",
      \"program\": \"${workspaceFolder}/main.berk\",
      \"stopOnEntry\": false
    }
  ]
}

सेटिंग्स

settings.json:

{
  \"berk.lsp.enabled\": true,
  \"berk.lsp.trace.server\": \"off\",
  \"berk.build.optimizationLevel\": 2,
  \"berk.format.indentSize\": 4,
  \"berk.lint.warnings\": true,
  \"berk.inlayHints.enabled\": true,
  \"berk.semanticTokens.enabled\": true
}

सेव पर फ़ॉर्मेट करें

{
  \"[berk]\": {
    \"editor.formatOnSave\": true,
    \"editor.defaultFormatter\": \"ArslantasM-tools.berk-lang\"
  }
}

कार्य धावक

tasks.json:

{
  \"version\": \"2.0.0\",
  \"tasks\": [
    {
      \"label\": \"build\",
      \"type\": \"shell\",
      \"command\": \"berk-lang build\",
      \"group\": {
        \"kind\": \"build\",
        \"isDefault\": true
      }
    }
  ]
}

समस्या मिलानकर्ता

BERK स्वचालित रूप से त्रुटि प्रारूप का पता लगाता है:

error[E0308]: type uyuşmazlığı
  --> src/main.berk:5:14
   |
 5 |     let x: sayı = \"merhaba\";
   |              ^^^^      ^^^^^^^^^

कार्यस्थल सुझाव

.vscode/extensions.json:

{
  \"recommendations\": [
    \"ArslantasM-tools.berk-lang\"
  ]
}

प्रदर्शन युक्तियाँ

  1. ✅ एलएसपी कैशउपयोग:

    \"berk.lsp.cache.enabled\": true

  2. ✅ वृद्धिशील विश्लेषणसक्रिय:

    \"berk.lsp.incrementalSync\": true

  3. ⚠️ बहुत बड़ी फ़ाइलों के लिएसिमेंटिक टोकनबंद करना:

    \"berk.semanticTokens.enabled\": false

समस्या निवारण

यदि एलएसपी काम नहीं करता है

  1. कमांड पैलेट → "बर्क: एलएसपी पुनरारंभ करें"
  2. वीएस कोड पुनः आरंभ करें
  3. आउटपुट पैनल → "BERK भाषा सर्वर" लॉग देखें

कोई सिंटैक्स हाइलाइटिंग नहीं

  1. फाइल एक्सटेंशन.berkहोना ही चाहिए
  2. भाषा मोड "BERK" का चयन किया जाना चाहिए (निचला दायां कोना)
