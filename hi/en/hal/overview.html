एचएएल - हार्डवेयर एब्स्ट्रैक्शन लेयर

बर्क एचएएल (हार्डवेयर एब्स्ट्रैक्शन लेयर) एम्बेडेड सिस्टम के लिए एक एकीकृत हार्डवेयर एब्स्ट्रैक्शन लेयर है।33 मॉड्यूलसाथ7 विभिन्न माइक्रोकंट्रोलर प्लेटफार्म100% बाज़ार कवरेज का समर्थन करता है और प्रदान करता है।

📊सांख्यिकी

  • 33 एचएएल मॉड्यूल- व्यापक हार्डवेयर समर्थन
  • 7 प्लेटफार्म- ESP32, STM32F4, RP2040, nRF52, GD32, Nuvoton, Arduino
  • 2,380 एलओसी- अनुकूलित एचएएल कोड
  • 100% बाज़ार कवरेज- माइक्रोकंट्रोलर सेगमेंट में पूर्ण कवरेज
  • 95% पूर्ण- उत्पादन के लिए तैयार स्थिति

🎯 समर्थित प्लेटफार्म

1. ESP32 (एस्प्रेसिव)

  • प्रोसेसर: डुअल-कोर Xtensa LX6 @ 240 मेगाहर्ट्ज
  • टक्कर मारना: 520 केबी एसआरएएम
  • चमक: 4-16एमबी
  • विशेषताएँ: वाईफाई 802.11 बी/जी/एन, ब्लूटूथ 4.2/बीएलई
  • उपयोग के क्षेत्र: IoT, स्मार्ट होम, पहनने योग्य वस्तुएं
  • लोकप्रियता: ⭐⭐⭐⭐⭐ (सबसे लोकप्रिय IoT प्लेटफ़ॉर्म)

2. STM32F4 (STMicroelectronics)

  • प्रोसेसर: एआरएम कॉर्टेक्स-एम4एफ @ 168 मेगाहर्ट्ज
  • टक्कर मारना: 192 केबी एसआरएएम
  • चमक: 512 केबी - 1 एमबी
  • विशेषताएँ: एफपीयू, डीएसपी निर्देश, ईथरनेट, यूएसबी ओटीजी
  • उपयोग के क्षेत्र: औद्योगिक स्वचालन, रोबोटिक्स, मोटर नियंत्रण
  • लोकप्रियता: ⭐⭐⭐⭐⭐ (पेशेवर मानक)

3. आरपी2040 (रास्पबेरी पाई)

  • प्रोसेसर: डुअल-कोर एआरएम कॉर्टेक्स-एम0+ @ 133 मेगाहर्ट्ज
  • टक्कर मारना: 264 केबी एसआरएएम
  • चमक: 2-16 एमबी (बाहरी क्यूएसपीआई)
  • विशेषताएँ: पीआईओ (प्रोग्रामेबल आई/ओ), यूएसबी 1.1
  • उपयोग के क्षेत्र: निर्माता परियोजनाएं, प्रशिक्षण, प्रोटोटाइप
  • लोकप्रियता: ⭐⭐⭐⭐⭐ (रास्पबेरी पाई पारिस्थितिकी तंत्र)

4. nRF52 (नॉर्डिक सेमीकंडक्टर)

  • प्रोसेसर: एआरएम कॉर्टेक्स-एम4एफ @ 64 मेगाहर्ट्ज
  • टक्कर मारना: 256KB
  • चमक: 1एमबी
  • विशेषताएँ: ब्लूटूथ 5.x/BLE, अल्ट्रा-लो पावर
  • उपयोग के क्षेत्र: पहनने योग्य उपकरण, बीकन, वायरलेस सेंसर
  • लोकप्रियता: ⭐⭐⭐⭐ (बीएलई उद्योग मानक)

5. GD32 (गीगाडिवाइस)

  • प्रोसेसर: एआरएम कॉर्टेक्स-एम4 @ 120 मेगाहर्ट्ज
  • टक्कर मारना: 128 केबी एसआरएएम
  • चमक: 512KB
  • विशेषताएँ: STM32 पिन-संगत, कम लागत
  • उपयोग के क्षेत्र: उपभोक्ता इलेक्ट्रॉनिक्स, औद्योगिक
  • लोकप्रियता: ⭐⭐⭐ (लागत प्रभावी विकल्प)

6. नुवोटन

  • प्रोसेसर: एआरएम कॉर्टेक्स-एम23/एम4 @ 72-192 मेगाहर्ट्ज
  • टक्कर मारना: 64-512 KB
  • चमक: 256 केबी - 1 एमबी
  • विशेषताएँ: सुरक्षा सुविधाएँ, CAN-FD
  • उपयोग के क्षेत्र: ऑटोमोटिव, औद्योगिक सुरक्षा
  • लोकप्रियता: ⭐⭐⭐ (विशेष अनुप्रयोग)

7. अरुडिनो (एवीआर/एआरएम)

  • प्रोसेसर: ATmega328P @ 16 MHz (AVR), ARM Cortex-M0+ @ 48 MHz
  • टक्कर मारना: 2-32 केबी
  • चमक: 32-256 केबी
  • विशेषताएँ: विस्तृत पारिस्थितिकी तंत्र, उपयोग में आसान
  • उपयोग के क्षेत्र: शिक्षा, शौक परियोजनाएं, प्रोटोटाइप
  • लोकप्रियता: ⭐⭐⭐⭐⭐ (सबसे आम निर्माता मंच)

IoT स्मार्ट होम डिवाइस (ESP32)

// Akıllı termostat - WiFi + sensör
import hal_wifi, hal_adc, hal_gpio, hal_http

function akıllı_termostat() do
    // WiFi bağlan
    hal_wifi_connect("EvWiFi", "sifre123", 10000)
    
    // Sıcaklık sensörü (LM35 - ADC)
    hal_adc_init(ADC1, CHANNEL_0, ADC_WIDTH_12BIT, ADC_ATTEN_11DB)
    
    // Röle çıkışı (ısıtıcı kontrolü)
    hal_gpio_init(GPIO_ROLE, GPIO_MODE_OUTPUT)
    
    while true do
        // Sıcaklık input
        let adc = hal_adc_read(ADC1, CHANNEL_0)
        let sıcaklık = (adc / 4095.0) * 330.0  // LM35: 10mV/°C
        
        // Buluta gönder
        let url = "http://api.iot.com/temp?value=" + sıcaklık
        hal_http_post(url, "")
        
        // Isıtıcı kontrolü (20°C altı)
        if sıcaklık < 20.0 then do
            hal_gpio_write(GPIO_ROLE, 1)  // Isıtıcı aç
        else do
            hal_gpio_write(GPIO_ROLE, 0)  // Isıtıcı kapat
        end
        
        hal_delay_ms(60000)  // 1 dakika sleep
    end
end

इंजन नियंत्रण प्रणाली (STM32F4)

// BLDC motor kontrolü - PWM + encoder + PID
import hal_pwm, hal_timer, hal_gpio

let hedef_hız = 1000  // RPM
let encoder_sayac = 0

// Encoder interrupt callback
function encoder_callback() do
    encoder_sayac = encoder_sayac + 1
end

function motor_kontrol() do
    // PWM başlat (20 kHz)
    hal_pwm_init(TIMER1, CHANNEL_1, 20000, 0)
    hal_pwm_start(TIMER1, CHANNEL_1)
    
    // Encoder interrupt
    hal_gpio_init_interrupt(GPIO_ENC_A, GPIO_MODE_INPUT_PULLUP, 
                           GPIO_INT_RISING, encoder_callback)
    
    // PID değişkenleri
    let Kp = 0.5, Ki = 0.1, Kd = 0.01
    let integral = 0.0, son_hata = 0.0
    
    while true do
        // Hız hesapla (encoder sayacından)
        let anlık_hız = encoder_sayac * 60  // RPM
        encoder_sayac = 0
        
        // PID kontrol
        let hata = hedef_hız - anlık_hız
        integral = integral + hata
        let türev = hata - son_hata
        
        let çıkış = Kp*hata + Ki*integral + Kd*türev
        son_hata = hata
        
        // PWM duty cycle ayarla (0-100%)
        let duty = math_clamp(çıkış, 0.0, 100.0)
        hal_pwm_set_duty(TIMER1, CHANNEL_1, duty)
        
        hal_delay_ms(100)  // 10 Hz kontrol döngüsü
    end
end

लो पावर सेंसर नोड (nRF52)

// BLE beacon + sensör - Ultra-low power
import hal_ble, hal_adc, hal_power

function ble_sensör_beacon() do
    // BLE başlat
    hal_ble_init("BERK_Sensör")
    hal_ble_set_advertising(100)  // 100ms interval
    
    // ADC başlat (sıcaklık sensörü)
    hal_adc_init(ADC1, CHANNEL_0, ADC_WIDTH_12BIT, ADC_GAIN_1_6)
    
    while true do
        // Sensör input
        let sıcaklık = hal_adc_read_temp()  // Internal temp
        let batarya = hal_adc_read_vbat()   // Battery voltage
        
        // BLE advertising paketine push
        hal_ble_update_data("temp", sıcaklık)
        hal_ble_update_data("vbat", batarya)
        
        // Deep sleep (1 dakika)
        hal_power_deep_sleep(60000)  // 60sn uyku, ~3µA
        // Wake-up sonrası buradan devam eder
    end
end
