BERK Programming Language

चर और स्थिरांक

बर्क में, मूल्यों को संग्रहीत करने के लिएचर(चर) औरस्थिरांक(स्थिरांक) का प्रयोग किया जाता है।

परिवर्तनशील घोषणा

तुर्की सिंटैक्स

let x = 10
let isim = "Ahmet"
variable pi = 3.14159

अंग्रेजी सिंटेक्स

var x = 10
var name = "John"
var pi = 3.14159

प्रकार विशिष्टता

बर्क एक स्थिर रूप से टाइप की जाने वाली भाषा है। प्रकार अनुमान (प्रकार अनुमान) समर्थित है:

// Type inference (recommended)
variable sayı = 42          // number tipi
variable String = "Hello"    // string tipi
variable gerçek = 3.14      // number tipi (float)

// Explicit type specification
variable sayı: number = 42
variable String: string = "Hello"
variable List: Liste<number> = [1, 2, 3]

परिवर्तनीय संशोधन

घोषणा के बाद चर मान बदले जा सकते हैं:

variable counter = 0
print(counter)  // 0

counter = counter + 1
print(counter)  // 1

counter += 5
print(counter)  // 6

स्थिरांक

एक बार असाइन किए जाने के बाद स्थिरांकों को बदला नहीं जा सकता:

constant PI = 3.14159
constant MAX_KULLANICI = 100
constant UYGULAMA_ADI = "BERK App"

// Error! constant cannot be changed
// PI = 3.14  // Compilation error

अंग्रेजी सिंटेक्स

const PI = 3.14159
const MAX_USERS = 100

नामकरण नियम

चर

  • साँप का मामलाउपयोग करें (अनुशंसित)
  • तुर्की वर्ण समर्थित हैं
  • किसी संख्या से प्रारंभ नहीं किया जा सकता
  • कीवर्ड नहीं हो सकता
// Valid variable names
variable user_name = "Alice"
variable total_price = 99.99
variable student_number = 12345
variable value1 = 10
variable _private = "gizli"

// Invalid variable isimleri
// variable 1değer = 10      // number ile başlıyor
// variable function = 5        // Anahtar kelime
// variable user-name = ""   // Tire kullanılamaz

स्थिरांक

  • SCREAMING_SNAKE_CASEउपयोग
  • सभी बड़े अक्षर
  • शब्द अंडरस्कोर द्वारा अलग किए गए
constant MAX_DEĞER = 1000
constant VERSİYON_NUMARASI = "0.8.0"
constant HATA_MESAJI = "Invalid Introduction"

दायरा

सार्वत्रिक चर

फ़ंक्शन परिभाषित बाहरी चर वैश्विक हैं:

variable global_sayaç = 0  // Global

function artır() {
    global_sayaç += 1
}

function main() {
    print(global_sayaç)  // 0
    artır()
    print(global_sayaç)  // 1
}

स्थानीय चर

वेरिएबल के अंदर परिभाषित फ़ंक्शन स्थानीय हैं:

function hesapla() {
    variable Local = 10  // Accessible only in this function
    print(Local)
}

function main() {
    hesapla()
    // print(Local)  // Err! Local not defined here
}

ब्लॉक का दायरा

प्रत्येक ब्लॉक अपना स्वयं का दायरा बनाता है:

function main() {
    variable x = 10
    
    if x > 5 {
        variable y = 20  // Bu blokta Valid
        print(x, y)     // 10, 20
    }
    
    print(x)     // 10
    // print(y)  // Err! y not in this scope
}

पीछा

समान नाम वाले एक वेरिएबल को आंतरिक दायरे में परिभाषित किया जा सकता है:

function main() {
    variable x = 5
    print(x)  // 5
    
    {
        variable x = 10  // Different variable
        print(x)        // 10
    }
    
    print(x)  // 5 (outer scope)
}

विध्वंसक

टपल और सूचियों से मान निकालना:

// Tuple destructuring
variable (x, y) = (10, 20)
print(x)  // 10
print(y)  // 20

// Liste destructuring
variable [ilk, ikinci, ...geri_kalan] = [1, 2, 3, 4, 5]
print(ilk)         // 1
print(ikinci)      // 2
print(geri_kalan)  // [3, 4, 5]

एकाधिक असाइनमेंट

एक साथ अनेक चर घोषित करें:

variable a, b, c = 1, 2, 3
print(a, b, c)  // 1 2 3

// Value swap (swap)
variable x = 10
variable y = 20
x, y = y, x
print(x, y)  // 20 10

निरर्थक चर

चर शून्य हो सकते हैं:

variable değer: number? = null  // Nullable type

if değer != null {
    print("Değer: ", değer)
} else {
    print("Değer yok")
}

// Default Value ile
variable sonuç = değer ?: 0  // if null then 0 use

अलियासिंग टाइप करें

उपनाम टाइप करें:

type KullanıcıID = number

variable id: KullanıcıID = 12345

उदाहरण कार्यक्रम

import math

// Global constants
constant YERÇEKIMI = 9.81  // m/s²
constant PI = 3.14159

function dairesel_hareket(yarıçap: number, hız: number) -> number {
    // Merkezcil ivme hesaplama
    variable ivme = (hız * hız) / yarıçap
    geri return ivme
}

function serbest_düşüş(yükseklik: number) -> number {
    // v = sqrt(2 * g * h)
    variable hız = math.sqrt(2.0 * YERÇEKIMI * yükseklik)
    geri return hız
}

function main() {
    // variables
    variable yarıçap = 5.0   // metre
    variable hız = 10.0      // m/s
    
    variable ivme = dairesel_hareket(yarıçap, hız)
    print("Merkezcil ivme: ", ivme, " m/s²")
    
    // constant değer
    constant YÜKSEKLİK = 50.0  // metre
    variable düşüş_hızı = serbest_düşüş(YÜKSEKLİK)
    print("Düşüş hızı: ", düşüş_hızı, " m/s")
}
