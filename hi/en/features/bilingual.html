द्विभाषी सिंटैक्स (तुर्की/अंग्रेज़ी)

बर्क,दुनिया की पहली वास्तविक द्विभाषी प्रोग्रामिंग भाषा है. आप एक ही कोड तुर्की और अंग्रेजी दोनों में लिख सकते हैं, या दोनों भाषाओं को एक ही फ़ाइल में मिला भी सकते हैं!

द्विभाषी क्यों?

सीखने में आसानी

तुर्की भाषी शुरुआती अपनी मूल भाषा में प्रोग्रामिंग सीख सकते हैं:

function merhaba() do
    print("Merhaba Dünya!")
end

अंतरराष्ट्रीय सहयोग

आप अंग्रेजी बोलने वाले डेवलपर्स के साथ आसानी से सहयोग कर सकते हैं:

function hello() do
    print("Hello World!")
end

पूर्ण समतुल्यता

दोनों भाषाएँवही AST (सार सिंटैक्स ट्री) बनाता है. कुंआ:

  • ✅ वही प्रदर्शन
  • ✅ एक जैसा व्यवहार
  • ✅ वही बाइटकोड
  • ✅ वही त्रुटि संदेश

तुलनात्मक उदाहरण

उदाहरण 1: फाइबोनैचि

अंग्रेज़ी:

function fibonacci(n: sayı) -> sayı
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

अंग्रेज़ी:

function fibonacci(n: int) -> int
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

उदाहरण 2: वर्ग परिभाषा

अंग्रेज़ी:

struct Kişi do
    isim: String,
    yaş: sayı
end

function yeni_kişi(isim: String, yaş: sayı) -> Kişi
do
    return Kişi { isim: isim, yaş: yaş }
end

अंग्रेज़ी:

struct Person do
    name: string,
    age: int
end

function new_person(name: string, age: int) -> Person
do
    return Person { name: name, age: age }
end

मिश्रित उपयोग

सबसे शक्तिशाली विशेषताएं:आप एक ही फाइल में दो भाषाओं को मिला सकते हैं!

// Türkçe function
function hesapla(x: sayı) -> sayı do
    let sonuç = x * 2
    return sonuç
end

// English function  
function calculate_advanced(x: int) -> int do
    let result = hesapla(x) + 10  // Türkçe fonksiyonu çağırıyoruz
    return result
end

// Türkçe main function
function main() do
    let değer = calculate_advanced(5)  // İngilizce fonksiyonu çağırıyoruz
    print(değer)
end

शैली सुझाव

परियोजना के भीतर निरंतरता

  • ✅ किसी प्रोजेक्ट के भीतर एक ही भाषा का उपयोग करना अक्सर बेहतर होता है
  • ✅ टीम के सदस्यों के साथ संवाद करें: तुर्की या अंग्रेजी?
  • ⚠️ मिश्रित उपयोग संभव है लेकिन पठनीयता कम हो सकती है

पुस्तकालयों के लिए

  • ✅ ओपन सोर्स लाइब्रेरी आम तौर पर अंग्रेजी में लिखी जानी चाहिए
  • ✅ स्थानीय/विशेष परियोजनाएं तुर्की में लिखी जा सकती हैं
  • ✅ एपीआई दस्तावेज़ दोनों भाषाओं में उपलब्ध है

पश्चगामी संगतता

बर्क के भविष्य के संस्करणों में:

  • ✅ दोनों भाषाएं पूरी तरह से समर्थित होंगी
  • ✅ दोनों भाषाओं में नए फीचर्स जोड़े जाएंगे
  • ✅ आपको अपना कोडबेस बदलने की आवश्यकता नहीं होगी

आईडीई समर्थन

वीएस कोड ऐड-ऑन दोनों भाषाओं का समर्थन करता है:

  • ✅ सिंटेक्स हाइलाइटिंग
  • ✅ स्वतः पूर्ण
  • ✅ जाँच में त्रुटि
  • ✅ कोड स्निपेट
  • ✅ होवर जानकारी

संकलक व्यवहार

संकलक चरण:

  1. लेक्सर: तुर्की और अंग्रेजी दोनों कीवर्ड को पहचानता है
  2. पार्सर: दोनों भाषाओं के लिए समान एएसटी नोड बनाता है
  3. सिमेंटिक विश्लेषक: भाषा भेद के बावजूद
  4. कोड जेनरेटर: समान एलएलवीएम आईआर उत्पन्न करता है

प्रदर्शन

शून्य लागत!

  • इससे कोई फर्क नहीं पड़ता कि आप किस भाषा का उपयोग करते हैं, प्रदर्शन वही रहेगा
  • संकलित कोड समान है
  • रनटाइम में कोई ओवरहेड नहीं है

भाषा अनुवाद उपकरण

आप बर्क सीएलआई के साथ कोड का अनुवाद कर सकते हैं:

# Türkçe'den İngilizce'ye
berk-lang convert --to=english dosya.berk -o file.berk

# İngilizce'den Türkçe'ye
berk-lang convert --to=turkish file.berk -o dosya.berk

भविष्य की योजनाएं

  • 🔮 स्वचालित भाषा पहचान
  • 🔮 कोड विश्लेषण और भाषा अनुशंसाएँ
  • 🔮त्रुटि संदेशों में भाषा प्राथमिकता
  • 🔮 दस्तावेज़ीकरण स्वचालित अनुवाद

समुदाय मानकों

ओपन सोर्स प्रोजेक्ट्स

  • README तुर्की और अंग्रेजी दोनों में होना चाहिए
  • कोड आमतौर पर अंग्रेजी में (अंतर्राष्ट्रीय योगदानकर्ताओं के लिए)
  • टिप्पणी पंक्तियाँ दोनों भाषाओं में हो सकती हैं

निजी/कॉर्पोरेट परियोजनाएँ

  • टीम वरीयता के अनुसार
  • तुर्किये में कंपनियाँ आम तौर पर तुर्की भाषा को प्राथमिकता देती हैं
  • अंतर्राष्ट्रीय टीमें अंग्रेजी का उपयोग कर सकती हैं

सारांश

  • ✅ दुनिया की पहली वास्तविक द्विभाषी प्रोग्रामिंग भाषा
  • ✅ पूर्ण तुल्यता: समान एएसटी, समान प्रदर्शन
  • ✅ एक ही फ़ाइल में मिश्रित उपयोग संभव है
  • ✅आईडीई पूर्ण समर्थन
  • ✅ शून्य प्रदर्शन लागत
