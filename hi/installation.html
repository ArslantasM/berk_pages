जंग स्थापना

बर्क रस्ट में लिखा गया है। आपको पहले रस्ट इंस्टॉल करना होगा:

विंडोज़/लिनक्स/मैकओएस

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

स्थापना के बाद:

rustc --version
cargo --version

आउटपुट:

rustc 1.75.0 (1.75.0 2024-01-01)
cargo 1.75.0 (1.75.0 2024-01-01)

एलएलवीएम इंस्टालेशन

मूल कोड जनरेशन के लिए BERK LLVM 17 का उपयोग करता है।

विंडोज़ (पूर्व-संकलित)

  1. एलएलवीएम 17.0.6 डाउनलोड करें:

    • एलएलवीएम रिलीज़
    • LLVM-17.0.6-win64.exeडाउनलोड फ़ाइल

  2. इलाज:

    • इंस्टॉलर चलाएँ
    • "सिस्टम पथ में एलएलवीएम जोड़ें" जांचें
    • स्थापना तरीका:C:\Program Files\LLVM(गलती करना)

  3. सत्यापित करें:

    llvm-config --version

विंडोज़ (स्रोत कोड से)

विस्तृत स्थापना के लिए:LLVM_SETUP.md

# LLVM kaynak kodunu indir
git clone --depth 1 --branch llvmorg-17.0.6 https://github.com/llvm/llvm-project.git

# Build dizini oluştur
cd llvm-project
mkdir build
cd build

# CMake yapılandırması
cmake -G Ninja ../llvm `
  -DCMAKE_BUILD_TYPE=Release `
  -DLLVM_TARGETS_TO_BUILD=all `
  -DCMAKE_INSTALL_PREFIX=C:\llvm-17

# Derle (2-3 saat sürebilir)
ninja
ninja install

लिनक्स (उबंटू/डेबियन)

# LLVM 17 repository ekle
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17

# Gerekli paketler
sudo apt install llvm-17-dev libllvm17 llvm-17-tools clang-17

लिनक्स (फेडोरा)

sudo dnf install llvm17-devel llvm17-libs clang17

मैकओएस (होमब्रू)

brew install llvm@17

# PATH'e ekle
echo 'export PATH="/opt/homebrew/opt/llvm@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

एलएलवीएम पर्यावरण चर

स्थापना के बाद पर्यावरण चर सेट करें:

विंडोज़ (पॉवरशेल):

$env:LLVM_SYS_170_PREFIX = "C:\llvm-17"
[Environment]::SetEnvironmentVariable("LLVM_SYS_170_PREFIX", "C:\llvm-17", "User")

Linux/macOS (बैश/Zsh):

export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17
echo 'export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17' >> ~/.bashrc

बर्क स्थापना

विधि 1: पूर्व-निर्मित बाइनरी (विंडोज़ - अनुशंसित) ⚡

Windows x64 उपयोगकर्ताओं के लिए सबसे तेज़ तरीका:

  1. डाउनलोड करना:

    • 🔗 बर्क-lang.exe (2.2 एमबी)
    • 🔗 berk-lsp.exe (1.2 एमबी)
    • 🔗 बर्क-repl.exe (464 KB)
    • तीन अलग-अलग फ़ाइलें: कंपाइलर, एलएसपी, और आरईपीएल (एलएलवीएम डायनेमिक लिंकिंग)

  2. इलाज:

    # İstediğiniz bir klasöre kopyalayın
New-Item -ItemType Directory -Path C:\BERK -Force
Move-Item .\BERK-lang.exe C:\BERK\

# PATH'e ekleyin
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\BERK",
    "User"
)

# Yeni terminal açın ve test edin
BERK-lang --version

  3. त्वरित परीक्षण:

    # REPL ile anında test
BERK-lang repl
>>> print("Merhaba!")
Merhaba!

विशेषताएँ:

  • ✅ एलएलवीएम 17 डायनेमिक लिंकिंग - सिस्टम एलएलवीएम का उपयोग करता है
  • ✅ सभी 19 लक्ष्य प्लेटफार्मों के लिए समर्थन
  • ✅ REPL, JIT रन और नेटिव कंपाइल मोड
  • ✅ रनटाइम लाइब्रेरी शामिल हैं (JSON, क्रिप्टो, HTTP)

टिप्पणियाँ:चूंकि एलएलवीएम डायनेमिक लिंकिंग का उपयोग किया गया था, कुल आकार घटकर ~3.8 एमबी हो गया (v0.8.0 में 83 एमबी था)।

विधि 2: स्रोत कोड से (सभी प्लेटफ़ॉर्म)

Linux/macOS या अनुकूलन चाहने वालों के लिए:

# Repository'yi klonla
git clone https://github.com/ArslantasM/berk.git
cd berk/berk-lang

# LLVM feature ile derle
cargo build --release --features llvm

# Test et
cargo test --features llvm

# Binary'yi PATH'e ekle (Linux/macOS)
sudo ln -s $(pwd)/target/release/BERK-lang /usr/local/bin/BERK-lang

# Binary'yi PATH'e ekle (Windows)
# target\release\BERK-lang.exe dosyasını PATH'teki bir dizine kopyalayın

संकलन समय:~40 सेकंड (रिलीज़ बिल्ड)

विधि 3: कार्गो इंस्टालेशन (भविष्य)

# Planlanan özellik
cargo install BERK-lang --features llvm

cd berk/berk-vscode
npm install
npm run compile
code --install-extension BERK-lang-0.1.0.vsix

  • इंटेलिजेंस (बुनियादी)
  • रन/डीबग कमांड
  • स्टेटस बार एकीकरण

आरईपीएल का उपयोग करना

आरईपीएल (रीड-एवल-प्रिंट लूप) मुख्य कंपाइलर के साथ आता है:

# REPL'i başlat
BERK-lang repl

आरईपीएल कमांड

BERK> :help

Kullanılabilir komutlar:
  :quit, :q      - REPL'den çık
  :help, :h      - Yardım göster
  :clear, :c     - Ekranı temizle
  :history       - Komut geçmişi
  :lang <tr|en>  - Dil değiştir (Türkçe/English)
  :type <expr>   - İfadenin tipini göster

आरईपीएल उदाहरण

सरल गणना:

>>> 5 + 3
8

>>> 10 * 2.5
25.0

चर:

>>> let isim = "BERK"
>>> print("Merhaba, " + isim)
Merhaba, BERK

कार्य:

>>> function topla(a: int, b: int) -> int { return a + b }
>>> topla(10, 20)
30

भाषा बदलना:

>>> :lang en
Language switched to English

>>> function hello(name: string) { print("Hello, " + name) }
>>> hello("World")
Hello, World

>>> :lang tr
Dil Türkçe'ye değiştirildi

समस्या निवारण

एलएलवीएम नहीं मिल सका

गलती:

error: could not find native static library `LLVM-17`

समाधान:

# LLVM_SYS_170_PREFIX doğru ayarlı mı?
echo $LLVM_SYS_170_PREFIX  # Linux/macOS
echo $env:LLVM_SYS_170_PREFIX  # Windows

# LLVM kurulu mu?
llvm-config --version

कार्गो निर्माण त्रुटि

गलती:

error: linker `link.exe` not found

समाधान (विंडोज़):

  • विजुअल स्टूडियो बिल्ड टूल्स 2022 इंस्टॉल होना चाहिए
  • "C++ के साथ डेस्कटॉप विकास" कार्यभार का चयन किया जाना चाहिए
