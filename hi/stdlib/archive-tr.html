ज़िप/टीएआर पुरालेख समर्थन - संपीड़न और निष्कर्षण

~350 पंक्तियाँ ~25 कार्य ज़िप/टीएआर

📖अवलोकन

पुरालेख मॉड्यूल ज़िप और टीएआर प्रारूपों में संग्रह निर्माण और निष्कर्षण प्रदान करता है। DEFLATE gzip और bzip2 संपीड़न का समर्थन करता है।

🚀 उपयोग

import archive

// Create ZIP
let zip = archive.new_zip()
zip.add_file("data.txt", "path/to/data.txt")?
zip.add_memory("config.json", "{}")?
zip.save("output.zip")?

// Extract
archive.unzip("archive.zip", "output_dir")?

// Quick functions
archive.zip_directory("my_folder", "backup.zip")?
