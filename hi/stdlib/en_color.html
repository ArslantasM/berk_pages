📋अवलोकन

colorमॉड्यूल आरजीबी, एचएसएल, एचएसवी कलर स्पेस, कलर मिक्सिंग और पैलेट निर्माण टूल के बीच रूपांतरण प्रदान करता है।

🎨रंग प्रतिपादन

  • रंग.आरजीबी()- आरजीबी रंग (0-255)
  • रंग.आरजीबीए()- अल्फा चैनल के साथ आरजीबी
  • रंग.एचएसएल()- एचएसएल कलर स्पेस
  • रंग.एचएसवी()- एचएसवी रंग स्थान
  • रंग.हेक्स()- हेक्स स्ट्रिंग से रंग (#FF5733)

🔄 रंग परिवर्तन

  • रंग.rgb_den_hsl()- आरजीबी → एचएसएल
  • रंग.hsl_den_rgb()- एचएसएल → आरजीबी
  • रंग.हेक्स_ई()- हेक्स स्ट्रिंग में परिवर्तित करना

🖌️ रंग हेरफेर

  • रंग.मिश्रण()- दो रंगों का मिश्रण
  • रंग.गहरा()- रंग गहरा करें
  • रंग.हल्का करें()- रंग हल्का करें
  • रंग.समायोजित_संतृप्ति()- संतृप्ति समायोजन

🎨 रंग पट्टियाँ

  • रंग.पूरक()- पूरक रंग
  • रंग.एनालॉग_रंग()- अनुरूप रंग
  • रंग.ट्रिपल_रंग()- त्रियादिक रंग
  • रंग.create_gradient()- रंग ढाल

💡 उपयोग के उदाहरण

रंग परिवर्तन

use color

// RGB renk oluştur
değer kırmızı = color.rgb(255, 0, 0)
print(f"RGB: {kırmızı}")

// Hex'e çevir
değer hex = kırmızı.hex_e()
print(f"Hex: {hex}")

// HSL'e dönüştür
değer hsl = color.rgb_den_hsl(255, 0, 0)
print(f"HSL: H={hsl.ton}, S={hsl.doygunluk}, L={hsl.parlaklık}")

// Renk karıştırma
değer mavi = color.rgb(0, 0, 255)
değer mor = color.shuffle(kırmızı, mavi, oran: 0.5)
print(f"Mor: {mor.hex_e()}")

एक रंग पैलेट बनाना

use color

// Ana renk
değer ana_renk = color.hex("#3498db")

// Tamamlayıcı renk
değer tamamlayıcı = ana_renk.tamamlayıcı()
print(f"Tamamlayıcı: {tamamlayıcı.hex_e()}")

// Analog renkler
değer analoglar = ana_renk.analog_renkler()
print("\nAnalog Renkler:")
for renk in analoglar {
    print(f"  {renk.hex_e()}")
}

// Gradyan oluştur
değer gradyan = color.gradyan_oluştur(
    color.rgb(255, 0, 0),
    color.rgb(0, 0, 255),
    adım_sayısı: 10
)

print("\nGradyan:")
for renk in gradyan {
    print(f"  {renk.hex_e()}")
}
