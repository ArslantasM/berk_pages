मॉड्यूल और संगठन

बीईआरके में, मॉड्यूल सिस्टम को आपके कोड को व्यवस्थित करने, पुन: प्रयोज्यता बढ़ाने और बड़ी परियोजनाओं को प्रबंधित करना आसान बनाने के लिए डिज़ाइन किया गया है।

मॉड्यूल बुनियादी बातें

प्रत्येक BERK फ़ाइल को एक मॉड्यूल माना जाता है। मॉड्यूल आपको संबंधित कार्यों, संरचनाओं और स्थिरांक को संयोजित करने की अनुमति देते हैं।

सरल मॉड्यूल उदाहरण

// matematik.berk
export function topla(a: sayı, b: sayı) -> sayı
do
    return a + b
end

export function çarp(a: sayı, b: sayı) -> sayı
do
    return a * b
end

export const PI = 3.14159

मॉड्यूल उपयोग

उपयोग कथन (मूल मॉड्यूल)

kullanआप अभिव्यक्ति के साथ मूल मॉड्यूल से प्रतीकों को आयात कर सकते हैं:

// Tek function içe aktarma
use matematik::topla;

// Birden fazla öğe içe aktarma
use matematik::{topla, çarp, PI};

// Tüm dışa aktarılanları içe aktarma
use matematik::*;

// Takma ad ile içe aktarma
use matematik::PI as pi_sayısı;

आयात विवरण (बाहरी पैकेज)

içe_aktarकथन का उपयोग बाहरी पैकेज स्थापित करने के लिए किया जाता है:

// Harici paket içe aktarma
import "serde" as json;

// Seçici içe aktarma
import "http"::{get, post, İstek};

मॉड्यूल संगठन

निर्देशिका संरचना

मॉड्यूल फ़ाइल सिस्टम संरचना का पालन करते हैं:

proje/
├── main.berk
├── matematik/
│   ├── temel.berk
│   ├── geometri.berk
│   └── istatistik.berk
└── String/
    ├── işlemler.berk
    └── biçimlendir.berk

मॉड्यूल पथ

// Alt modül kullanımı
kullan matematik::geometri::alan_hesapla;

// İç içe modüller
kullan matematik::geometri::{alan, çevre};

निर्यात

एकल वस्तु निर्यात

export function hesapla() -> sayı
do
    return 42
end

एकाधिक आइटम निर्यात करना

// Gruplama sözdizimi
export { fonk1, fonk2, YapıAdı };

// Her birini ayrı ayrı
export function fonk1() do end
export function fonk2() do end
export struct YapıAdı do end

दृश्यता नियम

बीईआरके में दृश्यता डिफ़ॉल्ट रूप से निजी है:

  • निर्यातआइटम का उपयोग अन्य मॉड्यूल द्वारा किया जा सकता है
  • निर्यात नहीं किया गयाआइटम केवल मॉड्यूल के भीतर उपलब्ध हैं
// Bu function dışa aktarıldı - dışarıdan erişilebilir
export function genel_işlev() do end

// Bu function dışa aktarılmadı - yalnızca module in
function özel_işlev() do end

मॉड्यूल विश्लेषण

पथ खोजें

बीईआरके कंपाइलर इस क्रम में मॉड्यूल खोजता है:

  1. वर्तमान निर्देशिका (.)
  2. ./src/निर्देशिका
  3. ./stdlib/निर्देशिका
  4. बाहरी पैकेट पथ (~/.berk/packages/)

प्रतीक प्राथमिकता

नाम विवाद के मामले में प्राथमिकता का क्रम:

  1. स्थानीय दायरा चर
  2. आयातित प्रतीक
  3. मॉड्यूल ग्लोबल्स

सर्वोत्तम प्रथाएं

मॉड्यूल संगठन सुझाव

  • ✅ समूह संबंधित कोड: समान कार्यक्षमता प्रदान करने वाला कोड एक ही मॉड्यूल में होना चाहिए
  • ✅ स्पष्ट संज्ञाओं का प्रयोग करें: मॉड्यूल नामों में सामग्री स्पष्ट रूप से इंगित होनी चाहिए
  • ✅ अनावश्यक निर्यात न करें: केवल उन तत्वों को निर्यात करें जिन्हें एपीआई का हिस्सा बनने की आवश्यकता है
  • ✅ चक्रीय निर्भरता से बचेंनिर्भरताएँ जैसे: A -> B -> A समस्याएँ पैदा करती हैं

शैलियाँ आयात करें

// ✅ İyi: Açık and okunabilir
use matematik::geometri::{domain, çevre};

// ⚠️ Dikkatli use: Tüm içe aktarmalar isim çakışmasına neden olabilir
use matematik::*;

// ✅ İyi: Uzun isimler for takma ad
use matematik::trigonometri as trig;

उन्नत विशेषताएँ

मॉड्यूल विवरण

आप किसी फ़ाइल के भीतर एक मॉड्यूल इनलाइन परिभाषित कर सकते हैं:

module yardımcılar do
    export function yardımcı() do
        print("Yardımcı function")
    end
end

use yardımcılar::yardımcı;

फिर से निर्यात

आप किसी मॉड्यूल से आयात की गई वस्तुओं को अपने स्वयं के मॉड्यूल से निर्यात कर सकते हैं:

// matematik/index.berk
use matematik::temel::*;
use matematik::geometri::*;

// Tüm alt module fonksiyonlarını dışa aktar
export *;

पैकेज प्रबंधन (बीपीएम)

बीईआरके पैकेज मैनेजर (बीपीएम) से आप बाहरी पैकेज प्रबंधित कर सकते हैं:

berk.toml कॉन्फ़िगरेशन

[package]
name = "projemiz"
version = "1.0.0"

[dependencies]
serde = "1.0"
http = "0.2"

पैकेज उपयोग

import "serde" as json;

function main() do
    let veri = json::serileştir({isim: "Ali", yaş: 30})
    print(veri)
end

नमूना परियोजना संरचना

// src/matematik/temel.berk
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

// src/matematik/geometri.berk  
export function domain(r: kesir) -> kesir do
    use matematik::temel::çarp;
    return 3.14159 * r * r
end

// src/main.berk
use matematik::temel::topla;
use matematik::geometri::domain;

function main() do
    let sonuç1 = topla(5, 3)
    let sonuç2 = domain(2.5)
    
    print("Toplam: " + sonuç1)
    print("Alan: " + sonuç2)
end
