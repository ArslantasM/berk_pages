BERK Programlama Dili

मॉड्यूल प्रणाली

बर्क मेंप्रत्येक फ़ाइल एक मॉड्यूल है. मॉड्यूल सिस्टम आपके कोड को व्यवस्थित करने और पुन: उपयोग करने का मूल तरीका है।

बुनियादी अवधारणाओं

मॉड्यूल क्या है?

मॉड्यूल कोड की एक इकाई है जिसमें संबंधित फ़ंक्शन, संरचनाएं और स्थिरांक शामिल होते हैं। प्रत्येक.berkफ़ाइल स्वचालित रूप से एक मॉड्यूल है.

// matematik.berk - Bu dosya "matematik" modülüdür
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

export const PI = 3.14159

मॉड्यूल पदानुक्रम

मॉड्यूल फ़ाइल सिस्टम संरचना का पालन करते हैं:

proje/
├── ana.berk
├── matematik/
│   ├── temel.berk       (matematik::temel)
│   ├── geometri.berk    (matematik::geometri)
│   └── ileri.berk       (matematik::ileri)
└── io/
    └── dosya.berk       (io::dosya)

मॉड्यूल उपयोग

कथन का प्रयोग करें

// Modül içe aktarma
kullan matematik;

// Belirli öğeleri içe aktarma
kullan matematik::topla;
kullan matematik::{topla, çarp, PI};

// Tüm öğeleri içe aktarma
kullan matematik::*;

// Takma ad ile kullanım
kullan matematik::topla olarak toplama;

मॉड्यूल पथ

// Alt modül erişimi
kullan matematik::geometri::alan;

// İç içe modüller
kullan matematik::geometri::{alan, çevre, hacim};

दृश्यता

निर्यात_निर्यात कीवर्ड

सभी आइटम डिफ़ॉल्ट रूप सेविशेष है. बाहरी पहुंच के लिएdışa_aktarउपयोग:

// Genel function - dışarıdan erişilebilir
export function hesapla() -> sayı do
    return dahili_hesaplama()
end

// Özel function - sadece bu modülde kullanılabilir
function dahili_hesaplama() -> sayı do
    return 42
end

संरचना और एनम दृश्यता

// Genel struct
export struct Nokta do
    x: sayı
    y: sayı
end

// Özel struct
struct DahiliVeri do
    değer: sayı
end

// matematik.berk

├── temel.berk      // matematik::temel

└── trigonometri.berk // matematik::trigonometri

// ana.berk
kullan matematik::temel::topla;
kullan matematik::geometri::alan;

मॉड्यूल विश्लेषण

खोज आदेश

बीईआरके कंपाइलर इस क्रम में मॉड्यूल खोजता है:

  1. वर्तमान निर्देशिका: ./
  2. स्रोत निर्देशिका: ./src/
  3. मानक पुस्तकालय: ./stdlib/
  4. बाहरी पैकेज: ~/.berk/packages/

उदाहरण विश्लेषण

kullan matematik::geometri;
// Arama sırası:
// 1. ./matematik/geometri.berk
// 2. ./src/matematik/geometri.berk
// 3. ./stdlib/matematik/geometri.berk
// 4. ~/.berk/packages/matematik/geometri.berk

मानक पुस्तकालय मॉड्यूल

use io;              // Giriş/Çıkış işlemleri
use String;           // String işlemleri
use matematik;       // Matematik fonksiyonları
use koleksiyonlar;   // Liste, HashMap vb.
use dosya;           // Dosya işlemleri
use ağ;              // Network işlemleri

सर्वोत्तम प्रथाएं

  • ✅ समूह संबंधित कोड: समान कार्यों को एक ही मॉड्यूल में रखें
  • ✅ स्पष्ट संज्ञाओं का प्रयोग करें: मॉड्यूल नाम में सामग्री स्पष्ट रूप से इंगित होनी चाहिए
  • ✅ न्यूनतम निर्यात: केवल वही निर्यात करें जो आवश्यक हो
  • ✅ चक्रीय निर्भरता से बचें: A → B → A बनाना
  • ✅ सुसंगत संरचना: प्रोजेक्ट के सभी मॉड्यूल की संरचना समान होनी चाहिए

उदाहरण

सरल गणित मॉड्यूल

// matematik.berk
export const PI = 3.14159
export const E = 2.71828

export function kare(x: sayı) -> sayı do
    return x * x
end

export function küp(x: sayı) -> sayı do
    return x * x * x
end

प्रयोग

// main.berk
use matematik::{kare, PI};

function main() do
    let sonuç = kare(5)
    print("Kare: {}", sonuç)
    print("Pi: {}", PI)
end
