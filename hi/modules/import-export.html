आयात और निर्यात

बर्क में मॉड्यूल के बीच कोड साझा करनाkullan, içe_aktarऔरdışa_aktarयह कीवर्ड के साथ किया जाता है.

निर्यात_निर्यात

बुनियादी उपयोग

dışa_aktarकीवर्ड किसी तत्व को अन्य मॉड्यूल से पहुंच योग्य बनाता है:

// Fonksiyon dışa aktarma
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

// Sabit dışa aktarma
export const MAKSIMUM = 100

// Yapı dışa aktarma
export struct Nokta do
    x: sayı
    y: sayı
end

// Enum dışa aktarma
export enum Renk do
    Kırmızı
    Yeşil
    Mavi
end

समूह निर्यात

// Birden fazla öğeyi birlikte dışa aktar
export { topla, çarp, split, PI, Nokta };

// Veya tek tek
export function topla(a: sayı, b: sayı) -> sayı do return a + b end
export function çarp(a: sayı, b: sayı) -> sayı do return a * b end

डिफ़ॉल्ट दृश्यता

बर्क में डिफ़ॉल्ट दृश्यतानिजीहै:

// Bu function SADECE bu modülde kullanılabilir
function dahili_fonksiyon() do
    // özel kod
end

// Bu function DİĞER modüllerden erişilebilir
export function genel_fonksiyon() do
    dahili_fonksiyon()  // Modül in kullanılabilir
end

उपयोग (उपयोग) - स्थानीय मॉड्यूल

सरल आयात

// Tek bir function
use matematik::topla;

// Birden fazla öğe
use matematik::{topla, çarp, split};

// Tüm dışa aktarılanlar
use matematik::*;

सबमॉड्यूल उपयोग

// İç içe modül yolları
kullan matematik::geometri::alan;
kullan matematik::geometri::{alan, çevre, hacim};

// Modülün kendisini içe aktar
kullan matematik::geometri;
// Kullanımı: geometri::alan(5.0)

एलियासिंग

// Fonksiyon for takma ad
use matematik::topla as toplama;
use matematik::çarp as product;

// Modül for takma ad
use matematik::geometri as geo;

// Kullanım
let sonuç = toplama(5, 10)
let domain = geo::daire_alanı(3.0)

आयात (आयात) - बाहरी पैकेज

बाहरी पैकेज उपयोग

içe_aktarपरियोजना में बाहरी पैकेज शामिल हैं:

// Tüm paketi içe aktar
import "serde" as json;

// Belirli öğeleri içe aktar
import "http"::{get, post, İstek};

// Versiyon belirterek
import "json@1.0.5";

पैकेज विन्यास

berk.tomlफ़ाइल में निर्भरताएँ:

[dependencies]
serde = "1.0"
http = "0.2"
json = { version = "1.0", features = ["preserve_order"] }

आयात उदाहरण

// main.berk in:

// Temel matematik fonksiyonları
use matematik::temel::{topla, çarp};

// Geometri modülünün tamamı
use matematik::geometri;

// İç içe module
use matematik::ileri::calculus::türev;

// IO modülü
use io::dosya::{input, print};

पुन: निर्यात

एक मॉड्यूल दूसरे मॉड्यूल से आयातित वस्तुओं को पुनः निर्यात कर सकता है:

// matematik/index.berk
kullan matematik::temel::topla;
kullan matematik::geometri::alan;

// Yeniden dışa aktar
dışa_aktar { topla, alan };

// ana.berk
kullan matematik::{topla, alan};  // Her ikisi de kullanılabilir

वाइल्डकार्ड आयात

// Tüm dışa aktarılanları içe aktar
use matematik::*;

// Kullanım
let sonuç = topla(5, 10)  // matematik::topla çağrıldı

⚠️ ध्यान: वाइल्डकार्ड आयात के कारण नाम में विवाद हो सकता है। सावधानी के साथ प्रयोग करें!

परिपत्र निर्भरताएँ

बीईआरके सर्कुलर निर्भरता की अनुमति नहीं देता है:

// ❌ YANLIŞ: A → B → A
// modül_a.berk
use modül_b;

// modül_b.berk
use modül_a;  // HATA: Döngüsel bağımlılık!

✅ समाधान: बॉयलरप्लेट कोड को तीसरे मॉड्यूल में ले जाएं:

// ortak.berk
export function paylaşılan() do end

// modül_a.berk
use ortak;

// modül_b.berk
use ortak;

सर्वोत्तम प्रथाएं

आयात खोलें

// ✅ İyi: Açık ve okunabilir
kullan matematik::{topla, çarp, PI};

// ❌ Kötü: Ne içe aktarıldığı belirsiz
kullan matematik::*;

// ✅ İyi: Sadece gerekli API
export function işle() do
    dahili_yardımcı()
end

function dahili_yardımcı() do
    // özel implementasyon
end

// ❌ Kötü: Gereksiz dışa aktarma
export function dahili_yardımcı() do end

सारांश

  • ✅ dışa_aktar: वस्तुओं को बाहर की ओर खोलता है
  • ✅ kullan: देशी मॉड्यूल से आयात
  • ✅ içe_aktar: बाहरी पैकेज स्थापित करता है
  • ✅ olarak: एक उपनाम बनाता है
  • ✅ ::: मॉड्यूल पथ विभाजक
  • ✅ *: सभी वस्तुओं का आयात करता है (सावधानी के साथ उपयोग करें)
  • ❌ चक्रीय निर्भरता से बचें
  • ✅ खुले आयात को प्राथमिकता दें
