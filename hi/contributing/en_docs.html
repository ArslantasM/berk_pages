दस्तावेज़ीकरण योगदान

बीईआरके के दस्तावेज़ीकरण को बेहतर बनाने में योगदान देने के लिए मार्गदर्शिका। किसी भी दस्तावेज़ीकरण योगदान की सराहना की जाती है!

📚 दस्तावेज़ीकरण के प्रकार

1. एमडीबुक दस्तावेज़ीकरण

मुख्य दस्तावेज़ीकरण पुस्तक (जिसे आप वर्तमान में पढ़ रहे हैं)

  • जगह: berk-lang/book/src/
  • प्रारूप:मार्कडाउन (.md)
  • औजार:एमडीबुक

2. एपीआई दस्तावेज़ीकरण

इन-कोड दस्तावेज़ टिप्पणियाँ जंग

  • जगह: berk-lang/src/
  • प्रारूप:रस्टडॉक टिप्पणियाँ (///)
  • औजार:कार्गो दस्तावेज़

3. एसटीडीलिब दस्तावेज़ीकरण

मानक पुस्तकालय मॉड्यूल विवरण

  • जगह: stdlib/*.berk
  • प्रारूप:बर्क दस्तावेज़ टिप्पणियाँ (///)

4. गिटहब पेज

HTML दस्तावेज़ प्रकाशित

  • जगह: berk_pagesकोष
  • यूआरएल:https://arslantasm.github.io/berk_pages/

/// İki sayıyı toplar and sonucu döndürür.
///
/// Bu function iki tam sayı alır and toplamlarını hesaplar.
/// Overflow kontrolü yapmaz.
///
/// # Parameters
/// * `a` - İlk sayı
/// * `b` - İkinci sayı
///
/// # Döndürür
/// İki sayının toplamı
///
/// # Examples
/// ```berk
/// variable sonuç = topla(5, 3)  // 8
/// variable büyük = topla(1000000, 2000000)  // 3000000
/// ```
///
/// # Err Durumları
/// Overflow durumunda tanımsız davranış
function topla(a: tam, b: tam) -> tam {
    döndür a + b
}

    </div>

  • ☑️ क्या कोड उदाहरणों का परीक्षण किया गया है?
  • ☑️ क्या लिंक काम करते हैं?
  • ☑️ यदि चित्र हैं, तो क्या उन्हें अपलोड किया गया है?
  • ☑️ क्या वर्तनी त्रुटि की जाँच कर ली गई है?

  • ☑️ क्या परिवर्तन सार्थक है?

  • ☑️ क्या नई सुविधाएँ जोड़ी गई हैं?

🚀 दस्तावेज़ीकरण प्रकाशित करें

GitHub पेज अपडेट

# mdBook build
cd berk-lang/book
mdbook build

# berk_pages repository'ye kopyala
cp -r book/html/* ../../berk_pages/

# Commit and push
cd ../../berk_pages
git add .
git commit -m "docs: Documentation güncellendi"
git push origin main

# GitHub Pages otomatik deploy eder (~2-3 dakika)

एपीआई डॉक्स प्रकाशित

# Rustdoc oluşturma
cd berk-lang
cargo doc --no-deps --open

# docs/ klasörüne kopyala
cp -r target/doc docs/api

💡अच्छे आचरण

  • ✅ प्रत्येक उदाहरणकार्य करना चाहिए
  • ✅ उदाहरणन्यूनतमहोना चाहिए (एकल अवधारणा)
  • ✅ तुर्की और अंग्रेजीउदाहरण दीजिए
  • ✅ त्रुटि बताती हैसमझाना
  • ✅ प्रदर्शन नोटजोड़ें (यदि आवश्यक हो)
  • ✅ संबंधित पेजों से लिंक करेंदेना
  • ✅ इमेजिसउपयोग करें (आरेख, स्क्रीनशॉट)

📊 गुणवत्ता मेट्रिक्स

  • कवरेज:सभी सार्वजनिक एपीआई का दस्तावेजीकरण किया जाना चाहिए
  • उदाहरण:प्रत्येक फ़ंक्शन के लिए कम से कम 1 उदाहरण की आवश्यकता होती है
  • सामयिकता:अस्वीकृत सुविधाओं को चिह्नित किया जाना चाहिए
  • लिंक:कोई टूटी कड़ियाँ नहीं होनी चाहिए

🎯योगदान युक्तियाँ

  • छोटे पीआर सबमिट करें (एक पृष्ठ/अनुभाग)
  • टाइपो पीआर का हमेशा स्वागत है
  • उदाहरण जोड़ना सबसे आसान योगदान है
  • छवियाँ/आरेख जोड़ना बहुत मूल्यवान है
  • अंग्रेजी अनुवाद सहायता की आवश्यकता है
