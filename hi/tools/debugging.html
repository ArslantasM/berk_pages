BERK Programlama Dili

डिबगिंग

बर्क,आधुनिक डिबगिंग उपकरणयह मजबूत डिबगिंग समर्थन प्रदान करता है। DWARF/PDB डिबग प्रतीकों, GDB/LLDB एकीकरण और VS कोड डिबगिंग के साथ व्यावसायिक विकास का अनुभव।

डिबग बिल्ड

डिबग प्रतीकों को सक्रिय करना

# Debug modda derle (optimizasyon yok, debug sembolleri var)
berk-lang build --debug

# Veya
berk-lang build -g

डिबग बनाम रिलीज़

विशेषताडीबग (-जी)रिलीज़ (-O2)
डिबग प्रतीक✅ हाँ❌ कोई नहीं
अनुकूलन❌ कोई नहीं (-O0)✅ हाँ (-O2)
संकलन की गति🚀 तेज🐌धीमा
कार्य करने की गति🐌धीमा🚀 तेज़ (10-50x)
बाइनरी आकार📦 बड़ा📦 छोटा
स्टैक ट्रेस✅ विस्तृत⚠️ लिमिटेड

जीडीबी डिबगर

बुनियादी उपयोग

# Program GDB ile başlat
gdb ./output

# GDB in
(gdb) run                    # Programı çalıştır
(gdb) break main.berk:10     # 10. satıra breakpoint
(gdb) continue               # Devam et
(gdb) next                   # Sonraki satır (step over)
(gdb) step                   # Fonksiyon içine gir (step into)
(gdb) print x                # Değişken değeri
(gdb) backtrace              # Call stack
(gdb) quit                   # Çık

ब्रेकप्वाइंट प्रकार

# Satır breakpoint
(gdb) break main.berk:25

# Fonksiyon breakpoint
(gdb) break hesapla

# Koşullu breakpoint
(gdb) break main.berk:30 if x > 10

# Watchpoint (let değiştiğinde break)
(gdb) watch x

# Tüm breakpointleri listele
(gdb) info breakpoints

# Breakpoint sil
(gdb) delete 1

परिवर्तनीय समीक्षा

# Basit let
(gdb) print x
$1 = 42

# Struct
(gdb) print kisi
$2 = {isim = \"Ali\", yaş = 25}

# Array
(gdb) print sayılar[0]@5  # İlk 5 eleman

# Pointer
(gdb) print *ptr

# Format belirle
(gdb) print/x x           # Hex
(gdb) print/t x           # Binary
(gdb) print/f x           # Float

एलएलडीबी डिबगर

बुनियादी आदेश

# LLDB başlat
lldb ./output

# LLDB in
(lldb) run
(lldb) breakpoint set --file main.berk --line 10
(lldb) breakpoint set --name hesapla
(lldb) continue
(lldb) next
(lldb) step
(lldb) frame variable x
(lldb) bt                    # Backtrace
(lldb) quit

वीएस कोड डिबगिंग सुविधाएँ

1. ब्रेकप्वाइंट

  • ✅ लाइन ब्रेकप्वाइंट (F9)
  • ✅ सशर्त ब्रेकप्वाइंट (राइट क्लिक)
  • ✅ लॉगप्वाइंट (प्रिंट आउटपुट, रुकता नहीं है)
  • ✅ फ़ंक्शन ब्रेकप्वाइंट

2. कदम रखना

शॉर्टकटकार्रवाई
F5जारी रखना
F10स्टेप ओवर (फ़ंक्शन पर जाएँ)
F11कदम बढ़ाएँ (फ़ंक्शन के अंदर जाएँ)
शिफ्ट+F11बाहर निकलें (निकास समारोह)
Ctrl+Shift+F5पुनः आरंभ करें
शिफ्ट+F5रुकना

3. चर पैनल

बाईं ओर "चर" पैनल में:

  • स्थानीय चर
  • सार्वत्रिक चर
  • परिवर्तनीय मान संपादित करें

4. भाव देखें

"वॉच" पैनल में जोड़ें:

x * 2
kisi.isim
sayılar.len()

5. कॉल स्टैक

फ़ंक्शन कॉल इतिहास दिखाता है - किसी भी फ़्रेम पर क्लिक करें

6. डिबग कंसोल

सजीव अभिव्यक्ति मूल्यांकन:

// Debug Console'da
x + 10
kisi.isim
hesapla(5, 10)

सशर्त ब्रेकप्वाइंट उदाहरण

// Sadece x > 100 olduğunda break
function işle(x: sayı) do
    if x < 0 do  // Breakpoint burada: x < 0
        return 0
    end
    return x * 2
end

लॉगपॉइंट का उपयोग करना

लाइन नंबर पर राइट क्लिक करें → "लॉगपॉइंट जोड़ें":

x değeri: {x}, y değeri: {y}

प्रोग्राम रुकता नहीं है, यह सिर्फ लॉग प्रिंट करता है

एंबेडेड डिबगिंग

ESP32 JTAG डिबगिंग

# OpenOCD başlat
openocd -f board/esp32.cfg

# GDB bağlan
xtensa-esp32-elf-gdb output.elf
(gdb) target remote :3333
(gdb) monitor reset halt
(gdb) break main
(gdb) continue

STM32 SWD डिबगिंग

# ST-Link ile
st-util

# GDB
arm-none-eabi-gdb output.elf
(gdb) target remote :4242
(gdb) load
(gdb) break main
(gdb) continue

प्रदर्शन प्रोफ़ाइलिंग

लिनक्स (पूर्ण)

# Profiling verisi topla
perf record -g ./output

# Analiz et
perf report

# Flame graph
perf script | flamegraph.pl > flame.svg

विंडोज़ (प्रदर्शन विश्लेषक)

# Visual Studio Profiler
devenv /DebugExe output.exe

मेमोरी डिबगिंग

वालग्रिंड (लिनक्स)

# Memory leak kontrolü
valgrind --leak-check=full ./output

# Cache profiling
valgrind --tool=cachegrind ./output

पता सेनिटाइजर

# LLVM AddressSanitizer ile derle
berk-lang build --sanitizer=address

# Çalıştır - memory hataları otomatik yakalanır
./output

सर्वोत्तम अभ्यासों को डिबग करना

  1. ✅ डिबग बिल्ड का उपयोग करें:

    berk-lang build --debug

  2. ✅ लॉगप्वाइंट को प्राथमिकता दें(कार्यक्रम नहीं रुकता)

  3. ✅ सशर्त विराम बिंदुउपयोग करें (लूप में)

  4. ✅ भाव देखेंजोड़ें (जटिल अभिव्यक्ति)

  5. ⚠️ अनुकूलन बंदडिबग मोड में होना चाहिए

  6. ⚠️ स्टैक ओवरफ़्लोनियंत्रण:

    ulimit -s unlimited  # Linux

डिबगिंग तकनीक

1. बाइनरी सर्च डिबगिंग

कोड के आधे भाग में ब्रेकप्वाइंट लगाएं - कौन सा आधा भाग त्रुटि है?

2. रबर डक डिबगिंग

कोड को पंक्ति दर पंक्ति समझाएं (स्वयं को या किसी को)

3.प्रिंट डिबगिंग

print(\"x değeri: {}\", x)
print(\"Buraya geldi mi?\")

4.अभिकथन का उपयोग

iddia_et(x > 0, \"x pozitif olmalı\")

समस्या निवारण

कोई डिबग प्रतीक नहीं

# Kontrol et
file output.exe | grep \"not stripped\"

# Strip edilmişse yeniden derle
berk-lang build --debug

ब्रेकपॉइंट रुकता नहीं है

  1. सुनिश्चित करें कि यह डिबग मोड में संकलित है
  2. अनुकूलन बंद होना चाहिए (-O0)
  3. क्या लाइन नंबर सही है?

परिवर्तनीय मान नहीं दिखाए गए

अनुकूलन ने वेरिएबल को हटा दिया होगा - डिबग बिल्ड का उपयोग करें
