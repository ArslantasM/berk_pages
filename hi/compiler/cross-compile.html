BERK Programlama Dili

पार संकलन

बर्क,एलएलवीएम बैकएंडइसके लिए धन्यवाद, यह कई अलग-अलग प्लेटफार्मों के लिए संकलित हो सकता है। आप एक प्लेटफ़ॉर्म पर विकास कर सकते हैं और दूसरे प्लेटफ़ॉर्म के लिए बायनेरिज़ तैयार कर सकते हैं।

क्रॉस-संकलन क्या है?

पार संकलनएक प्लेटफ़ॉर्म (होस्ट) पर दूसरे प्लेटफ़ॉर्म (लक्ष्य) के लिए कोड संकलित करना है:

  • भगाना: प्लेटफ़ॉर्म जिस पर संकलन बनाया गया था (उदाहरण: Windows x64)
  • लक्ष्य: प्लेटफ़ॉर्म जिस पर बाइनरी चलेगी (उदाहरण: लिनक्स एआरएम)

उदाहरण: आपके विंडोज पीसी पर रास्पबेरी पाई के लिए प्रोग्राम संकलित करना

बुनियादी उपयोग

# Target platform belirt
berk-lang build --target=<target-triple> program.berk

# Örnek: Windows'ta Linux for derle
berk-lang build --target=x86_64-unknown-linux-gnu program.berk

लक्ष्य ट्रिपल प्रारूप

लक्ष्य विशिष्टता प्रारूप:<arch>-<vendor>-<os>-<abi>

  • मेहराब: आर्किटेक्चर (x86_64, aarch64, आर्म, wasm32...)
  • विक्रेता: निर्माता (पीसी, सेब, अज्ञात...)
  • ओएस: ऑपरेटिंग सिस्टम (विंडोज़, लिनक्स, डार्विन, कोई नहीं...)
  • भाई: एबीआई (जीएनयू, एमएसवीसी, मसल, ईएबीआई...)

समर्थित प्लेटफार्म

डेस्कटॉप प्लेटफार्म

प्लैटफ़ॉर्मलक्ष्य ट्रिपलबाइनरी प्रारूप
विंडोज़ x64x86_64-pc-windows-msvc।प्रोग्राम फ़ाइल
विंडोज़ x86i686-pc-windows-msvc।प्रोग्राम फ़ाइल
लिनक्स x64x86_64-unknown-linux-gnuयोगिनी
लिनक्स ARM64aarch64-unknown-linux-gnuयोगिनी
मैकओएस x64x86_64-apple-darwinमच-ओ
मैकओएस एआरएमaarch64-apple-darwinमच-ओ

उदाहरण

# Windows x64
berk-lang build --target=x86_64-pc-windows-msvc program.berk -o program.exe

# Linux x64
berk-lang build --target=x86_64-unknown-linux-gnu program.berk -o program

# macOS ARM (M1/M2)
berk-lang build --target=aarch64-apple-darwin program.berk -o program

वेबअसेंबली (WASM)

प्लैटफ़ॉर्मलक्ष्य ट्रिपलउपयोग
WASM (ब्राउज़र)wasm32-unknown-unknownवेब अनुप्रयोग
मैं थाwasm32-wasiस्टैंडअलोन WASM

ब्राउज़र WASM

# WebAssembly derle
berk-lang build --target=wasm32-unknown-unknown program.berk -o program.wasm

# Optimize edilmiş (küçük boyut)
berk-lang build --target=wasm32-unknown-unknown --opt-size program.berk -o program.wasm

WASI (स्टैंडअलोन)

# WASI ile derle
berk-lang build --target=wasm32-wasi program.berk -o program.wasm

# Wasmtime ile çalıştır
wasmtime program.wasm

अंतः स्थापित प्रणालियाँ

एआरएम कॉर्टेक्स-एम (STM32)

एमसीयू परिवारलक्ष्य ट्रिपल
कॉर्टेक्स-M0/M0+thumbv6m-none-eabi
कॉर्टेक्स- एम 3thumbv7m-none-eabi
कॉर्टेक्स-एम4/एम7thumbv7em-none-eabi
कॉर्टेक्स-एम4एफ/एम7एफthumbv7em-none-eabihf
# STM32F4 for derle (Cortex-M4 with FPU)
berk-lang build --target=thumbv7em-none-eabihf program.berk -o firmware.elf

ईएसपी32 (एक्सटेन्सा)

# ESP32 for derle
berk-lang build --target=xtensa-esp32-none-elf program.berk -o firmware.bin

# ESP32-S3 for
berk-lang build --target=xtensa-esp32s3-none-elf program.berk

रास्पबेरी पाई पिको (आरपी2040)

# RP2040 for derle
berk-lang build --target=thumbv6m-none-eabi program.berk -o firmware.uf2

अरुडिनो (एवीआर)

# Arduino Uno (ATmega328P) for
berk-lang build --target=avr-unknown-gnu-atmega328 program.berk -o firmware.hex

# Arduino Mega (ATmega2560) for
berk-lang build --target=avr-unknown-gnu-atmega2560 program.berk

क्रॉस संकलन सेटअप

विंडोज़ → लिनक्स

# 1. Linux toolchain kur
berk-lang target add x86_64-unknown-linux-gnu

# 2. Derle
berk-lang build --target=x86_64-unknown-linux-gnu program.berk

लिनक्स → विंडोज़

# MinGW-w64 kur
sudo apt install mingw-w64

# Target ekle
berk-lang target add x86_64-pc-windows-gnu

# Derle
berk-lang build --target=x86_64-pc-windows-gnu program.berk -o program.exe

मैकओएस → लिनक्स

# Cross-compiler kur
brew install FiloSottile/musl-cross/musl-cross

# Derle
berk-lang build --target=x86_64-unknown-linux-musl program.berk

लक्ष्य प्रबंधन

# Mevcut target'ları listele
berk-lang target list

# Yeni target push
berk-lang target add aarch64-unknown-linux-gnu

# Target kaldır
berk-lang target remove aarch64-unknown-linux-gnu

# Varsayılan target ayarla
berk-lang target default x86_64-pc-windows-msvc

Berk.toml के साथ बहु-लक्ष्य

[package]
name = "my_app"
version = "1.0.0"

# Varsayılan target
[build]
default-target = "x86_64-pc-windows-msvc"

# Her platform for özel ayarlar
[target.x86_64-pc-windows-msvc]
linker = "link.exe"

[target.x86_64-unknown-linux-gnu]
linker = "gcc"
strip = true

[target.wasm32-unknown-unknown]
optimization = "size"
lto = true

यूनिवर्सल बाइनरी (मैकओएस)

इंटेल और एआरएम मैक के लिए एकल बाइनरी:

# Intel derle
berk-lang build --target=x86_64-apple-darwin program.berk -o program_intel

# ARM derle
berk-lang build --target=aarch64-apple-darwin program.berk -o program_arm

# Universal binary oluştur
lipo -create program_intel program_arm -output program

Sysroot और लिंकर सेटिंग्स

# Custom sysroot
berk-lang build --target=aarch64-unknown-linux-gnu \
  --sysroot=/opt/cross/aarch64-linux-gnu \
  program.berk

# Custom linker
berk-lang build --target=x86_64-unknown-linux-gnu \
  --linker=clang \
  program.berk

प्लेटफार्म विशेष कोड

सशर्त संकलन

#[if(hedef_os = "windows")]
function platform_özel() do
    print("Windows üzerinde çalışıyorum")
end

#[if(hedef_os = "linux")]
function platform_özel() do
    print("Linux üzerinde çalışıyorum")
end

#[if(hedef_arch = "wasm32")]
function platform_özel() do
    print("WebAssembly'de çalışıyorum")
end

प्लेटफ़ॉर्म स्थिरांक

const PLATFORM = #hedef_os
const ARCH = #hedef_arch

function main() do
    print("Platform: {}", PLATFORM)
    print("Mimari: {}", ARCH)
end

सर्वोत्तम प्रथाएं

  1. ✅ सीआई/सीडी के साथ परीक्षण करें:

    # GitHub Actions
jobs:
  build:
    strategy:
      matrix:
        target:
          - x86_64-pc-windows-msvc
          - x86_64-unknown-linux-gnu
          - aarch64-apple-darwin

  2. ✅ प्लेटफ़ॉर्म सुविधाओं का उपयोग करें:

    [features]
windows = []
linux = []
embedded = []

  3. ✅ बाइनरी आकार पर ध्यान दें(एम्बेडेड के लिए):

    berk-lang build --target=thumbv7em-none-eabihf --opt-size program.berk

  4. ⚠️ अंतहीनता का एहसास करोध्यान:

    • x86/एआरएम: लिटिल-एंडियन
    • कुछ एम्बेडेड: बिग-एंडियन

क्रॉस-संकलित बायनेरिज़ को डिबग करना

QEMU के साथ परीक्षण

# ARM binary'yi x86 PC'de çalıştır
qemu-arm program_arm

# Debug mode
qemu-arm -g 1234 program_arm
gdb-multiarch program_arm
(gdb) target remote :1234

रिमोट डिबगिंग

# Hedef cihazda gdbserver çalıştır
gdbserver :1234 program

# Host'ta bağlan
gdb program
(gdb) target remote 192.168.1.100:1234
