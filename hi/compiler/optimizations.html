BERK Programlama Dili

अनुकूलन स्तर

बर्क संकलक,एलएलवीएम अनुकूलकअधिकतम प्रदर्शन के लिए आपके कोड को अनुकूलित करता है

अनुकूलन स्तर

स्तरझंडाउपयोगसंकलनप्रदर्शनबाइनरी आकार
ओ0-O0डिबग🚀 बहुत तेज़🐌धीमा📦 बड़ा
O1-O1आधार⚡ तेज⚡मध्यम📦 मध्यम
O2-O2गलती करना🐌धीमा🚀 तेज📦 छोटा
ओ 3-O3अधिकतम🐌 सबसे धीमा🚀 सबसे तेज़📦 परिवर्तनीय

-O0 (कोई अनुकूलन नहीं)

berk-lang build --opt=0 program.berk
# veya
berk-lang build -O0 program.berk

विशेषताएँ:

  • ✅ सबसे तेज़ संकलन समय
  • ✅ डिबग प्रतीक संरक्षित हैं
  • ✅ स्टैक ट्रेस सही है
  • ❌ बहुत धीमा संचालन
  • ❌ बड़ा बाइनरी आकार

उपयोग का क्षेत्र: विकास और डिबगिंग

-O1 (बुनियादी अनुकूलन)

berk-lang build --opt=1 program.berk

कार्यान्वित अनुकूलन:

  • लगातार मोड़ना:5 + 10 → 15
  • डेड कोड उन्मूलन: अप्रयुक्त कोड हटा दिया जाता है
  • बेसिक इनलाइनिंग: बहुत छोटे फ़ंक्शन इनलाइन होते हैं
  • रजिस्टर आवंटन: रजिस्टरों को चर आवंटित किए जाते हैं

प्रदर्शन: ~2-5x त्वरण (O0 के सापेक्ष)

-O2 (पूर्ण अनुकूलन - डिफ़ॉल्ट)

berk-lang build --opt=2 program.berk
# veya sadece
berk-lang build --release program.berk

कार्यान्वित अनुकूलन:

  • सभी O1 अनुकूलन
  • लूप अनुकूलन: लूप त्वरण
  • फ़ंक्शन इनलाइनिंग: मध्यम आकार के कार्य
  • वैश्वीकरण: SIMD निर्देश
  • टेल कॉल अनुकूलन: पुनरावर्ती कॉल अनुकूलित करें
  • सामान्य उपअभिव्यक्ति उन्मूलन

प्रदर्शन: ~10-20x त्वरण (O0 के सापेक्ष)

-O3 (आक्रामक अनुकूलन)

berk-lang build --opt=3 program.berk

कार्यान्वित अनुकूलन:

  • सभी O2 अनुकूलन
  • आक्रामक इनलाइनिंग: यहां तक ​​कि बड़े फ़ंक्शन भी इनलाइन होते हैं
  • लूप का खुलना: लूप खोलता है
  • सट्टा निष्पादन
  • अंतरप्रक्रियात्मक अनुकूलन

प्रदर्शन: ~15-30x त्वरण (O0 के सापेक्ष)

⚠️ ध्यान: संकलन का समय बहुत लंबा है, बाइनरी आकार बढ़ सकता है

कस्टम अनुकूलन

एलटीओ (लिंक-टाइम ऑप्टिमाइज़ेशन)

सभी मॉड्यूल एक साथ अनुकूलित हैं:

berk-lang build --lto program.berk

लाभ:

  • क्रॉस-मॉड्यूल इनलाइनिंग
  • डेड कोड उन्मूलन (पूर्ण कार्यक्रम)
  • 10-30% प्रदर्शन में वृद्धि

नुकसान: बहुत लंबा संकलन समय

पीजीओ (प्रोफ़ाइल-निर्देशित अनुकूलन)

प्रोग्राम चलाकर यह प्रोफाइल एकत्र करता है, फिर उन्हें अनुकूलित करता है:

# 1. Profiling for derle
berk-lang build --profile-generate program.berk -o program.exe

# 2. Programı çalıştır (profil topla)
./program.exe

# 3. Profil kullanarak optimize et
berk-lang build --profile-use=default.profdata program.berk -o program_optimized.exe

प्रदर्शन: 15-40% अतिरिक्त त्वरण

आकार अनुकूलन

बाइनरी आकार कम करने के लिए:

# Boyut optimizasyonu
berk-lang build --opt-size program.berk

# Aggressive size optimization
berk-lang build --opt-size-aggressive program.berk

# Strip sembolleri
berk-lang build --strip program.berk

निष्कर्ष: 30-70% छोटी बाइनरी

अनुकूलन तकनीक

लगातार तह

// Kaynak kod
let x = 5 + 10 * 2

// Optimize sonrası
let x = 25

मृत संहिता उन्मूलन

// Kaynak kod
function hesapla() -> sayı do
    let x = 10
    let y = 20  // Kullanılmıyor
    return x
end

// Optimize sonrası
function hesapla() -> sayı do
    return 10
end

फ़ंक्शन इनलाइनिंग

// Kaynak kod
function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

let sonuç = topla(5, 10)

// Optimize sonrası (O2+)
let sonuç = 15  // Fonksiyon çağrısı yok!

लूप का खुलना

// Kaynak kod
for i 0'from 4'e do
    print(i)
end

// Optimize sonrası (O3)
print(0)
print(1)
print(2)
print(3)

वैश्वीकरण (SIMD)

// Kaynak kod
let a: [sayı; 4] = [1, 2, 3, 4]
let b: [sayı; 4] = [5, 6, 7, 8]
let c: [sayı; 4]

for i 0'from 4'e do
    c[i] = a[i] + b[i]
end

// Optimize sonrası (O2+ SIMD)
// Tek SIMD instruction ile 4 toplama birden!
// paddq xmm0, xmm1

अनुकूलन नियंत्रण

विशिष्ट अनुकूलन सक्षम/अक्षम करें

# Inlining'i kapat
berk-lang build -O2 --no-inline program.berk

# Vectorization'ı kapat
berk-lang build -O2 --no-vectorize program.berk

# Loop unrolling'i kapat
berk-lang build -O3 --no-unroll-loops program.berk

फ़ंक्शन आधारित अनुकूलन

// Bu fonksiyonu inline etme
#[no_inline]
function debug_fonksiyon() do
    // debug kodu
end

// Bu fonksiyonu her zaman inline et
#[always_inline]
function hızlı_işlem() do
    // kritik kod
end

किस स्तर का उपयोग करें?

परिस्थितिसुझावकहां से
🔧विकास-O0तेज़ संकलन, आसान डिबग
🧪परीक्षण-O1मध्यम प्रदर्शन, तेज़ संकलन
🚀 उत्पादन-O2अच्छा प्रदर्शन, उचित संकलन
🏆 अधिकतम गति-O3 --ltoसर्वोत्तम प्रदर्शन
📦 छोटी बाइनरी--opt-sizeअंतः स्थापित प्रणालियाँ

berk.toml कॉन्फ़िगरेशन

[build]
optimization = 2          # Varsayılan: O2
lto = true               # Link-Time Optimization
strip = false            # Debug sembolleri koru

[profile.dev]
optimization = 0
debug = true

[profile.release]
optimization = 3
lto = true
strip = true

[profile.bench]
optimization = 3
lto = true
pgo = true

प्रोफ़ाइल उपयोग

# Dev profili
berk-lang build --profile=dev program.berk

# Release profili
berk-lang build --profile=release program.berk

# Bench profili
berk-lang build --profile=bench program.berk

अनुकूलन युक्तियाँ

  1. ✅ रिलीज़ बिल्ड का उपयोग करें:

    berk-lang build --release program.berk

  2. ✅ एलटीओ जोड़ें(उत्पादन के लिए):

    berk-lang build --release --lto program.berk

  3. ✅ पीजीओ का प्रयोग करें(महत्वपूर्ण अनुप्रयोग):

    berk-lang build --profile-generate program.berk
./program.exe  # Profil topla
berk-lang build --profile-use=default.profdata program.berk

  4. ⚠️ ओ3 सावधान: कभी-कभी O2 से भी धीमा

  5. ⚠️ यदि बाइनरी आकार मायने रखता है: --opt-sizeउपयोग

सारांश

  • ✅ -ओ0: डीबग, तेज़ संकलन
  • ✅ -ओ1: बुनियादी अनुकूलन
  • ✅ -ओ2: उत्पादन (डिफ़ॉल्ट)
  • ✅ -ओ3: अधिकतम गति
  • ✅ --lto: +10-30% प्रदर्शन
  • ✅ --पीजीओ: +15-40% प्रदर्शन
  • ✅ --ऑप्ट-आकार: छोटा बाइनरी
