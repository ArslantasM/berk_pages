एलएलवीएम इंस्टालेशन

मूल कोड जनरेशन के लिए BERK LLVM 17 का उपयोग करता है।

विंडोज़ (पूर्व-संकलित)

  1. एलएलवीएम 17.0.6 डाउनलोड:

    • एलएलवीएम रिलीज़
    • LLVM-17.0.6-win64.exeफ़ाइल डाउनलोड करें

  2. स्थापित करना:

    • इंस्टॉलर चलाएँ
    • "सिस्टम पथ में एलएलवीएम जोड़ें" विकल्प को जांचें
    • स्थापना पथ:C:\Program Files\LLVM(गलती करना)

  3. सत्यापित करें:

    llvm-config --version

विंडोज़ (स्रोत से)

इसके लिए विस्तृत स्थापना:LLVM_SETUP.md

# LLVM kaynak kodunu indir
git clone --depth 1 --branch llvmorg-17.0.6 https://github.com/llvm/llvm-project.git

# Build create directory
cd llvm-project
mkdir build
cd build

# CMake configuration
cmake -G Ninja ../llvm `
  -DCMAKE_BUILD_TYPE=Release `
  -DLLVM_TARGETS_TO_BUILD=all `
  -DCMAKE_INSTALL_PREFIX=C:\llvm-17

# Compile (2-3 saat may take)
ninja
ninja install

लिनक्स (उबंटू/डेबियन)

# LLVM 17 repository ekle
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17

# Required packages
sudo apt install llvm-17-dev libllvm17 llvm-17-tools clang-17

लिनक्स (फेडोरा)

sudo dnf install llvm17-devel llvm17-libs clang17

मैकओएस (होमब्रू)

brew install llvm@17

# PATH'e ekle
echo 'export PATH="/opt/homebrew/opt/llvm@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

एलएलवीएम पर्यावरण चर

संस्थापन परिवेश के बाद वेरिएबल सेट करें:

विंडोज़ (पॉवरशेल):

$env:LLVM_SYS_170_PREFIX = "C:\llvm-17"
[Environment]::SetEnvironmentVariable("LLVM_SYS_170_PREFIX", "C:\llvm-17", "User")

Linux/macOS (बैश/Zsh):

export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17
echo 'export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17' >> ~/.bashrc

बर्क स्थापना

विधि 1: पूर्व-निर्मित बाइनरी (विंडोज़ - अनुशंसित) ⚡

सबसे तेज़ तरीके के लिए Windows x64 उपयोगकर्ता:

  1. डाउनलोड करना:

    • 🔗 बर्क-lang.exe (2.2 एमबी)
    • 🔗 berk-lsp.exe (1.2 एमबी)
    • 🔗 बर्क-repl.exe (464 KB)
    • तीन अलग-अलग फ़ाइलें: कंपाइलर, एलएसपी, और आरईपीएल (एलएलवीएम डायनेमिक लिंकिंग)

  2. स्थापित करना:

    # Copy to desired folder
New-Item -ItemType Directory -Path C:\BERK -Force
Move-Item .\BERK-lang.exe C:\BERK\

# Add to PATH
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\BERK",
    "User"
)

# Open new terminal and test
BERK-lang --version

  3. त्वरित परीक्षण:

    # test instantly with REPL
BERK-lang repl
>>> print("Merhaba!")
Merhaba!

विशेषताएँ:

  • ✅ एलएलवीएम 17 डायनेमिक लिंकिंग - सिस्टम एलएलवीएम का उपयोग करता है
  • ✅ सभी 19 लक्ष्य प्लेटफ़ॉर्म समर्थन करते हैं
  • ✅ REPL, JIT रन और नेटिव कंपाइल मोड
  • ✅ रनटाइम लाइब्रेरी शामिल हैं (JSON, क्रिप्टो, HTTP)

टिप्पणियाँ:एलएलवीएम डायनेमिक लिंकिंग का उपयोग किया जाता है, इसलिए कुल आकार घटकर ~3.8 एमबी हो जाता है (v0.8.0 में 83 एमबी था)।

विधि 2: स्रोत से (सभी प्लेटफ़ॉर्म)

Linux/macOS या उन लोगों के लिए जो अनुकूलन चाहते हैं:

# LLVM feature ile Compile

# Test

# Binary PATH'e ekle (Linux/macOS)
sudo ln -s $(pwd)/target/release/BERK-lang /usr/local/bin/BERK-lang

# Binary PATH'e ekle (Windows)
# target\release\BERK-lang.exe file PATH'teki copy to a directory

निर्माण समय:~40 सेकंड (रिलीज़ बिल्ड)

आरईपीएल उपयोग

आरईपीएल (रीड-एवल-प्रिंट लूप) मुख्य कंपाइलर के साथ आता है:

# Start REPL
BERK-lang repl

आरईपीएल कमांड

BERK> :help

Available commands:
  :quit, :q      - Exit from REPL
  :help, :h      - Show help
  :clear, :c     - Clear screen
  :history       - Command history
  :lang <tr|en>  - Change language (Turkish/English)
  :type <expr>   - Show expression type

आरईपीएल उदाहरण

सरल गणना:

>>> 5 + 3
8

>>> 10 * 2.5
25.0

चर:

>>> variable name = "BERK"
>>> print("Hello, " + name)
Hello, BERK

कार्य:

>>> function add(a: integer, b: integer) -> integer { return a + b }
>>> add(10, 20)
30

भाषा परिवर्तन:

>>> :lang en
Language switched to English

>>> function hello(name: string) { print("Hello, " + name) }
>>> hello("World")
Hello, World

>>> :lang tr
Language switched to Turkish

समस्या निवारण

एलएलवीएम नहीं मिला

गलती:

error: could not find native static library `LLVM-17`

समाधान:

# Is LLVM_SYS_170_PREFIX set correctly?
echo $LLVM_SYS_170_PREFIX  # Linux/macOS
echo $env:LLVM_SYS_170_PREFIX  # Windows

# Is LLVM installed?
llvm-config --version

कार्गो निर्माण त्रुटि

गलती:

error: linker `link.exe` not found

समाधान (विंडोज़):

  • विजुअल स्टूडियो बिल्ड टूल्स 2022 इंस्टॉल होना चाहिए
