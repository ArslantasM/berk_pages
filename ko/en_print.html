BERK 프로그래밍 언어

버크세계 최초로 진정한 이중 언어 구문(터키어/영어)으로 설계된 현대적이고 안전한 고성능 시스템 프로그래밍 언어입니다. 19가지의 다양한 대상 플랫폼(데스크톱, 모바일, 임베디드, WebAssembly)에서 생산성을 지원합니다.

📖 BERK라는 이름을 선택한 이유는 무엇인가요?

Öztürk 원산지: "강하고, 강하고, 단단합니다"

버크Öztürk의 단어"강하고, 내구성이 있고, 강하고 견고하다"수단. 이러한 특성은 프로그래밍 언어의 기술적 목표인 메모리 안전성, 유형 시스템 정확성, 강력한 컴파일러 아키텍처 및 안정적인 성능과 직접적으로 일치합니다.

아랍어의 의미: "번개"

터키어에서 발견되는 또 다른 의미는 **"번개"**입니다. 이 의미는 속도, 성능 및 민첩성에 대한 BERK 언어의 비전, 즉 LLVM, C++ 수준 성능 및 최적화된 커널 아키텍처를 기반으로 한 빠른 컴파일을 나타냅니다.

의미의 조합

BERK, 둘 다 터키 출신견고성개념뿐만 아니라 현대 기술의 세계에서도속도와 민첩성컨셉을 결합하여 강력한 브랜드 아이덴티티를 만들어냅니다.

국제적으로

버크,효율성이 뛰어난 런타임 커널(효율성을 뛰어넘는 런타임 코어).

1. 기능 정의

function ana() -> integer
  • function(또는function): 기능을 정의합니다.
  • ana(또는main): 함수의 이름입니다. 프로그램ana()함수에서 시작됩니다

do
    ...
end
  • do(또는do): 기능의 시작
  • end(또는end): 기능 종료

3. 인쇄

print("Merhaba Dünya!")
  • print()(또는print()): 화면에 인쇄합니다.
  • "Merhaba Dünya!": 문자열 리터럴

4. 반환 값

return 0
  • return(또는return): 기능 종료
  • 0: 성공적인 프로그램은 0을 반환합니다(Unix 전통).

    }
}

📚 API 참조

매트릭스 생성

linalg_birim_mat(n: tam_sayı) -> [float]

n×n 크기의 단위 행렬을 생성합니다.

매개변수:

  • n: 매트릭스 크기

보고:단위 행렬(일반 배열 형식)

예:

variable I3 = linalg_birim_mat(3)
// I3 = [1, 0, 0,
//       0, 1, 0,
//       0, 0, 1]

linalg_sıfır_mat(m: tam_sayı, n: tam_sayı) -> [float]

m×n 크기의 제로 행렬을 생성합니다.

linalg_birler_mat(m: tam_sayı, n: tam_sayı) -> [float]

모든 요소가 1인 m×n 크기의 행렬을 만듭니다.

linalg_diyagonal_mat(d: [float], n: tam_sayı) -> [float]

대각선 요소d배열인 n×n 행렬을 생성합니다.

예:

variable d = [2.0, 3.0, 5.0]
variable D = linalg_diyagonal_mat(d, 3)
// D = [2, 0, 0,
//      0, 3, 0,
//      0, 0, 5]

행렬 산술

linalg_mat_topla(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

두 개의 m×n 행렬을 추가합니다: C = A + B

linalg_mat_çıkar(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

두 개의 m×n 행렬을 뺍니다: C = A - B

linalg_mat_skaler(α: float, A: [float], m: tam_sayı, n: tam_sayı) -> [float]

행렬에 스칼라를 곱합니다. B = α · A

linalg_mat_çarp(A: [float], B: [float], m: tam_sayı, k: tam_sayı, n: tam_sayı) -> [float]

행렬 곱셈: C = A × B

  • A: m×k
  • B: k×n
  • C: m×n

예:

// 2×2 matris çarpımı
variable A = [1.0, 2.0,
              3.0, 4.0]
variable B = [5.0, 6.0,
              7.0, 8.0]
variable C = linalg_mat_çarp(A, B, 2, 2, 2)
// C = [19, 22,
//      43, 50]

linalg_mat_hadamard(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

요소별 곱(아다마르 곱): C[i,j] = A[i,j] × B[i,j]

벡터 연산

linalg_iç_çarpım(u: [float], v: [float], n: tam_sayı) -> float

내적: u · v = Σ(u[i] × v[i])

예:

variable u = [1.0, 2.0, 3.0]
variable v = [4.0, 5.0, 6.0]
variable dot = linalg_iç_çarpım(u, v, 3)  // 32.0

linalg_norm2(v: [float], n: tam_sayı) -> float

L2 노름(유클리드 노름): ||v|| = √(Σv[i]²)

linalg_norm1(v: [float], n: tam_sayı) -> float

L1 노름(맨해튼 노름): ||v||₁ = Σ|v[i]|

linalg_norm_inf(v: [float], n: tam_sayı) -> float

L결함수 노름(최대 노름): ||v||무한 = max(|v[i]|)

linalg_normalize(v: [float], n: tam_sayı) -> [float]

벡터를 정규화합니다: v̂ = v / ||v||

linalg_dış_çarpım(u: [float], v: [float], m: tam_sayı, n: tam_sayı) -> [float]

외부곱: A[i,j] = u[i] × v[j]

linalg_cross_3d(u: [float], v: [float]) -> [float]

3D 벡터 외적: w = u × v

예:

variable u = [1.0, 0.0, 0.0]
variable v = [0.0, 1.0, 0.0]

linalg_iz(A: [float], n: tam_sayı) -> float

linalg_frobenius_norm(A: [float], m: tam_sayı, n: tam_sayı) -> float

linalg_determinant_2x2(A: [float]) -> float

linalg_determinant_3x3(A: [float]) -> float

linalg_gauss_çöz(A: [float], b: [float], n: tam_sayı) -> [float]

📋개요

optim이 모듈은 수치 최적화 문제에 대한 포괄적인 알고리즘을 제공합니다. 기계 학습, 엔지니어링 최적화 및 과학 컴퓨팅을 위해 설계되었습니다.

특징:

  • ✅ 뿌리 찾기
  • ✅ 단일 변수 최적화(라인 검색)
  • ✅ 경사 기반 방법(경사 하강, BFGS)
  • ✅ 기울기가 필요하지 않은 방법(Nelder-Mead, Powell)
  • ✅ 제한된 최적화(페널티 방법)
  • ✅ 최소제곱
  • ✅ 메타휴리스틱 알고리즘(시뮬레이션 어닐링, 유전자 알고리즘)

function beam_cost(dimensions: [float], n: tam_sayı): float do
    variable width = dimensions[0]
    variable height = dimensions[1]
    
    // Maliyet = malzeme × domain
    variable cost = width * height

    end
    
    return cost + penalty
end

버크란 무엇인가?

BERK는 현대적이고 안전한 고성능 프로그래밍 언어입니다. 이중 언어 구문 지원을 통해 터키어와 영어 키워드를 모두 사용할 수 있습니다. LLVM 백엔드를 사용하여 네이티브 코드를 생성합니다.

왜 BERK를 사용해야 하나요?

  • 이중 언어 구문: 터키어 또는 영어 키워드, 원하는 것을 사용하세요
  • 메모리 보안: 현대식 시스템 및 오류 처리
  • 고성능: LLVM을 사용한 네이티브 코드, 비용이 들지 않는 추상화
  • 리치 Stdlib: 18개 모듈, 600개 이상의 기능, 과학계산 지원
  • 쉬운 학습: 깔끔한 구문, 명확한 오류 메시지

BERK는 어떤 플랫폼에서 작동하나요?

현재 Windows x64용 컴파일러를 사용할 수 있습니다. Linux 및 macOS 지원은 로드맵에 있습니다.

BERK는 오픈소스인가요?

예, BERK는 MIT 라이선스에 따른 오픈 소스 프로젝트입니다. GitHub에서 개발이 진행되고 있습니다.

BERK는 얼마나 빠른가요?

LLVM 백엔드 덕분에 C/C++에 필적하는 성능을 제공합니다. 벤치마크는 개발 중입니다.

최적화 수준은 무엇입니까?

berk build -O0  # Optimizasyon yok (hızlı derleme)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (균衡)
berk build -O3  # Agresif optimizasyon

병렬 프로그래밍이 지원되나요?

예,thread모듈을 사용하여 멀티스레딩을 수행할 수 있습니다.

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    variable t1 = thread.spawn(işçi, 1)
    variable t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}

문제 해결

"정의되지 않은 참조" 오류가 발생합니다.

모듈을 가져오는 것을 잊었을 수도 있습니다.

import math  // math Moduleünü ekleyin

function main() {
    variable x = math.sqrt(16)  // Artık çalışır
}

컴파일 시간이 너무 오래 걸림

-O0다음을 사용하여 빠르게 컴파일할 수 있습니다.

berk build -O0 program.berk

'스택 오버플로' 오류

재귀 함수에서 테일 콜 최적화를 사용하거나 반복 버전으로 전환하세요.

여기에 질문이 없나요? GitHub 토론에 물어보세요!
