BERK Programlama Dili

개발환경 설치

필요한 개발 환경 설치를 위해 BERK 프로그래밍 언어의 소스 코드에 기여합니다.

📋 요구사항

기본 도구

  • 가다- 버전 관리
  • 녹(1.70+) - 컴파일러 개발
  • LLVM(16.0+) - 코드 생성 백엔드
  • CMake(3.20+) - 빌드 시스템
  • 파이썬(3.8+) - 테스트 스크립트

플랫폼 기반

🪟윈도우

# Visual Studio 2022 (C++ Desktop Development)
# LLVM Installationu
winget install LLVM.LLVM

# Rust Installationu
winget install Rustlang.Rustup
rustup default stable

# Git
winget install Git.Git

🐧 리눅스(우분투/데비안)

sudo apt update
sudo apt install -y build-essential cmake git python3 python3-pip

# LLVM
sudo apt install -y llvm-16 llvm-16-dev clang-16

# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

🍎 맥OS

# Homebrew ile
brew install llvm cmake git python3 rust

🔧 저장소 설치

1. 리포지토리 복제

git clone https://github.com/ArslantasM/berk.git
cd berk/berk-lang

2. 종속성 설치

# Rust bağımlılıkları
cargo fetch

# Python test araçları
pip install pytest pytest-cov

3. 빌드

# Debug build (geliştirme for)
cargo build

# Release build (performans testleri for)
cargo build --release

# Test çalıştırma
cargo test

🛠️ IDE 설치

VS 코드(권장)

필수 플러그인:

  • 녹 분석기- 러스트 IntelliSense
  • 코드LLDB- 디버그 지원
  • 더 나은 TOML- Cargo.toml 편집자
  • 오류 렌즈- 오류 표시
# VS Code settings.json
{
    "rust-analyzer.checkOnSave.command": "clippy",
    "rust-analyzer.cargo.features": "all",
    "[rust]": {
        "editor.defaultFormatter": "rust-lang.rust-analyzer",
        "editor.formatOnSave": true
    }
}

IntelliJ IDEA/CLion

  • 러스트 플러그인설치하다
  • 프로젝트를 화물 프로젝트로 열기

📁 프로젝트 구조

berk/
├── berk-lang/              # Ana derleyici kodu
│   ├── src/
│   │   ├── lexer/         # Lexical analysis
│   │   ├── parser/        # Syntax parsing
│   │   ├── ast/           # Abstract Syntax Tree
│   │   ├── semantic/      # Semantic analysis
│   │   ├── codegen/       # LLVM code generation
│   │   ├── stdlib/        # Standard library (Rust tarafı)
│   │   └── main.rs        # Entry point
│   ├── tests/             # Integration testler
│   └── Cargo.toml
├── stdlib/                 # BERK stdlib kaynak kodları
│   ├── io.berk
│   ├── math.berk
│   └── ...
├── examples/              # Example programlar
└── docs/                  # Documentation

🔍 개발 워크플로우

1. 기능 분기 생성

git checkout -b feature/new-ozellik
# or
git checkout -b fix/hata-duzeltmesi

2. 코딩 및 테스트

# Kod değişikliği yaptıktan sonra
cargo build
cargo test
cargo clippy  # Lint kontrolü
cargo fmt     # Format düzeltme

3. 커밋 및 푸시

git add .
git commit -m "feat: yeni trait eklendi"
git push origin feature/yeni-ozellik

🧪 테스트 실행

# Tüm testler
cargo test

# Belirli bir test
cargo test test_parser

# Integration testler
cargo test --test integration

# Coverage raporu
cargo tarpaulin --out Html

🐛 디버그하지 마세요

VS 코드로

.vscode/launch.json:

{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "lldb",
            "request": "launch",
            "name": "Debug BERK",
            "cargo": {
                "args": ["build", "--bin=berk-lang"]
            },
            "args": ["run", "test.berk"],
            "cwd": "${workspaceFolder}/berk-lang"
        }
    ]
}

LLDB가 있는 터미널

lldb target/debug/berk-lang
(lldb) run test.berk
(lldb) breakpoint set -n parse_function
(lldb) continue

📊 성능 프로파일링

cargo install flamegraph

perf record --call-graph dwarf target/release/berk-lang compile test.berk
perf report
