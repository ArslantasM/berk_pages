운영자 우선순위

BERK 프로그래밍 언어에서 연산자의 우선순위와 조합 방향. 우선순위 수준이 높아지면 연산자가 먼저 평가됩니다.

📊 우선순위 테이블

우선 사항 연산자 설명 합병
1(가장 높음) () [] . 대괄호, 색인, 회원 액세스 왼쪽에서 오른쪽으로
2 ++ -- ! ~ + - 단항 연산자(증가, 감소, not, 비트 단위 not, 단항 +/-) 오른쪽에서 왼쪽으로
3 ** 지수화 오른쪽에서 왼쪽으로
4 * / % 곱셈, 나눗셈, 모드 왼쪽에서 오른쪽으로
5 + - 덧셈, 뺄셈 왼쪽에서 오른쪽으로
6 << >> 비트 시프트 왼쪽에서 오른쪽으로
7 < <= > >= 관계 비교 왼쪽에서 오른쪽으로
8 == != 동등성 검사 왼쪽에서 오른쪽으로
9 & 비트별 AND 왼쪽에서 오른쪽으로
10 ^ 비트별 XOR 왼쪽에서 오른쪽으로
11 | 비트별 OR 왼쪽에서 오른쪽으로
12 && and and 부울 및 왼쪽에서 오른쪽으로
13 || or or 부울 또는 왼쪽에서 오른쪽으로
14 ? : 삼항 조건 연산자 오른쪽에서 왼쪽으로
15 = += -= *= /= %= 할당 연산자 오른쪽에서 왼쪽으로
16(최저) , 쉼표 연산자 왼쪽에서 오른쪽으로

💡 예

우선순위

// Çarpma toplama önce gelir
variable sonuç = 5 + 3 * 2  // = 5 + 6 = 11 (not 16)

// Parantez en yüksek önceliğe sahip
variable sonuç2 = (5 + 3) * 2  // = 8 * 2 = 16

// Üs alma çarpmadan önce
variable sonuç3 = 2 * 3 ** 2  // = 2 * 9 = 18

// boolean operatörler
variable koşul = true or false and false  // = true (and önce)
variable koşul2 = (true or false) and false  // = false

합류방향

// Soldan sağa (çoğu operatör)
variable a = 10 - 5 - 2  // = (10 - 5) - 2 = 3

// Sağdan sola (atama)
variable x, y, z
x = y = z = 5  // Sağdan başlar: z=5, y=5, x=5

// Sağdan sola (üs alma)
variable b = 2 ** 3 ** 2  // = 2 ** (3 ** 2) = 2 ** 9 = 512

복잡한 표현

variable result = 10 + 5 * 2 - 3 ** 2 / 3
// Adım adım:
// 1. 3 ** 2 = 9 (pow alma)
// 2. 5 * 2 = 10 (çarpma)
// 3. 9 / 3 = 3 (bölme)
// 4. 10 + 10 = 20 (toplama)
// 5. 20 - 3 = 17 (çıkarma)
// Sonuç: 17

// Parantezle netleştirme
variable result2 = ((10 + (5 * 2)) - ((3 ** 2) / 3))  // Daha okunabilir

부울 연산자

variable x = 5
variable y = 10
variable z = 15

// && (and) || (or) önce gelir
variable sonuç = x < y || y > z && z > x
// = (x < y) || ((y > z) && (z > x))
// = true || (false && true)
// = true || false
// = true

// Parantez Usageı önerilir
variable pub = (x < y) || ((y > z) && (z > x))

비트 연산자

variable a = 0b1100  // 12
variable b = 0b1010  // 10

// Bitwise operatörler boolean operatörlerden önce
variable sonuç = a & b | a ^ b
// = (a & b) | (a ^ b)
// = (0b1000) | (0b0110)
// = 0b1110 = 14
