BERK Programlama Dili

설치

이 섹션에서는 시스템에 BERK 프로그래밍 언어를 설치하는 방법을 배웁니다.

요구사항

윈도우

  • Windows 10/11(64비트)
  • Rust 툴체인 (1.70+)
  • Visual Studio 빌드 도구 2022
  • LLVM 17.0.6
  • 가다
  • 최소 8GB RAM(컴파일 대상)

리눅스

  • 우분투 20.04+ / 데비안 11+ / 페도라 35+
  • Rust 툴체인(1.70+)
  • GCC/Clang 컴파일러
  • LLVM 17.0.6
  • 가다
  • 최소 4GB RAM

macOS

  • macOS 11(Big Sur) 이상
  • Rust 툴체인(1.70+)
  • Xcode 명령줄 도구
  • LLVM 17.0.6(홈브루)
  • 가다
  • 최소 4GB RAM

녹 설치

BERK, Rust가 작성되었습니다. 먼저 Rust를 설치해야 합니다.

윈도우/리눅스/맥OS

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

설치 후:

rustc --version
cargo --version

산출:

rustc 1.75.0 (1.75.0 2024-01-01)
cargo 1.75.0 (1.75.0 2024-01-01)

LLVM 설치

BERK는 네이티브 코드 생성을 위해 LLVM 17을 사용합니다.

Windows(사전 컴파일됨)

  1. LLVM 17.0.6 다운로드:

    • LLVM 릴리스
    • LLVM-17.0.6-win64.exe파일을 다운로드

  2. 설치하다:

    • 설치 프로그램 실행
    • "시스템 PATH에 LLVM 추가" 옵션을 확인하세요.
    • 설치 경로:C:\Program Files\LLVM(기본)

  3. 확인하다:

    llvm-config --version

Windows(소스에서)

다음에 대한 자세한 설치:LLVM_SETUP.md

# LLVM kaynak kodunu indir
git clone --depth 1 --branch llvmorg-17.0.6 https://github.com/llvm/llvm-project.git

# Build create directory
cd llvm-project
mkdir build
cd build

# CMake configuration
cmake -G Ninja ../llvm `
  -DCMAKE_BUILD_TYPE=Release `
  -DLLVM_TARGETS_TO_BUILD=all `
  -DCMAKE_INSTALL_PREFIX=C:\llvm-17

# Compile (2-3 saat may take)
ninja
ninja install

리눅스(우분투/데비안)

# LLVM 17 repository ekle
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17

# Required packages
sudo apt install llvm-17-dev libllvm17 llvm-17-tools clang-17

리눅스(페도라)

sudo dnf install llvm17-devel llvm17-libs clang17

macOS(홈브루)

brew install llvm@17

# PATH'e ekle
echo 'export PATH="/opt/homebrew/opt/llvm@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

LLVM 환경 변수

설치 환경 후 변수를 설정하십시오.

윈도우(파워셸):

$env:LLVM_SYS_170_PREFIX = "C:\llvm-17"
[Environment]::SetEnvironmentVariable("LLVM_SYS_170_PREFIX", "C:\llvm-17", "User")

리눅스/macOS(Bash/Zsh):

export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17
echo 'export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17' >> ~/.bashrc

버크 설치

방법 1: 사전 구축된 바이너리(Windows - 권장) ⚡

가장 빠른 방법을 찾는 Windows x64 사용자:

  1. 다운로드:

    • 🔗 BERK-lang.exe(2.2MB)
    • 🔗 berk-lsp.exe(1.2MB)
    • 🔗 berk-repl.exe(464KB)
    • 세 가지 개별 파일: 컴파일러, LSP 및 REPL(LLVM 동적 연결)

  2. 설치하다:

    # Copy to desired folder
New-Item -ItemType Directory -Path C:\BERK -Force
Move-Item .\BERK-lang.exe C:\BERK\

# Add to PATH
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\BERK",
    "User"
)

# Open new terminal and test
BERK-lang --version

  3. 빠른 테스트:

    # test instantly with REPL
BERK-lang repl
>>> print("Merhaba!")
Merhaba!

특징:

  • ✅ LLVM 17 동적 연결 - 시스템 LLVM 사용
  • ✅ 19개 대상 플랫폼 모두 지원
  • ✅ REPL, JIT 실행 및 기본 컴파일 모드
  • ✅ 런타임 라이브러리 포함(JSON, Crypto, HTTP)

참고:LLVM 동적 연결이 사용되므로 전체 크기가 ~3.8MB(v0.8.0에서는 83MB)로 줄었습니다.

방법 2: 소스에서(모든 플랫폼)

Linux/macOS 또는 사용자 정의를 원하는 경우:

# Clone the repository
git clone https://github.com/ArslantasM/berk.git
cd berk/berk-lang

# LLVM feature ile Compile
cargo build --release --features llvm

# Test

# Binary PATH'e ekle (Linux/macOS)
sudo ln -s $(pwd)/target/release/BERK-lang /usr/local/bin/BERK-lang

# Binary PATH'e ekle (Windows)
# target\release\BERK-lang.exe file PATH'teki copy to a directory

빌드 시간:~40초(릴리스 빌드)

방법 3: 화물 설치(향후)

# Planned feature
cargo install BERK-lang --features llvm

빠른 테스트: REPL

가장 빠른 방법 - REPL을 사용하세요.

BERK-lang repl

REPL에서 테스트:

>>> print("Installation successful! 🎉")
Installation successful! 🎉

>>> variable x = 42
>>> print(x * 2)
84

>>> function kare(n: integer) -> integer { return n * n }
>>> print(kare(5))
25

종료하려면::quit또는 Ctrl+C

테스트 프로그램(컴파일)

파일에서 실행:

test.berk:

function ana() -> integer
do
    print("Installation successful! 🎉")
    return 0
end

옵션 1: JIT 실행(빠름)

BERK-lang run test.berk

옵션 2: 네이티브 컴파일

BERK-lang compile test.berk -o test.exe
./test.exe

두 경우 모두 출력:

Installation successful! 🎉

REPL 사용법

REPL(Read-Eval-Print Loop)은 기본 컴파일러와 함께 제공됩니다.

# Start REPL
BERK-lang repl

REPL 명령

BERK> :help

Available commands:
  :quit, :q      - Exit from REPL
  :help, :h      - Show help
  :clear, :c     - Clear screen
  :history       - Command history
  :lang <tr|en>  - Change language (Turkish/English)
  :type <expr>   - Show expression type

REPL 예

간단한 계산:

>>> 5 + 3
8

>>> 10 * 2.5
25.0

변수:

>>> variable name = "BERK"
>>> print("Hello, " + name)
Hello, BERK

기능:

>>> function add(a: integer, b: integer) -> integer { return a + b }
>>> add(10, 20)
30

언어 전환:

>>> :lang en
Language switched to English

>>> function hello(name: string) { print("Hello, " + name) }
>>> hello("World")
Hello, World

>>> :lang tr
Language switched to Turkish

문제 해결

LLVM을 찾을 수 없음

오류:

error: could not find native static library `LLVM-17`

해결책:

# Is LLVM_SYS_170_PREFIX set correctly?
echo $LLVM_SYS_170_PREFIX  # Linux/macOS
echo $env:LLVM_SYS_170_PREFIX  # Windows

# Is LLVM installed?
llvm-config --version

화물 제작 오류

오류:

error: linker `link.exe` not found

해결 방법(Windows):

  • Visual Studio Build Tools 2022를 설치해야 합니다.
  • "C++를 사용한 데스크톱 개발" 워크로드를 선택해야 합니다.

느린 컴파일

팁:

# Parallel build (4 core)
cargo build --release --features llvm -j4

# Incremental compilation
export CARGO_INCREMENTAL=1

# Less optimization (debug build)
cargo build --features llvm

macOS ARM(M1/M2) 문제

# Rosetta 2 Installation
softwareupdate --install-rosetta

# ARM native LLVM
brew install llvm@17

# Architecture check
arch
# Output: arm64
