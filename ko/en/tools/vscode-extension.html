BERK Programlama Dili

VS 코드 추가 기능

BERK VS 코드 확장,전문 개발 경험에 대한 모든 기능을 갖춘 IDE 지원을 제공합니다. LSP(언어 서버 프로토콜)로 구동됩니다.

설정

마켓플레이스를 통해

  1. VS 코드 열기
  2. 확장 프로그램(Ctrl+Shift+X) 메뉴로 이동
  3. "BERK 언어 지원"을 검색하세요.
  4. "설치" 버튼을 클릭하세요

명령줄에서

code --install-extension ArslantasM-tools.berk-lang

주요 특징

1. 구문 강조

  • ✅ 터키어 및 영어 키워드
  • ✅ 문자열 보간
  • ✅ 코멘트 라인
  • ✅ 하이라이트 입력
  • ✅ 함수 이름

2. IntelliSense(코드 완성)

// 'let' yazın and Ctrl+Space
let x = 42

// 'x.' yazın - otomatik metodlar gösterilir
x.to_string()
x.karakter_uzunluğu()

3. 정의로 이동(F12)

함수/변수에서 F12를 누르세요.

let sonuç = hesapla(10)  // F12 ile hesapla() tanımına git

4. 모든 참고문헌 찾기(Shift+F12)

기호의 모든 용도 찾기

5. 기호 이름 바꾸기(F2)

안전한 이름 변경 - 모든 참조가 자동으로 업데이트됩니다.

6. 호버 정보

기호 위로 마우스를 가져가세요.

  • 유형 정보
  • 선적 서류 비치
  • 서명 정보

7. 진단(오류 ​​검사)

실시간 오류 확인:

  • 🔴 구문 오류
  • 🟠 경고
  • 🔵 정보

8. 코드 작업(Ctrl+.)

빠른 수정 및 리팩토링:

  • 자동 추가 가져오기
  • 유형 설명 추가
  • 변수 추출

9. 서명 도움말(Ctrl+Shift+Space)

function hesapla(x: sayı, y: sayı, z: sayı) do
end

10. 문서 기호(Ctrl+Shift+O)

파일의 모든 기호(함수, 변수) 목록

11. 시맨틱 토큰

고급 구문 강조 - 유형 정보에 따른 색상 지정

12. 인레이 힌트

인라인 유형 및 매개변수 설명

13. 코드 렌즈

참조 번호 및 빠른 작업

디버깅 지원

launch.json구성:

{
  \"version\": \"0.2.0\",
  \"configurations\": [
    {
      \"type\": \"berk\",
      \"request\": \"launch\",
      \"name\": \"Debug BERK Program\",
      \"program\": \"${workspaceFolder}/main.berk\",
      \"stopOnEntry\": false
    }
  ]
}

설정

settings.json:

{
  \"berk.lsp.enabled\": true,
  \"berk.lsp.trace.server\": \"off\",
  \"berk.build.optimizationLevel\": 2,
  \"berk.format.indentSize\": 4,
  \"berk.lint.warnings\": true,
  \"berk.inlayHints.enabled\": true,
  \"berk.semanticTokens.enabled\": true
}

저장 시 포맷

{
  \"[berk]\": {
    \"editor.formatOnSave\": true,
    \"editor.defaultFormatter\": \"ArslantasM-tools.berk-lang\"
  }
}

태스크 러너

문제 일치자

BERK는 오류 형식을 자동으로 감지합니다.

error[E0308]: type uyuşmazlığı
  --> src/main.berk:5:14
   |
 5 |     let x: sayı = \"merhaba\";
   |              ^^^^      ^^^^^^^^^

작업 공간 제안

.vscode/extensions.json:

{
  \"recommendations\": [
    \"ArslantasM-tools.berk-lang\"
  ]
}

성능 팁

  1. ✅ LSP 캐시사용:

    \"berk.lsp.cache.enabled\": true

  2. ✅ 증분 분석활동적인:

    \"berk.lsp.incrementalSync\": true

  3. ⚠️ 매우 큰 파일의 경우의미론적 토큰닫다:

    \"berk.semanticTokens.enabled\": false

문제 해결

LSP가 작동하지 않는 경우

  1. 커맨드 팔레트 → "BERK: LSP 재시작"
  2. VS 코드 다시 시작
  3. 출력 패널 → "BERK Language Server" 로그 참조

구문 강조 없음

  1. 파일 확장자.berk이어야 한다
  2. 언어 모드 "BERK"를 선택해야 합니다(오른쪽 하단).
