디버깅

버크,최신 디버깅 도구강력한 디버깅 지원을 제공합니다. DWARF/PDB 디버그 기호, GDB/LLDB 통합 및 VS Code 디버깅에 대한 전문적인 개발 경험.

# Debug modda derle (optimizasyon yok, debug sembolleri var)
berk-lang build --debug

berk-lang build -g

GDB 디버거

기본 사용법

# Program GDB ile başlat
gdb ./output

# GDB in
(gdb) run                    # Programı çalıştır
(gdb) break main.berk:10     # 10. satıra breakpoint
(gdb) continue               # Devam et
(gdb) next                   # Sonraki satır (step over)
(gdb) step                   # Fonksiyon içine gir (step into)
(gdb) print x                # Değişken değeri
(gdb) backtrace              # Call stack
(gdb) quit                   # Çık

중단점 유형

# Satır breakpoint
(gdb) break main.berk:25

# Fonksiyon breakpoint
(gdb) break hesapla

# Koşullu breakpoint
(gdb) break main.berk:30 if x > 10

# Watchpoint (let değiştiğinde break)
(gdb) watch x

# Tüm breakpointleri listele
(gdb) info breakpoints

# Breakpoint sil
(gdb) delete 1

가변 검토

# Basit let
(gdb) print x
$1 = 42

# Struct
(gdb) print kisi
$2 = {isim = \"Ali\", yaş = 25}

# Array
(gdb) print sayılar[0]@5  # İlk 5 eleman

# Pointer
(gdb) print *ptr

# Format belirle
(gdb) print/x x           # Hex
(gdb) print/t x           # Binary
(gdb) print/f x           # Float

LLDB 디버거

기본 명령

# LLDB başlat
lldb ./output

# LLDB in
(lldb) run
(lldb) breakpoint set --file main.berk --line 10
(lldb) breakpoint set --name hesapla
(lldb) continue
(lldb) next
(lldb) step
(lldb) frame variable x
(lldb) bt                    # Backtrace
(lldb) quit

VS 코드 디버깅

launch.json 구성

.vscode/launch.json:

{
  \"version\": \"0.2.0\",
  \"configurations\": [
    {
      \"name\": \"Debug BERK Program\",
      \"type\": \"cppdbg\",
      \"request\": \"launch\",
      \"program\": \"${workspaceFolder}/output.exe\",
      \"args\": [],
      \"stopAtEntry\": false,
      \"cwd\": \"${workspaceFolder}\",
      \"environment\": [],
      \"externalConsole\": false,
      \"MIMode\": \"gdb\",
      \"miDebuggerPath\": \"gdb.exe\",
      \"setupCommands\": [
        {
          \"description\": \"Enable pretty-printing\",
          \"text\": \"-enable-pretty-printing\",
          \"ignoreFailures\": true
        }
      ],
      \"preLaunchTask\": \"build-debug\"
    }
  ]
}

tasks.json(디버그 빌드)

.vscode/tasks.json:

{
  \"version\": \"2.0.0\",
  \"tasks\": [
    {
      \"label\": \"build-debug\",
      \"type\": \"shell\",
      \"command\": \"berk-lang\",
      \"args\": [\"build\", \"--debug\", \"-o\", \"output.exe\"],
      \"group\": {
        \"kind\": \"build\",
        \"isDefault\": true
      },
      \"problemMatcher\": []
    }
  ]
}

VS 코드 디버깅 기능

1. 중단점

  • ✅ 줄바꿈(F9)
  • ✅ 조건부 중단점(오른쪽 클릭)
  • ✅ 로그 포인트(인쇄 출력, 멈추지 않음)
  • ✅ 함수 중단점

2. 스테핑

지름길행동
F5계속하다
F10Step Over(기능 살펴보기)
F11Step Into(함수 내부로 이동)
Shift+F11Step Out(퇴장 기능)
Ctrl+Shift+F5다시 시작하다
Shift+F5멈추다

3. 변수 패널

왼쪽의 '변수' 패널에서:

  • 지역 변수
  • 전역 변수
  • 변수 값 편집

4. 시계 표현식

"감시" 패널에 추가:

x * 2
kisi.isim
sayılar.len()

5. 콜스택

함수 호출 기록을 표시합니다. 아무 프레임이나 클릭하세요.

6. 디버그 콘솔

실시간 표현 평가:

// Debug Console'da
x + 10
kisi.isim
hesapla(5, 10)

조건부 중단점 예

// Sadece x > 100 olduğunda break
function işle(x: sayı) do
    if x < 0 do  // Breakpoint burada: x < 0
        return 0
    end
    return x * 2
end

로그포인트 사용

줄 번호를 마우스 오른쪽 버튼으로 클릭 → "로그 지점 추가":

x değeri: {x}, y değeri: {y}

프로그램은 멈추지 않고 로그만 인쇄합니다.

3.인쇄 디버깅

4. Assertion의 활용

iddia_et(x > 0, \"x pozitif olmalı\")

문제 해결

디버그 기호 없음

# Kontrol et
file output.exe | grep \"not stripped\"

# Strip edilmişse yeniden derle
berk-lang build --debug

중단점은 멈추지 않습니다

  1. 디버그 모드로 컴파일되었는지 확인하세요.
  2. 최적화를 꺼야 합니다(-O0).
  3. 줄번호가 맞나요?

변수 값이 표시되지 않음

최적화로 인해 변수가 제거되었을 수 있습니다. 디버그 빌드를 사용하세요.
