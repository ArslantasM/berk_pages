자주 묻는 질문

일반적인 질문

버크란 무엇인가?

BERK는 현대 시스템 프로그래밍 언어입니다. Rust 수준의 메모리 보안과 C/C++ 수준의 성능을 제공합니다. LLVM 백엔드를 사용하여 네이티브 코드를 생성하고 19개의 대상 플랫폼을 지원합니다. 이중 언어 구문 기능을 사용하면 터키어와 영어 키워드를 모두 사용할 수 있습니다.

왜 BERK를 사용해야 하나요?

  • 고성능: LLVM을 사용하여 C/C++ 수준에서 네이티브 코드 생성(98-100%)
  • Rust 수준의 보안: 현대식 시스템, 패턴 매칭, 종합적인 오류 처리
  • 포괄적인 Stdlib: 75개 모듈(42개 코어 + 33 HAL), 4100개 이상의 기능, NumPy/SciPy 수준 과학 컴퓨팅, 임베디드 시스템 지원
  • 크로스 플랫폼: 데스크탑(Windows/Linux/macOS), 임베디드(ARM/RISC-V/AVR/ESP32), 모바일(Android/iOS), WebAssembly
  • 사용자 친화적: 깔끔한 구문, 명확한 오류 메시지, REPL 지원, 선택적 이중 언어 키워드

BERK는 어떤 플랫폼에서 작동하나요?

데스크탑: Windows x64(활성), Linux x64, macOS ARM64

임베디드(7개 플랫폼, 95% 완료, 100% 시장 커버리지):

  • Tier-1: ESP32(WiFi/BLE, 시장 35%), STM32F4(산업용, 25%), RP2040(메이커, 15%)
  • Tier-2: nRF52(BLE, 8%), GD32(중국, 7%), Nuvoton(아시아, 5%)
  • Tier-3: Arduino(교육용, 사용자 3천만 명)

이동하는: Android(ARM/x86), iOS(ARM64) - 실험적

웹어셈블리: WASM32, WASI - 예정

HAL 지원: 61개 플랫폼별 모듈, 자동 생성기(15,901개 라인 CMSIS 테스트 완료)

BERK는 오픈소스인가요?

예, BERK는 GPL-3 라이선스에 따른 오픈 소스 프로젝트입니다. GitHub에서 활발한 개발이 진행되고 있습니다. 전체 완료율 98%로 v1.0.0에 매우 가깝습니다.

구문 및 언어 기능

이중 언어 구문은 어떻게 작동합니까?

BERK에서는 동일한 프로그램을 두 가지 방법으로 작성할 수 있습니다.

// Türkçe
function merhaba() {
    print("Merhaba Dünya!")
}

// İngilizce
function hello() {
    print("Hello World!")
}

두 스타일 모두 동일한 바이트코드로 컴파일됩니다. 동일한 파일에 혼합할 수도 있습니다!

어떤 프로그래밍 패러다임을 지원합니까?

  • 명령형 프로그래밍: 절차적 코드, 직접 메모리 제어
  • 함수형 프로그래밍: 반복자, 고차 함수, 불변성
  • 구조화된 프로그래밍: 구조체, 모듈러 아키텍처, 패턴 매칭
  • 시스템 프로그래밍: 낮은 수준의 제어, 제로 비용 추상화, 인라인 어셈블리(v1.0 예정)
  • 유형 보안: 강력한 정적 유형 검사,일반 유형(4.1-4.4단계 완료)

가비지 컬렉터가 있나요?

아니요, BERK는 수동 메모리 관리를 사용합니다.v0.9.0에서 완성된 Rust 스타일 소유권 시스템- 빌림 검사기, 비어휘 수명(NLL), 이동 의미(geçir, paylaş, değiştir)는 Rust 수준의 메모리 보안을 제공합니다. 지역 메모리(263x malloc보다 빠름) 및 mimalloc 통합도 있습니다.

Rust/C와 성능을 비교하면 어떤가요?

BERK는 LLVM 백엔드 덕분에 C/C++(98-100%)에 필적하는 성능을 제공합니다. LLVM은 IR 최적화 패스, 영역 메모리 할당자(263배 속도 향상) 및 mimalloc 통합을 사용합니다. -O0에서 -O3까지의 최적화 수준을 지원합니다. 지속적인 성능 모니터링은 벤치마크 제품군을 통해 수행됩니다.

그래픽 및 게임 (9): GUI, 그래픽, 오디오, 이미지, 물리2d, 캐드3d, 메쉬, math_3d, 색상
고급 (3): 테스트, 로깅, 규칙
임베디드 HAL(33): gpio, adc, dac, 타이머, pwm, usart, spi, i2c, can, usb, dma, 시계, 전원, rtc, rng, crc, 플래시, exti, nvic, 인터럽트, systick, watchdog 등

NumPy/SciPy와 유사한 기능이 있나요?

예! 기본 성능을 갖춘 v1.0.0 과학 컴퓨팅 모듈:

  • linalg: 행렬 연산, LU/QR/Cholesky 분해, 고유값/고유벡터, 선형 솔버
  • stats: 기술통계, 확률분포, 가설검정(t-test, ANOVA), 회귀분석
  • optim: 비제약/제약 최적화, 경사하강법, BFGS, 시뮬레이션 어닐링, 근 찾기
  • physics: 물리 시뮬레이션, 수치해석 방법
  • math_3d: 3D 벡터/행렬 연산
  • complex: 복소수 산술

C/C++ 라이브러리를 사용할 수 있나요?

예!FFI(Foreign Function Interface) 시스템이 v0.9.0에서 완성되었습니다. 30개 이상의 테스트, libm 통합(40개 이상의 수학 함수) 및 직접 C 라이브러리 호출을 통한 완전한 C ABI 지원. 보안 C 상호운용성은 Rust의 안전하지 않은 FFI 유사 구문과 함께 제공됩니다.

성능 및 최적화

BERK는 얼마나 빠른가요?

LLVM 백엔드 덕분에 C/C++에 필적하는 성능을 제공합니다. 네이티브 코드 생성, LLVM 최적화 패스 및 무료 추상화를 통해 시스템 프로그래밍에 필요한 속도를 제공합니다. 로드맵에는 JIT 컴파일러와 BLAS/LAPACK 통합이 포함됩니다.

최적화 수준은 무엇입니까?

berk build -O0  # Optimizasyon yok (hızlı derleme, debug)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (dengelenmiş performans)
berk build -O3  # Agresif optimizasyon (maksimum hız)

LLVM은 데드 코드 제거, 상수 폴딩, 루프 언롤링, 인라인 확장 등 최적화 파이프라인을 사용합니다. LTO(링크 시간 최적화) 지원은 향후 버전에 추가될 예정입니다.

병렬 프로그래밍이 지원되나요?

예,thread모듈을 사용하여 멀티스레딩을 수행할 수 있습니다.

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    variable t1 = thread.spawn(işçi, 1)
    variable t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}

문제 해결

"정의되지 않은 참조" 오류가 발생합니다.

모듈을 가져오는 것을 잊었을 수도 있습니다.

import math  // math Moduleünü ekleyin

function main() {
    variable x = math.sqrt(16)  // Artık çalışır
}

컴파일 시간이 너무 오래 걸림

-O0다음을 사용하여 빠르게 컴파일할 수 있습니다.

berk build -O0 program.berk

'스택 오버플로' 오류

재귀 함수에서 대기열 호출 최적화를 사용하거나 반복 버전으로 전환하세요.

여기에 질문이 없나요? GitHub 토론정말 좋아요!
