키워드

BERK 프로그래밍 언어에서 사용되는 키워드 및 예약어입니다. BERK의 이중 언어(터키어/영어) 구조 덕분에 각 키워드에는 터키어와 영어가 모두 포함됩니다.

💡 사용 예

// Türkçe syntax
function sum(a: tam, b: tam) -> tam {
    if a > 0 and b > 0 {
        döndür a + b
    } else {
        döndür 0
    }
}

// İngilizce syntax (aynı kod)
fn sum(a: int, b: int) -> int {
    if a > 0 and b > 0 {
        return a + b
    } else {
        return 0
    }
}

// Karışık Usage da mümkün
variable sonuç = sum(5, 10)
let result = sum(5, 10)

📝참고

BERK의 독특한 특징은 동일한 프로그램에서 터키어와 영어 키워드를 자유롭게 혼합할 수 있다는 것입니다. 이를 통해 현지 팀과 국제 팀 모두 동일한 코드베이스에서 작업하기가 더 쉬워졌습니다.
