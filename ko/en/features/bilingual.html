이중 언어 구문(터키어/영어)

버크,세계 최초의 진정한 이중 언어 프로그래밍 언어입니다.. 동일한 코드를 터키어와 영어로 작성할 수도 있고, 동일한 파일에 두 언어를 혼합할 수도 있습니다!

왜 이중 언어를 사용하나요?

학습의 용이성

터키어를 구사하는 초보자는 모국어로 프로그래밍을 배울 수 있습니다.

function merhaba() do
    print("Merhaba Dünya!")
end

국제협력

영어를 사용하는 개발자와 쉽게 협업할 수 있습니다.

function hello() do
    print("Hello World!")
end

완전 동등성

두 언어 모두동일한 AST(추상 구문 트리)를 생성합니다.. 잘:

  • ✅ 동일한 성능
  • ✅ 같은 행동
  • ✅ 동일한 바이트코드
  • ✅ 같은 오류 메시지

비교예

예시 1: 피보나치

영어:

function fibonacci(n: sayı) -> sayı
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

영어:

function fibonacci(n: int) -> int
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

예제 2: 클래스 정의

영어:

struct Kişi do
    isim: String,
    yaş: sayı
end

function yeni_kişi(isim: String, yaş: sayı) -> Kişi
do
    return Kişi { isim: isim, yaş: yaş }
end

영어:

struct Person do
    name: string,
    age: int
end

function new_person(name: string, age: int) -> Person
do
    return Person { name: name, age: age }
end

function read_file(path: string) -> Result<string>
do

    // Read file

혼합 사용

가장 강력한 기능:동일한 파일에 두 가지 언어를 혼합할 수 있습니다!

// Türkçe function
function hesapla(x: sayı) -> sayı do
    let sonuç = x * 2
    return sonuç
end

// English function  
function calculate_advanced(x: int) -> int do
    let result = hesapla(x) + 10  // Türkçe fonksiyonu çağırıyoruz
    return result
end

// Türkçe main function
function main() do
    let değer = calculate_advanced(5)  // İngilizce fonksiyonu çağırıyoruz
    print(değer)
end

스타일 제안

프로젝트 내 일관성

  • ✅ 프로젝트 내에서 단일 언어를 사용하는 것이 더 나은 경우가 많습니다.
  • ✅ 팀원과 소통하세요: 터키어인가요, 아니면 영어인가요?
  • ⚠️ 혼합 사용 가능하지만 가독성이 떨어질 수 있음

도서관의 경우

  • ✅ 오픈 소스 라이브러리는 일반적으로 영어로 작성되어야 합니다.
  • ✅ 지역/특수 프로젝트는 터키어로 작성 가능
  • ✅ 두 언어로 제공되는 API 문서

이전 버전과의 호환성

BERK의 향후 버전에서는:

  • ✅ 두 언어 모두 완벽하게 지원됩니다
  • ✅ 새로운 기능이 두 언어 모두에 추가됩니다
  • ✅ 코드베이스를 변경할 필요가 없습니다

IDE 지원

VS Code 추가 기능은 두 언어를 모두 지원합니다.

  • ✅ 구문 강조
  • ✅ 자동완성
  • ✅ 오류 확인
  • ✅ 코드 조각
  • ✅ 호버 정보

컴파일러 동작

컴파일러 단계:

  1. 렉서: 터키어와 영어 키워드를 모두 인식합니다.
  2. 파서: 두 언어 모두에 대해 동일한 AST 노드를 생성합니다.
  3. 의미 분석기: 언어 차이에 관계없이
  4. 코드 생성기: 동일한 LLVM IR을 생성합니다.
Türkçe Kod    →  Lexer  →  Parser  →  AST
İngilizce Kod →  Lexer  →  Parser  →  AST (Aynı!)
                                       ↓
                              Semantic Analysis
                                       ↓
                                  Code Gen
                                       ↓
                                   LLVM IR

언어 번역 도구

BERK CLI를 사용하여 코드를 번역할 수 있습니다.

# Türkçe'den İngilizce'ye
berk-lang convert --to=english dosya.berk -o file.berk

# İngilizce'den Türkçe'ye
berk-lang convert --to=turkish file.berk -o dosya.berk
