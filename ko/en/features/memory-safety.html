BERK Programlama Dili

메모리 보안

버크,Rust 수준의 메모리 보안이는 분할 오류, 널 포인터 역참조 및 버퍼 오버플로를 BERK에서 컴파일 타임에 캡처하는 최신 시스템 프로그래밍 언어입니다.

기본 보안 보장

1. 안전이 보장되지 않음

버크에서null가치Seçenek(Option) 유형으로 명시적으로 처리됩니다.

// ❌ Err: Null olamaz
let isim: String = null  // Derleme hatası!

// ✅ Doğru: Seçenek use
let isim: Seçenek<String> = Hiçbiri

eşleştir isim do
    Bir(değer) => print("İsim: " + değer),
    Hiçbiri => print("İsim yok")
end

2. 국경 통제

어레이 액세스는 자동으로 확인됩니다.

let sayılar = [1, 2, 3, 4, 5]

// ❌ Runtime hatası: Index out of bounds
let x = sayılar[10]  // Panic!

// ✅ Güvenli erişim
if 10 < sayılar.len() do
    let x = sayılar[10]
yoksa do
    print("Geçersiz index")
end

유형 3 보안

강력한 유형 시스템을 사용하면 컴파일 타임에 런타임 오류가 포착됩니다.

// ❌ Err: Tip uyuşmazlığı
let x: sayı = "merhaba"  // Derleme hatası!

// ❌ Err: İmplicit dönüşüm yok
let y: kesir = 42  // Derleme hatası!

// ✅ Doğru: Açık dönüşüm
let y: kesir = 42.0
// or
let y: kesir = kayıt(kesir, 42)

소유권 시스템

BERK는 Rust에서 영감을 받은 소유권 시스템을 사용합니다.

기본 규칙

  1. 모든 값에는소유자있다
  2. 동시에주인은 단 한 명그럴 수도 있지
  3. 소유자가 범위를 벗어날 때의 값자동으로 청소됨

소유권 이전(이동)

function örnek() do
    let metin1 = "Merhaba"
    let metin2 = move metin1  // Sahiplik transfer edildi
    
    // ❌ Err: metin1 artık geçerli not
    print(metin1)  // Derleme hatası!
    
    // ✅ Doğru: metin2 now sahip
    print(metin2)
end

참고자료(공유)

function uzunluk_bul(share s: String) -> sayı do
    return s.len()
end

function örnek() do
    let metin1 = "Merhaba"
    let len = uzunluk_bul(share metin1)
    
    // ✅ Doğru: metin1 hala geçerli
    print(metin1)  // Çalışır!
    print("Uzunluk: " + len)
end

상호 교환 가능한 참조

function büyüt(share değiştirilebilir s: String) do
    s += " Dünya!"
end

function örnek() do
    let metin1 = "Merhaba"
    büyüt(share değiştirilebilir metin1)
    print(metin1)  // "Merhaba Dünya!"
end

수명

BERK 컴파일러는 참조의 유효성을 자동으로 확인합니다.

// ❌ Err: Dangling reference
function hatalı() -> share String do
    let yerel = "merhaba"
    return share yerel  // Derleme hatası! yerel scope dışına çıkacak
end

// ✅ Doğru: Sahipliği döndür
function true() -> String do
    let yerel = "merhaba"
    return move yerel  // Sahiplik transfer edildi
end

메모리 관리 전략

1. 자동 메모리 관리

기본적으로 BERK는 자동 메모리 관리를 사용합니다.

function örnek() do
    let List = [1, 2, 3, 4, 5]
    // Kullan...
end  // List otomatik as temizlenir

2. 지역 기반 메모리(263배 빨라짐!)

use region::Bölge;

function yüksek_performans() do
    let region = new Bölge()
    
    for i in 0..1000000 do
        let x = region.ayır(boyut_of(sayı))
        // Kullan...
    end
    
    region.temizle()  // Tek seferde tüm bellek serbest
end

3. 수동 메모리 관리(안전하지 않음)

// Sadece çok özel durumlar for
güvensiz do
    let ptr = ayır(1024)  // Raw pointer
    // Manuel yönetim...
    serbest_bırak(ptr)
end

데이터 경쟁 방지

단일 프린터 또는 다중 리더

// ❌ Err: Aynı anda birden fazla değiştirilebilir referans
let x = 5
let ref1 = share değiştirilebilir x
let ref2 = share değiştirilebilir x  // Derleme hatası!

// ✅ Doğru: Çoklu immutable referans
let x = 5
let ref1 = share x
let ref2 = share x  // OK

스레드로부터 안전한 데이터 구조

use thread::Mutex;

let count_occurrences = new Mutex(0)

function artır() do
    let kilit = count_occurrences.kilit()
    *kilit += 1
    // Kilit otomatik serbest bırakılır
end

일반적인 메모리 오류 및 예방

1.무료 사용 후 사용

C/C++에서:

int* ptr = malloc(sizeof(int));
free(ptr);
*ptr = 5;  // ❌ Use-after-free bug!

버크에서:

let x = new 42
serbest_bırak(x)
print(*x)  // ❌ Derleme hatası! x artık geçerli not

2. 더블 프리

C/C++에서:

int* ptr = malloc(sizeof(int));
free(ptr);
free(ptr);  // ❌ Double free bug!

버크에서:

let x = new 42
serbest_bırak(x)
serbest_bırak(x)  // ❌ Derleme hatası! x artık geçerli not

3. 버퍼 오버플로

C/C++에서:

int arr[5];
arr[10] = 42;  // ❌ Buffer overflow!

버크에서:

let arr = [0; 5]
arr[10] = 42  // ❌ Runtime panic! (debug modda)
              // Optimized modda bounds check yapılır

스마트 포인터

상자 - 힙 할당

let x = Kutu::new(42)
print(*x)  // 42
// Kutu scope dışına çıkınca otomatik temizlenir

Rc(참조 카운트 포함)

use bellek::Rc;

let x = Rc::new(42)
let y = x.klon()  // Referans sayısı artar
// Her iki let de aynı veriyi gösterir
// Son referans yok olunca bellek temizlenir

Arc(원자 참조 카운팅 포함 - 스레드 안전)

use bellek::Arc;
use thread;

let veri = Arc::new(vec![1, 2, 3])

let thread1 = thread::spawn(move || do
    print(veri[0])
end)

let thread2 = thread::spawn(move || do
    print(veri[1])
end)

요약

  • ✅ 무효 안전: 옵션형 있음
  • ✅ 국경 통제: 자동 배열 경계 확인
  • ✅ 유형 안전: 강력한 정적 타이핑
  • ✅ 소유권 시스템: 메모리 누수 없음
  • ✅ 수명: 매달린 참조 없음
  • ✅ 스레드 안전성: 데이터 경합을 방지합니다.
  • ✅ 비용이 들지 않는 추상화: 보안은 무료는 아니지만 매우 저렴합니다.
  • ⚡ 263배 더 빠름: 지역 메모리 포함
