BERK Programlama Dili

안녕하세요!

모든 프로그래밍 언어의 전통은 첫 번째 프로그램이 "Hello World!"라고 말하는 것입니다. 인쇄되었습니다. 우리는 BERK에서 이 전통을 이어갑니다!

첫 번째 프로그램

즐겨 사용하는 텍스트 편집기에서merhaba.berk다음 이름의 파일을 만듭니다.

function main() -> int
do
    print("Merhaba Dünya!")
    return 0
end

코드를 이해해보자

한 줄씩 살펴보겠습니다.

1. 기능 설명

function main() -> int
  • function(또는function): 기능 정의
  • ana(또는main): 함수의 이름입니다. 프로그램ana()함수에서 시작됩니다
  • (): 매개변수 목록(비어 있음)
  • -> int: 반환 유형(정수)

2. 기능 본체

do
    ...
end
  • do(또는do): 기능의 시작
  • end(또는end): 기능 종료

3.인쇄

print("Merhaba Dünya!")
  • print()(또는print()): 화면에 인쇄합니다.
  • "Merhaba Dünya!": 문자열 리터럴

4. 반환 값

return 0
  • return(또는return):기능 종료
  • 0: 성공적인 프로그램은 0을 반환합니다(Unix 전통).

영어 버전

BERK는 이중 언어를 사용합니다! 동일한 프로그램을 영어로 작성할 수도 있습니다.

hello.berk:

function main() -> integer
do
    print("Hello World!")
    return 0
end

편집:

BERK-lang hello.berk -o hello.exe
./hello.exe

산출:

Hello World!

혼합 사용

터키어와 영어를 혼합할 수도 있습니다.

function main() -> int
do
    print("Hello Dünya!")

end

이것도 유효한 BERK 코드입니다!

수업 과정

연습 1: 개인화

자신의 이름을 인쇄하도록 프로그램을 변경하십시오.

function main() -> int
do
    print("Merhaba, [ADINIZ]!")
    return 0
end

연습 2: 다중 인쇄

여러 줄을 인쇄합니다.

function main() -> int
do
    print("Merhaba Dünya!")
    print("BERK'a hoş geldiniz!")
    print("İyi kodlamalar!")
    return 0
end

연습 3: 변수 사용

문자열을 변수에 저장합니다.

function main() -> int
do
    let mesaj = "Merhaba Dünya!"
    print(mesaj)
    return 0
end

연습 4: 문자열 연결

두 문자열을 연결합니다.

function main() -> int
do
    let selamlama = "Merhaba"
    let isim = "Ahmet"
    print(selamlama + ", " + isim + "!")
    return 0
end

일반적인 실수

오류 1: 세미콜론 없음

BERK의 세미콜론필요하지 않다:

// ❌ Yanlış
print("Merhaba");

// ✅ Doğru
print("Merhaba")

오류 2: 괄호 누락

// ❌ Yanlış
print "Merhaba"

// ✅ Doğru
print("Merhaba")

오류 3: main() 함수 없음

// ❌ Yanlış - main() fonksiyonu yok
print("Merhaba")

// ✅ Doğru - main() fonksiyonu var
function main() -> int
do
    print("Merhaba")
    return 0
end

오류 4: 반환 값이 누락되었습니다.

// ❌ Yanlış - return eksik
function main() -> int
do
    print("Merhaba")
end

// ✅ Doğru - return var
function main() -> int
do
    print("Merhaba")
    return 0
end
