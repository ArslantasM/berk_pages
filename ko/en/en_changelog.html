BERK Programlama Dili

변경 내역

BERK 버전 기록. 각 버전에는 성능, 보안 및 기능에 초점을 맞춘 개선 사항이 포함되어 있습니다.

v1.0.0 - 프로덕션 릴리스(2025년 12월 2일)

근본적인 변화

  • LLVM 동적 연결: 정적 LLVM 대신 동적 연결 사용
  • 파일 크기: 83MB → 3.8MB (22배 감소)
    • BERK-lang.exe: 2.2MB
    • berk-lsp.exe: 1.2MB
    • berk-repl.exe: 464KB
  • 세 개의 별도 바이너리: 컴파일러, LSP 및 REPL 별도의 실행 파일
  • 생산 준비: 완성도 99%, 주요 기능 모두 안정적

완전한 기능

  • 소유권 시스템(98/98 테스트)
  • FFI(외부 함수 인터페이스, 30개 이상의 테스트)
  • BPM(패키지 관리자, 29/30 테스트)
  • LSP v0.9.4(9/9 기능)
  • HAL(33개 모듈, 7개 플랫폼)
  • 총 모듈 75개(42 stdlib + 33 HAL)
  • 4100개 이상의 기능

제거된 종속성

  • LLVM 정적 라이브러리는 이제 바이너리에 내장되어 있습니다.
  • LLVM 17은 사용자 시스템에 설치되어야 합니다(이전에는 필요함).

v0.8.0 - 표준 라이브러리 v1.4 "과학 컴퓨팅"

주요 업데이트

표준 라이브러리 v1.4 - 과학 컴퓨팅

대학 및 연구 수준의 수학 도서관. NumPy/SciPy 수준 기능, 기본 성능.

새 모듈(3개, 76.5KB):

  1. 라이날그(25.4KB) - 선형대수학
    • 행렬 연산(곱하기, 전치, 역)
    • 분해(LU, QR, Cholesky, SVD)
    • 고유값/고유벡터 계산
    • 선형 시스템 솔버
  2. 통계(24.5KB) - 통계 및 확률
    • 기술 통계(평균, 중앙값, 분산, 표준)
    • 확률 분포(정규, 카이제곱, t-검정)
    • 가설 검정(t-검정, ANOVA, 카이제곱)
    • 회귀 분석(선형, 다항식, 다중)
  3. 최적(26.6KB) - 최적화 알고리즘
    • 제약 없는 최적화(경사하강법, BFGS, 뉴턴)
    • 제한된 최적화(페널티 방법)
    • 전역 최적화(시뮬레이션 어닐링, 유전)
    • 근 찾기(이등분, Newton-Raphson, 시컨트)

향상된 모듈:

  • 푸시(9.2KB → 19.7KB, +10.5KB) - 반복자 확장, 지연 평가
  • fmt(9.1KB → 17.9KB, +8.8KB) - 고급 형식, printf 스타일

런타임 라이브러리 v0.9

  • JSON 라이브러리: 고성능 구문 분석/직렬화(11/11 테스트 통과)
  • 암호화 라이브러리: MD5, SHA-256, Base64, 보안 랜덤(13/13 테스트 통과)
  • HTTP 라이브러리: libcurl 백엔드가 있는 REST 클라이언트(11/11 테스트 통과)

컴파일러 개선

  • LLVM 백엔드: 네이티브 코드 생성, C/C++ 수준의 성능
  • CFG 분석: 제어 흐름 그래프 최적화
  • 데이터 흐름 최적화: 데드코드 제거, 지속적인 전파
  • 패턴 매칭: 완전성 검사, 보호 조항
  • 오류 처리: 결과 유형, try-catch 메커니즘

플랫폼 지원

19개 대상 플랫폼:

  • 데스크탑: Windows x64(활성), Linux x64, macOS ARM64
  • 임베디드: ARM Cortex-M, RISC-V, AVR(아두이노), ESP32
  • 이동하는: 안드로이드(ARM/x86), iOS(ARM64)
  • 웹어셈블리: WASM32, WASI

압형

  • REPL: 대화형 쉘, 즉시 실행
  • JIT 모드: 컴파일 없이 직접 실행
  • AOT 모드: 네이티브 실행 파일 생성
  • VS 코드 확장: 구문 강조, 코드 완성, 진단

Stdlib 통계

  • 총 75개 모듈:
    • 42개 코어/stdlib 모듈(코어, 수학/과학, 웹/데이터, 그래픽/게임, 고급)
    • 33개 HAL 모듈(임베디드 시스템 하드웨어 추상화)
  • 1140KB총 stdlib 코드(HAL 제외)
  • 4100개 이상의 기능: 모든 도메인에 걸친 포괄적인 API 적용 범위
  • 성능: 기본 구현, LLVM 최적화, 외부 런타임 종속성 없음

실적 하이라이트

  • 실행 속도: C/C++ 수준(98-100%)
  • 바이너리 크기: 83MB(LLVM 정적으로 연결됨 - v1.0.0에서 제거됨)
  • 최적화 수준: -O0(디버그) ~ -O3(최대 속도)
  • 비용이 전혀 들지 않는 추상화: 높은 수준의 구문, 낮은 수준의 성능

선적 서류 비치

  • 101페이지: 완전한 언어 참조
  • 42개의 stdlib 모듈: 전체 API 문서(코어, 수학, 웹, 그래픽)
  • HAL 모듈 33개: 임베디드 시스템을 위한 하드웨어 추상화
  • 이중 언어: 터키어/영어 병행 문서
  • 총: 75개의 라이브러리 모듈이 문서화되어 있습니다.

알려진 제한 사항

  • Windows 전용 컴파일러: 소스에서 Linux/macOS 빌드
  • 수동 메모리 관리: v1.5에 예정된 소유권 시스템
  • FFI 없음: v1.0에서는 C/C++ 상호 운용이 예정되어 있습니다.
  • 비동기/대기 없음: v1.0에서는 고성능 비동기화 예정
