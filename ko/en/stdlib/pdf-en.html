📖 개요

프로그래밍 방식의 PDF 문서 생성 및 조작. 텍스트, 도형, 이미지 및 다중 페이지 문서를 지원합니다.

🚀 빠른 시작

import pdf

// Create PDF
let doc = pdf.new()
doc.set_title("My Document")
doc.set_author("BERK")

// Add page
let page = doc.add_page(pdf.A4)
page.text(100, 700, "Hello PDF!", 12)
page.line(100, 690, 200, 690)

// Save
doc.save("output.pdf")?
