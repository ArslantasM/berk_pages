TOML v1.0.0 파서

~350줄 ~30가지 기능 v1.0.0

📖 개요

구성 파일용 TOML(Tom's Obvious Minimal Language) 파서. 문자열, 정수, 부동 소수점, 부울, 배열 및 테이블을 지원하여 인간 친화적입니다.

🚀 빠른 시작

import toml

let config = toml.parse("
    [database]
    host = \"localhost\"
    port = 5432
    
    [server]
    bind = \"0.0.0.0:8080\"
    workers = 4
")?

let host = config.get("database.host")?
let port = config.get_int("database.port")?
println("DB: {}:{}", host, port)
