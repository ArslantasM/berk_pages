BERK Programming Language

🎲 상태::rng

하드웨어 진정한 난수 생성기

~380줄 ~14가지 기능 STM32F4/F7/H7

📖 개요

RNG 모듈은 하드웨어 기반의 실제 난수를 생성합니다. 아날로그 노이즈 소스를 이용하여 암호화 품질의 난수값을 제공합니다. IoT 보안을 위해서는 UUID 생성, 암호화 키 생성 및 몬테카를로 시뮬레이션이 중요합니다.

🔑 주요 기능

  • 진정한 무작위:의사 랜덤 노트, 아날로그 노이즈 소스
  • 32비트 출력:각 읽기에서 전체 32비트 임의 값
  • FIPS 140-2 준수:암호화 표준 준수
  • 단일 사이클:40 CPU 주기의 새로운 임의 값
  • 시계 오류 감지:시계 문제가 감지되었습니다.
  • 시드 오류 감지:엔트로피 오류가 감지되었습니다.
  • 인터럽트 지원:데이터 준비 인터럽트
  • DMA 호환:지속적인 무작위 스트림

💡 예 1: UUID 생성(RFC 4122)

문제: 고유 식별자(IoT 장치 ID) 생성

import hal::rng

struct UUID do
    data: Dizi<sayı8> = Dizi.new(16)
end

function uuid_v4_generate() -> UUID do
    variable uuid = UUID do end
    
    // Generate 128 bits (16 bytes) of random data
    for i in 0..4 do
        variable rand32 = rng.get_random()
        
        // Split into 4 bytes
        uuid.data[i*4 + 0] = (rand32 >> 24) & 0xFF kayıt sayı8
        uuid.data[i*4 + 1] = (rand32 >> 16) & 0xFF kayıt sayı8
        uuid.data[i*4 + 2] = (rand32 >> 8) & 0xFF kayıt sayı8
        uuid.data[i*4 + 3] = rand32 & 0xFF kayıt sayı8
    end
    
    // Set version (4) and variant (RFC 4122)
    uuid.data[6] = (uuid.data[6] & 0x0F) | 0x40  // Version 4
    uuid.data[8] = (uuid.data[8] & 0x3F) | 0x80  // Variant RFC4122
    
    return uuid
end

function uuid_to_string(uuid: UUID) -> Metin do
    // Format: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx
    variable hex = ""
    for i in 0..16 do
        hex = hex + uuid.data[i].onaltılıya(2)
        if (i == 3 or i == 5 or i == 7 or i == 9) do
            hex = hex + "-"
        end
    end
    return hex
end

function main() do
    rng.init()
    
    for i in 0..5 do
        variable uuid = uuid_v4_generate()
        io.yazdir_satır("UUID: " + uuid_to_string(uuid))
    end
end

💡 예 2: 암호화 키 생성

문제: 256비트 임의 키용 AES-256 생성

import hal::rng, hal::crypto

constant AES256_KEY_SIZE: sayı = 32  // 256 bit = 32 bytes

struct CryptoKey do
    data: Dizi<sayı8>,
    size: sayı
end

function generate_aes256_key() -> CryptoKey do
    variable key = CryptoKey do
        data: Dizi.new(AES256_KEY_SIZE),
        size: AES256_KEY_SIZE
    end
    
    // Generate 256 bits of cryptographic random data
    for i in 0..8 do  // 8 * 32 bits = 256 bits
        variable rand = rng.get_random()
        
        if rng.get_flag(rng.FLAG_CECS) or rng.get_flag(rng.FLAG_SECS) do
            io.yazdir_satır("RNG ERROR: Clock or seed error!")
            return key  // Invalid key
        end
        
        key.data[i*4 + 0] = (rand >> 24) & 0xFF kayıt sayı8
        key.data[i*4 + 1] = (rand >> 16) & 0xFF kayıt sayı8
        key.data[i*4 + 2] = (rand >> 8) & 0xFF kayıt sayı8
        key.data[i*4 + 3] = rand & 0xFF kayıt sayı8
    end
    
    return key
end

function key_to_hex(key: CryptoKey) -> Metin do
    variable hex = ""
    for byte in key.data do
        hex = hex + byte.onaltılıya(2)
    end
    return hex
end

function main() do
    rng.init()
    
    io.yazdir_satır("Generating AES-256 key...")
    variable key = generate_aes256_key()
    io.yazdir_satır("Key: " + key_to_hex(key))
    
    // Use key for AES encryption
    crypto.aes_init(crypto.AES256, key.data)
end

보안:하드웨어 RNG 사용은 소프트웨어 PRNG보다 훨씬 안전합니다.

💡 예 3: 난수 분포(주사위 굴림)

문제: 균일한 분포를 사용한 주사위 굴리기 시뮬레이션

import hal::rng

// Random in range [min, max]
function random_range(min: sayı, max: sayı) -> sayı do
    variable range = max - min + 1
    variable rand = rng.get_random()
    
    // Avoid modulo bias using rejection sampling
    variable limit = 0xFFFF_FFFF - (0xFFFF_FFFF % range)
    
    loop do
        if rand < limit do
            return min + (rand % range)
        end
        rand = rng.get_random()
    end
end

function dice_roll() -> sayı do
    return random_range(1, 6)
end

function test_distribution() do
    variable histogram: Dizi<sayı> = Dizi.new(6, 0)
    constant ROLLS: sayı = 10000
    
    for i in 0..ROLLS do
        variable roll = dice_roll()
        histogram[roll - 1] = histogram[roll - 1] + 1
    end
    
    io.yazdir_satır("Dice roll distribution (" + ROLLS.metne() + " rolls):")
    for i in 0..6 do
        variable face = i + 1
        variable count = histogram[i]
        variable percent = (count kayıt kesir / ROLLS kayıt kesir) * 100.0
        
        io.yazdir_satır("  [" + face.metne() + "]: " + count.metne() +
                        " (" + percent.metne() + "%)")
    end
end

function main() do
    rng.init()
    test_distribution()
end

결론:100개당 ~16.67%의 균일 분포(이상적: 16.666...%).

⚠️ 중요 사항:
  • 필요한 시계:48MHz 클록에 대한 RNG 필요(PLL에서)
  • 오류 처리:CECS/SECS 플래그를 확인해야 합니다.
  • 첫 번째 읽기:~40주기 대기에 대한 첫 번째 임의 값
  • 모듈로 바이어스:범위 작업에서 거부 샘플링 사용

🖥️ 플랫폼 지원

STM32F4 ✅ 예 PLL 48MHz 40사이클

✅ 모범 사례

  • ✅ 오류 확인:CECS/SECS 플래그 확인
  • ✅ 파종:RNG에 PRNG 시드 사용
  • ✅ 키 생성:RNG의 암호화 키는 필수입니다
  • ✅ 거부 샘플링:모듈로 바이어스 방지
  • ❌ 예상 가능한 메모:RNG 디버그에서도 예측 불가능
  • ❌ 시계 종속성:48MHz 클럭이 없으면 작동하지 않습니다.
