🔐 상태::crc

하드웨어 CRC32 계산기 - 빠른 데이터 무결성 검사

~360줄 ~12가지 기능 STM32/GD32

📖 개요

CRC 모듈은 하드웨어 가속 CRC32 계산을 제공합니다. 다항식 0x04C11DB7(이더넷 표준)을 사용합니다. 이는 펌웨어 무결성 검사, 플래시 검증, 통신 프로토콜 및 데이터 손상 감지에 매우 중요합니다. 소프트웨어 CRC보다 10~100배 빠릅니다.

🔑 주요 기능

  • 하드웨어 CRC32:단일 주기 32비트 CRC 계산
  • 표준 다항식:0x04C11DB7(이더넷, ZIP, PNG)
  • 빠른 성능:32비트 워드당 1클럭 사이클
  • 초기값:구성 가능(기본값 0xFFFFFFFF)
  • DMA 호환:DMA 전송과 함께 사용할 수 있습니다.
  • 축적:순차적 CRC 계산 지원
  • 재설정 기능:초기값으로의 빠른 재설정
  • 저전력:최소 전력 소비

🚀 빠른 시작

import hal::crc, hal::rcc

// Enable CRC clock
rcc.periph_clock_enable(rcc.PERIPH_CRC)

// Initialize CRC
crc.init()

// Calculate CRC32 of data
let data: Dizi<sayı> = [0x12345678, 0xABCDEF00, 0xDEADBEEF]
let checksum = crc.calculate(data)

io.yazdir_satır("CRC32: 0x" + checksum.onaltılıya())

// Verify data
if crc.verify(data, checksum) do
    io.yazdir_satır("Data integrity OK")
end

💡 예 1: 펌웨어 무결성 검사

문제: 플래시의 펌웨어가 손상되지 않았는지 확인

import hal::crc, hal::flash

const FIRMWARE_START: sayı = 0x0800_8000  // Application start
const FIRMWARE_SIZE: sayı = 128 * 1024     // 128 KB
const CRC_STORAGE: sayı = 0x0807_FFFC      // Last 4 bytes of app region

function firmware_calculate_crc() -> sayı do
    crc.reset()
    
    // Calculate CRC of firmware (32-bit words)
    let word_count = FIRMWARE_SIZE / 4
    let addr = FIRMWARE_START
    
    for i in 0..word_count do
        let word = *(addr kayıt *sayı)
        crc.accumulate(word)
        addr = addr + 4
    end
    
    return crc.get_value()
end

function firmware_store_crc(checksum: sayı) do
    // Unlock flash
    flash.unlock()
    
    // Erase last page
    flash.erase_page(CRC_STORAGE)
    
    // Write CRC
    flash.program_word(CRC_STORAGE, checksum)
    
    flash.lock()
    
    io.yazdir_satır("CRC stored: 0x" + checksum.onaltılıya())
end

function firmware_verify() -> mantık do
    // Read stored CRC
    let stored_crc = *(CRC_STORAGE kayıt *sayı)
    
    // Calculate current CRC
    let calculated_crc = firmware_calculate_crc()
    
    io.yazdir_satır("Stored CRC:     0x" + stored_crc.onaltılıya())
    io.yazdir_satır("Calculated CRC: 0x" + calculated_crc.onaltılıya())
    
    if stored_crc == calculated_crc do
        io.yazdir_satır("✅ Firmware integrity OK")
        return true
    yoksa do
        io.yazdir_satır("❌ Firmware corrupted!")
        return false
    end
end

function main() do
    crc.init()
    
    // On firmware update: store CRC
    // firmware_store_crc(firmware_calculate_crc())
    
    // On boot: verify firmware
    if not firmware_verify() do
        io.yazdir_satır("ERROR: Cannot start corrupted firmware")
        // Enter safe mode or bootloader
        for do end  // Halt
    end
    
    io.yazdir_satır("Starting application...")
end

결론:부팅 중에 펌웨어 손상이 감지되었습니다. 안전한 시동이 보장됩니다.

💡 예 2: UART 패킷 확인

문제: 직렬 통신에서 패킷 무결성 검사

import hal::crc, hal::usart

struct Packet do
    header: sayı8 = 0xAA,
    length: sayı8,
    data: Dizi<sayı8>,
    crc32: sayı
end

function packet_calculate_crc(pkt: Packet) -> sayı do
    crc.reset()
    
    // CRC over header + length + data
    crc.accumulate_byte(pkt.header)
    crc.accumulate_byte(pkt.length)
    
    for byte in pkt.data do
        crc.accumulate_byte(byte)
    end
    
    return crc.get_value()
end

function packet_send(pkt: Packet) do
    // Calculate CRC
    pkt.crc32 = packet_calculate_crc(pkt)
    
    // Send packet
    usart.write_byte(usart.USART1, pkt.header)
    usart.write_byte(usart.USART1, pkt.length)
    
    for byte in pkt.data do
        usart.write_byte(usart.USART1, byte)
    end
    
    // Send CRC (big-endian)
    usart.write_byte(usart.USART1, (pkt.crc32 >> 24) & 0xFF kayıt sayı8)
    usart.write_byte(usart.USART1, (pkt.crc32 >> 16) & 0xFF kayıt sayı8)
    usart.write_byte(usart.USART1, (pkt.crc32 >> 8) & 0xFF kayıt sayı8)
    usart.write_byte(usart.USART1, pkt.crc32 & 0xFF kayıt sayı8)
end

function packet_receive() -> Seçenek<Packet> do
    // Read header
    let header = usart.read_byte(usart.USART1)
    if header != 0xAA do
        return Seçenek.Hiçbiri
    end
    
    // Read length
    let length = usart.read_byte(usart.USART1)
    
    // Read data
    let data = Dizi.new(length)
    for i in 0..length do
        data[i] = usart.read_byte(usart.USART1)
    end
    
    // Read CRC
    let crc_recv = 0 kayıt sayı
    crc_recv = (crc_recv << 8) | usart.read_byte(usart.USART1) kayıt sayı
    crc_recv = (crc_recv << 8) | usart.read_byte(usart.USART1) kayıt sayı
    crc_recv = (crc_recv << 8) | usart.read_byte(usart.USART1) kayıt sayı
    crc_recv = (crc_recv << 8) | usart.read_byte(usart.USART1) kayıt sayı
    
    // Create packet
    let pkt = Packet do
        header: header,
        length: length,
        data: data,
        crc32: crc_recv
    end
    
    // Verify CRC
    let crc_calc = packet_calculate_crc(pkt)
    
    if crc_calc == crc_recv do
        io.yazdir_satır("✅ Packet CRC OK")
        return Seçenek.Some(pkt)
    yoksa do
        io.yazdir_satır("❌ Packet CRC mismatch!")
        return Seçenek.Hiçbiri
    end
end

결론:UART를 통해 들어오는 손상된 패킷은 거부됩니다. 데이터 무결성이 보장됩니다.

💡 예 3: SD 카드 파일 확인

문제: SD 카드에서 읽은 파일이 손상되지 않았는지 확인

import hal::crc, hal::sdio

function file_calculate_crc(filename: Metin) -> sayı do
    // Open file
    let file = sdio.file_open(filename, sdio.MODE_READ)
    
    if not file.is_valid() do
        io.yazdir_satır("ERROR: Cannot open file")
        return 0
    end
    
    crc.reset()
    
    // Read file in 512-byte blocks
    let buffer: Dizi<sayı8> = Dizi.new(512)
    
    for do
        let bytes_read = sdio.file_read(file, buffer)
        
        if bytes_read == 0 do
            kır  // EOF
        end
        
        // Process full 32-bit words
        for i in 0..(bytes_read/4) do
            let word = (buffer[i*4] kayıt sayı) |
                           ((buffer[i*4+1] kayıt sayı) << 8) |
                           ((buffer[i*4+2] kayıt sayı) << 16) |
                           ((buffer[i*4+3] kayıt sayı) << 24)
            crc.accumulate(word)
        end
        
        // Handle remaining bytes
        let remainder = bytes_read % 4
        if remainder > 0 do
            for i in (bytes_read - remainder)..bytes_read do
                crc.accumulate_byte(buffer[i])
            end
        end
    end
    
    sdio.file_close(file)
    
    return crc.get_value()
end

function file_verify(filename: Metin, expected_crc: sayı) -> mantık do
    io.yazdir_satır("Verifying " + filename + "...")
    
    let calculated = file_calculate_crc(filename)
    
    io.yazdir_satır("Expected:   0x" + expected_crc.onaltılıya())
    io.yazdir_satır("Calculated: 0x" + calculated.onaltılıya())
    
    return calculated == expected_crc
end

사용:SD 카드에서 읽는 동안 펌웨어 업데이트 파일이 손상되지 않도록 보장합니다.

⚠️ 중요 사항:
  • 단어 정렬:CRC 하드웨어는 32비트 워드 정렬로 작동합니다.
  • 바이트 순서:리틀 엔디안 프로세서의 경우 바이트 순서를 고려해야 합니다.
  • 초기값:재설정 후 0xFFFFFFFF(0x00000000 참고)
  • 최종 XOR:일부 프로토콜에는 최종 XOR 0xFFFFFFFF가 필요합니다.

✅ 모범 사례

  • ✅ 펌웨어 확인:부팅 중 펌웨어 CRC 확인
  • ✅ 의사소통:패키지에서 CRC 사용(특히 무선)
  • ✅ 저장:플래시/SD 카드에서 데이터 읽기를 위한 CRC
  • ✅ 사용 전 재설정:각 계산 전에 crc.reset()을 호출하세요.
  • ❌ 암호화폐용 아님:CRC는 보안용이 아닌 오류 감지용입니다.
  • ❌ 바이트 정렬:정렬되지 않은 액세스로 인해 성능 손실이 발생함
