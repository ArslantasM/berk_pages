📝 yaml - YAML 작업

YAML(YAML Ain't Markup Language) 파일 읽기 및 쓰기

📦 59가지 기능 📝 595줄 💾 15.7KB

📋개요

yaml이 모듈은 YAML 형식의 구성 파일을 읽고, 쓰고, 편집하기 위한 도구를 제공합니다. 사람이 읽을 수 있는 데이터 직렬화 형식인 YAML을 사용하여 쉽게 작업할 수 있습니다.

📖 YAML 구문 분석

  • yaml.parse()- YAML 텍스트를 BERK 데이터 구조로 변환
  • load_from yaml.file()- YAML 파일 읽기
  • yaml.secure_load()- 보안 YAML 구문 분석
  • yaml.multi_load()- 여러 YAML 문서 업로드

✏️ YAML 생성

  • yaml.yaz()- BERK 데이터를 YAML 형식으로 변환
  • yaml.write_to_file()- YAML 파일에 쓰기
  • yaml.multi_write()- 여러 문서 작성

🔧 구성 옵션

  • yaml.indent()- 들여쓰기 수준 조정
  • yaml.폭()- 선 너비 조정
  • yaml.flow_style()- 스트림 또는 블록 스타일 선택
  • yaml.default_stream()- 기본 스트리밍 스타일 설정

💡 사용 예

YAML 구성 파일 읽기

use yaml
use fs

// config.yaml dosyası:
// veritabanı:
//   sunucu: localhost
//   port: 5432
//   kullanıcı: admin
//   parola: güvenli123
//   veritabanları:
//     - üretim
//     - test
//     - geliştirme
//
// uygulama:
//   ad: BerkApp
//   sürüm: 1.0.0
//   ortam: üretim
//   özellikler:
//     cache_aktif: true
//     log_seviye: info
//     max_bağlantı: 100

değer yapılandırma = yaml.dosyadan_yükle("config.yaml")

// Yapılandırma değerlerini okuma
değer vt_sunucu = yapılandırma["veritabanı"]["sunucu"]
değer vt_port = yapılandırma["veritabanı"]["port"]
değer uygulama_ad = yapılandırma["uygulama"]["ad"]

print(f"Uygulama: {uygulama_ad}")
print(f"Veritabanı: {vt_sunucu}:{vt_port}")

// Veritabanı listesi
değer veritabanları = yapılandırma["veritabanı"]["veritabanları"]
print("\nMevcut veritabanları:")
for vt in veritabanları {
    print(f"  - {vt}")
}

// Özellikler
değer özellikler = yapılandırma["uygulama"]["özellikler"]
if özellikler["cache_aktif"] {
    print("\nÖnbellek aktif")
}
print(f"Log seviyesi: {özellikler['log_seviye']}")
print(f"Maksimum bağlantı: {özellikler['max_bağlantı']}")

YAML 구성 생성

use yaml

// Uygulama yapılandırması oluşturma
değer yapılandırma = {
    "sunucu": {
        "host": "0.0.0.0",
        "port": 8080,
        "ssl": {
            "aktif": true,
            "sertifika": "/path/to/cert.pem",
            "anahtar": "/path/to/key.pem"
        }
    },
    "veritabanı": {
        "sürücü": "postgresql",
        "bağlantı": {
            "host": "localhost",
            "port": 5432,
            "kullanıcı": "app_user",
            "parola": "güvenli_parola"
        },
        "havuz": {
            "min_boyut": 5,
            "max_boyut": 20,
            "timeout": 30
        }
    },
    "özellikler": {
        "hata_ayıklama": false,
        "log_dosyası": "/var/log/app.log",
        "log_seviye": "info",
        "izin_verilen_originler": [
            "https://example.com",
            "https://api.example.com",
            "https://admin.example.com"
        ]
    },
    "cache": {
        "type": "redis",
        "sunucu": "localhost:6379",
        "ttl": 3600,
        "önbellek_anahtarları": [
            "kullanıcı_oturumları",
            "ürün_listesi",
            "yapılandırma"
        ]
    }
}

// YAML dosyasına yazma
yaml.dosyaya_yaz(yapılandırma, "app_config.yaml")
print("Yapılandırma dosyası oluşturuldu!")

// YAML metnine dönüştürme
değer yaml_metin = yaml.print(yapılandırma)
print("\nYAML içeriği:")
print(yaml_metin)

Kubernetes 매니페스트 관리자

use yaml

class K8sManifest {
    function deployment_oluştur(ad: Dize, imaj: Dize, port: Tam, replika: Tam) -> Sözlük {
        return {
            "apiVersion": "apps/v1",
            "kind": "Deployment",
            "metadata": {
                "name": ad,
                "labels": {
                    "app": ad
                }
            },
            "spec": {
                "replicas": replika,
                "selector": {
                    "matchLabels": {
                        "app": ad
                    }
                },
                "template": {
                    "metadata": {
                        "labels": {
                            "app": ad
                        }
                    },
                    "spec": {
                        "containers": [{
                            "name": ad,
                            "image": imaj,
                            "ports": [{
                                "containerPort": port
                            }]
                        }]
                    }
                }
            }
        }
    }
    
    function service_oluştur(ad: Dize, port: Tam, hedef_port: Tam) -> Sözlük {
        return {
            "apiVersion": "v1",
            "kind": "Service",
            "metadata": {
                "name": f"{ad}-service"
            },
            "spec": {
                "type": "LoadBalancer",
                "selector": {
                    "app": ad
                },
                "ports": [{
                    "protocol": "TCP",
                    "port": port,
                    "targetPort": hedef_port
                }]
            }
        }
    }
}

// Kubernetes manifestleri oluşturma
değer k8s = K8sManifest {}

değer deployment = k8s.deployment_oluştur(
    "web-app",
    "nginx:1.21",
    80,
    3
)

değer service = k8s.service_oluştur("web-app", 80, 80)

// Tek dosyaya birden fazla manifest yazma
değer manifestler = [deployment, service]
yaml.dosyaya_yaz(manifestler, "k8s-deployment.yaml")

print("Kubernetes manifestleri oluşturuldu!")
print(f"Deployment: {deployment['metadata']['name']}")
print(f"Replika sayısı: {deployment['spec']['replicas']}")
print(f"Service: {service['metadata']['name']}")
