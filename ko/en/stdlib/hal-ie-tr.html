📖 개요

이벤트 핸들러 및 콜백 관리를 중단합니다.

🚀 사용법

import hal::ie

// Register event handler
ie.register(ie.EVENT_GPIO_EXTI0, my_handler)

// Unregister
ie.unregister(ie.EVENT_GPIO_EXTI0)

// Trigger software event
ie.trigger(ie.EVENT_TIM2_UPDATE)

// Check pending events
if ie.is_pending(ie.EVENT_USART1_RX) then do
    ie.clear_pending(ie.EVENT_USART1_RX)
end
