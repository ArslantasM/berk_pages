📖 개요

TOML 모듈은 구성 파일을 위한 인간 친화적인 TOML v1.0.0 파서를 제공합니다. 문자열, 정수, 부동 소수점, 부울, 배열, 테이블 및 인라인 테이블을 지원합니다.

🚀 빠른 시작

import toml

// Parse TOML
let config = toml.parse("
    [database]
    host = \"localhost\"
    port = 5432
    
    [server]
    bind = \"0.0.0.0:8080\"
    workers = 4
")?

let host = config.get("database.host")?
let port = config.get_int("database.port")?
