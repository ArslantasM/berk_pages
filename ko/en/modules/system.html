BERK Programlama Dili

모듈 시스템

버크에서각 파일은 모듈입니다. 모듈 시스템은 코드를 구성하고 재사용하는 기본 방법입니다.

기본 개념

모듈이란 무엇입니까?

모듈은 관련 함수, 구조 및 상수를 포함하는 코드 단위입니다. 각.berk파일은 자동으로 모듈이 됩니다.

// matematik.berk - Bu dosya "matematik" modülüdür
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

export const PI = 3.14159

모듈 계층

모듈은 파일 시스템 구조를 따릅니다.

proje/
├── ana.berk
├── matematik/
│   ├── temel.berk       (matematik::temel)
│   ├── geometri.berk    (matematik::geometri)
│   └── ileri.berk       (matematik::ileri)
└── io/
    └── dosya.berk       (io::dosya)

모듈 사용법

사용 설명

// Modül içe aktarma
kullan matematik;

// Belirli öğeleri içe aktarma
kullan matematik::topla;
kullan matematik::{topla, çarp, PI};

// Tüm öğeleri içe aktarma
kullan matematik::*;

// Takma ad ile kullanım
kullan matematik::topla olarak toplama;

모듈 경로

// Alt modül erişimi
kullan matematik::geometri::alan;

// İç içe modüller
kullan matematik::geometri::{alan, çevre, hacim};

시계

수출_수출 키워드

기본적으로 모든 항목특별하다. 외부 접근용dışa_aktar사용:

// Genel function - dışarıdan erişilebilir
export function hesapla() -> sayı do
    return dahili_hesaplama()
end

// Özel function - sadece bu modülde kullanılabilir
function dahili_hesaplama() -> sayı do
    return 42
end

구조 및 열거형 가시성

// Genel struct
export struct Nokta do
    x: sayı
    y: sayı
end

// Özel struct
struct DahiliVeri do
    değer: sayı
end

모듈 구성

단일 파일 모듈

// matematik.berk
export function topla(a: sayı, b: sayı) -> sayı do return a + b end
export function çarp(a: sayı, b: sayı) -> sayı do return a * b end

다중 파일 모듈

matematik/
├── temel.berk      // matematik::temel
├── geometri.berk   // matematik::geometri
└── trigonometri.berk // matematik::trigonometri

// ana.berk
kullan matematik::temel::topla;
kullan matematik::geometri::alan;

모듈 분석

검색 순서

BERK 컴파일러는 다음 순서로 모듈을 검색합니다.

  1. 현재 디렉터리: ./
  2. 소스 디렉토리: ./src/
  3. 표준 라이브러리: ./stdlib/
  4. 외부 패키지: ~/.berk/packages/

예시 분석

kullan matematik::geometri;
// Arama sırası:
// 1. ./matematik/geometri.berk
// 2. ./src/matematik/geometri.berk
// 3. ./stdlib/matematik/geometri.berk
// 4. ~/.berk/packages/matematik/geometri.berk

표준 라이브러리 모듈

use io;              // Giriş/Çıkış işlemleri
use String;           // String işlemleri
use matematik;       // Matematik fonksiyonları
use koleksiyonlar;   // Liste, HashMap vb.
use dosya;           // Dosya işlemleri
use ağ;              // Network işlemleri

모범 사례

  • ✅ 그룹 관련 코드: 동일한 모듈에 유사한 기능을 유지합니다.
  • ✅ 명확한 명사를 사용하세요: 모듈 이름은 내용을 명확하게 나타내야 합니다.
  • ✅ 최소 수출: 꼭 필요한 것만 내보내기
  • ✅ 순환 종속성 방지: A → B → A로 만들기
  • ✅ 일관된 구조: 프로젝트의 모든 모듈은 유사한 구조를 가져야 합니다.

예

간단한 수학 모듈

// matematik.berk
export const PI = 3.14159
export const E = 2.71828

export function kare(x: sayı) -> sayı do
    return x * x
end

export function küp(x: sayı) -> sayı do
    return x * x * x
end

용법

// main.berk
use matematik::{kare, PI};

function main() do
    let sonuç = kare(5)
    print("Kare: {}", sonuç)
    print("Pi: {}", PI)
end
