BERK Programlama Dili

안녕하세요 월드!

모든 프로그래밍 언어의 전통, 첫 번째 프로그램 "Hello World!" 인쇄하는 것입니다. 우리는 BERK에서도 이 전통을 이어갑니다!

첫 번째 프로그램

즐겨 사용하는 텍스트 편집기에서hello.berk다음 이름의 파일을 만듭니다.

function ana() -> integer
do
    print("Hello World!")
    return 0
end

코드 이해

한 줄씩 살펴보겠습니다.

1. 기능 정의

function ana() -> integer
  • function(또는function): 함수를 정의합니다.
  • ana(또는main): 함수 이름입니다. 프로그램ana()기능 시작
  • (): 매개변수 목록(비어 있음)
  • -> integer: 반환 유형(정수)

2. 기능 본체

do
    ...
end
  • do(또는do): 기능 시작
  • end(또는end): 기능 종료

3.인쇄

print("Hello World!")
  • print()(또는print()): 화면에 인쇄합니다.
  • "Hello World!": 문자열 리터럴

4. 반환 값

return 0
  • return(또는return):기능 종료
  • 0: 성공적인 프로그램은 0을 반환합니다(Unix 전통).

수업 과정

연습 1: 개인화

자신의 이름을 인쇄하도록 프로그램을 수정하세요.

function main() -> integer
do
    print("Hello, [YOUR NAME]!")
    return 0
end

연습 2: 다중 압력

여러 줄을 인쇄합니다.

function main() -> integer
do
    print("Hello World!")
    print("Welcome to BERK!")
    print("Happy coding!")
    return 0
end

연습 3: 다양한 사용법

문자열을 변수에 저장합니다.

function main() -> integer
do
    variable message = "Hello World!"
    print(mesaj)
    return 0
end

연습 4: 문자열 연결

두 문자열을 연결합니다.

function main() -> integer
do
    variable greeting = "Hello"
    variable name = "John"
    print(greeting + ", " + name + "!")
    return 0
end

일반적인 오류

오류 1: 세미콜론 없음

세미콜론은필요하지 않음버크에서:

// ❌ Wrong
print("Hello");

// ✅ true
print("Merhaba")

오류 2: 괄호 누락

// ❌ Wrong
print "Hello"

// ✅ Correct
print("Hello")

오류 3: main() 함수 없음

// ❌ Wrong - no main() function
print("Hello")

// ✅ Correct - has main() function
function main() -> integer
do
    print("Hello")
    return 0
end

오류 4: 반환 값 누락

// ❌ Wrong - missing return
function main() -> integer
do
    print("Hello")
end

// ✅ Correct - has return
function main() -> integer
do
    print("Hello")
    return 0
end
