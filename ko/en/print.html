BERK 프로그래밍 언어

버크세계 최초로 진정한 이중 언어 구문(터키어/영어)으로 설계된 현대적이고 안전한 고성능 시스템 프로그래밍 언어입니다. 19가지의 다양한 대상 플랫폼(데스크톱, 모바일, 임베디드, WebAssembly)에서 생산성을 지원합니다.

📖 BERK라는 이름을 선택한 이유는 무엇인가요?

Öztürk 원산지: "강하고, 강하고, 단단합니다"

버크Öztürk의 단어"강하고, 내구성이 있고, 강하고 견고하다"이러한 특성은 프로그래밍 언어의 기술적 목표인 메모리 안전성, 유형 시스템 정확성, 강력한 컴파일러 아키텍처 및 안정적인 성능과 직접적으로 일치합니다.

아랍어의 의미: "번개"

터키어에서 발견되는 또 다른 의미는 **"번개"**입니다. 이 의미는 속도, 성능 및 민첩성에 대한 BERK 언어의 비전, 즉 LLVM, C++ 수준 성능 및 최적화된 커널 아키텍처를 기반으로 한 빠른 컴파일을 나타냅니다.

의미의 조합

BERK, 둘 다 터키 출신견고성개념뿐만 아니라 현대 기술의 세계에서도속도와 민첩성컨셉을 결합하여 강력한 브랜드 아이덴티티를 만들어냅니다.

국제적으로

버크,효율성이 뛰어난 런타임 커널(효율성을 뛰어넘는 런타임 코어).

BERK는 네이티브 코드 생성을 위해 LLVM 17을 사용합니다.

Windows(사전 컴파일됨)

  1. LLVM 17.0.6 다운로드:

    • LLVM 릴리스
    • LLVM-17.0.6-win64.exe파일 다운로드

  2. 치유법:

    • 설치 프로그램 실행
    • "시스템 PATH에 LLVM 추가"를 확인하십시오.
    • 설치 방법:C:\Program Files\LLVM(기본)

  3. 확인하다:

    llvm-config --version

Windows(소스 코드에서)

자세한 설치 방법:LLVM_SETUP.md

function main() -> int

do
    ...
end
  • do(또는do): 기능의 시작
  • end(또는end): 기능 종료

print("Merhaba Dünya!")

  • "Merhaba Dünya!": 문자열 리터럴

return 0
  • return(또는return):기능 종료
  • 0: 성공적인 프로그램은 0을 반환합니다(Unix 전통).

📚 API 참조

매트릭스 생성

linalg_birim_mat(n: tam_sayı) -> [float]

n×n 크기의 단위 행렬을 생성합니다.

매개변수:

  • n: 매트릭스 크기

보고:단위 행렬(일반 배열 형식)

예:

let I3 = linalg_birim_mat(3)
// I3 = [1, 0, 0,
//       0, 1, 0,
//       0, 0, 1]

linalg_sıfır_mat(m: tam_sayı, n: tam_sayı) -> [float]

m×n 크기의 제로 행렬을 생성합니다.

linalg_birler_mat(m: tam_sayı, n: tam_sayı) -> [float]

모든 요소가 1인 m×n 크기의 행렬을 만듭니다.

linalg_diyagonal_mat(d: [float], n: tam_sayı) -> [float]

대각선 요소d배열인 n×n 행렬을 생성합니다.

예:

let d = [2.0, 3.0, 5.0]
let D = linalg_diyagonal_mat(d, 3)
// D = [2, 0, 0,
//      0, 3, 0,
//      0, 0, 5]

행렬 산술

linalg_mat_topla(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

두 개의 m×n 행렬을 추가합니다: C = A + B

linalg_mat_çıkar(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

두 개의 m×n 행렬을 뺍니다: C = A - B

linalg_mat_skaler(α: float, A: [float], m: tam_sayı, n: tam_sayı) -> [float]

행렬에 스칼라를 곱합니다. B = α · A

linalg_mat_çarp(A: [float], B: [float], m: tam_sayı, k: tam_sayı, n: tam_sayı) -> [float]

행렬 곱셈: C = A × B

  • A: m×k
  • B: k×n
  • C: m×n

예:

// 2×2 matris çarpımı
let A = [1.0, 2.0,
              3.0, 4.0]
let B = [5.0, 6.0,
              7.0, 8.0]
let C = linalg_mat_çarp(A, B, 2, 2, 2)
// C = [19, 22,
//      43, 50]

linalg_mat_hadamard(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

요소별 곱(아다마르 곱): C[i,j] = A[i,j] × B[i,j]

벡터 연산

linalg_iç_çarpım(u: [float], v: [float], n: tam_sayı) -> float

내적: u · v = Σ(u[i] × v[i])

예:

let u = [1.0, 2.0, 3.0]
let v = [4.0, 5.0, 6.0]
let dot = linalg_iç_çarpım(u, v, 3)  // 32.0

linalg_norm2(v: [float], n: tam_sayı) -> float

L2 노름(유클리드 노름): ||v|| = √(Σv[i]²)

linalg_norm1(v: [float], n: tam_sayı) -> float

L1 노름(맨해튼 노름): ||v||₁ = Σ|v[i]|

linalg_norm_inf(v: [float], n: tam_sayı) -> float

L결함수 노름(최대 노름): ||v||무한 = max(|v[i]|)

linalg_normalize(v: [float], n: tam_sayı) -> [float]

벡터를 정규화합니다: v̂ = v / ||v||

linalg_dış_çarpım(u: [float], v: [float], m: tam_sayı, n: tam_sayı) -> [float]

외부곱: A[i,j] = u[i] × v[j]

linalg_cross_3d(u: [ondalık], v: [ondalık]) -> [ondalık]

3D 벡터 외적: w = u × v

예:

let u = [1.0, 0.0, 0.0]
let v = [0.0, 1.0, 0.0]

linalg_iz(A: [float], n: tam_sayı) -> float

linalg_frobenius_norm(A: [float], m: tam_sayı, n: tam_sayı) -> float

linalg_determinant_2x2(A: [ondalık]) -> ondalık

linalg_determinant_3x3(A: [ondalık]) -> ondalık

function center_data(data: [float], m: tam_sayı, n: tam_sayı): [float] do
    let centered = linalg_mat_kopyala(data, m, n)
    
    // Her sütun for ortalamayı pop
    let j = 0
    while (j < n) do
        let avg = 0.0
        let i = 0
        while (i < m) do
            avg = avg + linalg_mat_al(data, i, j, n)
            i = i + 1
        end
        avg = avg / m
        
        i = 0
        while (i < m) do
            let değer = linalg_mat_al(centered, i, j, n) - avg
            linalg_mat_yaz(centered, i, j, n, değer)
            i = i + 1
        end
        
        j = j + 1
    end
    
    return centered
end

// Kovaryans matrisini hesapla
function covariance_matrix(data: [float], m: tam_sayı, n: tam_sayı): [float] do
    let centered = center_data(data, m, n)
    let CT = linalg_transpoz(centered, m, n)
    let cov = linalg_mat_çarp(CT, centered, n, m, n)
    
    // (n-1) ile split
    let i = 0
    while (i < n * n) do
        cov[i] = cov[i] / (m - 1)
        i = i + 1
    end
    
    return cov
end

function beam_cost(dimensions: [float], n: tam_sayı): float do
    let width = dimensions[0]
    let height = dimensions[1]
    
    // Maliyet = malzeme × domain
    let cost = width * height
    
    // Kısıt: moment of inertia > I_min
    let I = (width * height * height * height) / 12.0
    let penalty = 0.0
    if (I < 1000.0) then do
        penalty = 1000.0 * (1000.0 - I)
    end
    
    return cost + penalty
end

BERK는 현대적이고 안전한 고성능 프로그래밍 언어입니다. 이중 언어 구문 지원을 통해 터키어와 영어 키워드를 모두 사용할 수 있습니다. LLVM 백엔드를 사용하여 네이티브 코드를 생성합니다.

왜 BERK를 사용해야 하나요?

  • 이중 언어 구문: 터키어 또는 영어 키워드, 원하는 것을 사용하세요
  • 메모리 보안: 현대식 시스템 및 오류 처리
  • 고성능: LLVM을 사용한 네이티브 코드, 비용이 들지 않는 추상화
  • 리치 Stdlib: 18개 모듈, 600개 이상의 기능, 과학계산 지원
  • 쉬운 학습: 깔끔한 구문, 명확한 오류 메시지

BERK는 어떤 플랫폼에서 작동하나요?

컴파일러는 현재 Windows x64에서 사용할 수 있습니다. Linux 및 macOS 지원은 로드맵에 있습니다.

성능 및 최적화

BERK는 얼마나 빠른가요?

LLVM 백엔드 덕분에 C/C++에 필적하는 성능을 제공합니다. 벤치마크는 개발 중입니다.

최적화 수준은 무엇입니까?

berk build -O0  # Optimizasyon yok (hızlı derleme)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (균衡)
berk build -O3  # Agresif optimizasyon

병렬 프로그래밍이 지원되나요?

예,thread모듈을 사용하여 멀티스레딩을 수행할 수 있습니다.

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    let t1 = thread.spawn(işçi, 1)
    let t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}

문제 해결

"정의되지 않은 참조" 오류가 발생합니다.

모듈을 가져오는 것을 잊었을 수도 있습니다.

import math  // math modülünü ekleyin

function main() {
    let x = math.sqrt(16)  // Artık çalışır
}

컴파일 시간이 너무 오래 걸림

-O0다음을 사용하여 빠르게 컴파일할 수 있습니다.

berk build -O0 program.berk

'스택 오버플로' 오류

재귀 함수에 대한 꼬리 호출 최적화를 사용하거나 반복 버전으로 전환하세요.

여기에 질문이 없나요? GitHub 토론정말 좋아요!
