문서 기여

BERK의 문서 개선에 기여하기 위한 가이드입니다. 모든 문서 기여에 감사드립니다!

📚 문서 유형

1. mdBook 문서

주요 문서 책(현재 읽고 있는 책)

  • 위치: berk-lang/book/src/
  • 체재:마크다운(.md)
  • 도구:MD북

2. API 문서

Rust 코드 내 문서 주석

  • 위치: berk-lang/src/
  • 체재:Rustdoc 주석(///)
  • 도구:화물 문서

3.Stdlib 문서

표준 라이브러리 모듈 설명

  • 위치: stdlib/*.berk
  • 체재:BERK 문서 주석(///)

4. GitHub 페이지

게시된 HTML 문서

  • 위치: berk_pages저장소
  • URL:https://arslantasm.github.io/berk_pages/

🛠️ 문서 개발 환경

mdBook 설치

# mdBook yükleme
cargo install mdbook

# Opsiyonel: Live reload for
cargo install mdbook-serve

로컬에서 문서 보기

cd berk-lang/book

# Build
mdbook build

# Serve (localhost:3000)
mdbook serve

# Tarayıcıda aç
# http://localhost:3000

/// Bu function iki tam sayı alır and toplamlarını hesaplar.
/// Overflow kontrolü yapmaz.
///
/// # Parameters
/// * `a` - İlk sayı
/// * `b` - İkinci sayı
///
/// # Döndürür
/// İki sayının toplamı
///
/// # Examples
/// ```berk
/// variable sonuç = topla(5, 3)  // 8
/// variable büyük = topla(1000000, 2000000)  // 3000000
/// ```
///
/// # Err Durumları
/// Overflow durumunda tanımsız davranış
function topla(a: tam, b: tam) -> tam {
    döndür a + b
}

🚀 문서 게시

GitHub 페이지 업데이트

# mdBook build
cd berk-lang/book
mdbook build

# berk_pages repository'ye kopyala
cp -r book/html/* ../../berk_pages/

# Commit and push
cd ../../berk_pages
git add .
git commit -m "docs: Documentation güncellendi"
git push origin main

# GitHub Pages otomatik deploy eder (~2-3 dakika)

API 문서 게시

# Rustdoc oluşturma
cd berk-lang
cargo doc --no-deps --open

# docs/ klasörüne kopyala
cp -r target/doc docs/api

💡 모범 사례

  • ✅ 각 예시작동해야 한다
  • ✅ 예시최소한의(단일 개념)이어야 합니다.
  • ✅ 터키어와 영어예를 들어보세요
  • ✅ 오류 상태설명하다
  • ✅ 성능 노트추가(필요한 경우)
  • ✅ 관련 페이지 링크주다
  • ✅ 이미지사용(다이어그램, 스크린샷)

📊 품질 지표

  • 적용 범위:모든 공개 API는 문서화되어야 합니다.
  • 예:각 기능에는 최소 1개의 예시가 필요합니다.
  • 일시적인 관심사:더 이상 사용되지 않는 기능을 표시해야 합니다.
  • 모래밭:끊어진 링크가 없어야 합니다.

🎯 기여 팁

  • 작은 PR 제출(1페이지/섹션)
  • 오타 PR은 언제나 환영입니다
  • 예제를 추가하는 것이 가장 쉬운 기여입니다
  • 이미지/다이어그램을 추가하는 것은 매우 중요합니다.
  • 영어 번역 도움이 필요합니다
