BERK Programlama Dili

데이터 유형

BERK는 정적으로 유형이 지정된 언어이며 다양한 내장 데이터 유형을 제공합니다.

기본 유형

숫자

다음에 대한 정수 및 십진수:

variable tam = 42
variable float = 3.14
variable negatif = -100
variable bilimsel = 1.5e10  // 15000000000

끈

텍스트 값:

variable isim = "Ahmet"
variable mesaj = 'Merhaba Dünya!'
variable çok_satır = """
    Bu
    çok satırlı
    bir metindir
"""

문자열 보간:

variable ad = "Ali"
variable yaş = 25
print("Benim adım {ad} and {yaş} yaşındayım")
// Çıktı: Benim adım Ali and 25 yaşındayım

부울(부울)

참/거짓 값:

variable doğru_mu = true  // true
variable yanlış_mı = false  // false

// İngilizce
var is_valid = true
var is_empty = false

null

가치 부족:

variable değer = null
variable sonuç: number? = null  // Nullable type

컬렉션 유형

목록

순서가 지정된 요소 모음:

variable sayılar = [1, 2, 3, 4, 5]
variable isimler: Liste<string> = ["Ahmet", "Mehmet", "Ayşe"]
variable karışık = [1, "iki", 3.0, true]  // Mixed types

// Erişim
print(sayılar[0])   // 1
print(isimler[2])   // Ayşe

// Değiştirme
sayılar[0] = 10

// Uzunluk
print(sayılar.len)  // 5

목록 방법:

variable liste = [1, 2, 3]

liste.ekle(4)           // [1, 2, 3, 4]
liste.çıkar(1)          // [1, 3, 4]
liste.içerir(3)         // true
liste.temizle()         // []

튜플

크기가 일정한 다양한 유형의 요소:

variable konum = (41.0082, 28.9784)  // (lat, lon)
variable kişi = ("Ahmet", 30, "İstanbul")

// Destructuring
variable (lat, lon) = konum
variable (ad, yaş, şehir) = kişi

// İndeks erişimi
print(konum.0)  // 41.0082
print(kişi.1)   // 30

지도(지도/사전)

키-값 쌍:

variable sözlük = {
    "ad": "Ahmet",
    "yaş": 30,
    "şehir": "İstanbul"
}

// Erişim
print(sözlük["ad"])  // Ahmet

// Ekleme/Güncelleme
sözlük["meslek"] = "Mühendis"
sözlük["yaş"] = 31

// Kontrol
if sözlük.contains("ad") {
    print("Ad bulundu")
}

// Tip belirtimi
variable Notes: Harita<string, number> = {
    "Mathematics": 85,
    "Fizik": 90,
    "Kimya": 78
}

세트

독특한 요소 컬렉션:

variable kume = {1, 2, 3, 3, 2, 1}  // {1, 2, 3}

kume.ekle(4)      // {1, 2, 3, 4}
kume.çıkar(2)     // {1, 3, 4}
kume.içerir(3)    // true

// Set işlemleri
variable a = {1, 2, 3}
variable b = {2, 3, 4}

variable birleşim = a | b     // {1, 2, 3, 4}
variable kesişim = a & b      // {2, 3}
variable fark = a - b         // {1}

구조체 유형

사용자 정의 데이터 구조 정의:

type Kişi = struct {
    ad: string,
    yaş: number,
    email: string
}

// Instance oluşturma
variable kişi = Kişi {
    ad: "Ahmet",
    yaş: 30,
    email: "ahmet@example.com"
}

// Alan erişimi
print(kişi.ad)      // Ahmet
print(kişi.yaş)     // 30

// Güncelleme
kişi.yaş = 31

결과 유형

다음에 대한 오류 관리:

type Sonuç<T, E> = enum {
    Ok(T),
    Err(E)
}

function split(a: number, b: number) -> Sonuç<number, string> {
    if b == 0 {
        hata return "Sıfıra bölme!"
    }
    tamam return a / b
}

variable sonuç = split(10, 2)
match sonuç {
    Ok(değer) => print("Sonuç: ", değer),
    Err(mesaj) => print("HATA: ", mesaj)
}

옵션 종류(옵션)

널 입력 가능 대안:

type Seçenek<T> = enum {
    Some(T),
    Hiç
}

function bul(List: Liste<number>, hedef: number) -> Seçenek<number> {
    loop i 0'from List.len'a to {
        if List[i] == hedef {
            geri return Some(i)
        }
    }
    geri return Hiç
}

variable indeks = bul([1, 2, 3, 4], 3)
match indeks {
    Some(i) => print("Bulundu: ", i),
    Hiç => print("Bulunamadı")
}

유형 추론

BERK는 강력한 유형 추론을 수행합니다.

// Tip otomatik belirlenir
variable sayı = 42            // number
variable pi = 3.14            // float
variable isim = "Ahmet"       // string
variable doğru_mu = true     // Boolean
variable List = [1, 2, 3]    // Liste<number>

// Karmaşık çıkarımlar
variable harita = {           // Harita<string, number>
    "a": 1,
    "b": 2
}

variable function = (x) => x * 2  // (number) -> number

모범 사례

✅ 즐길 거리

// Açık type belirtimi karmaşık durumlarda
variable kullanıcılar: Liste<Kullanıcı> = []

// Immutable veri for const use
constant API_ANAHTARI = "gizli_anahtar"

// Result tipi hata yönetimi for
function fs::read(yol: string) -> Sonuç<string, Err> { ... }

❌ 피해야 할 것

// Gereksiz type belirtimi
variable x: number = 10  // "variable x = 10" yeterli

// Any tipini fazla kullanmak
variable karışık: Any = ...  // Mümkünse spesifik type use

// Null yerine Option use
variable değer = null  // Option<T> tercih et

예: 모든 유형

function main() {
    // Temel tipler
    variable sayı: number = 42
    variable float: float = 3.14
    variable String: string = "Hello"
    variable bool: Boolean = true
    
    // Koleksiyonlar
    variable List: Liste<number> = [1, 2, 3]
    variable Tuple: (number, string) = (1, "bir")
    variable harita: Harita<string, number> = {"a": 1}
    variable küme: Küme<number> = {1, 2, 3}
    
    // Özel tipler
    type Nokta = struct { x: number, y: number }
    variable p = Nokta { x: 10, y: 20 }
    
    // Sonuç tipi
    variable sonuç: Sonuç<number, string> = Ok(42)
}
