BERK Programming Language

구문 및 구조

BERK 프로그래밍 언어의 기본 구문 규칙 및 코드 구조.

기본 구조

모든 BERK 프로그램은 다음과 같이 시작됩니다.ana()(또는main())기능:

function main() {
    print("Hello World!")
}

영어 구문:

function main() {
    print("Hello World!")
}

명령문 종결자

BERK에서는 명령문세미콜론이 필요하지 않습니다. 각 줄은 명령문으로 평가됩니다.

variable x = 10
variable y = 20
variable toplam = x + y
print(toplam)

여러 줄 문에서백슬래시당신은 사용할 수 있습니다 :

variable longText = "This is a very long string \
                      spanning multiple lines"

블록 구조

블록중괄호다음과 같이 정의됩니다.

function calculate() {
    variable a = 5
    variable b = 3
    
    if a > b {
        print("a is greater")
    } else {
        print("b is greater or equal")
    }
}

// Good examples
variable counter = 0
variable total_price = 99.99

톱니 모양

BERK는 들여쓰기에 유연성이 있지만,4칸권장됩니다:

function kontrol_et(x: number) {
    if x > 0 {
        print("Pozitif")
        if x > 100 {
            print("Çok büyük!")
        }
    } else if x < 0 {
        print("Negatif")
    } else {
        print("Sıfır")
    }
}

이중 언어 구문

BERK의 가장 중요한 기능은이중 언어 구문지원하다. 터키어와 영어 키워드를 혼합할 수 있습니다.

// Tamamen Türkçe
function hesapla(x: number) -> number {
    if x < 0 {
        hata return "Negatif sayı!"
    }
    geri return x * x
}

// Tamamen İngilizce
function calculate(x: Number) -> Number {
    if x < 0 {
        error return "Negative number!"
    }
    return x * x
}

// Karışık (geçerli ama önerilmez)
function hesapla(x: number) -> Number {
    if x < 0 {
        hata return "Negative!"
    }
    return x * x
}

모듈

각 파일은 모듈로 간주됩니다.

// Mathematics.berk
export function topla(a: number, b: number) -> number {
    geri return a + b
}

export constant PI = 3.14159

// main.berk
import Mathematics

function main() {
    print(Mathematics.topla(5, 3))
    print(Mathematics.PI)
}

예: 전체 프로그램

// Fibonacci sequence calculation

import math

// Recursive version
function fib_recursive(n: Number) -> Number {
    if n <= 1 {
        return n
    }
    return fib_recursive(n - 1) + fib_recursive(n - 2)
}

// Iterative version (more efficient)
function fib_iterative(n: Number) -> Number {
    if n <= 1 {
        return n
    }
    
    variable a = 0
    variable b = 1
    
    loop i from 2 to n+1 {
        variable temp = a + b
        a = b
        b = temp
    }
    
    return b
}

function main() {
    constant N = 10
    
    print("First ", N, " Fibonacci numbers:")
    
    loop i from 0 to N {
        print("fib(", i, ") = ", fib_iterative(i))
    }
}
