BERK Programlama Dili

구문 및 구조

BERK 프로그래밍 언어의 기본 구문 규칙 및 코드 구조.

기본 구조

모든 BERK 프로그램은ana()(또는main()) 다음 함수에서 시작합니다.

function main() {
    print("Merhaba Dünya!")
}

영어 구문:

function main() {
    print("Hello World!")
}

표현식 종결자

BERK의 진술세미콜론이 필요하지 않습니다. 각 줄은 표현식으로 평가됩니다.

let x = 10
let y = 20
let sum = x + y
print(sum)

여러 줄 표현식에서백슬래시당신은 사용할 수 있습니다 :

let uzunMetin = "Bu çok uzun bir yazı \
                      birden fazla satıra yayılıyor"

블록 구조

블록중괄호이는 다음과 같이 정의됩니다.

function hesapla() {
    let a = 5
    let b = 3
    
    if a > b {
        print("a büyük")
    } else {
        print("b büyük or eşit")
    }
}

톱니 모양

BERK는 들여쓰기에 있어서 유연성이 있지만,4칸권장 용도:

function kontrol_et(x: number) {
    if x > 0 {
        print("Pozitif")
        if x > 100 {
            print("Çok büyük!")
        }
    } else if x < 0 {
        print("Negatif")
    } else {
        print("Sıfır")
    }
}

공백

연산자 주위에 공백을 사용하면 가독성이 향상됩니다.

// Tercih edilen
let sonuç = a + b * c

// Geçerli ama okunabilir not
let sonuç=a+b*c

줄 길이

80~100자한도를 권장합니다. 다음과 같이 긴 줄을 나눌 수 있습니다:

let çokUzunDeğişken = birinciFonksiyon(parametere1, parametre2)
                            + ikinciFonksiyon(parametre3)
                            + üçüncüFonksiyon(parametre4)

이중 언어 구문

BERK의 가장 중요한 기능이중 언어 구문지원입니다. 터키어와 영어 키워드를 혼합할 수 있습니다.

// Tamamen Türkçe
function hesapla(x: number) -> number {
    if x < 0 {
        return Err "Negatif sayı!"
    }
    return x * x
}

// Tamamen İngilizce
function calculate(x: Number) -> Number {
    if x < 0 {
        error return "Negative number!"
    }
    return x * x
}

// Karışık (geçerli ama önerilmez)
function hesapla(x: number) -> Number {
    if x < 0 {
        return Err "Negative!"
    }
    return x * x
}

모범 사례: 프로젝트에서 단일 언어(터키어 또는 영어)를 선택하세요.

모듈

각 파일은 모듈로 간주됩니다.

// matematik.berk
export function topla(a: number, b: number) -> number {
    return a + b
}

export const PI = 3.14159

// main.berk
import matematik

function main() {
    print(matematik.topla(5, 3))
    print(matematik.PI)
}

예: 전체 프로그램

// Fibonacci sayı dizisi hesaplama

import math

// Recursive versiyonu
function fib_recursive(n: number) -> number {
    if n <= 1 {
        return n
    }
    return fib_recursive(n - 1) + fib_recursive(n - 2)
}

// Iterative versiyonu (daha verimli)
function fib_iterative(n: number) -> number {
    if n <= 1 {
        return n
    }
    
    let a = 0
    let b = 1
    
    for i 2'from n+1'e to {
        let temp = a + b
        a = b
        b = temp
    }
    
    return b
}

function main() {
    const N = 10
    
    print("İlk ", N, " Fibonacci sayısı:")
    
    for i 0'from N'ye to {
        print("fib(", i, ") = ", fib_iterative(i))
    }
}
