BERK Programming Language

변수와 상수

BERK에서는 값을 저장하기 위해변수(변수) 및상수(상수)가 사용됩니다.

변수 선언

터키어 구문

let x = 10
let isim = "Ahmet"
variable pi = 3.14159

영어 구문

var x = 10
var name = "John"
var pi = 3.14159

유형 사양

BERK는 정적으로 유형이 지정된 언어입니다. 유형 추론(유형 추론)이 지원됩니다.

// Type inference (recommended)
variable sayı = 42          // number tipi
variable String = "Hello"    // string tipi
variable gerçek = 3.14      // number tipi (float)

// Explicit type specification
variable sayı: number = 42
variable String: string = "Hello"
variable List: Liste<number> = [1, 2, 3]

변수 수정

변수 값은 선언 후에 변경될 수 있습니다.

variable counter = 0
print(counter)  // 0

counter = counter + 1
print(counter)  // 1

counter += 5
print(counter)  // 6

상수

상수는 한 번 할당된 후에는 변경할 수 없습니다.

constant PI = 3.14159
constant MAX_KULLANICI = 100
constant UYGULAMA_ADI = "BERK App"

// Error! constant cannot be changed
// PI = 3.14  // Compilation error

영어 구문

const PI = 3.14159
const MAX_USERS = 100

명명 규칙

변수

  • 뱀 케이스사용(권장)
  • 터키어 문자가 지원됩니다.
  • 숫자로 시작할 수 없습니다.
  • 키워드가 될 수 없습니다.
// Valid variable names
variable user_name = "Alice"
variable total_price = 99.99
variable student_number = 12345
variable value1 = 10
variable _private = "gizli"

// Invalid variable isimleri
// variable 1değer = 10      // number ile başlıyor
// variable function = 5        // Anahtar kelime
// variable user-name = ""   // Tire kullanılamaz

상수

  • 비명_SNAKE_CASE사용
  • 모두 대문자
  • 밑줄로 구분된 단어
constant MAX_DEĞER = 1000
constant VERSİYON_NUMARASI = "0.8.0"
constant HATA_MESAJI = "Invalid Introduction"

범위

전역 변수

외부 변수에 정의된 함수는 전역적입니다.

variable global_sayaç = 0  // Global

function artır() {
    global_sayaç += 1
}

function main() {
    print(global_sayaç)  // 0
    artır()
    print(global_sayaç)  // 1
}

지역 변수

변수 내부에 정의된 함수는 로컬입니다.

function hesapla() {
    variable Local = 10  // Accessible only in this function
    print(Local)
}

function main() {
    hesapla()
    // print(Local)  // Err! Local not defined here
}

블록 범위

각 블록은 자체 범위를 생성합니다.

function main() {
    variable x = 10
    
    if x > 5 {
        variable y = 20  // Bu blokta Valid
        print(x, y)     // 10, 20
    }
    
    print(x)     // 10
    // print(y)  // Err! y not in this scope
}

섀도잉

동일한 이름을 가진 변수는 내부 범위에서 정의될 수 있습니다.

function main() {
    variable x = 5
    print(x)  // 5
    
    {
        variable x = 10  // Different variable
        print(x)        // 10
    }
    
    print(x)  // 5 (outer scope)
}

구조분해

튜플 및 목록에서 값 추출:

// Tuple destructuring
variable (x, y) = (10, 20)
print(x)  // 10
print(y)  // 20

// Liste destructuring
variable [ilk, ikinci, ...geri_kalan] = [1, 2, 3, 4, 5]
print(ilk)         // 1
print(ikinci)      // 2
print(geri_kalan)  // [3, 4, 5]

다중 할당

한 번에 여러 변수를 선언합니다.

variable a, b, c = 1, 2, 3
print(a, b, c)  // 1 2 3

// Value swap (swap)
variable x = 10
variable y = 20
x, y = y, x
print(x, y)  // 20 10

널 입력 가능 변수

변수는 null일 수 있습니다.

variable değer: number? = null  // Nullable type

if değer != null {
    print("Değer: ", değer)
} else {
    print("Değer yok")
}

// Default Value ile
variable sonuç = değer ?: 0  // if null then 0 use

닉네임 입력:

variable id: KullanıcıID = 12345

예제 프로그램

import math

// Global constants
constant YERÇEKIMI = 9.81  // m/s²
constant PI = 3.14159

function dairesel_hareket(yarıçap: number, hız: number) -> number {
    // Merkezcil ivme hesaplama
    variable ivme = (hız * hız) / yarıçap
    geri return ivme
}

function serbest_düşüş(yükseklik: number) -> number {
    // v = sqrt(2 * g * h)
    variable hız = math.sqrt(2.0 * YERÇEKIMI * yükseklik)
    geri return hız
}

function main() {
    // variables
    variable yarıçap = 5.0   // metre
    variable hız = 10.0      // m/s
    
    variable ivme = dairesel_hareket(yarıçap, hız)
    print("Merkezcil ivme: ", ivme, " m/s²")
    
    // constant değer
    constant YÜKSEKLİK = 50.0  // metre
    variable düşüş_hızı = serbest_düşüş(YÜKSEKLİK)
    print("Düşüş hızı: ", düşüş_hızı, " m/s")
}
