BERK Programlama Dili

최적화 수준

BERK 컴파일러,LLVM 최적화 프로그램다음을 사용하여 최대 성능을 위해 코드를 최적화합니다.

최적화 수준

수준깃발사용편집성능바이너리 크기
O0-O0디버그🚀 매우 빠름🐌 천천히📦 대형
O1-O1기초⚡ 빠름⚡ 중간📦 매체
O2-O2기본🐌 천천히🚀 빠르게📦 작은
O3-O3최고🐌 가장 느림🚀 가장 빠름📦 변수

-O0(최적화 없음)

berk-lang build --opt=0 program.berk
# veya
berk-lang build -O0 program.berk

특징:

  • ✅ 가장 빠른 컴파일 시간
  • ✅ 디버그 기호는 보존됩니다
  • ✅ 스택 추적이 정확함
  • ❌ 매우 느린 작동
  • ❌ 큰 바이너리 크기

사용 영역: 개발 및 디버깅

-O1(기본 최적화)

berk-lang build --opt=1 program.berk

구현된 최적화:

  • 일정한 접기:5 + 10 → 15
  • 데드코드 제거 : 사용하지 않는 코드 삭제
  • 기본 인라인: 매우 작은 함수가 인라인됩니다.
  • 레지스터 할당: 변수가 레지스터에 할당됩니다.

성능: ~2-5x 가속도(O0에 비해)

-O2(전체 최적화 - 기본값)

berk-lang build --opt=2 program.berk
# veya sadece
berk-lang build --release program.berk

구현된 최적화:

  • 모든 O1 최적화
  • 루프 최적화: 루프 가속
  • 함수 인라인: 중간 크기의 기능
  • 벡터화: SIMD 지침
  • 테일 콜 최적화: 재귀 호출 최적화
  • 공통 하위 표현 제거

성능: ~10-20x 가속도(O0 기준)

-O3(공격적 최적화)

berk-lang build --opt=3 program.berk

구현된 최적화:

  • 모든 O2 최적화
  • 공격적인 인라인: 큰 함수도 인라인입니다.
  • 루프 풀기: 루프를 엽니다
  • 투기적 실행
  • 절차간 최적화

성능: ~15-30x 가속도(O0 기준)

⚠️ 주목: 컴파일 시간이 너무 길어서 바이너리 크기가 커질 수 있습니다.

맞춤형 최적화

LTO(링크 시간 최적화)

모든 모듈은 함께 최적화됩니다.

berk-lang build --lto program.berk

장점:

  • 크로스 모듈 인라인
  • 데드 코드 제거(전체 프로그램)
  • 10-30% 성능 향상

불리: 컴파일 시간이 너무 길다

PGO(프로필 기반 최적화)

프로그램을 실행하면 프로필을 수집한 다음 최적화합니다.

# 1. Profiling for derle
berk-lang build --profile-generate program.berk -o program.exe

# 2. Programı çalıştır (profil topla)
./program.exe

# 3. Profil kullanarak optimize et
berk-lang build --profile-use=default.profdata program.berk -o program_optimized.exe

성능: 15~40% 추가 가속

크기 최적화

바이너리 크기를 줄이려면:

# Boyut optimizasyonu
berk-lang build --opt-size program.berk

# Aggressive size optimization
berk-lang build --opt-size-aggressive program.berk

# Strip sembolleri
berk-lang build --strip program.berk

결론: 30-70% 더 작은 바이너리

최적화 기술

일정한 접기

// Kaynak kod
let x = 5 + 10 * 2

// Optimize sonrası
let x = 25

데드 코드 제거

// Kaynak kod
function hesapla() -> sayı do
    let x = 10
    let y = 20  // Kullanılmıyor
    return x
end

// Optimize sonrası
function hesapla() -> sayı do
    return 10
end

함수 인라인

// Kaynak kod
function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

let sonuç = topla(5, 10)

// Optimize sonrası (O2+)
let sonuç = 15  // Fonksiyon çağrısı yok!

루프 풀기

// Kaynak kod
for i 0'from 4'e do
    print(i)
end

// Optimize sonrası (O3)
print(0)
print(1)
print(2)
print(3)

벡터화(SIMD)

// Kaynak kod
let a: [sayı; 4] = [1, 2, 3, 4]
let b: [sayı; 4] = [5, 6, 7, 8]
let c: [sayı; 4]

for i 0'from 4'e do
    c[i] = a[i] + b[i]
end

// Optimize sonrası (O2+ SIMD)
// Tek SIMD instruction ile 4 toplama birden!
// paddq xmm0, xmm1

최적화 제어

특정 최적화 활성화/비활성화

# Inlining'i kapat
berk-lang build -O2 --no-inline program.berk

# Vectorization'ı kapat
berk-lang build -O2 --no-vectorize program.berk

# Loop unrolling'i kapat
berk-lang build -O3 --no-unroll-loops program.berk

기능 기반 최적화

// Bu fonksiyonu inline etme
#[no_inline]
function debug_fonksiyon() do
    // debug kodu
end

// Bu fonksiyonu her zaman inline et
#[always_inline]
function hızlı_işlem() do
    // kritik kod
end

어떤 레벨을 사용할 것인가?

상황제안어디서부터
🔧 개발-O0빠른 컴파일, 쉬운 디버그
🧪 테스트-O1중간 성능, 빠른 컴파일
🚀 생산-O2좋은 성능, 합리적인 편집
🏆 최대 속도-O3 --lto최고의 성능
📦 작은 바이너리--opt-size임베디드 시스템

berk.toml 구성

[build]
optimization = 2          # Varsayılan: O2
lto = true               # Link-Time Optimization
strip = false            # Debug sembolleri koru

[profile.dev]
optimization = 0
debug = true

[profile.release]
optimization = 3
lto = true
strip = true

[profile.bench]
optimization = 3
lto = true
pgo = true

프로필 사용

# Dev profili
berk-lang build --profile=dev program.berk

# Release profili
berk-lang build --profile=release program.berk

# Bench profili
berk-lang build --profile=bench program.berk

최적화 팁

  1. ✅ 릴리스 빌드 사용:

    berk-lang build --release program.berk

  2. ✅ LTO 추가(생산용):

    berk-lang build --release --lto program.berk

  3. ✅ PGO를 사용하다(중요한 애플리케이션):

    berk-lang build --profile-generate program.berk
./program.exe  # Profil topla
berk-lang build --profile-use=default.profdata program.berk

  4. ⚠️ O3 조심해: 때로는 O2보다 느림

  5. ⚠️ 바이너리 크기가 중요한 경우: --opt-size사용

요약

  • ✅ -O0: 디버그, 빠른 컴파일
  • ✅ -O1: 기본 최적화
  • ✅ -O2: 생산(기본값)
  • ✅ -O3: 최대 속도
  • ✅ --lto: 성능 +10-30%
  • ✅ --pgo: 성능 +15-40%
  • ✅ --선택 크기: 작은 바이너리
