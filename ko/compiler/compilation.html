BERK Programlama Dili

컴파일 프로세스

BERK 컴파일러, 소스 코드네이티브 기계 코드로변환하는 다단계 파이프라인을 사용합니다.

편집 단계

1. 어휘 분석(Lexer)

소스 코드토큰다음과 같이 나뉜다:

let x = 42
// Token'lar:
// [let] [x] [=] [42]

렉서 작업:

  • 공백과 댓글을 정리합니다.
  • 키워드 인식(변수, 함수, if...)
  • 터키어/영어 키워드 매핑
  • 숫자, 문자열, 연산자를 구별합니다.

2. 구문 분석(파서)

토큰추상 구문 트리(AST)이를 구조로 변환합니다.

let x = 42 + 10

AST:
VariableDeclaration
  ├─ name: "x"
  └─ value: BinaryExpression
      ├─ left: Literal(42)
      ├─ operator: "+"
      └─ right: Literal(10)

파서 임무:

  • 구문 규칙을 확인합니다.
  • 계층 구조를 생성합니다.
  • 구문 오류를 감지합니다.

3. 의미 분석

당신의 코드의미론적 정확성체크 무늬:

let x: sayı = "merhaba"  // ❌ Tip hatası!

의미 분석기 작업:

  • 유형 확인
  • 변수 정의 제어
  • 함수 서명 검증
  • 소유권 및 생애분석
  • 데드 코드 감지

4. 중간대리(IR)

ASTLLVM IR다음 형식으로 변환됩니다.

define i32 @main() {
entry:
  %x = alloca i32
  store i32 42, i32* %x
  %0 = load i32, i32* %x
  ret i32 %0
}

LLVM IR 장점:

  • 플랫폼 독립적
  • 최적화에 적합
  • 다양한 백엔드 지원

5. 최적화

LLVM 최적화 프로그램은 코드 속도를 향상시킵니다.

  • 데드 코드 제거: 사용하지 않는 코드를 삭제합니다.
  • 일정한 접기: 5 + 10 → 15
  • 인라인: 호출 대신 작은 기능을 복사합니다.
  • 루프 풀기: 사이클 성능 향상
  • 벡터화: SIMD 명령어를 사용합니다.

6. 코드 생성

최적화된 IR에서네이티브 어셈블리다음을 생산합니다:

main:
    push rbp
    mov rbp, rsp
    mov DWORD PTR [rbp-4], 42
    mov eax, DWORD PTR [rbp-4]
    pop rbp
    ret

7.링크

모든 개체 파일을 병합하고 실행 파일을 만듭니다.

  • 정적 링크: 모든 라이브러리가 바이너리에 포함됩니다.
  • 동적 연결: 시스템 라이브러리에 연결

컴파일 명령

간단한 편집

# Kaynak dosyayı derle
berk-lang build program.berk

# Çıktı dosyası belirt
berk-lang build program.berk -o program.exe

# Birden fazla dosya
berk-lang build main.berk lib.berk utils.berk

컴파일 모드

# Debug modu (varsayılan)
berk-lang build --debug program.berk

# Release modu (optimizasyonlu)
berk-lang build --release program.berk

# Profiling for
berk-lang build --profile program.berk

중간 산출물

# AST print
berk-lang build --print-ast program.berk

# Tip bilgilerini göster
berk-lang build --print-types program.berk

# LLVM IR oluştur
berk-lang build --emit-llvm program.berk -o program.ll

# Assembly oluştur
berk-lang build --emit-asm program.berk -o program.s

# Object file oluştur
berk-lang build --emit-obj program.berk -o program.o

컴파일 시간 최적화

증분 컴파일

변경된 모듈만 다시 컴파일합니다.

# İlk derleme: 10 saniye
berk-lang build main.berk

# Tek bir dosya değişti: 0.5 saniye
berk-lang build main.berk

캐시 메커니즘:

  • .berk-cache/중간 파일은 디렉토리에 저장됩니다
  • 파일이 변경되지 않은 경우 캐시에서 사용됩니다.
  • 종속성이 변경되면 관련 모듈이 다시 컴파일됩니다.

병렬 컴파일

# Tüm CPU çekirdeklerini use
berk-lang build --parallel program.berk

# Belirli sayıda thread
berk-lang build --jobs=4 program.berk

오류 메시지

BERK 컴파일러이해할 수 있는 오류 메시지다음을 제공합니다:

error[E0308]: type uyuşmazlığı
  --> src/main.berk:5:14
   |
 5 |     let x: sayı = "merhaba";
   |              ^^^^      ^^^^^^^^^ beklenen: sayı, bulunan: String
   |
   = yardım: "merhaba" string'ini sayıya çevirmek for `String::sayıya()` kullanın

오류 메시지 특성:

  • 오류 코드(E0308)
  • 파일 및 줄 번호
  • 코드 조각
  • 설명 및 권장 사항
  • 컬러 출력(단말기가 지원하는 경우)

편집실적

프로젝트 규모첫 번째 편집증분병렬(8코어)
1,000줄~0.2초~0.05초~0.15초
10,000줄~1초~0.1초~0.4초
100,000줄~8초~0.5초~2초
1,000,000줄~80년대~5초~20대

컴파일 플래그

일반 플래그

# Verbose çıktı
berk-lang build -v program.berk

# Uyarıları göster
berk-lang build --warnings program.berk

# Uyarıları hata say
berk-lang build --warnings-as-errors program.berk

# Bağımlılık grafiği göster
berk-lang build --show-deps program.berk

# İstatistikler
berk-lang build --stats program.berk

디버그 플래그

# Debug sembolleri ekle
berk-lang build -g program.berk

# Debug bilgisi seviyesi
berk-lang build --debug-info=2 program.berk

# Assertion'ları aktif et
berk-lang build --enable-assertions program.berk

시스템 통합 구축

만들다

build:
    berk-lang build main.berk -o program.exe

release:
    berk-lang build --release main.berk -o program.exe

clean:
    rm -rf .berk-cache/ program.exe

CMake

add_custom_command(
    OUTPUT program.exe
    COMMAND berk-lang build ${CMAKE_SOURCE_DIR}/main.berk -o program.exe
    DEPENDS main.berk
)

요약

  • ✅ 7단계 파이프라인: Lexer → Parser → Semantic → IR → Optimize → Codegen → Link
  • ✅ LLVM 백엔드: 플랫폼 독립적이고 최적화된 네이티브 코드
  • ✅ 증분 컴파일: 빠른 재컴파일
  • ✅ 병렬 컴파일: 멀티 코어 프로세서 지원
  • ✅ 이해할 수 있는 실수: 자세한 오류 메시지 및 제안 사항
  • ✅ 빠른 컴파일: 10K라인 ~1초
