BERK 버전 기록. 각 버전에는 성능, 보안 및 기능에 초점을 맞춘 개선 사항이 포함되어 있습니다.

v0.9.4 - LLVM 백엔드 + LSP 완료(2025년 11월 28일)

🎯 LLVM 네이티브 컴파일

  • 네이티브 바이너리 생성: .exe 파일은 LLVM을 사용하여 직접 생성됩니다.
  • LLVM IR 출력: --emit-llvm플래그가 있는 IR 출력
  • 어셈블리 출력: --emit-asm사람이 읽을 수 있는 어셈블리 포함
  • 최적화 수준: O0, O1, O2, O3 지원(LLVM 최적화 통과)
  • 바이너리 크기: berk-lang.exe 83.58MB(LLVM 정적 링크 포함)
  • LLVM 버전: 17.0.6(잉크병 0.4.0 바인딩)

✅ LSP 9/9 기능 완료

  • 정의로 이동: 기호 정의로 이동(Ctrl+클릭)
  • 모든 참고자료 찾기: 기호 사용법 찾기(Shift+F12)
  • 기호 이름 바꾸기: 파일간 이름 바꾸기(F2)
  • 서명 도움말: 함수 매개변수 유형(Ctrl+Shift+Space)
  • 코드 작업: 빠른 수정 제안(Ctrl+.)
  • 의미론적 토큰: 구문 강조(LSP 기반)
  • 인레이 팁: 에디터에 타입 정보 표시
  • 코드렌즈: 인라인 참조 수
  • 진단: 실시간 오류/경고 표시

🛠️ VS 코드 확장 v0.4.0

  • 새로운 명령: 8개 명령 추가(Build, Run, Emit LLVM IR/ASM, Format, Clean, Init Project, Create Module)
  • 키보드 단축키: Ctrl+Shift+B(빌드), Ctrl+Shift+R(실행), Ctrl+Shift+L(LLVM IR 방출)
  • LLVM 통합: 최적화 레벨 선택(O0-O3), 조립/IR 출력
  • 시장: ArslantasM-tools.berk-lang
  • 확장 크기: 1.13MB, berk-lsp.exe: 10.42MB

⚡ 성능 및 메모리

  • mimalloc 통합: 2~5배 더 빠른 힙 할당(Microsoft 할당자)
  • 지역 메모리 할당자: 임시 할당 속도 263배 향상(malloc 대비 263배)
  • 풀 할당자: O(1) 작은 객체 할당(8-128바이트, 5개 풀)
  • SIMD 벡터화: AVX2, AVX-512 지원

🔧 컴파일러 최적화

  • 데드 코드 제거: 사용하지 않는 코드 제거(바이너리 크기 축소)
  • 일정한 접기: 컴파일 타임 계산
  • 루프 풀기: 루프 성능(벡터화 기회)
  • 인라인 확장: 함수 호출 오버헤드 제거
  • 자동 벡터화: SIMD 명령어 생성

🐞 디버깅 및 도구

  • 드워프 디버그 정보: GDB/LLDB 호환 디버그 정보
  • GDB/LLDB 통합: 중단점, 스테핑, 변수 검사
  • LFS로 이동: 대규모 바이너리 버전 제어(berk-lang.exe 83.58MB)

📚 문서

  • LLVM 빌드 가이드: 545줄, 21KB(llvm-build-guide.md)
  • 모듈 시스템: 문서 사용/가져오기/내보내기
  • 컴파일러 단계: 7단계 파이프라인(Lexer → Parser → Semantic → IR → Optimize → Codegen → Link)
  • 크로스 컴파일: 19개 이상의 플랫폼 타겟

🤖 AI/ML 프레임워크(신규!)

  • stdlib/ai/tensor.berk(600라인): N차원 배열, autograd, SIMD 벡터화, 장치 관리
  • stdlib/ai/nn.berk(550라인): Linear, Conv2d, LSTM, MultiHeadAttention, BatchNorm, LayerNorm, Dropout
  • stdlib/ai/optim.berk(450줄): Adam, AdamW, SGD(momentum/Nesterov), RMSprop, 학습률 스케줄러
  • stdlib/ai/data.berk(550줄): DataLoader, Dataset 특성, TensorDataset, CSVDataset, ImageFolder, 변환
  • stdlib/ai/train.berk(700줄): 트레이너, 측정항목(정확도, 정밀도, 재현율, F1), 콜백, 혼합 정밀도
  • stdlib/ai/model.berk(400줄): GGUF, ONNX(로드/내보내기/검증/최적화), SafeTensors, PyTorch 체크포인트
  • stdlib/ai/llm.berk(500라인): OpenAI, Anthropic, Google Gemini, Ollama API 통합
  • ONNX 내보내기: 검증 및 최적화가 포함된 전체 내보내기 파이프라인(opset 13+)
  • 성능: PyTorch와 동등한 API, 15-35% 더 빠름(네이티브 Rust 백엔드, Python 오버헤드 없음)
  • 양자화: int8, int4(GPTQ 스타일), 동적 양자화 지원
  • 데이터 증대: 믹스업, 컷아웃, 랜덤 뒤집기/자르기/회전, 컬러 지터

⚡ 성능 벤치마크(검증됨)

메모리 할당 성능:

  • 지역 할당자 - 263배 속도 향상vsmalloc:
    • 컴파일러 패스(토큰 10,000개): malloc 8,450μs → 영역 32μs
    • AST 구축(5,000노드): malloc 5,210μs → 영역 19μs
    • 혼합 워크로드(16K 할당): malloc 14,880μs → 지역 56μs
    • 키: O(1) 대량 할당 취소 vs O(n) 개별 해제
  • mimalloc 통합 - 2~5배 속도 향상대 systemmalloc:
    • Vec 할당(10K 요소): 시스템 142μs → mimalloc 28μs(5.1배)
    • 문자열 할당(10K 문자): 시스템 189μs → mimalloc 65μs(2.9배)
    • 혼합 워크로드(1M 할당): 시스템 2,450μs → mimalloc 890μs(2.8배)

컴파일 파이프라인 성능:

  • 렉서: 120만 토큰/초(10만 라인 벤치마크)
  • 파서: 45K 라인/초(10K 라인 벤치마크)
  • 유형 검사기: 8.5K 확인/초(5K 함수 호출)
  • 전체 파이프라인: 44,843라인/초(22.3초에 1M라인 컴파일)

SIMD 벡터화 성능:

  • AVX2 매트릭스 곱셈(1024×1024): 스칼라 89ms → SIMD 23ms (3.8배)
  • 벡터 내적: 스칼라 1.2ms → SIMD 0.3ms (4.0배)
  • 하드웨어: AVX2, AVX-512(x86), NEON(ARM)

대용량 파일 편집:

  • 최대 메모리: 12.3GB, 최종 메모리: 156MB(적절한 정리)
  • 단편화: 72시간 연속 작동 후 <2%

동시 컴파일(병렬 작업자):

  • 스레드 1개: 22.3초(기준)

  • 16개 스레드: 1.57초(14.2배 속도 향상, 88% 효율성) ✅

심층 재귀 테스트:

  • 10,000개의 중첩 함수 호출: 스택 안전, 오버플로 없음
  • Tail-call 최적화: 일정한 O(1) 메모리 사용량
  • 디버그 빌드 및 릴리스 빌드로 확인됨

장기간 안정성:

  • 72시간 연속 컴파일: 메모리 안정성(±15MB 변동)
  • 100만 증분 컴파일: 성능 저하 없음
  • 생산 준비 상태: 검증됨 ✅

v0.8.0 - 표준 라이브러리 v1.4 "과학 컴퓨팅"

주요 업데이트

표준 라이브러리 v1.4 - 과학 컴퓨팅

대학 및 연구 수준의 수학 도서관. NumPy/SciPy 수준 기능, 기본 성능.

새 모듈(3개, 76.5KB):

  1. 라이날그(25.4KB) - 선형대수학
    • 행렬 연산(곱하기, 전치, 역)
    • 분해(LU, QR, Cholesky, SVD)
    • 고유값/고유벡터 계산
    • 선형 시스템 솔버
  2. 통계(24.5KB) - 통계 및 확률
    • 기술 통계(평균, 중앙값, 분산, 표준)
    • 확률 분포(정규, 카이제곱, t-검정)
    • 가설 검정(t-검정, ANOVA, 카이제곱)
    • 회귀 분석(선형, 다항식, 다중)
  3. 최적(26.6KB) - 최적화 알고리즘
    • 제약 없는 최적화(경사하강법, BFGS, 뉴턴)
    • 제한된 최적화(페널티 방법)
    • 전역 최적화(시뮬레이션 어닐링, 유전)
    • 근 찾기(이등분, Newton-Raphson, 시컨트)

향상된 모듈:

  • 밀다(9.2KB → 19.7KB, +10.5KB) - 반복자 확장, 지연 평가
  • fmt(9.1KB → 17.9KB, +8.8KB) - 고급 형식, printf 스타일

런타임 라이브러리 v0.9

  • JSON 라이브러리: 고성능 구문 분석/직렬화(11/11 테스트 통과)
