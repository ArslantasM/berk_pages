BERK Programlama Dili

If-Else 조건

조건문은 프로그램 흐름을 제어합니다.

기본 If

if x > 0 {
    print("Pozitif sayı")
}

영어 구문:

if x > 0 {
    print("Positive number")
}

If-Else

if yaş >= 18 {
    print("Yetişkin")
} else {
    print("Çocuk")
}

그렇지 않은 경우

if not >= 90 {
    print("Pekiyi")
} else if not >= 80 {
    print("İyi")
} else if not >= 70 {
    print("Orta")
} else {
    print("Zayıf")
}

중첩된 경우

if kullanıcı != null {
    if kullanıcı.aktif {
        if kullanıcı.doğrulanmış {
            print("Giriş başarılı")
        }
    }
}

삼항 연산자

let case = yaş >= 18 ? "Yetişkin" : "Çocuk"

If 식

BERK에서는 if를 표현식으로 사용할 수 있습니다.

let maksimum = if a > b { a } else { b }

let mesaj = if hata {
    "Err oluştu"
} else {
    "Başarılı"
}

보호 조항

조기 복귀 패턴:

function işle(değer: number?) -> Sonuç<number, string> {
    if değer == null {
        return Err "Değer null olamaz"
    }
    
    if değer < 0 {
        return Err "Değer negatif olamaz"
    }
    
    return Ok değer * 2
}

논리 연산자 사용

if yaş >= 18 && ehliyet_var {
    print("Araç kullanabilir")
}

if admin || moderator {
    print("Yetki var")
}

if !is_empty {
    print("Veri var")
}

단락 평가

// İkinci ifade değerlendirilmez
if kullanıcı == null || kullanıcı.sil() {
    // kullanıcı null then sil() çağrılmaz
}

모범 사례

✅ 즐길 거리

// Anlamlı değişkenler
if kullanıcı_doğrulandı && oturum_geçerli {
    izin_ver()
}

// Guard clauses kullanın
if !geçerli_mi {
    return
}

// Pozitif koşullar tercih edin
if aktif {
    işle()
}

❌ 피해야 할 것

// Çok uzun if-else zincirleri
if x == 1 {
    ...
} else if x == 2 {
    ...
} // 20 tane else if
// Bunun yerine match kullanın!

// Gereksiz iç içe if
if a {
    if b {
        if c {
            // 5 seviye
        }
    }
}
// && operatörü kullanın
