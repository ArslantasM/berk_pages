BERK Programlama Dili

모듈 및 조직

BERK에서 모듈 시스템은 코드를 구성하고 재사용성을 높이며 대규모 프로젝트를 보다 쉽게 ​​관리할 수 있도록 설계되었습니다.

모듈 기초

각 BERK 파일은 모듈로 간주됩니다. 모듈을 사용하면 관련 함수, 구조 및 상수를 결합할 수 있습니다.

간단한 모듈 예

// matematik.berk
export function topla(a: sayı, b: sayı) -> sayı
do
    return a + b
end

export function çarp(a: sayı, b: sayı) -> sayı
do
    return a * b
end

export const PI = 3.14159

모듈 사용법

Use 문(네이티브 모듈)

kullan다음 표현식을 사용하여 기본 모듈에서 기호를 가져올 수 있습니다.

// Tek function içe aktarma
use matematik::topla;

// Birden fazla öğe içe aktarma
use matematik::{topla, çarp, PI};

// Tüm dışa aktarılanları içe aktarma
use matematik::*;

// Takma ad ile içe aktarma
use matematik::PI as pi_sayısı;

가져오기 명세서(외부 패키지)

içe_aktar이 명령문은 외부 패키지를 설치하는 데 사용됩니다.

// Harici paket içe aktarma
import "serde" as json;

// Seçici içe aktarma
import "http"::{get, post, İstek};

모듈 구성

디렉토리 구조

모듈은 파일 시스템 구조를 따릅니다.

proje/
├── main.berk
├── matematik/
│   ├── temel.berk
│   ├── geometri.berk
│   └── istatistik.berk
└── String/
    ├── işlemler.berk
    └── biçimlendir.berk

모듈 경로

// Alt modül kullanımı
kullan matematik::geometri::alan_hesapla;

// İç içe modüller
kullan matematik::geometri::{alan, çevre};

내보내다

단품 수출

export function hesapla() -> sayı
do
    return 42
end

여러 항목 내보내기

// Gruplama sözdizimi
export { fonk1, fonk2, YapıAdı };

// Her birini ayrı ayrı
export function fonk1() do end
export function fonk2() do end
export struct YapıAdı do end

가시성 규칙

BERK의 가시성은 기본적으로 비공개입니다.

  • 수출됨다른 모듈에서 항목을 사용할 수 있습니다.
  • 수출되지 않음항목은 모듈 내에서만 사용할 수 있습니다.
// Bu function dışa aktarıldı - dışarıdan erişilebilir
export function genel_işlev() do end

// Bu function dışa aktarılmadı - yalnızca module in
function özel_işlev() do end

모듈 분석

검색 경로

BERK 컴파일러는 다음 순서로 모듈을 검색합니다.

  1. 현재 디렉터리(.)
  2. ./src/예배 규칙서
  3. ./stdlib/예배 규칙서
  4. 외부 패킷 경로(~/.berk/packages/)

기호 우선순위

이름이 충돌하는 경우 우선 순위:

  1. 지역 범위 변수
  2. 가져온 기호
  3. 모듈 전역

모범 사례

모듈 구성 제안

  • ✅ 그룹 관련 코드: 동일한 기능을 제공하는 코드는 동일한 모듈에 있어야 합니다.
  • ✅ 명확한 명사를 사용하세요: 모듈 이름은 내용을 명확하게 나타내야 합니다.
  • ✅ 불필요한 내보내기를 수행하지 마십시오: API의 일부가 되어야 하는 요소만 내보냅니다.
  • ✅ 순환 종속성 방지A -> B -> A와 같은 종속성은 문제를 일으킵니다.

스타일 가져오기

// ✅ İyi: Açık and okunabilir
use matematik::geometri::{domain, çevre};

// ⚠️ Dikkatli use: Tüm içe aktarmalar isim çakışmasına neden olabilir
use matematik::*;

// ✅ İyi: Uzun isimler for takma ad
use matematik::trigonometri as trig;

고급 기능

모듈 설명

파일 내에서 모듈을 인라인으로 정의할 수 있습니다.

module yardımcılar do
    export function yardımcı() do
        print("Yardımcı function")
    end
end

use yardımcılar::yardımcı;

재수출

모듈에서 가져온 항목을 자신의 모듈에서 내보낼 수 있습니다.

// matematik/index.berk
use matematik::temel::*;
use matematik::geometri::*;

// Tüm alt module fonksiyonlarını dışa aktar
export *;

패키지 관리(BPM)

BERK 패키지 관리자(BPM)를 사용하면 외부 패키지를 관리할 수 있습니다.

berk.toml 구성

[package]
name = "projemiz"
version = "1.0.0"

[dependencies]
serde = "1.0"
http = "0.2"

패키지 사용법

import "serde" as json;

function main() do
    let veri = json::serileştir({isim: "Ali", yaş: 30})
    print(veri)
end

샘플 프로젝트 구조

// src/matematik/temel.berk
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

// src/matematik/geometri.berk  
export function domain(r: kesir) -> kesir do
    use matematik::temel::çarp;
    return 3.14159 * r * r
end

// src/main.berk
use matematik::temel::topla;
use matematik::geometri::domain;

function main() do
    let sonuç1 = topla(5, 3)
    let sonuç2 = domain(2.5)
    
    print("Toplam: " + sonuç1)
    print("Alan: " + sonuç2)
end

요약

  • 각 파일은 모듈입니다
  • kullan로컬 모듈의 경우,içe_aktar외부 패키지의 경우
  • dışa_aktar다른 모듈에 대한 항목 열기
  • 모듈은 디렉토리 구조를 따릅니다.
  • 공개 상태는 기본적으로 비공개입니다.
  • BPM을 통한 패키지 관리 지원
