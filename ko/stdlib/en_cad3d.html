📋개요

cad3d이 모듈은 3D 솔리드 모델링, CSG(Constructive Solid Geometry) 작업 및 파라메트릭 설계를 위한 도구를 제공합니다. STL, OBJ, STEP 형식을 지원합니다.

📦 기본 모양

  • CAD3D.큐브()- 입방체/직사각형 프리즘
  • cad3d.Sphere()- 글로브
  • cad3d.실린더()- 실린더
  • cad3d.콘()- 콘
  • cad3d.토러스()- 반지

🔧 CSG 운영

  • cad3d.merge()- Union (두 개의 도형을 합치는 것)
  • cad3d.subtract()- 차이(모양에서 빼기)
  • cad3d.교차점()- 교차로

🔄 전환

  • cad3d.오프셋()- 운송
  • cad3d.회전()- 회전
  • cad3d.스케일링()- 스케일링
  • cad3d.미러링()- 대칭

📐 고급

  • cad3d.압출()- 2D를 3D로 만들기
  • cad3d.create_rotate()-혁명
  • cad3d.sweep()-스위프
  • cad3d.loft()- 섹션 간 전환

💾 파일 작업

  • cad3d.stl_export()- STL 파일 생성
  • cad3d.obj_export()- OBJ 파일
  • cad3d.step_export()- STEP 파일

💡 사용 예

간단한 기계 부품

use cad3d

// Ana gövde (dikdörtgen prizma)
değer gövde = cad3d.Küp(
    genişlik: 50.0,
    derinlik: 30.0,
    yükseklik: 10.0
)

// Delikler for silindirler
değer delik1 = cad3d.Silindir(
    yarıçap: 4.0,
    yükseklik: 12.0
).öteleme(-15.0, 0.0, -1.0)

değer delik2 = cad3d.Silindir(
    yarıçap: 4.0,
    yükseklik: 12.0
).öteleme(15.0, 0.0, -1.0)

// Delikleri gövdeden pop
değer parça = gövde
    .pop(delik1)
    .pop(delik2)

// STL dosyası as kaydet
cad3d.stl_dışa_aktar(parça, "mekanik_parça.stl")
print("✓ Parça oluşturuldu: mekanik_parça.stl")

파라메트릭 나사 설계

use cad3d
use math

function vida_oluştur(
    çap: Gerçek,
    len: Gerçek,
    adım: Gerçek,
    kafa_çapı: Gerçek
) -> cad3d.Katı {
    // Vida gövdesi
    değer gövde = cad3d.Silindir(
        yarıçap: çap / 2.0,
        yükseklik: len
    )
    
    // Vida başı (altıgen)
    değer başı = cad3d.Silindir(
        yarıçap: kafa_çapı / 2.0,
        yükseklik: çap * 0.7,
        kenar_sayısı: 6
    ).öteleme(0.0, 0.0, len)
    
    // Allen (altıgen yuva)
    değer yuva = cad3d.Silindir(
        yarıçap: kafa_çapı / 4.0,
        yükseklik: çap * 0.5,
        kenar_sayısı: 6
    ).öteleme(0.0, 0.0, len + çap * 0.3)
    
    // Parçaları join and yuvayı pop
    değer vida = gövde
        .join(başı)
        .pop(yuva)
    
    return vida
}

// M6 vida oluştur
değer m6_vida = vida_oluştur(
    çap: 6.0,
    len: 40.0,
    adım: 1.0,
    kafa_çapı: 10.0
)

cad3d.stl_dışa_aktar(m6_vida, "m6_vida.stl")
print("✓ M6 vida oluşturuldu")

박스 디자인(뚜껑 포함)

use cad3d

function kutu_tasarla(
    genişlik: Gerçek,
    derinlik: Gerçek,
    yükseklik: Gerçek,
    duvar_kalınlığı: Gerçek
) -> (cad3d.Katı, cad3d.Katı) {
    // Dış kutu
    değer dış = cad3d.Küp(genişlik, derinlik, yükseklik)
    
    // İç boşluk
    değer iç = cad3d.Küp(
        genişlik - 2.0 * duvar_kalınlığı,
        derinlik - 2.0 * duvar_kalınlığı,
        yükseklik - duvar_kalınlığı
    ).öteleme(0.0, 0.0, duvar_kalınlığı)
    
    // Alt kutu (içi oyuk)
    değer alt_kutu = dış.pop(iç)
    
    // Kapak
    değer kapak_yükseklik = duvar_kalınlığı * 3.0
    değer kapak_dış = cad3d.Küp(genişlik, derinlik, kapak_yükseklik)
    
    // Kapak iç kısmı (kutuya oturacak)
    değer kapak_iç = cad3d.Küp(
        genişlik - 2.0 * duvar_kalınlığı - 0.2,  // 0.2mm tolerans
        derinlik - 2.0 * duvar_kalınlığı - 0.2,
        kapak_yükseklik - duvar_kalınlığı
    ).öteleme(0.0, 0.0, duvar_kalınlığı)
    
    değer kapak = kapak_dış.pop(kapak_iç)
    
    // Kapağı kutunun üstüne yerleştir
    kapak = kapak.öteleme(0.0, 0.0, yükseklik)
    
    return (alt_kutu, kapak)
}

// 100x80x50mm kutu oluştur
değer (kutu, kapak) = kutu_tasarla(
    genişlik: 100.0,
    derinlik: 80.0,
    yükseklik: 50.0,
    duvar_kalınlığı: 2.0
)

// Ayrı dosyalar as kaydet
cad3d.stl_dışa_aktar(kutu, "kutu_alt.stl")
cad3d.stl_dışa_aktar(kapak, "kutu_kapak.stl")

print("✓ Kutu and kapak oluşturuldu")
print("  - kutu_alt.stl")
print("  - kutu_kapak.stl")

🎯 모범 사례

  • 3D 프린터의 벽 두께는 최소 2mm 이상이어야 합니다.
  • 움직이는 부품에 대해 0.2-0.5mm 공차 허용
  • 복잡한 모델을 단순한 모양으로 분해
  • 부울 연산 후 메시 품질 확인
  • STL 내보내기에 충분한 해상도 사용
