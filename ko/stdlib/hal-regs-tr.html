🎛️ 상태::regs

직접 레지스터 액세스 및 비트 조작

366라인 메모리 매핑된 I/O

📖 개요

레지스터 모듈은 하드웨어 레지스터 및 비트 조작 기능에 대한 직접 액세스를 제공합니다.

🚀 사용법

import hal::regs

// Read/Write registers
let value = regs.read(0x40020000)  // Read GPIOA base
regs.write(0x40020014, 0x2000)  // Write to GPIOA_ODR

// Bit operations
regs.set_bit(0x40020000, 13)    // Set bit 13
regs.clear_bit(0x40020000, 13)  // Clear bit 13
regs.toggle_bit(0x40020000, 13) // Toggle bit 13

// Bit field operations
regs.modify(0x40020000, 0x0F, 0x05, 4)  // Modify bits [7:4]

⚠️ 중요 사항

  • 직접 등록 액세스는 위험할 수 있습니다.
  • HAL 함수 선호
  • 원자적 작업에 임계 섹션 사용
