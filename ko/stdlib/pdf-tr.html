📄 PDF

PDF 문서 생성 및 조작

~400줄 ~35개 기능 PDF 1.7

📖 개요

PDF 모듈은 프로그래밍 방식으로 PDF 문서 생성 및 조작을 제공합니다. 텍스트, 도형, 이미지 및 다중 페이지 문서를 지원합니다.

🚀 사용법

import pdf

// Create PDF
let doc = pdf.new()
doc.set_title("My Document")
doc.set_author("BERK")

// Add page
let page = doc.add_page(pdf.A4)
page.text(100, 700, "Hello PDF!", 12)

// Save
doc.save("output.pdf")?
