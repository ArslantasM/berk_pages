    개요

    BERK AI/ML 라이브러리는 최신 인공 지능 및 기계 학습 애플리케이션을 위한 포괄적인 도구를 제공합니다. PyTorch 및 TensorFlow와 호환되는 API 설계는 SIMD 최적화 및 병렬 처리 지원으로 고성능을 제공합니다.

    주요 특징

    • SIMD 최적화:AVX2 지원으로 70GB/s 처리량
    • 병렬 처리:레이온 사용 시 4.96배 가속
    • LZ4 압축:28.8배 더 빠르게, 882배 더 작은 파일을 저장하는 모델
    • 캐시 최적화:블록형 행렬 곱셈으로 2.5배 속도 향상
    • 법학 석사 지원:OpenAI, Anthropic, Gemini, Ollama API 통합
    • 종속성 없음:BERK로 완전히 작성, 기본 성능

    단순 신경망

    module use ai/tensor;
use ai/nn;
use ai/optim;

// Model oluştur
let model = Sequential::new([
    Linear::new(784, 128),
    ReLU::new(),
    Dropout::new(0.2),
    Linear::new(128, 10),
    Softmax::new()
]);

// Optimizer
let optimizer = Adam::new(model.parametreler(), lr: 0.001);

// Eğitim döngüsü
her epoch in range(10) for do
    let çıktı = model.ileri(X_train);
    let kayıp = cross_entropy(çıktı, y_train);
    
    optimizer.sıfırla();
    kayıp.geri();
    optimizer.adım();
    
    print("Epoch {}: Kayıp = {:.4f}", epoch, kayıp);
end

    기술적인 세부사항

    SIMD 최적화

    AVX2 명령어 세트를 사용한 256비트 벡터 연산:

    • 8개의 부동 소수점 병렬 덧셈/뺄셈/곱셈/나눗셈
    • 런타임 CPU 기능 감지
    • AVX2를 사용할 수 없는 경우 자동 스칼라 폴백
    • 대형 텐서의 경우 70GB/s 처리량

    블록 매트릭스 곱셈

    L1 캐시 최적화 타일링:

    • 32×32 블록(4KB, L1 캐시: 32KB)
    • 캐시 미스율 최소화
    • 256×256 행렬의 경우 2.5배 속도 향상
    • 512×512 행렬의 경우 1.8배 속도 향상

    LZ4 모델 압축

    빠른 무손실 압축:

    • 레벨 1(빠른) 압축
    • 바이너리 형식: BERK 매직 + 버전 + 데이터
    • 28.8배 더 빠른 녹화
    • 882x 더 작은 파일
    • 100% 정확도, 데이터 무결성이 보존됩니다.

    병렬 일괄 처리

    레이온을 사용한 멀티스레딩:

    • 4.96배 더 빠른 일괄 처리
    • 18,546 배치/초(대 4,410 순차)
    • 작업 도용을 통한 로드 밸런싱
    • 자동 스레드 풀 관리
