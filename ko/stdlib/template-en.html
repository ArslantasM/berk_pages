🎨 템플릿

템플릿 엔진(Jinja2/Mustache에서 영감을 받음)

~300줄 ~20가지 기능 변수 및 필터

📖 개요

Jinja2와 Mustache에서 영감을 받은 템플릿 엔진입니다. 변수 보간 및 필터를 사용하여 HTML, 이메일 및 텍스트 생성에 이상적입니다.

🚀 빠른 시작

import template

let ctx = template.context()
ctx.set("name", "Alice")
ctx.set("age", 30)

let result = template.render("Hello, {{name}}! Age: {{age}}", ctx)
println(result)
// Output: Hello, Alice! Age: 30
