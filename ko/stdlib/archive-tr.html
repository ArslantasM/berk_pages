📦 아카이브

ZIP/TAR 아카이브 지원 - 압축 및 추출

~350줄 ~25개 기능 우편번호/TAR

📖 개요

아카이브 모듈은 ZIP 및 TAR 형식의 아카이브 생성 및 추출을 제공합니다. DEFLATE는 gzip 및 bzip2 압축을 지원합니다.

🚀 사용법

import archive

// Create ZIP
let zip = archive.new_zip()
zip.add_file("data.txt", "path/to/data.txt")?
zip.add_memory("config.json", "{}")?
zip.save("output.zip")?

// Extract
archive.unzip("archive.zip", "output_dir")?

// Quick functions
archive.zip_directory("my_folder", "backup.zip")?
