📖 개요

이미지 처리: PNG/JPEG 로드/저장, 필터(흐림, 선명, 가장자리 감지), 크기 조정, 회전, 색상 조작.

🚀 빠른 시작

import image

// Load image
let img = image.load("photo.jpg")?

// Apply filters
let blurred = image.blur(img, radius: 5.0)
let grayscale = image.to_grayscale(blurred)

// Resize
let resized = image.resize(grayscale, 800, 600)

// Save
image.save(resized, "output.png")?
