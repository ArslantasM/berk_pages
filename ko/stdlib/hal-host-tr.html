367라인 USB/디버그

📖 개요

호스트 통신: USB, 디버그 인터페이스, 세미호스팅.

🚀 사용법

import hal::host

// Debug print (ITM/SWO)
host.debug_print("Hello from MCU\n")

// Semihosting (debug only)
host.semihost_write("Debug message")

// USB CDC
let usb = host.usb_cdc_init()
host.usb_write(usb, "USB message")

// Get host status
if host.is_debugger_connected() then do
    host.debug_print("Debugger active")
end
