366라인 유용

📖 개요

하드웨어 유틸리티: 원자 연산, 중요 섹션, 메모리 장벽, 감시

🚀 사용법

import hal::hw

// Critical section (disable interrupts)
hw.enter_critical()
// ... critical code ...
hw.exit_critical()

// Atomic operations
hw.atomic_add(&counter, 1)
hw.atomic_sub(&counter, 1)
hw.atomic_exchange(&value, new_value)

// Memory barriers
hw.memory_barrier()
hw.data_sync_barrier()

// Watchdog
hw.watchdog_init(1000)  // 1 second timeout
hw.watchdog_refresh()

// Reset
hw.reset()
hw.reset_cause()  // Get last reset reason
