BERK Programlama Dili

변수와 상수

BERK에 값을 저장하려면변수(변수) 및상수(상수)가 사용됩니다.

변수 정의

터키어 구문

let x = 10
let isim = "Ahmet"
let pi = 3.14159

영어 구문

var x = 10
var name = "John"
var pi = 3.14159

유형 지정

BERK는 정적 유형 언어입니다. 유형 추론이 지원됩니다.

// Tip çıkarımı (önerilen)
let sayı = 42          // number tipi
let String = "Hello"    // string tipi
let gerçek = 3.14      // number tipi (float)

// Açık type belirtimi
let sayı: number = 42
let String: string = "Hello"
let List: Liste<number> = [1, 2, 3]

변수 대체

변수가 정의되면 해당 값을 변경할 수 있습니다.

let count_occurrences = 0
print(count_occurrences)  // 0

count_occurrences = count_occurrences + 1
print(count_occurrences)  // 1

count_occurrences += 5
print(count_occurrences)  // 6

상수

상수는 일단 할당되면 변경할 수 없습니다.

const PI = 3.14159
const MAX_KULLANICI = 100
const UYGULAMA_ADI = "BERK App"

// Err! Sabit değiştirilemez
// PI = 3.14  // Derleme hatası

영어 구문

const PI = 3.14159
const MAX_USERS = 100

명명 규칙

변수

  • 뱀 케이스사용(권장)
  • 터키어 문자 지원
  • 숫자로 시작할 수 없습니다.
  • 키워드가 될 수 없습니다

let değer1 = 10
let _private = "gizli"

// Geçersiz let isimleri
// let 1değer = 10      // number ile başlıyor

// let user-name = ""   // Tire kullanılamaz

상수

  • 비명_SNAKE_CASE사용
  • 모두 대문자
  • 단어는 밑줄로 구분됩니다.
const MAX_DEĞER = 1000
const VERSİYON_NUMARASI = "0.8.0"
const HATA_MESAJI = "Geçersiz giriş"

범위

전역 변수

함수 외부에 정의된 변수는 전역 변수입니다.

let global_sayaç = 0  // Global

function artır() {
    global_sayaç += 1
}

function main() {
    print(global_sayaç)  // 0
    artır()
    print(global_sayaç)  // 1
}

지역 변수

함수 내에 정의된 변수는 로컬입니다.

function hesapla() {
    let yerel = 10  // Sadece bu fonksiyonda erişilebilir
    print(yerel)
}

function main() {
    hesapla()
    // print(yerel)  // Err! yerel burada tanımlı not
}

블록 범위

각 블록은 자체 범위를 생성합니다.

function main() {
    let x = 10
    
    if x > 5 {
        let y = 20  // Bu blokta geçerli
        print(x, y)     // 10, 20
    }
    
    print(x)     // 10
    // print(y)  // Err! y bu kapsamda yok
}

섀도잉

동일한 이름을 가진 변수는 내부 범위에서 정의될 수 있습니다.

function main() {
    let x = 5
    print(x)  // 5
    
    {
        let x = 10  // Farklı let
        print(x)        // 10
    }
    
    print(x)  // 5 (dış kapsam)
}

구조분해

튜플과 리스트에서 값 추출:

// Tuple destructuring
let (x, y) = (10, 20)
print(x)  // 10
print(y)  // 20

// Liste destructuring
let [first, ikinci, ...geri_kalan] = [1, 2, 3, 4, 5]
print(first)         // 1
print(ikinci)      // 2
print(geri_kalan)  // [3, 4, 5]

다중 할당

한 번에 여러 변수 정의:

let a, b, c = 1, 2, 3
print(a, b, c)  // 1 2 3

// Değer takası (swap)
let x = 10
let y = 20
x, y = y, x
print(x, y)  // 20 10

널 입력 가능 변수

변수는 null일 수 있습니다.

let değer: number? = null  // Nullable type

if değer != null {
    print("Değer: ", değer)
} else {
    print("Değer yok")
}

// Varsayılan değer ile
let sonuç = değer ?: 0  // Eğer null then 0 use

샘플 프로그램

import math

// Global sabitler
const YERÇEKIMI = 9.81  // m/s²
const PI = 3.14159

function dairesel_hareket(yarıçap: number, hız: number) -> number {
    // Merkezcil ivme hesaplama
    let ivme = (hız * hız) / yarıçap
    return ivme
}

function serbest_düşüş(yükseklik: number) -> number {
    // v = sqrt(2 * g * h)
    let hız = math.sqrt(2.0 * YERÇEKIMI * yükseklik)
    return hız
}

function main() {
    // Değişkenler
    let yarıçap = 5.0   // metre
    let hız = 10.0      // m/s
    
    let ivme = dairesel_hareket(yarıçap, hız)
    print("Merkezcil ivme: ", ivme, " m/s²")
    
    // Sabit değer
    const YÜKSEKLİK = 50.0  // metre
    let düşüş_hızı = serbest_düşüş(YÜKSEKLİK)
    print("Düşüş hızı: ", düşüş_hızı, " m/s")
}
