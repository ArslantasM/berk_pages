Installation

In this section you will learn how to install BERK programming language on your system.

Requirements

Windows

  • Windows 10/11 (64-bit)
  • Rust toolchain (1.70+)
  • Visual Studio Build Tools 2022
  • LLVM 17.0.6
  • Go
  • Minimum 8GB RAM (Compiling for)

Linux

  • Ubuntu 20.04+ / Debian 11+ / Fedora 35+
  • Rust toolchain (1.70+)
  • GCC/Clang compiler
  • LLVM 17.0.6
  • Go
  • Minimum 4GB RAM

macOS

  • macOS 11 (Big Sur) or higher
  • Rust toolchain (1.70+)
  • Xcode Command Line Tools
  • LLVM 17.0.6 (Homebrew)
  • Go
  • Minimum 4GB RAM

Rust Installation

BERK, Rust is written in. First you need to install Rust:

Windows/Linux/macOS

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

After installation:

rustc --version
cargo --version

Output:

rustc 1.75.0 (1.75.0 2024-01-01)
cargo 1.75.0 (1.75.0 2024-01-01)

LLVM Installation

BERK uses LLVM 17 for native code generation.

Windows (Pre-compiled)

  1. LLVM 17.0.6 Download:

    • LLVM Releases
    • LLVM-17.0.6-win64.exedownload the file

  2. Install:

    • Run the installer
    • "Add LLVM to system PATH" check the option
    • Installation path:C:\Program Files\LLVM(default)

  3. Verify:

    llvm-config --version

Windows (From Source)

Detailed Installation for:LLVM_SETUP.md

# LLVM kaynak kodunu indir
git clone --depth 1 --branch llvmorg-17.0.6 https://github.com/llvm/llvm-project.git

# Build create directory
cd llvm-project
mkdir build
cd build

# CMake configuration
cmake -G Ninja ../llvm `
  -DCMAKE_BUILD_TYPE=Release `
  -DLLVM_TARGETS_TO_BUILD=all `
  -DCMAKE_INSTALL_PREFIX=C:\llvm-17

# Compile (2-3 saat may take)
ninja
ninja install

Linux (Ubuntu/Debian)

# LLVM 17 repository ekle
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17

# Required packages
sudo apt install llvm-17-dev libllvm17 llvm-17-tools clang-17

Linux (Fedora)

sudo dnf install llvm17-devel llvm17-libs clang17

macOS (Homebrew)

brew install llvm@17

# PATH'e ekle
echo 'export PATH="/opt/homebrew/opt/llvm@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

LLVM Environment Variables

After installation environment set the variables:

Windows (PowerShell):

$env:LLVM_SYS_170_PREFIX = "C:\llvm-17"
[Environment]::SetEnvironmentVariable("LLVM_SYS_170_PREFIX", "C:\llvm-17", "User")

Linux/macOS (Bash/Zsh):

export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17
echo 'export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17' >> ~/.bashrc

BERK Installation

Method 1: Pre-built Binary (Windows - Recommended) ⚡

Windows x64 users for the fastest way:

  1. Download:

    • 🔗 BERK-lang.exe (2.2 MB)
    • 🔗 berk-lsp.exe (1.2 MB)
    • 🔗 berk-repl.exe (464 KB)
    • Three separate files: Compiler, LSP, and REPL (LLVM dynamic linking)

  2. Install:

    # Copy to desired folder
New-Item -ItemType Directory -Path C:\BERK -Force
Move-Item .\BERK-lang.exe C:\BERK\

# Add to PATH
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\BERK",
    "User"
)

# Open new terminal and test
BERK-lang --version

  3. Quick Test:

    # test instantly with REPL
BERK-lang repl
>>> print("Merhaba!")
Merhaba!

Features:

  • ✅ LLVM 17 dynamic linking - uses system LLVM
  • ✅ All 19 target platforms support
  • ✅ REPL, JIT run, and native compile mode
  • ✅ Runtime Libraries included (JSON, Crypto, HTTP)

Notes:LLVM dynamic linking is used so total size reduced to ~3.8 MB (was 83 MB in v0.8.0).

REPL Usage

REPL (Read-Eval-Print Loop) comes with the main compiler:

# Start REPL
BERK-lang repl

REPL Commands

BERK> :help

Available commands:
  :quit, :q      - Exit from REPL
  :help, :h      - Show help
  :clear, :c     - Clear screen
  :history       - Command history
  :lang <tr|en>  - Change language (Turkish/English)
  :type <expr>   - Show expression type

REPL Examples

Simple calculations:

>>> 5 + 3
8

>>> 10 * 2.5
25.0

Variables:

>>> variable name = "BERK"
>>> print("Hello, " + name)
Hello, BERK

Functions:

>>> function add(a: integer, b: integer) -> integer { return a + b }
>>> add(10, 20)
30

Language switching:

>>> :lang en
Language switched to English

>>> function hello(name: string) { print("Hello, " + name) }
>>> hello("World")
Hello, World

>>> :lang tr
Language switched to Turkish

Troubleshooting

LLVM Not Found

Error:

error: could not find native static library `LLVM-17`

Solution:

# Is LLVM_SYS_170_PREFIX set correctly?
echo $LLVM_SYS_170_PREFIX  # Linux/macOS
echo $env:LLVM_SYS_170_PREFIX  # Windows

# Is LLVM installed?
llvm-config --version

Cargo Build Error

Error:

error: linker `link.exe` not found

Solution (Windows):

  • Visual Studio Build Tools 2022 must be installed
  • "Desktop development with C++" workload must be selected

Slow Compilation

Tips:

# Parallel build (4 core)
cargo build --release --features llvm -j4

# Incremental compilation
export CARGO_INCREMENTAL=1

# Less optimization (debug build)
cargo build --features llvm

macOS ARM (M1/M2) Issues

# Rosetta 2 Installation
softwareupdate --install-rosetta

# ARM native LLVM
brew install llvm@17

# Architecture check
arch
# Output: arm64
