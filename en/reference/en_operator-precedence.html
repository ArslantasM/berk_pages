Operator Priority

Priority order and combination directions of operators in BERK programming language. As the priority level increases, operators are evaluated first.

📊 Priority Table

Priority Operator Description Merger
1 (Highest) () [] . Brackets, Index, Member access left to right
2 ++ -- ! ~ + - Unary operators (increment, decrement, not, bitwise not, unary +/-) right to left
3 ** exponentiation right to left
4 * / % Multiplication, division, mod left to right
5 + - addition, subtraction left to right
6 << >> Bit shift left to right
7 < <= > >= Relational comparison left to right
8 == != Equality check left to right
9 & Bitwise AND left to right
10 ^ Bitwise XOR left to right
11 | Bitwise OR left to right
12 && and and boolean and left to right
13 || or or boolean or left to right
14 ? : Ternary condition operator right to left
15 = += -= *= /= %= Assignment operators right to left
16 (Lowest) , comma operator left to right

💡 Examples

Order of Priority

// Çarpma toplama önce gelir
variable sonuç = 5 + 3 * 2  // = 5 + 6 = 11 (not 16)

// Parantez en yüksek önceliğe sahip
variable sonuç2 = (5 + 3) * 2  // = 8 * 2 = 16

// Üs alma çarpmadan önce
variable sonuç3 = 2 * 3 ** 2  // = 2 * 9 = 18

// boolean operatörler
variable koşul = true or false and false  // = true (and önce)
variable koşul2 = (true or false) and false  // = false

Joining Direction

// Soldan sağa (çoğu operatör)
variable a = 10 - 5 - 2  // = (10 - 5) - 2 = 3

// Sağdan sola (atama)
variable x, y, z
x = y = z = 5  // Sağdan başlar: z=5, y=5, x=5

// Sağdan sola (üs alma)
variable b = 2 ** 3 ** 2  // = 2 ** (3 ** 2) = 2 ** 9 = 512

Complex Expressions

variable result = 10 + 5 * 2 - 3 ** 2 / 3
// Adım adım:
// 1. 3 ** 2 = 9 (pow alma)
// 2. 5 * 2 = 10 (çarpma)
// 3. 9 / 3 = 3 (bölme)
// 4. 10 + 10 = 20 (toplama)
// 5. 20 - 3 = 17 (çıkarma)
// Sonuç: 17

// Parantezle netleştirme
variable result2 = ((10 + (5 * 2)) - ((3 ** 2) / 3))  // Daha okunabilir

boolean Operators

variable x = 5
variable y = 10
variable z = 15

// && (and) || (or) önce gelir
variable sonuç = x < y || y > z && z > x
// = (x < y) || ((y > z) && (z > x))
// = true || (false && true)
// = true || false
// = true

// Parantez Usageı önerilir
variable pub = (x < y) || ((y > z) && (z > x))

Bitwise Operators

variable a = 0b1100  // 12
variable b = 0b1010  // 10

// Bitwise operatörler boolean operatörlerden önce
variable sonuç = a & b | a ^ b
// = (a & b) | (a ^ b)
// = (0b1000) | (0b0110)
// = 0b1110 = 14
