Optimization Levels

BERK compiler,LLVM optimizerOptimizes your code for maximum performance using

Optimization Levels

LevelFlagUseCompilationPerformanceBinary Size
O0-O0Debug🚀 Very Fast🐌 Slow📦 Large
O1-O1Basis⚡ Fast⚡ Medium📦 Medium
O2-O2Default🐌 Slow🚀 Fast📦 Small
O3-O3Maximum🐌 Slowest🚀 Fastest📦 Variable

-O0 (No Optimization)

berk-lang build --opt=0 program.berk
# veya
berk-lang build -O0 program.berk

Features:

  • ✅ Fastest compilation time
  • ✅ Debug symbols are preserved
  • ✅ Stack trace is correct
  • ❌ Very slow operation
  • ❌ Large binary size

Area of ​​Use: Development and debugging

-O1 (Basic Optimizations)

berk-lang build --opt=1 program.berk

Implemented Optimizations:

  • Constant folding:5 + 10 → 15
  • Dead code elimination: Unused code is deleted
  • Basic inlining: Very small functions are inlined
  • Register allocation: Variables are assigned to registers

Performance: ~2-5x acceleration (relative to O0)

-O2 (Full Optimization - Default)

berk-lang build --opt=2 program.berk
# veya sadece
berk-lang build --release program.berk

Implemented Optimizations:

  • All O1 optimizations
  • Loop optimization: Loop acceleration
  • Function inlining: Medium sized functions
  • Vectorization: SIMD instructions
  • Tail call optimization: Optimize recursive calls
  • Common subexpression elimination

Performance: ~10-20x acceleration (relative to O0)

-O3 (Aggressive Optimization)

berk-lang build --opt=3 program.berk

Implemented Optimizations:

  • All O2 optimizations
  • Aggressive inlining: Even large functions are inline
  • Loop unrolling: Opens loops
  • Speculative execution
  • Interprocedural optimization

Performance: ~15-30x acceleration (relative to O0)

⚠️ Attention: Compilation time is too long, binary size may increase

Custom Optimizations

LTO (Link-Time Optimization)

All modules are optimized together:

berk-lang build --lto program.berk

Advantages:

  • Cross-module inlining
  • Dead code elimination (full program)
  • 10-30% performance increase

Disadvantage: Too long compilation time

PGO (Profile-Guided Optimization)

By running the program it collects profiles, then optimizes them:

# 1. Profiling for derle
berk-lang build --profile-generate program.berk -o program.exe

# 2. Programı çalıştır (profil topla)
./program.exe

# 3. Profil kullanarak optimize et
berk-lang build --profile-use=default.profdata program.berk -o program_optimized.exe

Performance: 15-40% additional acceleration

Size Optimization

To reduce binary size:

# Boyut optimizasyonu
berk-lang build --opt-size program.berk

# Aggressive size optimization
berk-lang build --opt-size-aggressive program.berk

# Strip sembolleri
berk-lang build --strip program.berk

Conclusion: 30-70% smaller binary

Optimization Techniques

Constant Folding

// Kaynak kod
let x = 5 + 10 * 2

// Optimize sonrası
let x = 25

Dead Code Elimination

// Kaynak kod
function hesapla() -> sayı do
    let x = 10
    let y = 20  // Kullanılmıyor
    return x
end

// Optimize sonrası
function hesapla() -> sayı do
    return 10
end

Function Inlining

// Kaynak kod
function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

let sonuç = topla(5, 10)

// Optimize sonrası (O2+)
let sonuç = 15  // Fonksiyon çağrısı yok!

Loop Unrolling

// Kaynak kod
for i 0'from 4'e do
    print(i)
end

// Optimize sonrası (O3)
print(0)
print(1)
print(2)
print(3)

Vectorization (SIMD)

// Kaynak kod
let a: [sayı; 4] = [1, 2, 3, 4]
let b: [sayı; 4] = [5, 6, 7, 8]
let c: [sayı; 4]

for i 0'from 4'e do
    c[i] = a[i] + b[i]
end

// Optimize sonrası (O2+ SIMD)
// Tek SIMD instruction ile 4 toplama birden!
// paddq xmm0, xmm1

Optimization Control

Enable/Disable Specific Optimizations

# Inlining'i kapat
berk-lang build -O2 --no-inline program.berk

# Vectorization'ı kapat
berk-lang build -O2 --no-vectorize program.berk

# Loop unrolling'i kapat
berk-lang build -O3 --no-unroll-loops program.berk

Function Based Optimization

// Bu fonksiyonu inline etme
#[no_inline]
function debug_fonksiyon() do
    // debug kodu
end

// Bu fonksiyonu her zaman inline et
#[always_inline]
function hızlı_işlem() do
    // kritik kod
end

berk.toml Configuration

[build]
optimization = 2          # Varsayılan: O2
lto = true               # Link-Time Optimization
strip = false            # Debug sembolleri koru

[profile.dev]
optimization = 0
debug = true

[profile.release]
optimization = 3
lto = true
strip = true

[profile.bench]
optimization = 3
lto = true
pgo = true

Profile Usage

# Dev profili
berk-lang build --profile=dev program.berk

# Release profili
berk-lang build --profile=release program.berk

# Bench profili
berk-lang build --profile=bench program.berk

Optimization Tips

  1. ✅ Use release build:

    berk-lang build --release program.berk

  2. ✅ add LTO(for production):

    berk-lang build --release --lto program.berk

  3. ✅ use PGO(critical applications):

    berk-lang build --profile-generate program.berk
./program.exe  # Profil topla
berk-lang build --profile-use=default.profdata program.berk

  4. ⚠️ O3 careful: Sometimes slower than O2

  5. ⚠️ If binary size matters: --opt-sizeuse
