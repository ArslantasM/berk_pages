📖 Overview

Template engine inspired by Jinja2 and Mustache. Ideal for HTML, email, and text generation with variable interpolation and filters.

🚀 Quick Start

import template

let ctx = template.context()
ctx.set("name", "Alice")
ctx.set("age", 30)

let result = template.render("Hello, {{name}}! Age: {{age}}", ctx)
println(result)
// Output: Hello, Alice! Age: 30
