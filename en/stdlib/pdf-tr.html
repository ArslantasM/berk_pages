PDF Document Creation & Manipulation

~400 lines ~35 functions PDF 1.7

📖 Overview

The PDF module provides programmatically PDF document creation and manipulation. It supports text, shapes, images and multi-page documentation.

🚀 Usage

import pdf

// Create PDF
let doc = pdf.new()
doc.set_title("My Document")
doc.set_author("BERK")

// Add page
let page = doc.add_page(pdf.A4)
page.text(100, 700, "Hello PDF!", 12)

// Save
doc.save("output.pdf")?
