🎨 color - Color Processes

Color transformations, mixing and palette creation

📦 47 Functions 📝 560 Lines 💾 17.2 KB

📋Overview

colorThe module provides conversions between RGB, HSL, HSV color spaces, color mixing and palette creation tools.

🎨 Color Rendering

  • color.rgb()- RGB color (0-255)
  • color.rgba()- RGB with alpha channel
  • color.hsl()- HSL color space
  • color.hsv()- HSV color space
  • color.hex()- Color from hex string (#FF5733)

🔄 Color Transformations

  • color.rgb_den_hsl()- RGB → HSL
  • color.hsl_den_rgb()- HSL → RGB
  • color.hex_e()- Converting to hex string

🖌️ Color Manipulation

  • color.mix()- Mixing two colors
  • color.dark()- Darken the color
  • color.lighten()- Lighten color
  • color.adjust_saturation()- Saturation adjustment

🎨 Color Palettes

  • color.complementary()- Complementary color
  • color.analog_colors()- Analogous colors
  • color.triple_colors()- Triadic colors
  • color.create_gradient()- Color gradient

💡 Usage Examples

Color Transformations

use color

// RGB renk oluştur
değer kırmızı = color.rgb(255, 0, 0)
print(f"RGB: {kırmızı}")

// Hex'e çevir
değer hex = kırmızı.hex_e()
print(f"Hex: {hex}")

// HSL'e dönüştür
değer hsl = color.rgb_den_hsl(255, 0, 0)
print(f"HSL: H={hsl.ton}, S={hsl.doygunluk}, L={hsl.parlaklık}")

// Renk karıştırma
değer mavi = color.rgb(0, 0, 255)
değer mor = color.shuffle(kırmızı, mavi, oran: 0.5)
print(f"Mor: {mor.hex_e()}")

Creating a Color Palette

use color

// Ana renk
değer ana_renk = color.hex("#3498db")

// Tamamlayıcı renk
değer tamamlayıcı = ana_renk.tamamlayıcı()
print(f"Tamamlayıcı: {tamamlayıcı.hex_e()}")

// Analog renkler
değer analoglar = ana_renk.analog_renkler()
print("\nAnalog Renkler:")
for renk in analoglar {
    print(f"  {renk.hex_e()}")
}

// Gradyan oluştur
değer gradyan = color.gradyan_oluştur(
    color.rgb(255, 0, 0),
    color.rgb(0, 0, 255),
    adım_sayısı: 10
)

print("\nGradyan:")
for renk in gradyan {
    print(f"  {renk.hex_e()}")
}
