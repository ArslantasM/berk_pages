TOML Parser - Tom's Obvious Minimal Language

~350 lines ~30 functions v1.0.0

📖 Overview

The TOML module provides human-friendly TOML v1.0.0 parser for configuration files. It supports strings, integers, floats, booleans, arrays, tables and inline tables.

🚀 Quick Start

import toml

// Parse TOML
let config = toml.parse("
    [database]
    host = \"localhost\"
    port = 5432
    
    [server]
    bind = \"0.0.0.0:8080\"
    workers = 4
")?

let host = config.get("database.host")?
let port = config.get_int("database.port")?
