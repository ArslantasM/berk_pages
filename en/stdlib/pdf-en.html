📖 Overview

Programmatic PDF document creation and manipulation. Supports text, shapes, images, and multi-page documents.

🚀 Quick Start

import pdf

// Create PDF
let doc = pdf.new()
doc.set_title("My Document")
doc.set_author("BERK")

// Add page
let page = doc.add_page(pdf.A4)
page.text(100, 700, "Hello PDF!", 12)
page.line(100, 690, 200, 690)
