Data Pipes & Stream Processing

369 lines Streaming

📖 Overview

Data pipes, stream processing and buffering.

🚀 Usage

import hal::pipe

// Create pipe
let pipe = pipe.create(1024)  // 1KB buffer

// Write data
pipe.write(pipe, [1, 2, 3, 4, 5])

// Read data
let data = pipe.read(pipe, 5)

// Pipe status
let available = pipe.available(pipe)
let is_full = pipe.is_full(pipe)

// Clear pipe
pipe.clear(pipe)
