    Overview

    The llm module provides a unified interface for accessing popular LLM API providers. You can perform chat completion, streaming and asynchronous operations with a consistent API for all providers.

    OpenAI

    GPT-4, GPT-3.5-turbo

    • Chat completion
    • Function calling
    • Vision (GPT-4V)

    Anthropic

    Claude 3 (Opus, Sonnet, Haiku)

    • 100K context
    • Extended thinking
    • document analysis

    Google

    Gemini Pro, Gemini Ultra

    • Multimodal input
    • Code generation
    • long context

    Don't be

    Llama 2, Mistral, Mixtral

    • local interference
    • privacy first
    • No API key

    OpenAI Client

    Chat Completion

    use ai/llm;

let client = OpenAI::new(
    api_key: env::var("OPENAI_API_KEY")?
);

let response = client.chat(
    model: "gpt-4",
    messages: [
        Message { role: "system", content: "Sen yardımcı bir asistansın." },
        Message { role: "user", content: "Rust ile Berk arasındaki farklar neler?" }
    ],
    temperature: 0.7,
    max_tokens: 1000
).await?;

print("{}", response.content);

    Streaming Response

    use ai/llm;

let stream = client.chat_stream(
    model: "gpt-4",
    messages: messages
).await?;

her chunk in stream for do
    print!("{}", chunk.content); // Anında print
end
print!();  // Yeni satır

    Function Calling

    use ai/llm;

let functions = [
    Function {
        name: "get_weather",
        description: "Hava durumu bilgisini receive",
        parameters: json!({
            "type": "object",
            "properties": {
                "location": { "type": "string" },
                "unit": { "type": "string", "enum": ["celsius", "fahrenheit"] }
            }
        })
    }
];

let response = client.chat(
    model: "gpt-4",
    messages: messages,
    functions: functions,
    function_call: "auto"
).await?;

if response.function_call.is_some() then do
    let func = response.function_call.unwrap();
    print("Fonksiyon çağrısı: {}({})", func.name, func.arguments);
end

    Unified API

    Provider-Agnostic Code

    use ai/llm;

// Tüm provider'lar for aynı arayüz
function chat(provider: LLMProvider, prompt: dizgi) -> dizgi do
    let response = provider.chat(
        messages: [Message::user(prompt)],
        temperature: 0.7
    ).await?;
    
    return response.content;
end

// Kullanım
let openai = OpenAI::new(openai_key);
let claude = Anthropic::new(anthropic_key);

let r1 = chat(openai, "Merhaba")?;
let r2 = chat(claude, "Merhaba")?;

    Advanced Features

    Conversation History

    use ai/llm;

let conversation = Conversation::new();

conversation.add_system("Sen bir BERK uzmanısın.");
conversation.add_user("BERK'te vektör nasıl tanımlanır?");

let response = client.chat(
    messages: conversation.messages(),
    temperature: 0.7
).await?;

conversation.add_assistant(response.content);

// Devam eden konuşma
conversation.add_user("Peki matris nasıl?");
let response2 = client.chat(
    messages: conversation.messages()
).await?;

    Token Counting

    use ai/llm;

let tokens = client.count_tokens(
    model: "gpt-4",
    messages: messages
)?;

print("Token sayısı: {}", tokens);
print("Tahmini maliyet: ${:.4}", tokens as float * 0.00003);

    Retry & Error Handling

    use ai/llm;

let client = OpenAI::new(api_key)
    .with_retry(max_attempts: 3, backoff: 2.0)
    .with_timeout(30.0);

deneme do
    let response = client.chat(messages).await?;
    print("{}", response.content);
catch hata for do
    match hata {
        LLMError::RateLimit => print!("Rate limit aşıldı, bekleyin..."),
        LLMError::InvalidKey => print!("API key geçersiz"),
        LLMError::Timeout => print!("Zaman aşımı"),
        _ => print!("Err: {}", hata)
    }
end

    API Reference

    Provider Trait

    • chat(messages, options) -> Response- Chat completion
    • chat_stream(messages) -> Stream- Streaming chat
    • count_tokens(messages) -> usize- Number of tokens
    • list_models() -> Vec<String>- Available models

    Message Structure

    • role: "system" | "user" | "assistant"
    • content: dizgi- Message content
    • name: Option<dizgi>- Optional name
