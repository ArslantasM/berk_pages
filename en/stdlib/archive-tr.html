📦 archive

ZIP/TAR Archive Support - Compression & Extraction

~350 lines ~25 functions ZIP/TAR

📖 Overview

Archive module provides archive creation and extraction in ZIP and TAR formats. DEFLATE supports gzip and bzip2 compression.

🚀 Usage

import archive

// Create ZIP
let zip = archive.new_zip()
zip.add_file("data.txt", "path/to/data.txt")?
zip.add_memory("config.json", "{}")?
zip.save("output.zip")?

// Extract
archive.unzip("archive.zip", "output_dir")?

// Quick functions
archive.zip_directory("my_folder", "backup.zip")?
