    Overview

    BERK AI/ML library provides comprehensive tools for modern artificial intelligence and machine learning applications. API design compatible with PyTorch and TensorFlow provides high performance with SIMD optimizations and parallel processing support.

    Key Features

    • SIMD Optimization:70 GB/s throughput with AVX2 support
    • Parallel Processing:4.96x acceleration with rayon
    • LZ4 Compression:Model saving 28.8x faster, 882x smaller files
    • Cache Optimization:2.5x speedup with blocky matrix multiplication
    • LLM Support:OpenAI, Anthropic, Gemini, Ollama API integration
    • Zero Dependency:Written entirely in BERK, native performance

    Quick Start

    Simple Neural Network

    module use ai/tensor;
use ai/nn;
use ai/optim;

// Model oluştur
let model = Sequential::new([
    Linear::new(784, 128),
    ReLU::new(),
    Dropout::new(0.2),
    Linear::new(128, 10),
    Softmax::new()
]);

// Optimizer
let optimizer = Adam::new(model.parametreler(), lr: 0.001);

// Eğitim döngüsü
her epoch in range(10) for do
    let çıktı = model.ileri(X_train);
    let kayıp = cross_entropy(çıktı, y_train);
    
    optimizer.sıfırla();
    kayıp.geri();
    optimizer.adım();
    
    print("Epoch {}: Kayıp = {:.4f}", epoch, kayıp);
end

    Technical Details

    SIMD Optimization

    256-bit vector operations with the AVX2 instruction set:

    • 8 float parallel addition/subtraction/multiplication/division
    • Runtime CPU feature detection
    • Automatic scalar fallback if AVX2 is not available
    • 70 GB/s throughput for large tensors

    Blocky Matrix Multiplication

    L1 cache-optimized tiling:

    • 32×32 blocks (4KB, L1 cache: 32KB)
    • Minimizes cache miss rate
    • 2.5x speedup for 256×256 matrices
    • 1.8x speedup for 512×512 matrices

    LZ4 Model Compression

    Fast lossless compression:

    • Level 1 (fast) compression
    • Binary format: BERK magic + version + data
    • 28.8x faster recording
    • 882x smaller files
    • 100% accuracy, data integrity is preserved

    Parallel Batch Processing

    Multi-threading with Rayon:

    • Batch processing 4.96x faster
    • 18,546 batch/sec (vs 4,410 sequential)
    • Load balancing with work stealing
    • Automatic thread pool management
