Setup

In this section, you will learn how to install the BERK programming language on your system.

Requirements

Windows

  • Windows 10/11 (64-bit)
  • Rust toolchain (1.70+)
  • Visual Studio Build Tools 2022
  • LLVM 17.0.6
  • Go
  • Minimum 8GB RAM (for compilation)

Linux

  • Ubuntu 20.04+ / Debian 11+ / Fedora 35+
  • Rust toolchain (1.70+)
  • GCC/Clang compiler
  • LLVM 17.0.6
  • Go
  • Minimum 4GB RAM

macOS

  • macOS 11 (Big Sur) or later
  • Rust toolchain (1.70+)
  • Xcode Command Line Tools
  • LLVM 17.0.6 (Homebrew)
  • Go
  • Minimum 4GB RAM

Rust Installation

BERK is written in Rust. You need to install Rust first:

Windows/Linux/macOS

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

After installation:

rustc --version
cargo --version

Output:

rustc 1.75.0 (1.75.0 2024-01-01)
cargo 1.75.0 (1.75.0 2024-01-01)

LLVM Installation

BERK uses LLVM 17 for native code generation.

Windows (Pre-compiled)

  1. Download LLVM 17.0.6:

    • LLVM Releases
    • LLVM-17.0.6-win64.exedownload file

  2. Cure:

    • Run the installer
    • Check "Add LLVM to system PATH"
    • Installation way:C:\Program Files\LLVM(default)

  3. Verify:

    llvm-config --version

Windows (From Source Code)

For detailed installation:LLVM_SETUP.md

# LLVM kaynak kodunu indir
git clone --depth 1 --branch llvmorg-17.0.6 https://github.com/llvm/llvm-project.git

# Build dizini oluştur
cd llvm-project
mkdir build
cd build

# CMake yapılandırması
cmake -G Ninja ../llvm `
  -DCMAKE_BUILD_TYPE=Release `
  -DLLVM_TARGETS_TO_BUILD=all `
  -DCMAKE_INSTALL_PREFIX=C:\llvm-17

# Derle (2-3 saat sürebilir)
ninja
ninja install

Linux (Ubuntu/Debian)

# LLVM 17 repository ekle
wget https://apt.llvm.org/llvm.sh
chmod +x llvm.sh
sudo ./llvm.sh 17

# Gerekli paketler
sudo apt install llvm-17-dev libllvm17 llvm-17-tools clang-17

Linux (Fedora)

sudo dnf install llvm17-devel llvm17-libs clang17

macOS (Homebrew)

brew install llvm@17

# PATH'e ekle
echo 'export PATH="/opt/homebrew/opt/llvm@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

LLVM Environment Variables

Set environment variables after installation:

Windows (PowerShell):

$env:LLVM_SYS_170_PREFIX = "C:\llvm-17"
[Environment]::SetEnvironmentVariable("LLVM_SYS_170_PREFIX", "C:\llvm-17", "User")

Linux/macOS (Bash/Zsh):

export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17
echo 'export LLVM_SYS_170_PREFIX=/usr/lib/llvm-17' >> ~/.bashrc

BERK Installation

Method 1: Pre-built Binary (Windows - Recommended) ⚡

Fastest way for Windows x64 users:

  1. Download:

    • 🔗 BERK-lang.exe (2.2 MB)
    • 🔗 berk-lsp.exe (1.2 MB)
    • 🔗 berk-repl.exe (464 KB)
    • Three separate files: Compiler, LSP, and REPL (LLVM dynamic linking)

  2. Cure:

    # İstediğiniz bir klasöre kopyalayın
New-Item -ItemType Directory -Path C:\BERK -Force
Move-Item .\BERK-lang.exe C:\BERK\

# PATH'e ekleyin
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\BERK",
    "User"
)

# Yeni terminal açın ve test edin
BERK-lang --version

  3. Quick Test:

    # REPL ile anında test
BERK-lang repl
>>> print("Merhaba!")
Merhaba!

Features:

  • ✅ LLVM 17 dynamic linking - the system uses LLVM
  • ✅ Support for all 19 target platforms
  • ✅ REPL, JIT run, and native compile mode
  • ✅ Runtime libraries included (JSON, Crypto, HTTP)

Notes:Since LLVM dynamic linking was used, the total size decreased to ~3.8 MB (was 83 MB in v0.8.0).

Method 2: From Source Code (All Platforms)

For Linux/macOS or those wanting customization:

# Repository'yi klonla
git clone https://github.com/ArslantasM/berk.git
cd berk/berk-lang

# LLVM feature ile derle
cargo build --release --features llvm

# Test et
cargo test --features llvm

# Binary'yi PATH'e ekle (Linux/macOS)
sudo ln -s $(pwd)/target/release/BERK-lang /usr/local/bin/BERK-lang

# Binary'yi PATH'e ekle (Windows)
# target\release\BERK-lang.exe dosyasını PATH'teki bir dizine kopyalayın

Compilation Time:~40 seconds (release build)

Method 3: Cargo Install (Future)

Using REPL

REPL (Read-Eval-Print Loop) comes with the main compiler:

# REPL'i başlat
BERK-lang repl

REPL Commands

BERK> :help

Kullanılabilir komutlar:
  :quit, :q      - REPL'den çık
  :help, :h      - Yardım göster
  :clear, :c     - Ekranı temizle
  :history       - Komut geçmişi
  :lang <tr|en>  - Dil değiştir (Türkçe/English)
  :type <expr>   - İfadenin tipini göster

REPL Examples

Simple calculations:

>>> 5 + 3
8

>>> 10 * 2.5
25.0

Variables:

>>> let isim = "BERK"
>>> print("Merhaba, " + isim)
Merhaba, BERK

Functions:

>>> function topla(a: int, b: int) -> int { return a + b }
>>> topla(10, 20)
30

Changing language:

>>> :lang en
Language switched to English

>>> function hello(name: string) { print("Hello, " + name) }
>>> hello("World")
Hello, World

>>> :lang tr
Dil Türkçe'ye değiştirildi

Troubleshooting

LLVM Cannot Be Found

Mistake:

error: could not find native static library `LLVM-17`

Solution:

# LLVM_SYS_170_PREFIX doğru ayarlı mı?
echo $LLVM_SYS_170_PREFIX  # Linux/macOS
echo $env:LLVM_SYS_170_PREFIX  # Windows

# LLVM kurulu mu?
llvm-config --version

Cargo Build Error

Mistake:

error: linker `link.exe` not found

Solution (Windows):

  • Visual Studio Build Tools 2022 must be installed
  • "Desktop development with C++" workload must be selected

Slow Compilation

Tips:

# Parallel build (4 core)
cargo build --release --features llvm -j4

# Incremental compilation
export CARGO_INCREMENTAL=1

# Daha az optimization (debug build)
cargo build --features llvm

macOS ARM (M1/M2) Problems

# Rosetta 2 kurulumu
softwareupdate --install-rosetta

# ARM native LLVM
brew install llvm@17

# Architecture kontrol
arch
# Çıktı: arm64
