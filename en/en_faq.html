Frequently Asked Questions

General Questions

What is BERK?

BERK is a modern systems programming language. It offers Rust-level memory security and C/C++-level performance. It generates native code using LLVM backend and provides support for 19 target platforms. With the bilingual syntax feature, you can use both Turkish and English keywords.

Why should I use BERK?

  • High Performance: Native code generation at C/C++ level with LLVM (98-100%)
  • Rust-Level Security: Modern type system, pattern matching, comprehensive error handling
  • Comprehensive Stdlib: 75 modules (42 core + 33 HAL), 4100+ functions, NumPy/SciPy level scientific computing, embedded systems support
  • Cross Platform: Desktop (Windows/Linux/macOS), Embedded (ARM/RISC-V/AVR/ESP32), Mobile (Android/iOS), WebAssembly
  • User friendly: Clean syntax, clear error messages, REPL support, optional bilingual keywords

On which platforms does BERK work?

desktop: Windows x64 (active), Linux x64, macOS ARM64

Embedded (7 platforms, 95% complete, 100% market coverage):

  • Tier-1: ESP32 (WiFi/BLE, 35% market), STM32F4 (Industrial, 25%), RP2040 (Maker, 15%)
  • Tier-2: nRF52 (BLE, 8%), GD32 (China, 7%), Nuvoton (Asia, 5%)
  • Tier-3: Arduino (Educational, 30M users)

Mobile: Android (ARM/x86), iOS (ARM64) - Experimental

WebAssembly: WASM32, WASI - Planned

HAL Support: 61 platform-specific modules, auto-generator (15,901 lines CMSIS tested)

Is BERK open source?

Yes, BERK is an open source project under GPL-3 license. Active development is taking place on GitHub. Very close to v1.0.0 with 98% overall completion.

Syntax and Language Features

How does bilingual syntax work?

In BERK you can write the same program in two different ways:

// Türkçe
function merhaba() {
    print("Merhaba Dünya!")
}

// İngilizce
function hello() {
    print("Hello World!")
}

Both styles compile to the same bytecode. You can even mix them in the same file!

What programming paradigms does it support?

  • Imperative Programming: Procedural code, direct memory control
  • Functional Programming: Iterators, higher-order Functions, immutability
  • Structured Programming: Structs, Moduleer architecture, pattern matching
  • System Programming: Low level control, zero-cost abstractions, inline assembly (v1.0 planned)
  • Type Security: Strong static type checking,generic types (Phase 4.1-4.4 complete)

Is there Garbage Collector?

No, BERK uses manual memory management.Rust-style ownership system completed in v0.9.0- borrow checker, non-lexical lifetimes (NLL), move semantics (geçir, paylaş, değiştir) provides Rust-level memory security. There is also Region Memory (faster than 263x malloc) and mimalloc integration.

How does performance compare to Rust/C?

BERK offers performance comparable to C/C++ (98-100%) thanks to the LLVM backend. LLVM uses IR optimization passes, region memory allocator (263x speedup), and mimalloc integration. Supports optimization levels from -O0 to -O3. Continuous performance monitoring is done with the Benchmark suite.

Performance and Optimization

How fast is BERK?

Thanks to the LLVM backend, it offers performance comparable to C/C++. It provides the necessary speed for system programming with native code generation, LLVM optimization passes and zero-cost abstractions. The roadmap includes JIT compiler and BLAS/LAPACK integration.

What are the optimization levels?

berk build -O0  # Optimizasyon yok (hızlı derleme, debug)
berk build -O1  # Temel optimizasyonlar
berk build -O2  # Varsayılan (dengelenmiş performans)
berk build -O3  # Agresif optimizasyon (maksimum hız)

LLVM uses optimization pipeline: dead code elimination, constant folding, loop unrolling, inline expansion. Link-time optimization (LTO) support will be added in future versions.

Is parallel programming supported?

Yes,threadYou can do multi-threading with the module:

import thread

function işçi(id: number) {
    print("Thread ", id, " çalışıyor")
}

function main() {
    variable t1 = thread.spawn(işçi, 1)
    variable t2 = thread.spawn(işçi, 2)
    
    thread.join(t1)
    thread.join(t2)
}

Troubleshooting

I'm getting "Undefined Reference" error

You may have forgotten to import the module:

import math  // math Moduleünü ekleyin

function main() {
    variable x = math.sqrt(16)  // Artık çalışır
}

Compilation takes too long

-O0You can quickly compile with:

berk build -O0 program.berk

"Stack overflow" error

Use tail-call optimization in Recursive Functions or switch to the iterative version.
