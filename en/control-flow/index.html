Control Structures

BERK offers various structures to control program flow.

Contents

If-Else Conditions

Conditional statements and branching:

if x > 0 {
    print("Pozitif")
} else {
    print("Negatif or sıfır")
}

loops

Loop structures for repetitive operations:

  • for(for)
  • iken(while)
  • do-while(do-while)
for i 0'from 5'e to {
    print(i)
}

Pattern Matching

Advanced matching and destruction:

match deđfer {
    Ok(x) => print("Başarılı: ", x),
    Err(e) => print("Err: ", e)
}
