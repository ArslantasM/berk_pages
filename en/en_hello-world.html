Hello World!

The tradition in every programming language, the first program "Hello World!" is to print. We continue this tradition in BERK too!

Your First Program

In your favorite text editorhello.berkcreate a file named:

function ana() -> integer
do
    print("Hello World!")
    return 0
end

Understanding the Code

Let's examine line by line:

1.function Definition

function ana() -> integer
  • function(orfunction): defines a function
  • ana(ormain): Function name. Programana()function starts
  • (): Parameter list (empty)
  • -> integer: Return Type (integer)

2.function Body

do
    ...
end
  • do(ordo): Function start
  • end(orend): Function end

3.Printing

print("Hello World!")
  • print()(orprint()): Prints to screen
  • "Hello World!": String literal

4. Return Value

return 0
  • return(orreturn):Exit from function
  • 0: Successful programs return 0 (Unix tradition)

English Version

BERK bilingual! You can write the same program in English:

hello.berk:

function main() -> integer
do
    print("Hello World!")
    return 0
end

Compilation:

BERK-lang hello.berk -o hello.exe
./hello.exe

Output:

Hello World!

Mixed Usage

You can even mix Turkish and English:

function main() -> integer
do
    print("Hello World!")
    return 0
end

This is also valid BERK code!

Optimization Levels

O0 - Optimization none (default):

BERK-lang hello.berk -o merhaba_o0.exe -O0

O1 - Basic optimizations:

BERK-lang hello.berk -o merhaba_o1.exe -O1

O2 - Medium level (recommended):

BERK-lang hello.berk -o merhaba_o2.exe -O2

O3 - Aggressive optimizations:

BERK-lang hello.berk -o merhaba_o3.exe -O3

Different Output Formats

LLVM IR show:

BERK-lang hello.berk --emit llvm-ir

Assembly show:

BERK-lang hello.berk --emit asm

IR show:

BERK-lang hello.berk --emit ir

exercises

Exercise 1: Personalization

Modify the program to print your own name:

function main() -> integer
do
    print("Hello, [YOUR NAME]!")
    return 0
end

Exercise 2: Multiple Pressure

Print multiple lines:

function main() -> integer
do
    print("Hello World!")
    print("Welcome to BERK!")
    print("Happy coding!")
    return 0
end

Exercise 3: Variable Usage

Store the string in a variable:

function main() -> integer
do
    variable message = "Hello World!"
    print(mesaj)
    return 0
end

Exercise 4: String Concatenation

Concatenate two strings:

function main() -> integer
do
    variable greeting = "Hello"
    variable name = "John"
    print(greeting + ", " + name + "!")
    return 0
end

Common Errors

Error 1: No Semicolons

Semicolons arenot requiredin BERK:

// ❌ Wrong
print("Hello");

// ✅ true
print("Merhaba")

Error 2: Missing Parentheses

// ❌ Wrong
print "Hello"

// ✅ Correct
print("Hello")

Error 3: No main() Function

// ❌ Wrong - no main() function
print("Hello")

// ✅ Correct - has main() function
function main() -> integer
do
    print("Hello")
    return 0
end

Error 4: Missing Return Value

// ❌ Wrong - missing return
function main() -> integer
do
    print("Hello")
end

// ✅ Correct - has return
function main() -> integer
do
    print("Hello")
    return 0
end
