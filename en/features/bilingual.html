BERK Programlama Dili

Bilingual Syntax (Turkish/English)

BERK,is the world's first truly bilingual programming language. You can write the same code in both Turkish and English, or even mix the two languages ​​in the same file!

Why Bilingual?

Ease of Learning

Turkish-speaking beginners can learn programming in their native language:

function merhaba() do
    print("Merhaba Dünya!")
end

International Cooperation

You can easily collaborate with English-speaking developers:

function hello() do
    print("Hello World!")
end

Comparative Examples

Example 1: Fibonacci

Turkish:

function fibonacci(n: sayı) -> sayı
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

English:

function fibonacci(n: int) -> int
do
    if n <= 1 do
        return n
    end
    return fibonacci(n-1) + fibonacci(n-2)
end

Example 2: Class Definition

Turkish:

struct Kişi do
    isim: String,
    yaş: sayı
end

function yeni_kişi(isim: String, yaş: sayı) -> Kişi
do
    return Kişi { isim: isim, yaş: yaş }
end

English:

struct Person do
    name: string,
    age: int
end

function new_person(name: string, age: int) -> Person
do
    return Person { name: name, age: age }
end

Example 3: Error Handling

Turkish:

function fs::read(yol: String) -> Sonuç<String>
do
    if yol == "" do
        return Err("Boş yol")
    end
    
    // Dosyayı input
    return Ok(içerik)
end

English:

function read_file(path: string) -> Result<string>
do
    if path == "" do
        return Error("Empty path")
    end
    
    // Read file
    return Ok(content)
end

Mixed Use

Most powerful feature:You can mix two languages ​​in the same file!

// Türkçe function
function hesapla(x: sayı) -> sayı do
    let sonuç = x * 2
    return sonuç
end

// English function  
function calculate_advanced(x: int) -> int do
    let result = hesapla(x) + 10  // Türkçe fonksiyonu çağırıyoruz
    return result
end

// Türkçe main function
function main() do
    let değer = calculate_advanced(5)  // İngilizce fonksiyonu çağırıyoruz
    print(değer)
end

Style Suggestions

Consistency within the Project

  • ✅ It is often better to use a single language within a project
  • ✅ Communicate with team members: Turkish or English?
  • ⚠️ Mixed use possible but readability may be reduced

For Libraries

  • ✅ Open source libraries should generally be written in English
  • ✅ Local/special projects can be written in Turkish
  • ✅ API documentation available in both languages

Backwards Compatibility

In future versions of BERK:

  • ✅ Both languages ​​will be fully supported
  • ✅ New features will be added in both languages
  • ✅ You won't need to change your codebase

IDE Support

VS Code add-on supports both languages:

  • ✅ Syntax highlighting
  • ✅ Autocomplete
  • ✅ Error checking
  • ✅ Code snippets
  • ✅ Hover information

Compiler Behavior

Compiler steps:

  1. Lexer: Recognizes both Turkish and English keywords
  2. Parser: Creates the same AST nodes for both languages
  3. Semantic Analyzer: Regardless of language difference
  4. Code Generator: Produces the same LLVM IR
Türkçe Kod    →  Lexer  →  Parser  →  AST
İngilizce Kod →  Lexer  →  Parser  →  AST (Aynı!)
                                       ↓
                              Semantic Analysis
                                       ↓
                                  Code Gen
                                       ↓
                                   LLVM IR

Performance

Zero cost!

  • No matter what language you use, performance is the same
  • Compiled code is identical
  • There is no overhead in runtime

Language Translation Tool

You can translate code with BERK CLI:

# Türkçe'den İngilizce'ye
berk-lang convert --to=english dosya.berk -o file.berk

# İngilizce'den Türkçe'ye
berk-lang convert --to=turkish file.berk -o dosya.berk

Community Standards

Open Source Projects

  • README must be in both Turkish and English
  • Code usually in English (for international contributors)
  • Comment lines can be in both languages

Private/Corporate Projects

  • According to team preference
  • Companies in Türkiye generally prefer Turkish
  • International teams may use English
