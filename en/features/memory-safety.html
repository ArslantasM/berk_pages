Memory Security

BERK,Rust-level memory securityIt is a modern systems programming language that provides Segmentation faults, null pointer dereferences and buffer overflows are captured at compile-time in BERK.

Basic Security Guarantees

1. Null Safety

in BERKnullvaluesSeçenekIt is explicitly handled with the (Option) type:

// ❌ Err: Null olamaz
let isim: String = null  // Derleme hatası!

// ✅ Doğru: Seçenek use
let isim: Seçenek<String> = Hiçbiri

eşleştir isim do
    Bir(değer) => print("İsim: " + değer),
    Hiçbiri => print("İsim yok")
end

2. Border Control

Array accesses are checked automatically:

let sayılar = [1, 2, 3, 4, 5]

// ❌ Runtime hatası: Index out of bounds
let x = sayılar[10]  // Panic!

// ✅ Güvenli erişim
if 10 < sayılar.len() do
    let x = sayılar[10]
yoksa do
    print("Geçersiz index")
end

Type 3 Security

With its strong type system, runtime errors are caught at compile-time:

// ❌ Err: Tip uyuşmazlığı
let x: sayı = "merhaba"  // Derleme hatası!

// ❌ Err: İmplicit dönüşüm yok
let y: kesir = 42  // Derleme hatası!

// ✅ Doğru: Açık dönüşüm
let y: kesir = 42.0
// or
let y: kesir = kayıt(kesir, 42)

Ownership System

BERK uses a Rust-inspired ownership system:

Basic Rules

  1. Every value has aownerthere is
  2. simultaneouslyonly one ownerit could be
  3. Value when owner goes out of scopeautomatically cleaned

Ownership Transfer (Move)

function örnek() do
    let metin1 = "Merhaba"
    let metin2 = move metin1  // Sahiplik transfer edildi
    
    // ❌ Err: metin1 artık geçerli not
    print(metin1)  // Derleme hatası!
    
    // ✅ Doğru: metin2 now sahip
    print(metin2)
end

References (Share)

function uzunluk_bul(share s: String) -> sayı do
    return s.len()
end

function örnek() do
    let metin1 = "Merhaba"
    let len = uzunluk_bul(share metin1)
    
    // ✅ Doğru: metin1 hala geçerli
    print(metin1)  // Çalışır!
    print("Uzunluk: " + len)
end

Interchangeable References

function büyüt(share değiştirilebilir s: String) do
    s += " Dünya!"
end

function örnek() do
    let metin1 = "Merhaba"
    büyüt(share değiştirilebilir metin1)
    print(metin1)  // "Merhaba Dünya!"
end

Lifetimes

The BERK compiler automatically checks the validity of references:

// ❌ Err: Dangling reference
function hatalı() -> share String do
    let yerel = "merhaba"
    return share yerel  // Derleme hatası! yerel scope dışına çıkacak
end

// ✅ Doğru: Sahipliği döndür
function true() -> String do
    let yerel = "merhaba"
    return move yerel  // Sahiplik transfer edildi
end

Data Race Prevention

Single Printer or Multiple Readers

// ❌ Err: Aynı anda birden fazla değiştirilebilir referans
let x = 5
let ref1 = share değiştirilebilir x
let ref2 = share değiştirilebilir x  // Derleme hatası!

// ✅ Doğru: Çoklu immutable referans
let x = 5
let ref1 = share x
let ref2 = share x  // OK

Thread-Safe Data Structures

use thread::Mutex;

let count_occurrences = new Mutex(0)

function artır() do
    let kilit = count_occurrences.kilit()
    *kilit += 1
    // Kilit otomatik serbest bırakılır
end

Common Memory Errors and Prevention

1.Use-After-Free

In C/C++:

int* ptr = malloc(sizeof(int));
free(ptr);
*ptr = 5;  // ❌ Use-after-free bug!

In BERK:

let x = new 42
serbest_bırak(x)
print(*x)  // ❌ Derleme hatası! x artık geçerli not

2. Double Free

In C/C++:

int* ptr = malloc(sizeof(int));
free(ptr);
free(ptr);  // ❌ Double free bug!

In BERK:

let x = new 42
serbest_bırak(x)
serbest_bırak(x)  // ❌ Derleme hatası! x artık geçerli not

3. Buffer Overflow

In C/C++:

int arr[5];
arr[10] = 42;  // ❌ Buffer overflow!

In BERK:

let arr = [0; 5]
arr[10] = 42  // ❌ Runtime panic! (debug modda)
              // Optimized modda bounds check yapılır
