BERK Programlama Dili

Modules and Organization

At BERK, the module system is designed to organize your code, increase reusability, and make it easier to manage large projects.

Module Fundamentals

Each BERK file is considered a module. Modules allow you to combine related functions, structures, and constants.

Simple Module Example

// matematik.berk
export function topla(a: sayı, b: sayı) -> sayı
do
    return a + b
end

export function çarp(a: sayı, b: sayı) -> sayı
do
    return a * b
end

export const PI = 3.14159

Module Usage

Use Statement (Native Modules)

kullanYou can import symbols from native modules with the expression:

// Tek function içe aktarma
use matematik::topla;

// Birden fazla öğe içe aktarma
use matematik::{topla, çarp, PI};

// Tüm dışa aktarılanları içe aktarma
use matematik::*;

// Takma ad ile içe aktarma
use matematik::PI as pi_sayısı;

Import Statement (External Packages)

içe_aktarThe statement is used to install external packages:

// Harici paket içe aktarma
import "serde" as json;

// Seçici içe aktarma
import "http"::{get, post, İstek};

Module Organization

Directory Structure

Modules follow the file system structure:

proje/
├── main.berk
├── matematik/
│   ├── temel.berk
│   ├── geometri.berk
│   └── istatistik.berk
└── String/
    ├── işlemler.berk
    └── biçimlendir.berk

Module Paths

// Alt modül kullanımı
kullan matematik::geometri::alan_hesapla;

// İç içe modüller
kullan matematik::geometri::{alan, çevre};

Export

Single Item Export

export function hesapla() -> sayı
do
    return 42
end

Exporting Multiple Items

// Gruplama sözdizimi
export { fonk1, fonk2, YapıAdı };

// Her birini ayrı ayrı
export function fonk1() do end
export function fonk2() do end
export struct YapıAdı do end

Visibility Rules

Visibility in BERK is private by default:

  • exporteditems can be used by other modules
  • not exporteditems are only available within the module
// Bu function dışa aktarıldı - dışarıdan erişilebilir
export function genel_işlev() do end

// Bu function dışa aktarılmadı - yalnızca module in
function özel_işlev() do end

Module Analysis

Search Paths

The BERK compiler searches for modules in this order:

  1. Current directory (.)
  2. ./src/directory
  3. ./stdlib/directory
  4. External packet paths (~/.berk/packages/)

Symbol Priority

Order of precedence in case of name conflicts:

  1. Local scope variables
  2. Imported symbols
  3. Module globals

Best Practices

Module Organization Suggestions

  • ✅ Group related code: Code providing the same functionality must be in the same module
  • ✅ Use clear nouns: Module names should clearly indicate the content
  • ✅ Don't do unnecessary exports: Export only elements that need to be part of the API
  • ✅ Avoid circular dependenciesDependencies like: A -> B -> A cause problems

Import Styles

// ✅ İyi: Açık and okunabilir
use matematik::geometri::{domain, çevre};

// ⚠️ Dikkatli use: Tüm içe aktarmalar isim çakışmasına neden olabilir
use matematik::*;

// ✅ İyi: Uzun isimler for takma ad
use matematik::trigonometri as trig;

Advanced Features

Module Description

You can define a module inline within a file:

module yardımcılar do
    export function yardımcı() do
        print("Yardımcı function")
    end
end

use yardımcılar::yardımcı;

Re-Export

You can export items you import from a module from your own module:

// matematik/index.berk
use matematik::temel::*;
use matematik::geometri::*;

// Tüm alt module fonksiyonlarını dışa aktar
export *;

Package Management (BPM)

With BERK Package Manager (BPM) you can manage external packages:

berk.toml Configuration

[package]
name = "projemiz"
version = "1.0.0"

[dependencies]
serde = "1.0"
http = "0.2"

Package Usage

import "serde" as json;

function main() do
    let veri = json::serileştir({isim: "Ali", yaş: 30})
    print(veri)
end

Sample Project Structure

// src/matematik/temel.berk
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

// src/matematik/geometri.berk  
export function domain(r: kesir) -> kesir do
    use matematik::temel::çarp;
    return 3.14159 * r * r
end

// src/main.berk
use matematik::temel::topla;
use matematik::geometri::domain;

function main() do
    let sonuç1 = topla(5, 3)
    let sonuç2 = domain(2.5)
    
    print("Toplam: " + sonuç1)
    print("Alan: " + sonuç2)
end
