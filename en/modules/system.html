Module System

in BERKeach file is a module. The module system is the basic way to organize and reuse your code.

Basic Concepts

What is a Module?

A module is a unit of code that contains related functions, structures, and constants. Each.berkThe file is automatically a module.

// matematik.berk - Bu dosya "matematik" modülüdür
export function topla(a: sayı, b: sayı) -> sayı do
    return a + b
end

export const PI = 3.14159

Module Hierarchy

Modules follow the file system structure:

proje/
├── ana.berk
├── matematik/
│   ├── temel.berk       (matematik::temel)
│   ├── geometri.berk    (matematik::geometri)
│   └── ileri.berk       (matematik::ileri)
└── io/
    └── dosya.berk       (io::dosya)

Module Usage

Use Statement

// Modül içe aktarma
kullan matematik;

// Belirli öğeleri içe aktarma
kullan matematik::topla;
kullan matematik::{topla, çarp, PI};

// Tüm öğeleri içe aktarma
kullan matematik::*;

// Takma ad ile kullanım
kullan matematik::topla olarak toplama;

Module Paths

// Alt modül erişimi
kullan matematik::geometri::alan;

// İç içe modüller
kullan matematik::geometri::{alan, çevre, hacim};

matematik/
├── temel.berk      // matematik::temel

Module Analysis

Search Order

The BERK compiler searches for modules in this order:

  1. current directory: ./
  2. Source directory: ./src/
  3. standard library: ./stdlib/
  4. External packages: ~/.berk/packages/

Example Analysis

kullan matematik::geometri;
// Arama sırası:
// 1. ./matematik/geometri.berk
// 2. ./src/matematik/geometri.berk
// 3. ./stdlib/matematik/geometri.berk
// 4. ~/.berk/packages/matematik/geometri.berk

Standard Library Modules

use io;              // Giriş/Çıkış işlemleri
use String;           // String işlemleri
use matematik;       // Matematik fonksiyonları
use koleksiyonlar;   // Liste, HashMap vb.
use dosya;           // Dosya işlemleri
use ağ;              // Network işlemleri

Best Practices

  • ✅ Group related code: Keep similar functions in the same module
  • ✅ Use clear nouns: Module name must clearly indicate the content
  • ✅ Minimal export: Export only what is necessary
  • ✅ Avoid circular dependencies: making A → B → A
  • ✅ Consistent structure: All modules in the project must have a similar structure

examples

Simple Mathematics Module

// matematik.berk
export const PI = 3.14159
export const E = 2.71828

export function kare(x: sayı) -> sayı do
    return x * x
end

export function küp(x: sayı) -> sayı do
    return x * x * x
end

Usage

// main.berk
use matematik::{kare, PI};

function main() do
    let sonuç = kare(5)
    print("Kare: {}", sonuç)
    print("Pi: {}", PI)
end
