Syntax and Structure

Basic syntax rules and code structure of BERK programming language.

Basic Structure

Every BERK program is aana()(ormain()) starts from the function:

function main() {
    print("Merhaba Dünya!")
}

English syntax:

function main() {
    print("Hello World!")
}

Expression Terminators

Statements in BERKdoes not require a semicolon. Each line evaluates to an expression:

let x = 10
let y = 20
let sum = x + y
print(sum)

In multi-line expressionsbackslashyou can use:

let uzunMetin = "Bu çok uzun bir yazı \
                      birden fazla satıra yayılıyor"

Bilingual Syntax

The most important feature of BERKbilingual syntaxis the support. You can mix Turkish and English keywords:

// Tamamen Türkçe
function hesapla(x: number) -> number {
    if x < 0 {
        return Err "Negatif sayı!"
    }
    return x * x
}

// Tamamen İngilizce
function calculate(x: Number) -> Number {
    if x < 0 {
        error return "Negative number!"
    }
    return x * x
}

// Karışık (geçerli ama önerilmez)
function hesapla(x: number) -> Number {
    if x < 0 {
        return Err "Negative!"
    }
    return x * x
}

Best Practice: Choose a single language in your project (Turkish OR English).

Modules

Each file is considered a module:

// matematik.berk
export function topla(a: number, b: number) -> number {
    return a + b
}

export const PI = 3.14159

// main.berk
import matematik

function main() {
    print(matematik.topla(5, 3))
    print(matematik.PI)
}

Example: Full Program

// Fibonacci sayı dizisi hesaplama

import math

// Recursive versiyonu
function fib_recursive(n: number) -> number {
    if n <= 1 {
        return n
    }
    return fib_recursive(n - 1) + fib_recursive(n - 2)
}

// Iterative versiyonu (daha verimli)
function fib_iterative(n: number) -> number {
    if n <= 1 {
        return n
    }
    
    let a = 0
    let b = 1
    
    for i 2'from n+1'e to {
        let temp = a + b
        a = b
        b = temp
    }
    
    return b
}

function main() {
    const N = 10
    
    print("İlk ", N, " Fibonacci sayısı:")
    
    for i 0'from N'ye to {
        print("fib(", i, ") = ", fib_iterative(i))
    }
}
