Documentation Contribution

Guide for contributing to improving BERK's Documentation. Any Documentation contributions are appreciated!

📚 Types of Documentation

1. mdBook Documentation

Main Documentation book (the one you are currently reading)

  • Location: berk-lang/book/src/
  • Format:Markdown (.md)
  • Tool:mdbook

2. API Documentation

Rust in-code doc comments

  • Location: berk-lang/src/
  • Format:Rustdoc comments (///)
  • Tool:cargo doc

3. Stdlib Documentation

Standard library module Descriptions

  • Location: stdlib/*.berk
  • Format:BERK doc comments (///)

4. GitHub Pages

Published HTML documents

  • Location: berk_pagesrepository
  • URL:https://arslantasm.github.io/berk_pages/

🛠️ Documentation Development Environment

  • ✅ clear and clearbe
  • ✅ with examplesexplain

  • ✅ technical termsadd for Description

structure

  2. Basic Concepts- Things to Learn
  3. examples- Practical Usage
  4. Best Practices- Tips

✅ Documentation Checklist

When Adding a New Page

  • ☑️ SUMMARY.mdAdded to ?
  • ☑️ Are the title and meta information true?
  • ☑️ Have the Code Examples been tested?
  • ☑️ Do the links work?
  • ☑️ If there are images, have they been uploaded?
  • ☑️ Has the spelling error been checked?

While Editing

  • ☑️ Is the change meaningful?
  • ☑️ Is old information up to date?
  • ☑️ Have new features been added?
  • ☑️ Has deprecated information been removed?

🚀 Documentation Publish

GitHub Pages Update

# mdBook build
cd berk-lang/book
mdbook build

# berk_pages repository'ye kopyala
cp -r book/html/* ../../berk_pages/

# Commit and push
cd ../../berk_pages
git add .
git commit -m "docs: Documentation güncellendi"
git push origin main

# GitHub Pages otomatik deploy eder (~2-3 dakika)

API Docs Publish

# Rustdoc oluşturma
cd berk-lang
cargo doc --no-deps --open

# docs/ klasörüne kopyala
cp -r target/doc docs/api

💡 Good Practices

  • ✅ Each Exampleshould work
  • ✅ Examplesminimalshould be (single concept)
  • ✅ Turkish and EnglishGive examples
  • ✅ Error statesexplain the
  • ✅ Performance Noteadd (if necessary)
  • ✅ Link to Related Pagesgive
  • ✅ Imagesuse (diagram, screenshot)

📊 Quality Metrics

  • Coverage:All public APIs must be documented
  • Examples:Each function requires at least 1 Example
  • Topicality:Deprecated features should be marked
  • Links:There should be no broken links

🎯 Contribution Tips

  • Submit small PRs (one Page/Section)
  • Typo PRs always welcome
  • Adding examples is the easiest contribution
  • Adding images/diagrams is very valuable
  • English translation help required

📞 Documentation Issues

  • Missing information?Open Issue
  • False information?send PR
  • Isn't it understandable?Start Discussion
  • Translation error?Fix it and open PR
