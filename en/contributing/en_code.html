How to Contribute Code

Guide for contributing code to BERK Programming Language. Code standards, best practices and contribution process.

📝 Contribution Process

1. Creating or Selecting an Issue

  • New trait? Beforeissueopen and discuss
  • Is it bug fix? Find the relevant issue or create a new one
  • good-first-issuestart with label

2. Creating a Fork and Branch

# Repository'yi fork edin (GitHub UI'from)
# Sonra local'e klonlayın
git clone https://github.com/KULLANICI_ADINIZ/berk.git
cd berk

# Upstream ekleyin
git remote add upstream https://github.com/ArslantasM/berk.git

# Feature branch oluşturun
git checkout -b feature/aciklayici-isim
# or bug fix for
git checkout -b fix/bug-aciklamasi

3. Writing Code

# Değişiklik yapın
# Build and test
cargo build
cargo test
cargo clippy
cargo fmt

# Değişiklikleri commit
git add .
git commit -m "feat: new trait eklendi"

4. Opening a Pull Request

# Değişiklikleri push edin
git push origin feature/aciklayici-isim

# GitHub'da Pull Request açın
# - Açıklayıcı başlık and description

🧪 Test Writing

Unit Testing

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_parse_simple_expression() {
        let input = "5 + 3";
        let result = parse_expression(input);
        
        assert!(result.is_ok());
        let expr = result.unwrap();
        assert_eq!(expr.evaluate(), 8);
    }

    #[test]
    fn test_parse_invalid_syntax() {
        let input = "5 +";
        let result = parse_expression(input);
        
        assert!(result.is_err());
        assert_eq!(
            result.unwrap_err().kind,
            ErrorKind::UnexpectedEndOfInput
        );
    }
}

Integration Testing

// tests/integration/parser_tests.rs
use berk_lang::*;

#[test]
fn test_full_program_parsing() {
    let source = r#"
        function main() {
            variable x = 10
            variable y = 20
            print(x + y)
        }
    "#;
    
    let ast = parse_program(source).unwrap();
    assert_eq!(ast.functions.len(), 1);
    assert_eq!(ast.functions[0].name, "main");
}

📋 Commit Message Format

We use Conventional Commits:

type(scope): kısa Description

Detaylı Description (opsiyonel)

Breaking changes (opsiyonel)

Fixes #123

Types:

  • feat- New trait
  • fix-Bugfix
  • docs- Documentation
  • style- Format change
  • refactor- Code refactoring
  • test- Adding/correcting tests
  • chore- Build/tooling change
  • perf- Performance improvement

Examples:

git commit -m "feat(parser): pattern matching desteği eklendi"
git commit -m "fix(codegen): LLVM pointer hatası düzeltildi"
git commit -m "docs(stdlib): math Moduleü Examplesi eklendi"
git commit -m "perf(lexer): token buffer size optimize edildi"

🎯 Best Practices

Code Quality

  • ✅ KISS-Keep It Simple, Stupid
  • ✅ DRY– Don't Repeat Yourself
  • ✅ SOLIDcomply with the principles
  • ✅ Perform error handling (unwrap()in its place?)
  • ✅ Avoid Panic,Resultuse

Performance

  • ⚡ Avoid Allocation (use borrow if possible)
  • ⚡ Avoid Clone
  • ⚡ Instead of String&struse (if appropriate)
  • ⚡ Write Benchmark (for critical code paths)
// ❌ Kötü - gereksiz allocation
fn process_string(s: String) -> String {
    s.to_uppercase()
}

// ✅ İyi - borrow Usageı
fn process_string(s: &str) -> String {
    s.to_uppercase()
}

Error Management

// ❌ Kötü - panic
fn read_file(path: &str) -> String {
    std::fs::read_to_string(path).unwrap()
}

// ✅ İyi - Result döndürme
fn read_file(path: &str) -> Result {
    std::fs::read_to_string(path)
}

// ✅ Daha iyi - custom error type
fn read_file(path: &str) -> Result {
    std::fs::read_to_string(path)
        .map_err(|e| BerkError::FileNotFound {
            path: path.to_string(),
            source: e,
        })
}

LLVM Code Generation

// Example: Binary operasyon for LLVM IR üretme
fn codegen_binary_op(
    &mut self,
    op: BinaryOp,
    lhs: &Expr,
    rhs: &Expr,
) -> Result {
    let lhs_val = self.codegen_expr(lhs)?;
    let rhs_val = self.codegen_expr(rhs)?;
    
    match op {
        BinaryOp::Add => self.builder.build_add(lhs_val, rhs_val),
        BinaryOp::Sub => self.builder.build_sub(lhs_val, rhs_val),
        BinaryOp::Mul => self.builder.build_mul(lhs_val, rhs_val),
        BinaryOp::Div => self.builder.build_div(lhs_val, rhs_val),
    }
}
