BERK Programming Language

BERKis a modern, secure and high-performance systems programming language designed with true bilingual syntax (Turkish/English) for the first time in the world. Enables productivity on 19 different target platforms (desktop, mobile, embedded, WebAssembly).

📖 Why was the name BERK chosen?

Öztürk Origin: "Strong, Strong, Solid"

BERKthe word in Öztürk"strong, durable, firm and solid"means. These qualities directly coincide with the technical goals of the programming language: memory safety, type system correctness, strong compiler architecture and stable performance.

Meaning from Arabic: "Lightning"

Another meaning found in Turkish is **"lightning"**. This meaning represents the BERK language's vision of speed, performance and agility: fast compilation based on LLVM, C++ level performance and optimized kernel architecture.

Combination of Meanings

BERK, both of Turkish originrobustnessconcept as well as in the world of modern technologyspeed and agilityIt creates a strong brand identity by combining concepts.

Internationally

BERK,Beyond-Efficient Runtime Kernel(Runtime Core Beyond Efficiency).

Philosophy of Language

BERK's basic design principles:

1. accessibility

Thanks to Turkish keywords, Introduction to programming has been made easier for those who do not speak English.

2. Security

Catches memory errors at compile time. It minimizes runtime errors.

3. Performance

It offers C/C++ level performance thanks to the LLVM backend.

4. Legibility

Clear and understandable syntax. It is optimized for reading code rather than writing code.

5. interop

Compatible with C/C++ Libraries. It can integrate into existing ecosystems.

Frequently Asked Questions

General Questions

What is BERK?

BERK is a modern, safe and high-performance programming language. With bilingual syntax support, you can use both Turkish and English keywords. Generates native code using LLVM backend.

Why should I use BERK?

  • Bilingual Syntax: Turkish or English keywords, use whatever you want
  • Memory Security: Modern type system and error handling
  • High Performance: Native code with LLVM, zero cost abstractions
  • Rich Stdlib: 18 modules, 600+ functions, scientific calculation support
  • Easy Learning: Clean syntax, clear error messages

On which platforms does BERK work?

A compiler for Windows x64 is currently available. Linux and macOS support is on the roadmap.

Is BERK open source?

Yes, BERK is an open source project under the MIT license. Development is taking place on GitHub.

Syntax and Language Features

How does bilingual syntax work?

In BERK you can write the same program in two different ways:

// Türkçe
function merhaba() {
    print("Merhaba Dünya!")
}

// İngilizce
function hello() {
    print("Hello World!")
}

Both styles compile to the same bytecode. You can even mix them in the same file!

What programming paradigms does it support?

  • Imperative Programming: Classic procedural code
  • Functional Programming: Iterators, higher-order Functions, immutability
  • Structured Programming: Structs, Moduleer architecture
  • Type Security: Static type checking, generics (in roadmap)

Is there Garbage Collector?

No, BERK uses manual memory management (for now). A Rust-like ownership system or optional GC is planned in the future.
