BERK Programlama Dili

Hello world!

The tradition in every programming language is that the first program says "Hello World!" It has been printed. We continue this tradition at BERK!

Your First Program

In your favorite text editormerhaba.berkCreate a file named:

function main() -> int
do
    print("Merhaba Dünya!")
    return 0
end

Let's Understand the Code

Let's examine it line by line:

1. Function Description

function main() -> int
  • function(orfunction): Function definitions
  • ana(ormain): Name of the function. Programana()starts from the function
  • (): Parameter list (empty)
  • -> int: Return type (integer)

2. Function Body

do
    ...
end
  • do(ordo): Start of the function
  • end(orend): End of function

3. Printing

print("Merhaba Dünya!")
  • print()(orprint()): Prints to the screen
  • "Merhaba Dünya!": String literal

4. Return Value

return 0
  • return(orreturn): Exit from function
  • 0: Successful programs return 0 (Unix tradition)

English Version

BERK is bilingual! You can also write the same program in English:

hello.berk:

function main() -> integer
do
    print("Hello World!")
    return 0
end

Compilation:

BERK-lang hello.berk -o hello.exe
./hello.exe

Output:

Hello World!

Mixed Use

You can even mix Turkish and English:

function main() -> int
do
    print("Hello Dünya!")
    return 0
end

This is also a valid BERK code!

Optimization Levels

O0 - No optimization (default):

BERK-lang merhaba.berk -o merhaba_o0.exe -O0

O1 - Basic optimizations:

BERK-lang merhaba.berk -o merhaba_o1.exe -O1

O2 - Medium (recommended):

BERK-lang merhaba.berk -o merhaba_o2.exe -O2

O3 - Aggressive optimizations:

BERK-lang merhaba.berk -o merhaba_o3.exe -O3

Different Output Formats

LLVM IR show:

BERK-lang merhaba.berk --emit llvm-ir

Show assembly:

BERK-lang merhaba.berk --emit asm

IR show:

BERK-lang merhaba.berk --emit ir

Exercises

Exercise 1: Personalization

Change the program to print your own name:

function main() -> int
do
    print("Merhaba, [ADINIZ]!")
    return 0
end

Exercise 2: Multi-Print

Print multiple lines:

function main() -> int
do
    print("Merhaba Dünya!")
    print("BERK'a hoş geldiniz!")
    print("İyi kodlamalar!")
    return 0
end

Exercise 3: Using Variables

Store the string in a variable:

function main() -> int
do
    let mesaj = "Merhaba Dünya!"
    print(mesaj)
    return 0
end

Exercise 4: String Concatenation

Concatenate two strings:

function main() -> int
do
    let selamlama = "Merhaba"
    let isim = "Ahmet"
    print(selamlama + ", " + isim + "!")
    return 0
end

Common Mistakes

Error 1: No Semicolon

Semicolon in BERKnot necessary:

// ❌ Yanlış
print("Merhaba");

// ✅ Doğru
print("Merhaba")

Error 2: Missing Parentheses

// ❌ Yanlış
print "Merhaba"

// ✅ Doğru
print("Merhaba")

Error 3: No main() Function

// ❌ Yanlış - main() fonksiyonu yok
print("Merhaba")

// ✅ Doğru - main() fonksiyonu var
function main() -> int
do
    print("Merhaba")
    return 0
end

Error 4: Return Value Missing

// ❌ Yanlış - return eksik
function main() -> int
do
    print("Merhaba")
end

// ✅ Doğru - return var
function main() -> int
do
    print("Merhaba")
    return 0
end
