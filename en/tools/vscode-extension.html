BERK Programlama Dili

VS Code Add-in

BERK VS Code Extension,professional development experienceIt offers full-featured IDE support for . Powered by Language Server Protocol (LSP).

Setup

Via Marketplace

  1. Open VS Code
  2. Go to Extensions (Ctrl+Shift+X) menu
  3. Search for "BERK Language Support"
  4. Click the "Install" button

From Command Line

code --install-extension ArslantasM-tools.berk-lang

Key Features

1. Syntax Highlighting

  • ✅ Turkish and English keywords
  • ✅ String interpolation
  • ✅ Comment lines
  • ✅ Type highlights
  • ✅ Function names

2. IntelliSense (Code Completion)

// 'let' yazın and Ctrl+Space
let x = 42

// 'x.' yazın - otomatik metodlar gösterilir
x.to_string()
x.karakter_uzunluğu()

3. Go to Definition (F12)

Press F12 on any function/variable:

let sonuç = hesapla(10)  // F12 ile hesapla() tanımına git

4. Find All References (Shift+F12)

Find all uses of a symbol

5. Rename Symbol (F2)

Secure name change - all references are updated automatically

6. Hover Information

Hover over any symbol:

  • Type information
  • Documentation
  • Signature information

7. Diagnostics (Error Checking)

Real-time error checking:

  • 🔴 Syntax errors
  • 🟠 Warnings
  • 🔵 Information

8. Code Actions (Ctrl+.)

Quick fixes and refactoring:

  • Import automatic addition
  • Add type description
  • Variable extraction

9. Signature Help (Ctrl+Shift+Space)

function hesapla(x: sayı, y: sayı, z: sayı) do
end

hesapla(  // Ctrl+Shift+Space - parametre yardımı

10. Document Symbols (Ctrl+Shift+O)

List of all symbols (functions, variables) in the file

11. Semantic Tokens

Advanced syntax highlighting - coloring based on type information

12. Inlay Hints

Inline type and parameter descriptions

13. Code Lens

Reference numbers and quick actions

Debugging Support

launch.jsonconfiguration:

{
  \"version\": \"0.2.0\",
  \"configurations\": [
    {
      \"type\": \"berk\",
      \"request\": \"launch\",
      \"name\": \"Debug BERK Program\",
      \"program\": \"${workspaceFolder}/main.berk\",
      \"stopOnEntry\": false
    }
  ]
}

Settings

settings.json:

{
  \"berk.lsp.enabled\": true,
  \"berk.lsp.trace.server\": \"off\",
  \"berk.build.optimizationLevel\": 2,
  \"berk.format.indentSize\": 4,
  \"berk.lint.warnings\": true,
  \"berk.inlayHints.enabled\": true,
  \"berk.semanticTokens.enabled\": true
}

Format on Save

{
  \"[berk]\": {
    \"editor.formatOnSave\": true,
    \"editor.defaultFormatter\": \"ArslantasM-tools.berk-lang\"
  }
}

Troubleshooting

If LSP Doesn't Work

  1. Command Palette → "BERK: Restart LSP"
  2. Restart VS Code
  3. Output panel → See "BERK Language Server" logs

No Syntax Highlighting

  1. File extension.berkmust be
  2. Language mode "BERK" must be selected (lower right corner)
