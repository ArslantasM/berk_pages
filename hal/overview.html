BERK Programlama Dili

HAL - Hardware Abstraction Layer

BERK HAL (Hardware Abstraction Layer), gömülü sistemler için unified bir donanım soyutlama katmanıdır. 33 modül ile 7 farklı mikrodenetleyici platformunu destekler ve %100 pazar kapsamı sağlar.

📊 İstatistikler

  • 33 HAL modülü - Kapsamlı donanım desteği
  • 7 platform - ESP32, STM32F4, RP2040, nRF52, GD32, Nuvoton, Arduino
  • 2,380 LOC - Optimize edilmiş HAL kodu
  • %100 pazar kapsamı - Mikrodenetleyici segmentinde tam kapsam
  • %95 tamamlanma - Production-ready durum

🎯 Desteklenen Platformlar

1. ESP32 (Espressif)

  • İşlemci: Dual-core Xtensa LX6 @ 240 MHz
  • RAM: 520 KB SRAM
  • Flash: 4-16 MB
  • Özellikler: WiFi 802.11 b/g/n, Bluetooth 4.2/BLE
  • Kullanım Alanları: IoT, akıllı ev, wearables
  • Popülerlik: ⭐⭐⭐⭐⭐ (En popüler IoT platformu)

2. STM32F4 (STMicroelectronics)

  • İşlemci: ARM Cortex-M4F @ 168 MHz
  • RAM: 192 KB SRAM
  • Flash: 512 KB - 1 MB
  • Özellikler: FPU, DSP instructions, Ethernet, USB OTG
  • Kullanım Alanları: Endüstriyel otomasyon, robotik, motor kontrol
  • Popülerlik: ⭐⭐⭐⭐⭐ (Profesyonel standart)

3. RP2040 (Raspberry Pi)

  • İşlemci: Dual-core ARM Cortex-M0+ @ 133 MHz
  • RAM: 264 KB SRAM
  • Flash: 2-16 MB (external QSPI)
  • Özellikler: PIO (Programmable I/O), USB 1.1
  • Kullanım Alanları: Maker projeleri, eğitim, prototipler
  • Popülerlik: ⭐⭐⭐⭐⭐ (Raspberry Pi ekosistemi)

4. nRF52 (Nordic Semiconductor)

  • İşlemci: ARM Cortex-M4F @ 64 MHz
  • RAM: 256 KB
  • Flash: 1 MB
  • Özellikler: Bluetooth 5.x/BLE, ultra-low power
  • Kullanım Alanları: Wearables, beacons, wireless sensors
  • Popülerlik: ⭐⭐⭐⭐ (BLE endüstri standardı)

5. GD32 (Gigadevice)

  • İşlemci: ARM Cortex-M4 @ 120 MHz
  • RAM: 128 KB SRAM
  • Flash: 512 KB
  • Özellikler: STM32 pin-compatible, düşük maliyet
  • Kullanım Alanları: Tüketici elektroniği, endüstriyel
  • Popülerlik: ⭐⭐⭐ (Maliyet-etkin alternatif)

6. Nuvoton

  • İşlemci: ARM Cortex-M23/M4 @ 72-192 MHz
  • RAM: 64-512 KB
  • Flash: 256 KB - 1 MB
  • Özellikler: Security features, CAN-FD
  • Kullanım Alanları: Otomotiv, endüstriyel güvenlik
  • Popülerlik: ⭐⭐⭐ (Özel uygulamalar)

7. Arduino (AVR/ARM)

  • İşlemci: ATmega328P @ 16 MHz (AVR), ARM Cortex-M0+ @ 48 MHz
  • RAM: 2-32 KB
  • Flash: 32-256 KB
  • Özellikler: Geniş ekosistem, kolay kullanım
  • Kullanım Alanları: Eğitim, hobi projeleri, prototipleme
  • Popülerlik: ⭐⭐⭐⭐⭐ (En yaygın maker platformu)

🚀 Hızlı Başlangıç

GPIO - LED Blink

// ESP32 - GPIO LED kontrolü
içe_aktar hal_gpio

// GPIO2'yi çıkış olarak ayarla (ESP32 yerleşik LED)
hal_gpio_init(2, GPIO_MODE_OUTPUT)

// Sonsuz döngü
iken doğru yap
    hal_gpio_write(2, 1)  // LED aç
    hal_delay_ms(1000)     // 1 saniye bekle
    
    hal_gpio_write(2, 0)  // LED kapat
    hal_delay_ms(1000)
son

UART - Seri Haberleşme

// STM32F4 - UART ile veri gönderme
içe_aktar hal_uart

// UART1'i 115200 baud rate ile başlat
hal_uart_init(UART1, 115200)

değişken mesaj = "Merhaba BERK!\n"
hal_uart_write_string(UART1, mesaj)

// Veri okuma
değişken buffer = yeni_dizi(64)
değişken okunan = hal_uart_read(UART1, buffer, 64, 1000)  // 1sn timeout

eğer okunan > 0 ise yap
    yazdır("Alınan: " + buffer)
son

I2C - Sensör Okuma

// RP2040 - BME280 sıcaklık/nem sensörü
içe_aktar hal_i2c

değişken BME280_ADDR = 0x76
değişken REG_TEMP = 0xFA

// I2C0'ı 100 kHz ile başlat
hal_i2c_init(I2C0, 100000)

// Sıcaklık register'ını oku (3 byte)
değişken veri = yeni_dizi(3)
hal_i2c_read_reg(I2C0, BME280_ADDR, REG_TEMP, veri, 3)

// Ham veriyi işle
değişken adc_T = (veri[0] << 12) | (veri[1] << 4) | (veri[2] >> 4)
değişken sıcaklık = adc_T / 5120.0  // Basitleştirilmiş
yazdır("Sıcaklık: " + sıcaklık + "°C")

ADC - Analog Okuma

// ESP32 - Analog potansiyometre okuma
içe_aktar hal_adc

// ADC1 Channel 0 (GPIO36)
hal_adc_init(ADC1, CHANNEL_0, ADC_WIDTH_12BIT, ADC_ATTEN_11DB)

iken doğru yap
    // 0-4095 arası değer oku (12-bit)
    değişken ham = hal_adc_read(ADC1, CHANNEL_0)
    
    // Voltaja çevir (0-3.3V)
    değişken voltaj = (ham / 4095.0) * 3.3
    
    yazdır("ADC: " + ham + " -> " + voltaj + "V")
    hal_delay_ms(500)
son

PWM - Motor Kontrolü

// STM32F4 - DC motor PWM kontrolü
içe_aktar hal_pwm

// Timer2, Channel 1, Pin PA5
// 1 kHz frekans, %50 duty cycle
hal_pwm_init(TIMER2, CHANNEL_1, 1000, 50)

// PWM'i başlat
hal_pwm_start(TIMER2, CHANNEL_1)

// Yavaşça hızlan (0% -> 100%)
değişken i = 0
iken i <= 100 yap
    hal_pwm_set_duty(TIMER2, CHANNEL_1, i)
    hal_delay_ms(50)
    i = i + 1
son

// PWM'i durdur
hal_pwm_stop(TIMER2, CHANNEL_1)

🎓 Kullanım Senaryoları

IoT Akıllı Ev Cihazı (ESP32)

// Akıllı termostat - WiFi + sensör
içe_aktar hal_wifi, hal_adc, hal_gpio, hal_http

fonksiyon akıllı_termostat() yap
    // WiFi bağlan
    hal_wifi_connect("EvWiFi", "sifre123", 10000)
    
    // Sıcaklık sensörü (LM35 - ADC)
    hal_adc_init(ADC1, CHANNEL_0, ADC_WIDTH_12BIT, ADC_ATTEN_11DB)
    
    // Röle çıkışı (ısıtıcı kontrolü)
    hal_gpio_init(GPIO_ROLE, GPIO_MODE_OUTPUT)
    
    iken doğru yap
        // Sıcaklık oku
        değişken adc = hal_adc_read(ADC1, CHANNEL_0)
        değişken sıcaklık = (adc / 4095.0) * 330.0  // LM35: 10mV/°C
        
        // Buluta gönder
        değişken url = "http://api.iot.com/temp?value=" + sıcaklık
        hal_http_post(url, "")
        
        // Isıtıcı kontrolü (20°C altı)
        eğer sıcaklık < 20.0 ise yap
            hal_gpio_write(GPIO_ROLE, 1)  // Isıtıcı aç
        değilse yap
            hal_gpio_write(GPIO_ROLE, 0)  // Isıtıcı kapat
        son
        
        hal_delay_ms(60000)  // 1 dakika bekle
    son
son

Motor Kontrol Sistemi (STM32F4)

// BLDC motor kontrolü - PWM + encoder + PID
içe_aktar hal_pwm, hal_timer, hal_gpio

değişken hedef_hız = 1000  // RPM
değişken encoder_sayac = 0

// Encoder interrupt callback
fonksiyon encoder_callback() yap
    encoder_sayac = encoder_sayac + 1
son

fonksiyon motor_kontrol() yap
    // PWM başlat (20 kHz)
    hal_pwm_init(TIMER1, CHANNEL_1, 20000, 0)
    hal_pwm_start(TIMER1, CHANNEL_1)
    
    // Encoder interrupt
    hal_gpio_init_interrupt(GPIO_ENC_A, GPIO_MODE_INPUT_PULLUP, 
                           GPIO_INT_RISING, encoder_callback)
    
    // PID değişkenleri
    değişken Kp = 0.5, Ki = 0.1, Kd = 0.01
    değişken integral = 0.0, son_hata = 0.0
    
    iken doğru yap
        // Hız hesapla (encoder sayacından)
        değişken anlık_hız = encoder_sayac * 60  // RPM
        encoder_sayac = 0
        
        // PID kontrol
        değişken hata = hedef_hız - anlık_hız
        integral = integral + hata
        değişken türev = hata - son_hata
        
        değişken çıkış = Kp*hata + Ki*integral + Kd*türev
        son_hata = hata
        
        // PWM duty cycle ayarla (0-100%)
        değişken duty = math_clamp(çıkış, 0.0, 100.0)
        hal_pwm_set_duty(TIMER1, CHANNEL_1, duty)
        
        hal_delay_ms(100)  // 10 Hz kontrol döngüsü
    son
son

Düşük Güç Sensör Düğümü (nRF52)

// BLE beacon + sensör - Ultra-low power
içe_aktar hal_ble, hal_adc, hal_power

fonksiyon ble_sensör_beacon() yap
    // BLE başlat
    hal_ble_init("BERK_Sensör")
    hal_ble_set_advertising(100)  // 100ms interval
    
    // ADC başlat (sıcaklık sensörü)
    hal_adc_init(ADC1, CHANNEL_0, ADC_WIDTH_12BIT, ADC_GAIN_1_6)
    
    iken doğru yap
        // Sensör oku
        değişken sıcaklık = hal_adc_read_temp()  // Internal temp
        değişken batarya = hal_adc_read_vbat()   // Battery voltage
        
        // BLE advertising paketine ekle
        hal_ble_update_data("temp", sıcaklık)
        hal_ble_update_data("vbat", batarya)
        
        // Deep sleep (1 dakika)
        hal_power_deep_sleep(60000)  // 60sn uyku, ~3µA
        // Wake-up sonrası buradan devam eder
    son
son
