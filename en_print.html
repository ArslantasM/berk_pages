BERK Programlama Dili

BERK, dünyada ilk kez gerçek çift dilli syntax (Türkçe/İngilizce) ile tasarlanmış, modern, güvenli and yüksek performanslı bir systems programming languagedir. 19 farklı hedef platformda (masaüstü, mobil, gömülü, WebAssembly) üretkenlik sağlar.

📖 Neden BERK Adı Seçilmiştir?

Öztürkçe Kökeni: "Güçlü, Muhkem, Sağlam"

BERK kelimesi, Öztürkçe'de "güçlü, dayanıklı, muhkem and sağlam" anlamlarına gelir. Bu nitelikler, programlama dilinin teknik hedefleriyle doğrudan örtüşmektedir: bellek güvenliği, tip sistemi doğruluğu, güçlü derleyici mimarisi and kararlı performans.

Arapçadan Gelen Anlamı: "Şimşek"

Türkçe'de karşılık bulan bir diğer anlam **"şimşek"**tir. Bu anlam, BERK dilinin hız, performans and çeviklik vizyonunu temsil eder: LLVM tabanlı hızlı derleme, C++ seviyesinde performans and optimize edilmiş çekirdek mimarisi.

Anlamların Birleşimi

BERK, hem Türkçe kökenli sağlamlık kavramını hem de modern teknoloji dünyasındaki hız and çeviklik kavramlarını birleştirerek güçlü bir marka kimliği oluşturur.

Uluslararası Alanda

BERK, Beyond-Efficient Runtime Kernel (Verimliliğin Ötesinde Çalışma Zamanı Çekirdeği) olarak tanımlanacaktır.

Her programlama dilinde gelenek, ilk programın "Merhaba Dünya!" yazdırması olmuştur. BERK'ta da bu geleneği sürdürüyoruz!

Kodu Anlayalım

Satır satır inceleyelim:

1. function Tanımı

function ana() -> integer
  • function (or function): function tanımlar
  • ana (or main): Fonksiyonun adı. Program ana() fonksiyonundan başlar
  • (): Parametre listesi (null)
  • -> integer: Return Type (integer)

2. function Gövdesi

do
    ...
end

📚 API Referenceı

Matris Oluşturma

linalg_birim_mat(n: tam_sayı) -> [float]

n×n boyutunda birim (identity) matris oluşturur.

Parametre:

  • n: Matris boyutu

Döndürür: Birim matris (düz dizi formatında)

Example:

variable I3 = linalg_birim_mat(3)
// I3 = [1, 0, 0,
//       0, 1, 0,
//       0, 0, 1]

linalg_sıfır_mat(m: tam_sayı, n: tam_sayı) -> [float]

m×n boyutunda sıfır matrisi oluşturur.

linalg_birler_mat(m: tam_sayı, n: tam_sayı) -> [float]

m×n boyutunda tüm elemanları 1 olan matris oluşturur.

linalg_diyagonal_mat(d: [float], n: tam_sayı) -> [float]

Köşegen elemanları d dizisi olan n×n matris oluşturur.

Example:

variable d = [2.0, 3.0, 5.0]
variable D = linalg_diyagonal_mat(d, 3)
// D = [2, 0, 0,
//      0, 3, 0,
//      0, 0, 5]

Matris Aritmetiği

linalg_mat_topla(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

İki m×n matrisini toplar: C = A + B

linalg_mat_çıkar(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

İki m×n matrisini çıkarır: C = A - B

linalg_mat_skaler(α: float, A: [float], m: tam_sayı, n: tam_sayı) -> [float]

Matrisi skaler ile çarpar: B = α · A

linalg_mat_çarp(A: [float], B: [float], m: tam_sayı, k: tam_sayı, n: tam_sayı) -> [float]

Matris çarpımı: C = A × B

  • A: m×k
  • B: k×n
  • C: m×n

Example:

// 2×2 matris çarpımı
variable A = [1.0, 2.0,
              3.0, 4.0]
variable B = [5.0, 6.0,
              7.0, 8.0]
variable C = linalg_mat_çarp(A, B, 2, 2, 2)
// C = [19, 22,
//      43, 50]

linalg_mat_hadamard(A: [float], B: [float], m: tam_sayı, n: tam_sayı) -> [float]

Element-wise çarpım (Hadamard product): C[i,j] = A[i,j] × B[i,j]

Vektör İşlemleri

linalg_iç_çarpım(u: [float], v: [float], n: tam_sayı) -> float

İç çarpım (dot product): u · v = Σ(u[i] × v[i])

Example:

variable u = [1.0, 2.0, 3.0]
variable v = [4.0, 5.0, 6.0]
variable dot = linalg_iç_çarpım(u, v, 3)  // 32.0

linalg_norm2(v: [float], n: tam_sayı) -> float

L2 norm (Euclidean norm): ||v|| = √(Σv[i]²)

linalg_norm1(v: [float], n: tam_sayı) -> float

L1 norm (Manhattan norm): ||v||₁ = Σ|v[i]|

linalg_norm_inf(v: [float], n: tam_sayı) -> float

L∞ norm (maximum norm): ||v||∞ = max(|v[i]|)

linalg_normalize(v: [float], n: tam_sayı) -> [float]

Vektörü normalize eder: v̂ = v / ||v||

linalg_dış_çarpım(u: [float], v: [float], m: tam_sayı, n: tam_sayı) -> [float]

Dış çarpım (outer product): A[i,j] = u[i] × v[j]

linalg_cross_3d(u: [float], v: [float]) -> [float]

3D vektör cross product (vektörel çarpım): w = u × v

Example:

variable u = [1.0, 0.0, 0.0]
variable v = [0.0, 1.0, 0.0]
variable w = linalg_cross_3d(u, v)  // [0, 0, 1]

Sık Sorulan Sorular

Genel Sorular

BERK nedir?

BERK, modern, güvenli and performanslı bir programlama dilidir. İki dilli syntax desteğiyle hem Türkçe hem İngilizce anahtar kelimeler kullanabilirsiniz. LLVM backend kullanarak native kod üretir.

Neden BERK kullanmalıyım?

  • İki Dilli Syntax: Türkçe or İngilizce anahtar kelimeler, dilediğinizi kullanın
  • Bellek Güvenliği: Modern tip sistemi and hata yönetimi
  • Yüksek Performans: LLVM ile native kod, sıfır maliyet abstraksiyonlar
  • Zengin Stdlib: 18 module, 600+ function, bilimsel hesaplama desteği
  • Kolay Öğrenme: Temiz syntax, anlaşılır hata mesajları

BERK hangi platformlarda çalışır?

Şu anda Windows x64 for derleyici mevcuttur. Linux and macOS desteği yol haritasında bulunmaktadır.

BERK açık kaynak mı?

Evet, BERK MIT lisansı altında açık kaynak bir projedir. GitHub'da geliştirme yapılmaktadır.

Syntax and Dil Özellikleri

İki dilli syntax nasıl çalışır?

BERK'te aynı programı iki farklı şekilde yazabilirsiniz:

// Türkçe

Her iki style de aynı bytecode'a derlenir. Hatta aynı dosyada karıştırarak kullanabilirsiniz!

Hangi programlama paradigmalarını destekler?

  • İmperatif Programlama: Klasik prosedürel kod
  • Fonksiyonel Programlama: İteratörler, higher-order Functions, immutability
  • Yapısal Programlama: Struct'lar, Moduleer mimari
  • Tip Güvenliği: Statik tip kontrolü, generic'ler (yol haritasında)

Garbage Collector var mı?

Hayır, BERK manuel bellek yönetimi kullanır (şu an for). Gelecekte Rust benzeri ownership sistemi or optional GC planlanmaktadır.
