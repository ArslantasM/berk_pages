## 🚀 Hızlı Başlangıç

### Kurulum
```bash
# 1. BERK-lang.exe'yi indirin
# 2. PATH'e ekleyin
```

### Kullanım

**REPL (Etkileşimli):**
```bash
BERK-lang repl
>>> yazdır("Merhaba!")
```

**Direkt Çalıştırma:**
```bash
BERK-lang run program.berk
```

**Native Derleme:**
```bash
BERK-lang compile program.berk -o program.exe
.\program.exe
```
