BERK Programlama Dili

Sözdizimi and struct

BERK programlama dilinin temel syntax kuralları and kod yapısı.

Temel struct

Her BERK programı bir ana() (or main()) fonksiyonundan başlar:

işlev ana() {
    print("Merhaba Dünya!")
}

İngilizce syntax:

function main() {
    print("Hello World!")
}

İfade Sonlandırıcılar

BERK'te ifadeler noktalı virgül gerektirmez. Her satır bir ifade olarak değerlendirilir:

variable x = 10
variable y = 20
variable toplam = x + y
print(toplam)

Çok satırlı ifadelerde backslash kullanabilirsiniz:

variable uzunMetin = "Bu çok uzun bir string \
                      birden fazla satıra yayılıyor"

Blok Yapıları

Bloklar süslü parantez ile tanımlanır:

işlev hesapla() {
    variable a = 5
    variable b = 3
    
    if a > b {
        print("a büyük")
    } else {
        print("b büyük or eşit")
    }
}

İsimlendirme Kuralları

Değişkenler and Functions

  • snake_case (önerilen): variable kullanıcı_adı = "Ahmet"
  • camelCase (alternatif): variable kullanıcıAdı = "Ahmet"

Sabitler

  • SCREAMING_SNAKE_CASE: constant MAX_DEĞER = 100

Türler

  • PascalCase: tür KullanıcıBilgisi = struct { ... }
// İyi Examples

variable toplam_fiyat = 99.99
constant PI_DEĞERI = 3.14159

işlev hesapla_alan(yarıçap: Sayı) -> Sayı {
    geri return PI_DEĞERI * yarıçap * yarıçap
}

// Kaçınılması gerekenler
variable s = 0              // Çok kısa, anlaşılmaz
variable ÖzelSayı123 = 5    // Karışık format

Girinti (Indentation)

BERK girinti konusunda esnek olmakla birlikte, 4 boşluk Usageı önerilir:

işlev kontrol_et(x: Sayı) {
    if x > 0 {
        print("Pozitif")
        if x > 100 {
            print("Çok büyük!")
        }
    } else if x < 0 {
        print("Negatif")
    } else {
        print("Sıfır")
    }
}

Boşluklar (Whitespace)

Operatörler etrafında boşluk Usageı okunabilirliği artırır:

// Tercih edilen
variable sonuç = a + b * c

// Geçerli ama okunabilir not
variable sonuç=a+b*c

Satır Uzunluğu

80-100 karakter sınırı önerilir. Uzun satırları şöyle bölebilirsiniz:

variable çokUzunDeğişken = birinciFonksiyon(parametere1, parametre2)
                            + ikinciFonksiyon(parametre3)
                            + üçüncüFonksiyon(parametre4)

İki Dilli Syntax

BERK'in en Important özelliği iki dilli syntax desteğidir. Türkçe and İngilizce anahtar kelimeleri karıştırabilirsiniz:

// Tamamen Türkçe
işlev hesapla(x: Sayı) -> Sayı {
    if x < 0 {
        hata return "Negatif sayı!"
    }
    geri return x * x
}

// Tamamen İngilizce
function calculate(x: Number) -> Number {
    if x < 0 {
        error return "Negative number!"
    }
    return x * x
}

// Karışık (geçerli ama önerilmez)
function hesapla(x: Sayı) -> Number {
    if x < 0 {
        hata return "Negative!"
    }
    return x * x
}

Best Practice: Projenizde tek bir dil tercih edin (Türkçe or İngilizce).

Moduleler

Her dosya bir module olarak değerlendirilir:

// Mathematics.berk
export işlev topla(a: Sayı, b: Sayı) -> Sayı {
    geri return a + b
}

export constant PI = 3.14159

// ana.berk
import Mathematics

işlev ana() {
    print(Mathematics.topla(5, 3))
    print(Mathematics.PI)
}

Example: Tam Program

// Fibonacci sayı dizisi hesaplama

import math

// Recursive versiyonu
işlev fib_recursive(n: Sayı) -> Sayı {
    if n <= 1 {
        geri return n
    }
    geri return fib_recursive(n - 1) + fib_recursive(n - 2)
}

// Iterative versiyonu (daha verimli)
işlev fib_iterative(n: Sayı) -> Sayı {
    if n <= 1 {
        geri return n
    }
    
    variable a = 0
    variable b = 1
    
    loop i 2'den n+1'e kadar {
        variable temp = a + b
        a = b
        b = temp
    }
    
    geri return b
}

işlev ana() {
    constant N = 10
    
    print("İlk ", N, " Fibonacci sayısı:")
    
    loop i 0'dan N'ye kadar {
        print("fib(", i, ") = ", fib_iterative(i))
    }
}
