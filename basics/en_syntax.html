BERK Programming Language

Syntax and struct

BERK Programming Languagenin basic syntax rules and code structure.

Basic Structure

Every BERK program starts with a ana() (or main()) function:

function main() {
    print("Hello World!")
}

English syntax:

function main() {
    print("Hello World!")
}

Statement Terminators

In BERK, statements do not require semicolons. Each line is evaluated as a statement:

variable x = 10
variable y = 20
variable toplam = x + y
print(toplam)

In multi-line statements backslash you can use:

variable longText = "This is a very long string \
                      spanning multiple lines"

Block Structures

Blocks curly braces are defined with:

function calculate() {
    variable a = 5
    variable b = 3
    
    if a > b {
        print("a is greater")
    } else {
        print("b is greater or equal")
    }
}

Naming Conventions

Variables and Functions

  • snake_case (recommended): variable user_name = "John"
  • camelCase (alternative): variable userName = "John"

Constants

  • SCREAMING_SNAKE_CASE: constant MAX_DEĞER = 100

Types

  • PascalCase: tür KullanıcıBilgisi = struct { ... }
// Good examples
variable counter = 0
variable total_price = 99.99
constant PI_VALUE = 3.14159

function calculate_area(radius: Number) -> Number {
    return PI_VALUE * radius * radius
}

// Things to avoid
variable s = 0              // Too short, unclear
variable SpecialNum123 = 5  // Mixed format

Indentation

While BERK is flexible about indentation, 4 space is recommended:

işlev kontrol_et(x: Sayı) {
    if x > 0 {
        print("Pozitif")
        if x > 100 {
            print("Çok büyük!")
        }
    } else if x < 0 {
        print("Negatif")
    } else {
        print("Sıfır")
    }
}

spacelar (Whitespace)

Operatörler around space Usageı improves readability:

// Preferred
variable sonuç = a + b * c

// Valid but not readable
variable sonuç=a+b*c

Line Length

80-100 character limit is recommended. You can break long lines like this:

variable çokUzunDeğişken = birinciFonksiyon(parametere1, parametre2)
                            + ikinciFonksiyon(parametre3)
                            + üçüncüFonksiyon(parametre4)

Bilingual Syntax

BERK's most important feature is Bilingual Syntax support. Türkçe and İngilizce you can mix keywords:

// Tamamen Türkçe
işlev hesapla(x: Sayı) -> Sayı {
    if x < 0 {
        hata return "Negatif sayı!"
    }
    geri return x * x
}

// Tamamen İngilizce
function calculate(x: Number) -> Number {
    if x < 0 {
        error return "Negative number!"
    }
    return x * x
}

// Karışık (geçerli ama önerilmez)
function hesapla(x: Sayı) -> Number {
    if x < 0 {
        hata return "Negative!"
    }
    return x * x
}

Best Practice: Choose one language for your project (Turkish or English).

Modules

Each file is considered a module:

// Mathematics.berk
export işlev topla(a: Sayı, b: Sayı) -> Sayı {
    geri return a + b
}

export constant PI = 3.14159

// ana.berk
import Mathematics

işlev ana() {
    print(Mathematics.topla(5, 3))
    print(Mathematics.PI)
}

Example: Complete Program

// Fibonacci sequence calculation

import math

// Recursive version
function fib_recursive(n: Number) -> Number {
    if n <= 1 {
        return n
    }
    return fib_recursive(n - 1) + fib_recursive(n - 2)
}

// Iterative version (more efficient)
function fib_iterative(n: Number) -> Number {
    if n <= 1 {
        return n
    }
    
    variable a = 0
    variable b = 1
    
    loop i from 2 to n+1 {
        variable temp = a + b
        a = b
        b = temp
    }
    
    return b
}

function main() {
    constant N = 10
    
    print("First ", N, " Fibonacci numbers:")
    
    loop i from 0 to N {
        print("fib(", i, ") = ", fib_iterative(i))
    }
}
