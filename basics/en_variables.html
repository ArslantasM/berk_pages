BERK Programlama Dili

Değişkenler and Sabitler

BERK'te değerler saklamak for değişkenler (variables) and sabitler (constants) kullanılır.

variable Tanımlama

Türkçe Syntax

variable x = 10
variable isim = "Ahmet"
variable pi = 3.14159

İngilizce Syntax

var x = 10
var name = "John"
var pi = 3.14159

Tip Belirtme

BERK statik tipli bir dildir. Tip çıkarımı (type inference) desteklenir:

// Tip çıkarımı (önerilen)
variable sayı = 42          // Sayı tipi
variable metin = "Hello"    // string tipi
variable gerçek = 3.14      // Sayı tipi (float)

// Açık tip belirtimi
variable sayı: Sayı = 42
variable metin: string = "Hello"
variable liste: Liste<Sayı> = [1, 2, 3]

variable Değiştirme

Değişkenler tanımlandıktan sonra değerleri değiştirilebilir:

variable sayaç = 0
print(sayaç)  // 0

sayaç = sayaç + 1
print(sayaç)  // 1

sayaç += 5
print(sayaç)  // 6

Sabitler (Constants)

Sabitler bir kez atandıktan sonra değiştirilemez:

constant PI = 3.14159
constant MAX_KULLANICI = 100
constant UYGULAMA_ADI = "BERK App"

// Hata! constant değiştirilemez
// PI = 3.14  // Derleme hatası

İngilizce Syntax

const PI = 3.14159
const MAX_USERS = 100

İsimlendirme Kuralları

Değişkenler

  • snake_case kullanın (önerilen)
  • Türkçe karakterler desteklenir
  • Sayı ile başlayamaz
  • Anahtar kelime olamaz
// Geçerli variable isimleri
variable kullanıcı_adı = "Ayşe"
variable toplam_fiyat = 99.99
variable öğrenci_numarası = 12345
variable değer1 = 10
variable _private = "gizli"

// Geçersiz variable isimleri
// variable 1değer = 10      // Sayı ile başlıyor
// variable işlev = 5        // Anahtar kelime
// variable user-name = ""   // Tire kullanılamaz

Sabitler

  • SCREAMING_SNAKE_CASE kullanın
  • Tümü büyük harf
  • Kelimeler alt çizgi ile ayrılır
constant MAX_DEĞER = 1000
constant VERSİYON_NUMARASI = "0.8.0"
constant HATA_MESAJI = "Geçersiz Introduction"

Kapsam (Scope)

Global Değişkenler

function dışında tanımlanan değişkenler global'dir:

variable global_sayaç = 0  // Global

işlev artır() {
    global_sayaç += 1
}

işlev ana() {
    print(global_sayaç)  // 0
    artır()
    print(global_sayaç)  // 1
}

Yerel Değişkenler

function içinde tanımlanan değişkenler yerel'dir:

işlev hesapla() {
    variable yerel = 10  // Sadece bu fonksiyonda erişilebilir
    print(yerel)
}

işlev ana() {
    hesapla()
    // print(yerel)  // Hata! yerel burada tanımlı not
}

Blok Kapsamı

Her blok kendi kapsamını oluşturur:

işlev ana() {
    variable x = 10
    
    if x > 5 {
        variable y = 20  // Bu blokta geçerli
        print(x, y)     // 10, 20
    }
    
    print(x)     // 10
    // print(y)  // Hata! y bu kapsamda yok
}

Shadowing

İç kapsamda aynı isimli variable tanımlanabilir:

işlev ana() {
    variable x = 5
    print(x)  // 5
    
    {
        variable x = 10  // Farklı variable
        print(x)        // 10
    }
    
    print(x)  // 5 (dış kapsam)
}

Destructuring

Tuple and listelerden değer çıkarma:

// Tuple destructuring
variable (x, y) = (10, 20)
print(x)  // 10
print(y)  // 20

// Liste destructuring
variable [ilk, ikinci, ...geri_kalan] = [1, 2, 3, 4, 5]
print(ilk)         // 1
print(ikinci)      // 2
print(geri_kalan)  // [3, 4, 5]

Çoklu Atama

Birden fazla değişkeni aynı anda tanımlama:

variable a, b, c = 1, 2, 3
print(a, b, c)  // 1 2 3

// Değer takası (swap)
variable x = 10
variable y = 20
x, y = y, x
print(x, y)  // 20 10

Nullable Değişkenler

Değişkenler null olabilir:

variable değer: Sayı? = null  // Nullable tip

if değer != null {
    print("Değer: ", değer)
} else {
    print("Değer yok")
}

// Varsayılan değer ile
variable sonuç = değer ?: 0  // if null ise 0 kullan

Type Aliasing

Tip takma adları:

tip KullanıcıID = Sayı
tip Eposta = string

variable id: KullanıcıID = 12345
variable email: Eposta = "user@example.com"

Best Practices

✅ Yapılması Gerekenler

// Anlamlı isimler kullanın
variable öğrenci_sayısı = 30
variable toplam_fiyat = 199.99

// Sabitler for büyük harf
constant MAX_RETRY = 3
constant API_URL = "https://api.example.com"

// Tip belirtimi gerektiğinde
variable liste: Liste<string> = []
variable harita: Harita<string, Sayı> = {}

❌ Kaçınılması Gerekenler

// Çok kısa or anlamsız isimler
variable x = 30
variable tmp = 199.99
variable a1, a2, a3 = 1, 2, 3

// Tutarsız isimlendirme
variable UserName = ""    // PascalCase değişkende kullanılmaz
variable user-name = ""   // Tire kullanılamaz

// Gereksiz tip belirtimi (tip çıkarımı yeterli)
variable sayı: Sayı = 10  // Gereksiz, "variable sayı = 10" yeter

Örnek Program

import math

// Global sabitler
constant YERÇEKIMI = 9.81  // m/s²
constant PI = 3.14159

işlev dairesel_hareket(yarıçap: Sayı, hız: Sayı) -> Sayı {
    // Merkezcil ivme hesaplama
    variable ivme = (hız * hız) / yarıçap
    geri return ivme
}

işlev serbest_düşüş(yükseklik: Sayı) -> Sayı {
    // v = sqrt(2 * g * h)
    variable hız = math.sqrt(2.0 * YERÇEKIMI * yükseklik)
    geri return hız
}

işlev ana() {
    // Değişkenler
    variable yarıçap = 5.0   // metre
    variable hız = 10.0      // m/s
    
    variable ivme = dairesel_hareket(yarıçap, hız)
    print("Merkezcil ivme: ", ivme, " m/s²")
    
    // constant değer
    constant YÜKSEKLİK = 50.0  // metre
    variable düşüş_hızı = serbest_düşüş(YÜKSEKLİK)
    print("Düşüş hızı: ", düşüş_hızı, " m/s")
}
