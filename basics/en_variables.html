BERK Programming Language

Variables and Constants

In BERK, to store values variables (variables) and constants (constants) are used.

variable Declaration

Turkish Syntax

değişken x = 10
değişken isim = "Ahmet"
variable pi = 3.14159

English Syntax

var x = 10
var name = "John"
var pi = 3.14159

Type Specification

BERK is a statically typed language. Type inference (type inference) is supported:

// Type inference (recommended)
variable sayı = 42          // Sayı tipi
variable metin = "Hello"    // string tipi
variable gerçek = 3.14      // Sayı tipi (float)

// Explicit type specification
variable sayı: Sayı = 42
variable metin: string = "Hello"
variable liste: Liste<Sayı> = [1, 2, 3]

variable Modification

variables values can be changed after declaration:

variable counter = 0
print(counter)  // 0

counter = counter + 1
print(counter)  // 1

counter += 5
print(counter)  // 6

constants (Constants)

constants cannot be changed after being assigned once:

constant PI = 3.14159
constant MAX_KULLANICI = 100
constant UYGULAMA_ADI = "BERK App"

// Error! constant cannot be changed
// PI = 3.14  // Compilation error

English Syntax

const PI = 3.14159
const MAX_USERS = 100

Naming Rules

Variables

  • snake_case use (recommended)
  • Turkish characters are supported
  • Cannot start with a number
  • Cannot be a keyword
// Valid variable names
variable user_name = "Alice"
variable total_price = 99.99
variable student_number = 12345
variable value1 = 10
variable _private = "gizli"

// Invalid variable isimleri
// variable 1değer = 10      // Sayı ile başlıyor
// variable işlev = 5        // Anahtar kelime
// variable user-name = ""   // Tire kullanılamaz

Constants

  • SCREAMING_SNAKE_CASE use
  • All uppercase letters
  • Words separated by underscores
constant MAX_DEĞER = 1000
constant VERSİYON_NUMARASI = "0.8.0"
constant HATA_MESAJI = "Invalid Introduction"

Scope

Global variables

function defined outside variables are global:

variable global_sayaç = 0  // Global

işlev artır() {
    global_sayaç += 1
}

işlev ana() {
    print(global_sayaç)  // 0
    artır()
    print(global_sayaç)  // 1
}

Local variables

function defined inside variables are local:

işlev hesapla() {
    variable Local = 10  // Accessible only in this function
    print(Local)
}

işlev ana() {
    hesapla()
    // print(Local)  // Hata! Local not defined here
}

Block Scope

Each block creates its own scope:

işlev ana() {
    variable x = 10
    
    if x > 5 {
        variable y = 20  // Bu blokta Valid
        print(x, y)     // 10, 20
    }
    
    print(x)     // 10
    // print(y)  // Hata! y not in this scope
}

Shadowing

A variable with the same name can be defined in inner scope:

işlev ana() {
    variable x = 5
    print(x)  // 5
    
    {
        variable x = 10  // Different variable
        print(x)        // 10
    }
    
    print(x)  // 5 (outer scope)
}

Destructuring

Tuple and extracting values from lists:

// Tuple destructuring
variable (x, y) = (10, 20)
print(x)  // 10
print(y)  // 20

// Liste destructuring
variable [ilk, ikinci, ...geri_kalan] = [1, 2, 3, 4, 5]
print(ilk)         // 1
print(ikinci)      // 2
print(geri_kalan)  // [3, 4, 5]

Multiple Assignment

Declare multiple variables at once:

variable a, b, c = 1, 2, 3
print(a, b, c)  // 1 2 3

// Value swap (swap)
variable x = 10
variable y = 20
x, y = y, x
print(x, y)  // 20 10

Nullable variables

variables null olabilir:

variable değer: Sayı? = null  // Nullable tip

if değer != null {
    print("Değer: ", değer)
} else {
    print("Değer yok")
}

// Default Value ile
variable sonuç = değer ?: 0  // if null ise 0 kullan

Type Aliasing

Tip takma adları:

tip KullanıcıID = Sayı
tip Eposta = string

variable id: KullanıcıID = 12345
variable email: Eposta = "user@example.com"

Best Practices

✅ Things to Do

// Use meaningful names
variable öğrenci_sayısı = 30
variable toplam_fiyat = 199.99

// constants for büyük harf
constant MAX_RETRY = 3
constant API_URL = "https://api.example.com"

// Tip belirtimi gerektiğinde
variable liste: Liste<string> = []
variable harita: Harita<string, Sayı> = {}

❌ Things to Avoid

// Çok kısa or anlamsız isimler
variable x = 30
variable tmp = 199.99
variable a1, a2, a3 = 1, 2, 3

// Tutarsız isimlendirme
variable UserName = ""    // PascalCase değişkende kullanılmaz
variable user-name = ""   // Tire kullanılamaz

// Gereksiz tip belirtimi (Type inference yeterli)
variable sayı: Sayı = 10  // Gereksiz, "variable sayı = 10" yeter

Example Program

import math

// Global constants
constant YERÇEKIMI = 9.81  // m/s²
constant PI = 3.14159

işlev dairesel_hareket(yarıçap: Sayı, hız: Sayı) -> Sayı {
    // Merkezcil ivme hesaplama
    variable ivme = (hız * hız) / yarıçap
    geri return ivme
}

işlev serbest_düşüş(yükseklik: Sayı) -> Sayı {
    // v = sqrt(2 * g * h)
    variable hız = math.sqrt(2.0 * YERÇEKIMI * yükseklik)
    geri return hız
}

işlev ana() {
    // variables
    variable yarıçap = 5.0   // metre
    variable hız = 10.0      // m/s
    
    variable ivme = dairesel_hareket(yarıçap, hız)
    print("Merkezcil ivme: ", ivme, " m/s²")
    
    // constant değer
    constant YÜKSEKLİK = 50.0  // metre
    variable düşüş_hızı = serbest_düşüş(YÜKSEKLİK)
    print("Düşüş hızı: ", düşüş_hızı, " m/s")
}
