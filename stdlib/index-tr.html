📖 Nasıl Kullanılır?

1. Modül İçe Aktarma

// Tek modül
içe_aktar math

// Çoklu modül
içe_aktar math, stats, linalg

// Alias kullanımı
içe_aktar math olarak m
içe_aktar http olarak h

2. Fonksiyon Çağırma

// Tam isim
değişken sonuç = math.sqrt(16.0)

// Alias ile
içe_aktar math olarak m
değişken sonuç = m.sqrt(16.0)

3. Sabit Kullanımı

içe_aktar math

yazdır(math.PI)        // 3.14159...
yazdır(math.E)         // 2.71828...
yazdır(math.TAU)       // 6.28318... (2π)
