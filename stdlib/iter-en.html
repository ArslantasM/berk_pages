📖 Overview

Functional programming with iterators: map, filter, reduce, zip, chain, lazy evaluation.

🚀 Quick Start

import iter

let numbers = [1, 2, 3, 4, 5]
let result = iter.from(numbers)
    .filter(|x| x % 2 == 0)
    .map(|x| x * 2)
    .collect()
// [4, 8]
