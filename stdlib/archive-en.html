📦 archive

ZIP/TAR Archive Support

~350 lines ~25 functions ZIP/TAR

📖 Overview

Archive creation and extraction for ZIP and TAR formats. Supports DEFLATE, gzip, and bzip2 compression.

🚀 Quick Start

import archive

// Create ZIP
let zip = archive.new_zip()
zip.add_file("data.txt", "path/to/data.txt")?
zip.add_memory("config.json", "{}")?
zip.save("output.zip")?

// Extract
archive.unzip("archive.zip", "output_dir")?

// Quick functions
archive.zip_directory("my_folder", "backup.zip")?
