📖 Genel Bakış

PDF modülü, programmatically PDF döküman oluşturma ve manipülasyon sağlar. Text, shapes, images ve multi-page dokümantasyon destekler.

🚀 Kullanım

içe_aktar pdf

// Create PDF
değişken doc = pdf.new()
doc.set_title("My Document")
doc.set_author("BERK")

// Add page
değişken page = doc.add_page(pdf.A4)
page.text(100, 700, "Hello PDF!", 12)

// Save
