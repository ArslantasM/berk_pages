BERK Programlama Dili

Hata Mesajları Rehberi

BERK derleyicisi and runtime tarafından üretilen hata mesajlarının Descriptionları and çözüm önerileri.

⚠️ Compile-Time Hataları

Syntax Hataları

E001: Beklenmeyen token

// HATA
function test() {
    variable x = 5
    // Noktalı virgül eksik
}

// ÇÖZÜM
function test() {
    variable x = 5;
}

Description: Parser beklenmeyen bir token ile karşılaştı. Genellikle eksik noktalama işareti or yazım hatasından kaynaklanır.

E002: Parantez eşleşmiyor

// HATA
variable sonuç = (5 + 3 * 2

// ÇÖZÜM
variable sonuç = (5 + 3) * 2

Çözüm: Tüm parantezlerin, köşeli parantezlerin and süslü parantezlerin eşleştiğinden emin olun.

Type Hataları

E101: Tip uyumsuzluğu

// HATA
variable x: tam = "merhaba"  // string, tam'a atanamaz

// ÇÖZÜM
variable x: metin = "merhaba"  // true tip
// or
variable x: tam = 42  // true değer

Description: Değişkenin tipi ile atanan değerin tipi uyuşmuyor.

E102: Tip çıkarımı başarısız

// HATA
variable x  // Tip and değer yok

// ÇÖZÜM
variable x: tam = 0  // Açık tip
// or
variable x = 0  // Tip çıkarımı

E103: Geçersiz operatör Usageı

// HATA
variable x = "hello" * 5  // String ile sayı çarpılamaz

// ÇÖZÜM
variable x = "hello" + " world"  // String concatenation
// or
variable x = 5 * 3  // Sayısal çarpma

Kapsam Hataları

E201: Tanımlanmamış variable

// HATA
print(isim)  // 'isim' tanımlanmamış

// ÇÖZÜM
variable isim = "BERK"
print(isim)

E202: variable zaten tanımlı

// HATA
variable x = 5
variable x = 10  // Tekrar tanımlama

// ÇÖZÜM
variable x = 5
x = 10  // Yeniden atama (tanımlama not)

E203: Sabite atama yapılamaz

// HATA
constant PI = 3.14
PI = 3.14159  // Sabite atama

// ÇÖZÜM
variable pi = 3.14  // variable kullan
pi = 3.14159  // Artık değiştirilebilir

function Hataları

E301: function bulunamadı

// HATA
sonuç = hesapla(5, 10)  // 'hesapla' tanımlanmamış

// ÇÖZÜM
function hesapla(a: tam, b: tam) -> tam {
    döndür a + b
}
sonuç = hesapla(5, 10)

E302: Parametre sayısı uyumsuz

function topla(a: tam, b: tam) -> tam {
    döndür a + b
}

// HATA
sonuç = topla(5)  // 2 parametre gerekli, 1 verildi

// ÇÖZÜM
sonuç = topla(5, 10)

E303: Return Type uyumsuz

// HATA
function al_isim() -> metin {
    döndür 42  // tam, metin not
}

// ÇÖZÜM
function al_isim() -> metin {
    döndür "BERK"
}

🔥 Runtime Hataları

Aritmetik Hataları

R001: Sıfıra bölme

// HATA
variable x = 10 / 0

// ÇÖZÜM
if bölen != 0 {
    variable x = 10 / bölen
} else {
    print("Sıfıra bölme hatası!")
}

R002: Sayısal overflow

// HATA
variable x: tam8 = 200  // tam8 max: 127

// ÇÖZÜM
variable x: tam32 = 200  // Daha büyük tip

Bellek Hataları

R101: Null pointer erişimi

// HATA
variable ptr: *tam = boş_değer
print(*ptr)  // Null dereference

// ÇÖZÜM
if ptr != boş_değer {
    print(*ptr)
}

R102: Array sınır aşımı

// HATA
variable dizi = [1, 2, 3]
print(dizi[5])  // Index out of bounds

// ÇÖZÜM
if 5 < dizi.uzunluk {
    print(dizi[5])
} else {
    print("Geçersiz index")
}

I/O Hataları

R201: Dosya bulunamadı

// HATA
variable Content = fs.oku_dosya("yok.txt")

// ÇÖZÜM
if fs.var_mı("dosya.txt") {
    variable Content = fs.oku_dosya("dosya.txt")
} else {
    print("Dosya bulunamadı")
}

// or try-catch kullan
dene {
    variable Content = fs.oku_dosya("dosya.txt")
} yakala hata {
    print("Hata: " + hata.mesaj)
}

R202: Erişim izni yok

// ÇÖZÜM
dene {
    fs.yaz_dosya("/root/dosya.txt", veri)
} yakala hata {
    print("İzin hatası: " + hata.mesaj)
}

🧪 Test Hataları

T001: Assert başarısız

import testing

test "toplama testi" {
    variable sonuç = topla(2, 2)
    testing.assert_eşit(sonuç, 5)  // HATA: 4 != 5
}

// ÇÖZÜM: Beklenen değeri düzelt
testing.assert_eşit(sonuç, 4)  // OK

💡 Hata Ayıklama İpuçları

Compiler Verbose Mode

BERK-lang compile --verbose program.berk
# Detaylı compile bilgisi

Debug Print

// variable değerlerini kontrol et
variable x = hesapla()
io.print("x değeri: " + x)

// Type kontrolü
io.print("Tip: " + type_of(x))

Stack Trace

dene {
    tehlikeli_fonksiyon()
} yakala hata {
    // Stack trace göster
    io.print(hata.stack_trace)
}

🔧 Yaygın Hatalar and Çözümleri

HataNedenÇözüm
Segmentation fault Geçersiz bellek erişimi Pointer kontrolü, bounds checking
Stack overflow Sonsuz recursion Base case ekle, iteration kullan
Deadlock Thread'ler birbirini bekliyor Lock sırası düzenle, timeout ekle
Memory leak Allocation'lar free edilmemiş Scope sonunda cleanup, RAII pattern
