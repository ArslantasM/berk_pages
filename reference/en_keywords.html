BERK Programlama Dili

Anahtar Kelimeler

BERK programlama dilinde kullanılan anahtar kelimeler and rezerve edilmiş sözcükler. BERK'in iki dilli (Türkçe/İngilizce) yapısı sayesinde her anahtar kelimenin hem Türkçe hem İngilizce karşılığı bulunur.

💡 Örnek Usage

// Türkçe syntax
function toplam(a: tam, b: tam) -> tam {
    if a > 0 and b > 0 {
        döndür a + b
    } else {
        döndür 0
    }
}

// İngilizce syntax (aynı kod)
fn sum(a: int, b: int) -> int {
    if a > 0 and b > 0 {
        return a + b
    } else {
        return 0
    }
}

// Karışık Usage da mümkün
variable sonuç = toplam(5, 10)
let result = sum(5, 10)

📝 Not

BERK'in benzersiz özelliği, aynı programda Türkçe and İngilizce anahtar kelimeleri serbestçe karıştırabilmenizdir. Bu, hem yerel hem uluslararası ekiplerin aynı kod tabanında çalışmasını kolaylaştırır.
