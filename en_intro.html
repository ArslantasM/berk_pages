BERK Programming Language

BERK Programming Language

BERK is the world's first truly bilingual systems programming language with dual syntax (Turkish/English), designed to be modern, safe, and high-performance. It provides productivity across 19 different target platforms (desktop, mobile, embedded, WebAssembly).

📖 Why the Name BERK?

Turkish Origin: "Strong, Robust, Solid"

The word BERK in pure Turkish means "strong, durable, robust, and solid". These qualities directly align with the language's technical goals: memory safety, type system correctness, powerful compiler architecture, and stable performance.

Arabic-Derived Meaning: "Lightning"

Another meaning found in Turkish is "lightning". This represents BERK's vision of speed, performance, and agility: LLVM-based fast compilation, C++ level performance, and optimized core architecture.

Combined Meaning

BERK combines both the Turkish-origin concept of robustness and the modern tech world's concepts of speed and agility to create a strong brand identity.

International Interpretation

BERK stands for Beyond-Efficient Runtime Kernel in the international context.

Installation

# 1. Download BERK-lang.exe
# 2. Copy to your preferred folder (e.g., C:\BERK)
# 3. Add to PATH:
$env:PATH += ";C:\BERK"

# Test it
BERK-lang --version

Quick Start

Option 1: Interactive REPL (Instant Testing)

# Start REPL
BERK-lang repl

# Write code and press Enter - runs instantly!
>>> print("Hello, BERK!")
Hello, BERK!

>>> variable x = 5 + 3
>>> print(x * 2)
16

Option 2: Compilation (Native Executable)

# Write your first program (hello.berk)
function main() -> integer
do
    print("Hello, BERK!")
    return 0
end

# Generate native code with LLVM
BERK-lang compile hello.berk -o hello.exe

# Run it (now standalone executable)
.\hello.exe

Option 3: JIT Execution (Compile + Run)

# Run directly (LLVM JIT in background)
BERK-lang run hello.berk

Other Platforms

Linux and macOS: Compilation from source required.

# Install Rust toolchain
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Compile BERK
git clone https://github.com/ArslantasM/berk
cd berk/berk-lang
cargo build --release --features llvm

🌟 What Makes BERK Special

🌍 World First: True Bilingual Syntax

For the first time in programming languages, you can write code with both Turkish and English keywords in the same compiler. This is not just translation, but a core feature of the language.

⚡ C/C++/Rust Level Performance

  • LLVM Backend: Native code generation with zero-cost abstractions
  • Benchmark Results: 98-100% performance parity with C++
  • Memory Efficiency: Manual control + safety guarantees
  • Optimization Levels: Aggressive optimization from O0 to O3

🧠 Rules-Based AI Approach

The compiler uses rules-based artificial intelligence techniques for:

  • Intelligent error detection and suggestions
  • Code optimization decisions
  • Type inference and analysis
  • Quality assurance through semantic analysis

🔬 Scientific Computing Libraries (stdlib v1.4)

18 modules, 600+ functions, 285 KB of code:

  • linalg: Matrix operations, LU/QR/Cholesky decomposition, eigenvalue
  • stats: Statistics, regression, hypothesis testing, distributions
  • optim: Gradient descent, BFGS, simulated annealing
  • NumPy/SciPy/Julia level scientific computing

🚀 19 Target Platforms

Cross-compilation support:

  • Desktop: Windows (x64/ARM), Linux (x64/ARM), macOS (Intel/Apple Silicon)
  • Embedded: ARM Cortex-M, RISC-V, AVR, ESP32
  • Mobile: Android (ARM/x86), iOS (ARM64)
  • WebAssembly: Browser and server
  • Cloud: AWS Lambda, Azure Functions compatible

📚 Extremely Easy Learning

  • Intuitive Syntax: Python's simplicity + Rust's power
  • Comprehensive Documentation: 70+ pages comprehensive guide
  • Clear Error Messages: With solution suggestions
  • Learning Curve: Become productive in 1-2 weeks

🔧 Embedded Systems Capability

  • Bare-metal programming support
  • RTOS integration (FreeRTOS, Zephyr)
  • Low-level hardware access
  • Interrupt handling and DMA support
  • Minimal runtime: 2-5 KB overhead

# BERK'u derle

cd berk/berk-lang

// merhaba.berk
