BERK Programming Language

Writing Your First Program

Let's start by writing a simple calculation program in BERK. In this example we'll take two numbers from the user and perform various mathematical operations.

Example: Calculator

Create a new file named calculate.berk:

// Bilingual syntax support - English keywords
function add(a: Number, b: Number) -> Number {
    return a + b
}

function subtract(a: Number, b: Number) -> Number {
    return a - b
}

function multiply(a: Number, b: Number) -> Number {
    return a * b
}

function divide(a: Number, b: Number) -> Result<Number, String> {
    if b == 0 {
        error return "Division by zero error!"
    }
    ok return a / b
}

// Main function
function main() {
    variable x = 10.0
    variable y = 3.0
    
    print("x = ", x)
    print("y = ", y)
    print("")
    
    print("Sum: ", add(x, y))
    print("Difference: ", subtract(x, y))
    print("Product: ", multiply(x, y))
    
    // Division with error handling
    variable result = divide(x, y)
    match result {
        Ok(value) => print("Quotient: ", value),
        Error(msg) => print("ERROR: ", msg)
    }
}

Turkish Syntax Version

BERK's advantage is bilingual syntax support. You can also write the same program with Turkish keywords:

işlev topla(a: Sayı, b: Sayı) -> Sayı {
    geri dön a + b
}

işlev böl(a: Sayı, b: Sayı) -> Sonuç<Sayı, Yazı> {
    eğer b == 0 {
        hata dön "Sıfıra bölme hatası!"
    }
    tamam dön a / b
}

işlev ana() {
    değişken x = 10.0
    değişken y = 3.0
    
    yazdır("Toplam: ", topla(x, y))
    
    değişken sonuç = böl(x, y)
    eşle sonuç {
        Tamam(değer) => yazdır("Sonuç: ", değer),
        Hata(mesaj) => yazdır("HATA: ", mesaj)
    }
}

Running the Program

# Run directly
berk run calculate.berk

# Build and run
berk build calculate.berk -o calculate.exe
./calculate.exe
